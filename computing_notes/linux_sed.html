Linux - sed

  • stream editor
  • sed SCRIPT INPUTFILE...
  • If you do not specify an INPUTFILE, sed uses standard input
  • By default, sed prints all input (exluding anything deleted)

Equivalent Commands

sed 's/hello/world/g' input.txt >output.txt
sed 's/hello/world/g' <input.txt >output.txt
cat input.txt | sed 's/hello/world/g' >output.txt
