Client Side JS - CSS

  • CSS allows you to specify style for your website. I.e. it allows you to specify fonts, colors, etc.
  • It is also very useful for client-side JS developers

Scripting Inline Styles

  • Allows you to alter the style attribute of individual document elements via the style property
  • Remember that the style attribute allows you to specify inline styles
  • inline styles have the highest specificity and therefore take precedence over other styles
  • The style property is an CSSStyleDeclaration object which represents all of the CSS properties specified by the style attribute
  • Because hyphens can cause problems with parsing, CSS style property names containing hyphens are referenced in JS via removing the hyphen and capitalizing the letter immediately following the hyphen
  • For example, the border-left property in CSS is referenced via style.borderLeft in JS
  • Similarly, when a CSS property name is a reserved word (e.g. float), it is prefixed with css with the following letter capitalized in JS.
  • For example, the CSS float property is referenced via style.cssFloat in JS 
    // where o is a HTML document element
// - all values are strings
o.style.fontSize = "12pt";
o.style.fontFamily = "sans-serif";
o.style.color = "red";
o.style.backgroundColor = "green";

Querying Computed Styles

  • Computed Styles take into account any styles applied to the given element (regardless if specified by inline, internal, or external style sheets)
  • You can obtain the computed style for a given element via getComputedStyle() method of the Window object.
  • It accepts 2 arguments. The 1st argument is the element. The 2nd argument is required but hardly ever used -- pass null
  • getComputedStyle() returns a CSSStyleDeclaration object -- because its computed, it's read-only 
    computedStyle = getComputedStyle(o, null);

Scripting CSS Classes

  • Script the value of HTML class attribute
  • Since class is JS reserved word, the HTML class attibute is available in JS via the className property
  • However, keep in mind that the class attribute can specify more than one class 
    // specify a class name
// - you can specify multiple class names - space delimited)
o.className = "important super-important ultra-super-important";

// does element o's class attribute contain the "important" classname
o.contains ("important")

// removes/inserts the "important" classname from o's class list
o.toggle("important")

// cross browser solution
if (! document.getElementById("MyElement").contains("important"))
{
    document.getElementById("MyElement") += " important";       // note the space before the class name
}

if (o.contains("important"))
{
    o.className = o.className.replace(/(?:^|\s)important(?!\S)/g , '' );
}


// HTML5 have support for clssList
document.getElementById("MyElement").classList.add("important");
document.getElementById("MyElement").classList.remove("important");

if (document.getElementById("MyElement").classList.contains("important"))
{
    document.getElementById("MyElement").classList.remove("important");
}
