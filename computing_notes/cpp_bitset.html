C++ bitset

  • Similar to an array of booleans
  • Optimized for space
  • Usually a bit per entry as opposed to a byte per entry (for a vector of bool)
  • Note that since bitset is implemented as a template, the size must be declared at compile time.
  • If you need a dynamic bitset, possible options include vector<bool> or maybe a vector of statically sized bitmaps 
#include <bitset>

template < typename size_t N>
class bitset;

Constructors

  • Default Constructor
    • Create a bitset with all values initialized to 0 
    bitset<16> set1;
std::cout << set1 << std::endl; // 0000000000000000
  • Integer Value
    • Create a bitset initialized with bits initialized via an integer 
    bitset<16> set2(9);
std::cout << set1 << std::endl; // 0000000000001001
  • String Value
    • Create a bitset initialized with bits initialized via binary string (string with '0''s and '1''s) 
    bitset<16> set3(std::string("0000000000000101");
std::cout << set3 << std::endl; // 0000000000000101

Member Functions

  • bool bitset::test(size_t pos) const
    • Return the value of the bit as the specified position - indexed from 0
    • Range checking is enforced. Will throw a out_of_range exception if pos is invalid
  • bool bitset::operator[]
  • bool& bitset::operator[]
    • Return the value (or a reference) of the bit as the specified position - indexed from 0
    • Caution - no range check is performed.
    • See also bitset::test()
  • bitset& bitset::reset()
  • bitset& bitset::reset(size_t pos)
    • reset all bits (or a single bit at the specified position pos) to zero
    • returns a reference to the bitset
  • size_t bitset::size() const
    • return number of bits in the bitset
  • size_t bitset::count() const
    • return number of bits enabled (value = 1)
  • bool bitset::any() const
    • returns bolean as to whether or not any bits are set (value = 1)
    • true = at least one bit is set
    • false otherwise
  • bool bitset::none() const
    • returns bolean as to whether or not any bits are set (value = 1)
    • true = no bits are set
    • false otherwise
  • bool bitset::all() const
    • returns bolean as to whether or not all bits are set (value = 1)
    • true = all bits are set
    • false otherwise
  • bitset& bitset::flip()
    • flip the value of all bits (or a single bit at specified position pos)
    • returns a reference to the bitset

Bitwise Operators

  • & bitwise and
  • | bitwise or
  • ^ bitwise xor
  • &= bitwise and with assignment
  • |= bitwise or with assignment
  • ^= bitwise xor with assignment
  • << left shift
  • >> right shift
  • <<= left shift with assignment 
    std::bitset<16> x(1);         // 0000000000000001
x <<= 1;                      // 0000000000000010

std::bitset<16> y("1000000000000000");        // 1000000000000000
y << 1;                                       // 0000000000000000
  • >>= right shift with assignment
