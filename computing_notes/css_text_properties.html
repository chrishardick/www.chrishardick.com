CSS - Text Properties

text-align

  • Horizontal alignment
  • Values: left, center, right, justify

    center center center center center
    right
    justify justify justify justify justify justify justify justify justify justify justify justify justify justify justify justify justify justify justify justify justify justify
  • Default value: html rendering agent specific
  • Applies to: block-level elements

line-height

  • Line height
  • Values: normal, <length>, <percentage>, <number>
  • Default value: normal

    25%

    50%

    100%

    200%

vertical-align

  • Vertical alignment (e.g. subscript, superscript)
  • Values: baseline, sub, super, top, text-top, middle, bottom, text-bottom, <length>, <percentage>
  • Default value: baseline
  • regular baseline
  • regular sub
  • regular super
  • regular top
  • regular text-top
  • regular middle
  • regular bottom
  • regular text-bottom
  • Applies to: inline elements and table cells

text-transform

  • Adjust capitalization
  • Values: none, uppercase, lowercase, capitalize
  • uppercase
  • lowercase
  • capitalize
  • Default value: none
  • Applies to: all elements

text-decoration

  • Text decoration
  • Values: none, underline, overline, line-through, blink
  • underline
  • overline
  • line-through
  • blink
  • Default value: none
  • Applies to: all elements

text-shadow

  • Adds shadow to text
  • text-shadow: h-shadow v-shadow blur-radius color
  • h-shadow - Required. Position of the horizontal shadow. Negative values are allowed
  • v-shadow - Required. Position of the vertical shadow. Negative values are allowed
  • blur-radius - Optional. Default value is 0.
  • color - Optional. The color of the shadow

    5px 10px 5px rgba(0,0,0,1.0)
