Linux - GDB

  • gdb is the GNU Debuger
  • Ensure you compiled with debugging information with -g. E.g. g++ -g foo.cpp -o foo

Installation

sudo apt-get install libc6-dbg dbg valgrind

Cheat Sheet

gdb foo
break 45        # break at line 45
break bar       # break at function bar
watch x != 0    # set a watchpoint. pause a program when a condition occurs
continue        # continue execution after being paused
delete N        # delete breakpoint N (breakpoints are numbered as they're created)
r               # run
r arg1 arg2     # run with arguments 
r < file     # 
l               # list
l 500           # list line 500
l bar           # list a function
next            # execcute the next line
step            # execute the next instruction, if it's a function, execute the 1st statement of the function and pause
finish          # finish executing the current function 
next            
print x         # print the current value of variable x
set x = 3       # set x equal to 3
display x       # constantly display the value of variable x. it will be shown after each step or pause
undisplay x     
bt              # backtrace - print the call stack
up              # move up the call stack
down            # move down the call stack
