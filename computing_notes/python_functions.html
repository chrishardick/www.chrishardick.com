Python: Functions

  • In Python, functions are defined with the keyword def, followed by the function name, followed by a list of optional parameters surrounded by paranthesis, followed by a colon (:)
  • The code block of the function must be indented
  • Functions must be defined before they are called. I.e. it is not legal to call a function which is defined later in the same source code
  • When calling a function, you can specify parameters either by name or by position
  • When defining a function, you can specify default values for the parameters
  • All objects passed into a function are passed by reference 
#
# function definition
#
def foo(x, y, z=None):
    print "foo: Hello, World"
    print "foo: x=" ,x
    print "foo: y=" ,y

    if z != None:
        print "foo: z=" ,z

    return x

#
# function call
#
foo (5, 10)

# same thing using parameter names (allows you to pass arguments in any order)
foo (y=10, x=5)

Function Parameters and Local Variables

  • A variable defined inside a function is local to that function
  • It is visible (i.e. its scope) is from the point at which it's defined to the end of the function
  • Parameters are similar to local variables
  • See also Python Variables

Pass by Value vs. Pass by Reference

  • Primative types are passed by value
  • Complex types (lists, dictionaries, objects, etc.) are passed by reference
  • Strings in Python are immutable. Although they are passed by reference, if you modify a string inside a function, you're creating a new string which the local variable will point to. This has the effect of behaving similar to pass by value.

Function Return Values

  • Functions can return values by using the return keyword
  • when a return statement is reached, control immediately exits the function
  • You can specify a return value after the return statement.
  • Functions can only return a single value - however it can be a list, tuple, or dictionary
  • By default (i.e. if you do not specify one), all functions return None

Default Parameter Values

  • Python does not support function overloading - i.e. for a given namespace, there can be only one function with a given name. If you define a second function with the same name, it will overrite the first function
  • Python does support default parameter values
  • A parameter with a default value is also called an optional parameter
  • Optional parameters must come after all required parameters
  • When calling a function, you must provide a value for all non-optional parameters. Not doing so will cause an exception to be raised. 
    # mname (middle name defaults to a blank string
def foo (fname, lname, mname=""):
    ...

Positional vs. Keyword (Named) Parameters

  • When calling a function which accepts input parameters, you can pass the parameters as positional parameters (i.e. passing the parameters in the order in which they were defined in the function definition) 
    foo ("chris", "hardick")
  • You can also pass the parameters via name i.e. (keyword parameters or named paramters) - in which case you can specify the parameters in any order 
    foo (lname="hardick", fname="chris")
  • For functions with multiple optional arguments, keyword parameters allow you to pass one optional parameter without passing another one - regardless of the order in which they were defined
  • You can also mix positional and keyword parameters, however the keyword parameters must come after any positional parameters

Variable Number of Parameters

*args

  • When defining a function, Python allows you to use * followed by a variable name, to accept a variable number of function parameters
  • By convention, the variable name is usually args. However, in reality, Python does not dictate the variable name 
#
# a function which accepts a variable number of arguments
# - remember, the name 'args' is only by convention. 
# - for instance, we could have used argv to make C/C++ programmers feel more comfortable
#
def myPrint (*args):
    for a in args:
        print (a)

myPrint("a", "b", "c")

# yields:
a
b
c

# here args will be the remaining arguments
def myAdd (a, *args)
    for arg in args:
        a += arg

    return a

# yields 18 (notice how 5 is not double counted)
print "sum=%d" % myAdd(5, 6, 7)

**kwargs

  • When defining a function, Python allows you to use ** followed by a variable name, to accept a variable number of named parameters
  • By convention, the variable name is usually kwargs. However, in reality, Python does not dictate the variable name
  • kwargs can be used inside the function as a dictionary of all named parameters which were not explicitly in the function definition 
# variable number of named parameters

def my_print (a, **kwargs):

    for k in kwargs:
        print ("%s: %s" % (k, kwargs[k]))
                   

my_print (a="a", b="b", c="c", d="d")

# yields: (notice how 'a' is not included)
c: c
b: b
d: d

Using *argsand **kwargs Together

  • When using both *args and **kwargs together, *args will contain all the undeclared position parameters and **kwargs will contain all the undeclared named parameters 
# an example using both *args and **kwargs
def foo(*args, **kwargs):
    print "args="
    for a in args:
        print a
    print ""

    print "kwargs="
    print k in kwargs:
        print "%s=%s" (k, kwargs[k])
    print ""


foo ('a', 'b', 'c', aa="aa", bb="bb", cc="cc")

# yields
args=
a
b
c

kwargs=
aa=aa
bb=bb
cc=cc
