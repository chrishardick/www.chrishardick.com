Bash: Order of Precedence

So now that we've talked about functions and scripts, if you have a function (which has been loaded into memory) and a script, both with the same name, how do you tell which one will execute?

The following list is in order of highest to lowest precedence:

  • alias - not covered, but here's the syntax: alias AliasName='AliasValue'. Basically, the alias name is a synonym for the alias value. This is extremely useful when you have long commands that you use frequently.
  • keywords - i.e. function, if, for, ...
  • functions
  • built-in commands; commands which are built into the shell (e.g. cd, type)
  • scripts & executable programs - for which the shell searches in the directories listed in the PATH variable

The built-in command 'type' when given the command as the first argument will tell you how bash would interpret the command.
