Python: unittest.mock

  • Python mock object library
  • A mock object substitutes and imitates a real object - usually within a testing environment in order to better control your tests
  • Mock objects also track their own usage which can be queried to ensure your code is behaving as expected 
import xyz

import unittest
from unittest import mock

class TestXyz
    with mock.patch ('xyz.subprocess') as mock_subprocess:
        mock_subprocess.check_output.return_value = b"blah"         # any call to subprocess.check_output from within module xyz will return b"blah"

        # code which executes your test
