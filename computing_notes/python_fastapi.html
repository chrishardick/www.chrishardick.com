Python: FastAPI

  • FastAPI is a modern, fast web framework for building web services
  • It usually runs on top of Uvicorn
  • FastAPI defines your API's logic, while Uvicorn listens for incoming requests and feeds them to FastAPI
  • It's built on the ASGI (Asynchronous Server Gateway) standard.
  • ASGI is the standard calling convention in Python that allows web servers (like Uvicorn) to communicate with asynchronous-capable web frameworks and applications (like FastAPI)
  • To install: pip install fastapi; pip install uvicorn 
# main.py

import uvicorn
from fastapi import FastAPI

app = FastAPI()

#==========
# root() 
# - handle "/" (root) requests - using a get operation
#==========
@app.get("/")
def root():
    return {"message": "Hello, World"}


#==========
# read_item()
# - handle "items/{item_id}" requests which take an optional query string q
#==========
@app.get("/items/{item_id}")
def read_item (item_id: int, q: str = None):
    return {"item_id": item_id, "q": q}


if __name__ == "__main__":
    uvicorn.run(app,host="0.0.0.0", port=8000)
  • python3 ./main.py
  • From your favorite web browser: http://127.0.0.1:8000 and http://127.0.0.1:8000/items/5?q=blah
  • This basic web service will handle HTTP requests for / and /items/{item_id}
  • The path /items/{item_id} has a path parameter - which should be an int and an optional str query parameter q
