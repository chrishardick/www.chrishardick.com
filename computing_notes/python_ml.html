    Arrays

    • A NumPy array is similar to a Python List.
    • The main difference is all elements of a NumPy array must be of the same type
    • Operations on a NumPy array are also usually much faster 
    import numpy

arr = numpy.array([1,2,3,4,5])

mat = numpy.array(
        [
            [1,2,3], 
            [4,5,6]
         ])

arr3 = numpy.array(
        [
            [
                [1,2,3], 
                [4,5,6]
            ], 
            [
                [1,2,3], 
                [4,5,6]
            ]
        ])

print (arr)

print (mat)
print (mat[0,1])    # 2

print (arr3)
print (arr3[0,1,2]) # 6

    Negative Indexes

    • Just like lists, negative indexes (arr[-1]) are supported

    Slices

    • Just like lists, slices are supported
    • [start:end]
    • where start is included, and end is not included
    • [start:end:step] is also supported
    • If you do not specify start, it defaults to 0. E.g. [:end]
    • If you do not specify end, it defaults to the length of the array. E.g. [3:]

    random

    • Generate a random integer from 0 - given value (inclusive)
    • You can also generate arrays of random numbers of variable dimensions 
    from nymby import random

# generate a random number from 0-100
x = random.randint(100)
print (x)

# generate a 1-D array containing 5 random integers from 0-100
y = random.randint(100, size=(5))
print (y)

# generate a 2-D array containing 3 rows, each with 10 elements
z = random.randint(100, size=(3,5))
print (z)
    • Generate a random float from 0 to 1
    • You can also generate arrays of random numbers of variable dimensions 
    from numpy import random

x = random.rand()
print (x)

# generate a 1-D array of random floats from 0 to 1
y = random.rand(5)
print (y)

# generate a 2-D array (3 rows, each with 5 columns) of random floats from 0 to 1
z = random.rand(3,5)
print (z)
    • choice() allows you to obtain a random number from an array
    • It takes an array as a parameter and randomly returns one of its values
    • Use the size parameter to generate an array of arbitray dimensions
    • Use the p parameter to specify probabilities for each value. The numbers should be floating point values between 0 and 1. The sum of all the probabilities specified should be 1. 
    x = random.choice([1,2,3,4])
print (x)

y = random.choicxe([1,2,3,4], size=(3,5))
print (y)

# probability: 1:50%, 2:30%, 3:10%, 4:10%
z = random.choicxe([1,2,3,4], p=[0.5, 0.3, 0.1, 0.1], size=(3,5))
print (y)
