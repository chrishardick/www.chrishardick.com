Machine Learning: Introduction

  • Machine Learning - a branch of Artificial Intelligence and Computer Science which focuses on the use of data and algorithms which can learn without being explicitly programmed and over time can improve their accuracy
  • ML is the process of training software (a model) to make useful predictions or generate content
  • Machine Learning is an important component of Data Science.
  • Data Science is the study of data - to extract meaningful insight

Applications

  • Recommendations. I.e. music, movies, etc.
  • Predictions - i.e. weather, stock market
  • Language processing - written and oral
  • Vision processing
  • Self driving cars

Features

  • Features are the attributes which describe the input data
  • The goal is to choose the most relevant features which are applicable to the job at hand (feature selection)

Model

  • The mathematical representation of the relationship between the input (features) and the output (predictions or decisions)
  • Models are trained using a training dataset and evaluated using a validation dataset

Types of ML Sytems

  • Supervised Learning
  • Unsupervised Learning
  • Reinforcement Learning
  • Generative AI

Supervised Learning

  • Supervised Learning is given data which contains the correct answer
  • Two of the most common use cases for supervised learning are regression and classification
  • A Regression model predicts a numeric value. E.g. the amount of rain expected
  • A Classification model predicts the likelihood that something belongs to a category

Unsupervised Learning

  • Unsupervised Learning is given data which does not contain the correct answers
  • It finds groupings within the data
  • Clustering is a commonly used unsupervised learning model which finds data points that produce natural demarcations

Reinforcement Learning

  • Reinforcement Learning is when the algorithm learns by receiving positive or negative feedback

Generative AI

  • Generative AI is a class of models which create content based on user input

Supervised Learning

  • Training a model on labeled data

Decision Tree

  • A non-parametric supervised learning algorithm
  • Non-parametric statistics refers to a statistical method in which the data is not required to fit in a normal distribution
  • Decision Trees are a hierarchical tree structure with a root node, branches, internal nodes and leaf nodes
  • Internal nodes are also known as decision nodes
  • Each internal node represents a test on an attribute and each branch represents the outcome of the test
  • Leaf nodes represent all the possible outcomes with the dataset.
  • Decision Trees employ a divide and conquor strategy by conducting a greedy search to identify the optimal split points within the tree
  • The process is repeated in a top-down recursive manner until all

Python Libraries

  • numpy - provides multi-dimensional array
  • pandas - data analysis. provides data frames (2d array)
  • MatPlotLib - 2d plotting library for creating graphs/plots
  • Scikit-Learn - ML library. Contains common algorithms. Neural networks, decision trees, etc.

Steps in ML Project

  1. Import data
  2. Clean data
  3. Split data into training/test sets
  4. Create a model
  5. Train the model
  6. Make predictions
  7. Evaluate and improve
