C++ Lambdas

  • Lambda Functions (closures) are useful for inline functions. I.e. a small amount of code that you're not going to re-use and is not worth naming
  • See also std::function
  • Requires C++ 11 
//
// NOTE: most of the time the return type is not specified
// - instead it is inferred from the function body

[capture clause] (parameters) -> return_type
{
    // function body
}

//
// simple example
//
auto func = []() { std::cout << "hello, world!" << std::endl; };
func(); // call the function

Variable Capture

TIP: Variable capture by value can be very useful with threads. For example when enqueuing to a thread pool, as the copies it creates can be freely accessed by the worker threads

  • [] - empty capture clause. do not capture any variables. A lambda with an empty capture clause can access only those variables which are local to it.
  • [&] - capture any referenced variable by reference. E.g. the lambda refers directly to the original variable in the surrounding scope rather than creating a copy of it
  • [=] - capture any referenced variable by value
  • [=] - capture any referenced variable by making a copy
  • [foo] - capture foo by making a copy. Do not copy anything else
  • [=, &;foo] - capture any referenced variable by making a copy. Capture foo by reference [&] -
