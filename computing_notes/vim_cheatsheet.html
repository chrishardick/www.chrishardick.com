Sample .vimrc

".vimrc
"vim initialization file
"comments denoted from quotation mark (") to end of line

"shut off vi compatible mode -- which some linux flavors enable
set nocp


"show line #'s
set number

"enable autoindentation; works off of the previous line
set autoindent

set expandtab
set tabstop=4

"syntax highlighting
syntax on

":PrettyPrintJSON
command! PrettyPrintJSON %!phython -m json.tool

"stop the beeping
set belloff=all


if has ("autocmd")

    " vim installation has autocmd

    " BufNewFile - editing a new (non-existent) file

    " .cpp
    autocmd BufNewFile *.cpp 0r ~/.vim/templates/template.cpp

    " CMakeLists.txt
    autocmd BufNewFile CMakeLists.txt 0r ~/.vim/templates/CMakeLists.txt
endif

Misc

  • Global .vimrc for all users 
    /etc/vim/vimrc
  • Convert a file from DOS to UNIX format 
    :set ff=unix
:w
  • Convert a file from UNIX to DOS format: 
    :set ff=dos
:w
  • Back Reference 
    1,$s/\(^.*$\)/\1 ..\/html_\1/
  • Clean up tabular data 
    %!column -t
  • Sort the file 
    %!sort

Skeleton Files

  • Skeleton or template files are useful to create a skeleton file for a given type. I.e. html, c++ source code 
if has ("autocmd")

    " vim installation has autocmd

    " BufNewFile - editing a new (non-existent) file

    " .html
    autocmd BufNewFile *.html 0r ~/.vim/templates/template.html
endif

Back References

  • You can group parts of the pattern expression by enclosing them with \( and \)
  • You can then refer to the parts inside the replacement pattern using their number \1 for the 1st pattern, \2 for the 2nd pattern, etc.
