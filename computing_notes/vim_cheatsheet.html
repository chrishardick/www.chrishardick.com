VIM

Sample .vimrc

".vimrc
"vim initialization file
"comments denoted from quotation mark (") to end of line

"shut off vi compatible mode -- which some linux flavors enable
set nocp


"show line #'s
set number

"enable autoindentation; works off of the previous line
set autoindent

set expandtab
set tabstop=4

"syntax highlighting
syntax on

UNIX/DOS

  • to convert a file from dos to unix format: 
    :set ff=unix
:w
  • to convert a file from unix to dos format: 
    :set ff=dos
:w
