CSS - HTML Element Types

  • Replaced elements are elements which are completely replaced by other content. An example of a replaced element is the img element.
  • Non-replaced elements are all the other elements. E.g. h1, h2, p, etc.
  • Block elements are elements in which a break is implicitly added before and after the element. Block level elements cannot have additional content to the left and right of the element. Examples include: h1, h2, p, and div. Div is a block level element in which browsers (and other html rendering engines) do not implicitly add any other style.
  • Inline elements do not implicitly add a break before and after the element. Examples include: strong, a, span. Span is an inline element in which browsers (and other html rendering engines) do not implicitly add any other style.
