C++ Exceptions

  • A method of handling runtime errors
  • Provides a standard mechanism for handling runtime errors
  • 3 new keywords: try, throw, and catch

I. try block

  • defines a region of code where an exception may be thrown
  • When an exception is thrown:
    1. Destructors are invoked for any automatic objects defined within the block
    2. Control goes to the catch block and the catch block is executed
    3. When The catch block completes, execution continues with the statement immediately following the catch block
  • If an exception is not thrown, the catch block is not executed
  • The throw statement throws an exception
  • The operand following the throw statement determines the exception type
  • If an exception is not caught by the function which generated the exception, it will be delivered to the calling function, and if not caught there, the calling function's caller, down the entire call stack until the exception is caught.
  • One of the benefits (and complexities) of using exceptions is that they can be handled high up in a given module
  • If the exception is never caught, the program will terminate by calling the registered terminate handler or abort() -- the default terminate handler -- see discussion below.

II. catch block

  • catch any exception of a given type
  • you must specify @ least 1 catch block for a try block
  • catch block must immediately follow the try block
  • a catch block will catch all exceptions (of the correct type) that occur anywhere in the immediately proceding try block--including any functions which are called from within the try block (and the functions which they call... etc.)
  • you can specify that a catch block should handle all exceptions (regardless of type) by placing an elipse within the parenthesis--rather than an explicit type. If you're going to use this catch block along with others, make sure this is the last one you define.

III. Nested try blocks

  • you may nest try blocks within one another
  • if an exception is thrown from within an inner try block which is not handled in a catch block immediately following the nested try block, the catch handlers for the outer try block will be searched.

IV. Code

#include <iostream.h>
#include <string>
#include <exception.h>
#include <stdlib.h>


struct foo_exception : public std::exception
{
        //  
        // throw()
        // - an exception specification
        // - allows you to specify a comma delimited list as to which
        //      exceptions the given function handles
        // - throw(int), throw(int, const char*), ...
        // - the absence of an exception specification means the funtion can throw any exception
        // - throw() meant that the function did not throw exceptions
        // - this was deprecated in c++11
        // - it could not be checked at compile time and was extra overhead at run time
        // - however, it seems throw() - i.e. specifying that the method does not throw exceptions - has remained 
        // - here, we're specifying what() does not throw exceptions
        //  

        virtual const char* what() const throw()
        {   
                return "foo_exception";
        }   
};


void foo ()
{
    std::cout << "foo: START" << std::endl;
    throw foo_exception();
    std::cout << "foo: END" << std::endl;
}

void my_terminate ()
{
    std::cout << "my_terminate has been called" << std::endl;
    abort();
}

int main (int argc, const char* argv[])
{
    //
    // a terminate handler is a function automatically called when exception
    // handling cannot continue -- usually becasue no catch handler is defined
    //
    // if you do not register a terminate handler, the default terminate handler is abort()
    //
    std::set_terminate(my_terminate);

    std::cout << "main: START" << std::endl;


    //  
    //  
    //  

    std::cout << "A CAUGHT EXCEPTION..." << std::endl;

    try 
    {   
            foo();
    }   
    catch (std::exception& e)
    {   
        std::cout << "CAUGHT STD EXCEPTION. WHAT=|" << e.what() << "|" << std::endl;
    }   
    catch (...)
    {   
        std::cout << "CAUGHT UNKNOWN EXCEPTION" << std::endl;
    }   


    //  
    //  
    //  

    std::cout << "AN UNCAUGHT EXCEPTION..." << std::endl;

    foo();


    std::cout << "main: END" << std::endl;    


    return 0;
}
