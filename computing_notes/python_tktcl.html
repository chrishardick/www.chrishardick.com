Python: Tk/Tcl

  • Tk/Tcl provides a platform independent windowing toolkit which is available via the tkinter package along with extension tkinter.tix and tkinter.ttk
  • tkinter is a thin object-oriented layer on top of Tcl/Tk
  • tkindter is a set of wrappers which implement the Tk widgets
