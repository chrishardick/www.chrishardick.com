Python: pip

  • Package Manager for Python Modules
  • pip is for Python 2
  • pip3 is for Python 3
  • By default, pip installs packages into a folder called site-packages
  • Depending upon how you invoke pip and your permissions, packages are either installed site-wide - e.g. /usr/lib/pythonX.X/site-packages or /usr/local/lib/pythonX.X/site-packages or user-level.
  • User level installs are generally installed to ~/.local/lib/pythonX.X/site-packages
  • You can force user level installs by specifying --user option
  • Run pip show <package-name> to find the location of a specific package or pip list -v to see where every package is installed 
Basic Usage:

pip install <package>
pip uninstall <package>
pip list                            # list all packages installed on the system

pip3 install <package>
pip3 uninstall <package>
pip3 list                            # list all packages installed on the system

Install pip

Debian

apt-get install python-pip
apt-get install python3-pip
