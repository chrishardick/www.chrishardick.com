Python: pip

  • Package Manager for Python Modules
  • pip is for Python 2
  • pip3 is for Python 3 
Basic Usage:

pip install <package>
pip uninstall <package>
pip list                            # list all packages installed on the system

pip3 install <package>
pip3 uninstall <package>
pip3 list                            # list all packages installed on the system

Install pip

Debian

apt-get install python-pip
apt-get install python3-pip
