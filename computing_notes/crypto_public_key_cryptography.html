Public-Key Cryptography

  • Public-Key Cryptography (asymetric cryptography) uses a pair of keys
  • public keys which can be widely disseminated
  • private keys which are known only by the owner
  • Effective security involving public-key cryptography requires keeping the private keys private
  • Public keys can be freely disseminated without compromising security

Message Encryption

  • A sender can encrypt a message using the receiver's public key
  • The encrypted message can decrypted using the receiver's private key
