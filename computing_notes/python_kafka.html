Python: kafka

  • kafka is a Python client for Apache Kafka

Install

  • pip3 install kafka-python

KafkaConsumer

import kafka

consumer = kafka.KafkaConsumer('foo_topic')

for msg in consumer:
    print (msg)

# join a consumer group
# - e.g. work queue design pattern, kafka will deliver the message to only one instance of the consumer group

import kafka

consumer = kafka.KafkaConsumer('foo_topic', group_id='foo_group')

for msg in consumer:
    print (msg)

KafkaProducer

  • KafkaProducer is a Kafka client which asynchronously publishes events to the Kafka cliuster
  • Thread safe. Sharing a single producer instance across multiple threads will generally be faster than having multiple instances
  • send() is asynchronous. 
import kafka

producer = kafka.KafkaProducer(bootstrap_servers='localhost:1234')
