CSS - Color and Background Properties

In CSS, colors can be specified via any of the 3 color specification types:

  • Named color. E.g. red
  • Hex value. E.g. #ff00ff
  • RGB value. E.g. rgb(0,0,255)

color Property

  • Foreground color
  • Values: color specification (see above)
  • Default value: html rendering agent dependent

background-color Property

  • background color
  • Values: transparent, color specification (see above)
  • Default value: transparent

    <p style="background-color: red">...</p>

    <p style="background-color: #00ff00">...</p>

    <p style="background-color: rgb(0,0,255)">...</p>

    background-image Property

    • Set backgound image
    • Values: none, <url>
    • Default value: none

    background-repeat Property

    • Background repeat
    • Values: no-repeat, repeat, repeat-x, repeat-y
    • Default value: no-repeat

    background-position Property

    • Control the placement of the background image
    • Values: left, center, right
    • Default value:
    • Applies to: block-level and replaced elements

    background-attachment Property

    • Values: scroll, fixed
    • Default value: scroll
