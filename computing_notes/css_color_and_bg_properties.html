CSS - Color and Background Properties

color

  • Foreground color
  • Values: <color>
  • Like all color properties, you can set this via either of the 3 color specification types:
  • named color
  • a hex value (e.g. #00ff00)
  • a rgb value (e.g. rgb (0,255,0))
  • red
  • #00ff00
  • rgb(0,0,255)
  • Default value: html rendering agent dependant

background-color

  • background color
  • Values: transparent, <color>
  • Default value: transparent

    red

    #00ff00

    rgb(0,0,255)

    background-image

    • Set backgound image
    • Values: none, <url>
    • Default value: none

    background-repeat

    • Background repeat
    • Values: no-repeat, repeat, repeat-x, repeat-y
    • Default value: no-repeat

    background-position

    • Control the placement of the background image
    • Values: left, center, right
    • Default value:
    • Applies to: block-level and replaced elements

    background-attachment

    • Values: scroll, fixed
    • Default value: scroll
