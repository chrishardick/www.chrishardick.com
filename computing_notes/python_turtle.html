  • A popular way to introduce programming to kids
  • Provides turtle graphic primatives, both object oriented and procedural
  • Uses tkinter - Tk Interface for the underlying graphics. Therefore it needs a version of Python with Tk support

Turtle class

Turtle Move and Draw Methods

  • forward(distance) - move turtle forward by the specified distance (integer or floating point) in the turtle's current direction
  • backward(distance) - move turtle backward by the specified distance (integer or floating point) in the turtle's current direction
  • right(angle) - move turtle right by angle units (default is degrees)
  • left(angle) - move turtle left by angle units (default is degrees)
  • setposition(x,y=None) - move turtle to an absolute position. If the pen is down, draw line
  • setx(x) - set turtle's x coordinate
  • sety(y) - set turtle's y coordinate
  • setheading(to_angle) - set the orientation of the turtle to the specified angle. 0 is East, 90 is North, 180 is West, 270 is South.
  • home() - move turtle to the origin (0,0) and set its heading to start-orientation which depends on mode()
  • circle(radius,extent=None,steps=None) - draw a circle with given radius. The center is radius units left of the turtle. Extent is an angle andn determines which part of the circle is drawn.
  • dot(size=None, *color) - draw a circular dot with specified size and color. If size is not given, the max of pensize+4 and 2*pensize is used.
  • stamp() - stamp a copy of turtle's shape onto the canvas at the current position. Returns a stamp_id which can be passed to clearstamp()
  • clearstamp(stampid) - delete the stamp with the given stampid
  • clearstamps(n=None) - delete all or the first/last turtle stamps. None = delete all stamps. n > 0 delete first n stamps; n < 0 delete last n stamps
  • undo() - undo turtle's last action. Number of available undo actions is determined by size of undobuffer
  • speed(speed=None) - speed - an integer in the range 0-10 or a speedstring ("fastest":0, "fast": 10, "normal": 6, "slow": 3, "slowest": 1). speed = 0 means no animation takes place
