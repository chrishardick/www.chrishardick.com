Swift - Enumerations

  • A cross between a enum and a union in C/C++.
    • Similar to C/C++, an enum is a type which allows you to group related values
    • Similar to a C/C++ union in that for each enum value, you can store associated values
  • Unlike C/C++, enums are not restricted to integers.
  • Each value can be a string, a character, an integer or a floating point number
  • You do not need to provide a value for each enum case
  • Enumerations can have initializers 
enum MyEnum
{
}

//
// each value (north, south, east, west) is a case
//
enum Direction
{
    case north
    case south
    case east
    case west
}

var direction = Direction.north

// once the variable bound to a type, you can omit the prefix
direction = .east

enum Planet
{
    case mercury, venus, earth, mars, jupiter, saturn, uranus, neptune
}

Iterating over Enum Choices: CaseIterable Protocol

  • If you're defining an enumeration in which you'd like to iterate through all of the enum cases, you can declare that the enumeration conforms to the CaseIterable protocol.
  • This is done by appending the following to the end of the enum name : CaseIterable 
enum Beverage: CaseIterable
{
    case coffee, tea, juice
}

//
// allCases property of an enumerated type 
// - gives you access to a collection which contains all of cases of the enumeration
//

for bev in Beverage.allCases
{
    print (bev)
}

let numBev = Beverage.allCases.count       

print (numBev)      // 3

Associated Values

  • Allows you to store values alongside case values
  • Similar to a C/C++ union
  • You can use a switch statement to determine which type is currently stored in the enum 
enum Barcode
{
    // Barcode.upc stores 4 integers
    case upc(Int, Int, Int, Int)

    // Barcode.qrCode stores a string
    case qrCode (String)
}

var product1 = Barcode.upc(1, 5000, 456, 962)
var product2 = Barcode.qrCode ("YSDKFSDJFKKS")

// assignment example
// - note that you can switch types
product1 = Barcode.qrCode ("BLAHBLAH")

switch barcode
{
    case .upc(let numberSystem, let manufacturer, let product, let check):
        print ("UPC: \(numberSystem), \(manufacturer), \(product), \(check).")
    case .qrCode(letProductCode):
        print ("QR Code: \(productCode).")
}

Raw Values

enum ASCIIControlCharacter: Character
{
    case tab = "\t"
    case lineFeed = "\n"
    case carriageReturn = "\r"
}
  • Each enumeration case can come prepopulated with default values which all must be of the same type
  • Each case must be mapped to a unique value within the enum and all values must be of the same type (Character, String, Integer or Floating Point type)
  • The raw values need to be assigned when the enum case is defined and cannot be changed

Implicitly Assigned Raw Values

  • Swift supports implicitly assigned raw values for enumerations with raw values of type integer and string
  • For enumerations with integer raw values, the implicit value is one more than the previous case. If the first case does not have a value set, its value is 0.
  • For enumerations with string raw values, the implicit value is a string set to the text of the case name 
// Implicit Raw Values - Integer 
// Planet.mercury=1, Planet.venus=2, Planet.earth=3, ...
enum Planet: Int
{
    case mercury = 1, venus, earth, mars, jupitor, saturn, uranus, neptune
}

let earthRawValue = Planet.earth.rawValue   // 3


// Implicit Raw Value - String
// Direction.north="north", Direction.south="south", ...
enum Direction: String
{
    case north, south, east, west
}

let californiaDirection = Direction.west.rawValuea      // "west"

Initializing from a Raw Value

enum Planet: Int
{
    case mercury = 1, venus, earth, mars, jupiter, saturn, uranus, neptune
}

// planet is of type Planet? and equals Planet.uranus
let planet = Planet(rawValue: 7) 

// however, since it's possible to specify a raw value which does not have an equivalent
// value in the enumeration, using a raw value initializer, always returns an optional enumeration type (e.g. Planet? or optional Planet).
// In other words, the raw value initizlier is a failable initializer


// planet is of type optional Planet (Planet?)
// since we passed in an invalid value, nil is returned
let planet = Planet(rawValue: 11)

if planet
{
    switch planet
    {
        case .earth:
            print ("EARTH")
        default:
            print ("NOT EARTH")
    }
}
else
{
    print ("NOT A VALID RAW VALUE") // this will print out
}
