Cryptographic Hash Funcions

A hash function which has properties which make it suitable to use in cryptography

  • Maps data of any size to a fixed size hash (digest)
  • As all hash functions, it must be deterministic
  • Should be quick to compute
  • Input data is typically called a message
  • Output data is typically called a hash or digest
  • Should be a one way function
  • I.e. Should be infeasible to invert without a brute-force search
  • A small change in input should result in a hash which appears uncorrelated to previous hash value
  • Should be infeasible for two different messages to generate the same hash values
  • Great for storing passwords!
  • Also useful for tinyurl implementations

MD5

  • Produces 128 bit (16 byte) digest
  • Insecure. Too many collisions

SHA-1

  • Produces 160 bit (20 byte) digest
  • Insecure. Too many collisions

SHA-2

  • Secure Hash Algorithm 2
  • Developed by US NSA (National Security Agency)
  • Contains 2 Algorithsm: SHA-256 and SHA-512

SHA-256

  • 32 byte (256 bit) hash

SHA-512

  • 64 byte (512 bit) hash
  • more secure than SHA-256 and usually faster on 64 bit machines
