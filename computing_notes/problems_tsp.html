Traveling Salesman Problem (TSP)

  • Famous NP Hard problem.
  • I believe NP Hard problems can be bounded by a polynomial expression (n^k)
  • Given a list of cities and the distance between each pair of cities
  • What is the shortest possible route that visits each city and return to the origin city
  • Given a set of vertices {1, 2, ... n}
  • Consider 1 as starting and ending point
  • For every other vertex i (2-n), find the minimum cost path with 1 as the starting point, i as the ending point and all vertices appearing exactly once. The cost of this path is cost(i)
  • The cost of the corresponding cycle is cost(i) + dist(i, 1) where dist(i, 1) is the distance from i to 1
  • Find the minimum of all cost(i) + dist(i, 1)
  • For all subsets of size 2, calculate C(S, i) where C is cost and S is the subset
