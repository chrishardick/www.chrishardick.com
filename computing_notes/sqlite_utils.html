SQLite: Utilities

Command Line Shell -- sqlite3

  • .tables - show tables
  • .schema - show table schemas
  • .header on - display column headers
  • .mode column - display output as columns
  • .help - display all options
  • CTRL-D to exit
  • To start: 
    sqlite3 dbname
  • Easy way to get data dictionary 
    echo ".tables" | sqlite3 dbname >dbname.tables
echo ".schema" | sqlite3 dbname >dbname.schema

Importing Data

sqlite dbname
.mode csv               # interpret input file as csv
.import file table      # insert data into table (table will be created if it does not exist)

.schema                 # to verify
select * from table;    # to verify
