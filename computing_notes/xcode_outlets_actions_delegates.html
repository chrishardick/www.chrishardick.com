Xcode - Outlets, Actions and Delegates

  • An Outlet links a Storyboard Object to a variable in your source code.
  • An Action links an event in an app to a method in your source code. When the action occurs, the method will be called
  • A Delegate is an object in your source code which receives a message (e.g. one of its methods is called) when an event in an app occurs.

View Controllers

  • Each screen in a storyboard typically has a its own View Controller
  • View Controllers implement your app's behavior
  • All View Controllers objects in iOS are of type of UIViewController
  • Xcode created a UIViewController sub-class for you named ViewController in ViewController.swift

Outlets and Actions

Outlets

  • Outlets provide a mechanism to link objects in your storyboard to variables in your source code
  • To create an outlet, Control-drag from an object in your storyboard to a view controller file
  • This creates a property for the object in your view controller file which allows you to access and manipulate the object from the source code

To Create an Outlet for a text field:

  • Click the assistant editor (icon with two overlapping circles). ViewController.swift should display in the editor
  • In ViewController.swift, find the class declaration line 
    class ViewController: UIViewController {
    and add the following comment on the subsequent line: 
    //MARK: Properties
  • In the storyboard, select the text field
  • Control-drag from the text field to the source code in the editor right below your added comment
  • In the dialog which appears, enter a name (under Name) and click 'Connect'
  • That should add the following code 
    @IBOutlet weak var yourTextFieldName: UITextField!
  • IBOutlet - Interface Builder Outlet
  • weak - the reference does not prevent the system from deallocating the referenced object. Weak references help prevent reference cycles
  • The explamation point at the end of the declaration indicates that the type is an implicitly wrapped optional - which means the system will assume it has a valid value and will automatically unwrap it for you. This will cause the app to terminate if the variable has not been set. Similar to a reference in C++

To Create an Outlet for a label

  • If necessary, click the assistant editor (icon with two overlapping circles). ViewController.swift should display in the editor
  • In the storyboard, select the label
  • Control-draw from the label to the editor on the right some place in the class ViewController definition
  • In the dialog which appears, enter labelName and click 'Connect'
  • The following code should be added: 
    @IBOutlet weak var labelName: UILabel!

Actions

  • An Action or Action method is code linked to an event in an app
  • When an event occurs, the system executes the action

To Create an Action

  • In ViewController.swift just above the last curly brace, add the following: (which indicates that this is the section of your code which lists actions) 
    //MARK: Actions
  • In the storyboard, select the UI Object
  • Control-drag from the object in the storyboard to the view controller file right below the newly added comment
  • In the dialog which appears, for Connection, select Action
  • For Name, enter an appropriate name
  • For Type, select the appropriate type
  • Click Connect and Xcode will add the Action Method 
    @IBAction func setFoo(_ sender: UIButton)   // the UI Object responsible for triggering the action
{
}
  • sender is the object responsible for triggering the action
  • IBAction attribute indicates that this method is an action which connects from your storyboard in the Interface Builder

Delegates

  • ObjectA can declare that ObjectB is a delegate of it.
  • This means that ObjectB will receive a message (i.e. one of it's methods will be called) when something happens
  • The delegating object keeps a reference to the delegate object and at the appropriate time, it sends a message to the delegate object
  • I.e. a text field can have delegate which takes an action when it receives input
  • Any object can serve as a delegate to another object as long as it confirms to the appropriate protocol.
  • The protocol that defines a text field's delegate is UITextFieldDelegate.
  • It's very common to make the view controller the delegate for objects which it manages
  • First, ViewController needs to adopt the UITextFieldDelegate protocol. You do this by adding it as part of the class declaraction line. In ViewController.swift, change the following: 
    class ViewController: UIViewController, UITextFieldDelegate {
  • By adopting the UITextFieldDelegate protocol, you tell the compiler that you implement the protocol's methods
  • You can now assign ViewController as a delegate of the text field. In ViewController.swift, find the viewDidLoad() method and add the following: 
    override func viewDidLoad()
{
    super.viewDidLoad()
    
    textField1.delegate = self
}
  • The UITextFieldDelegate protocol defines eight optional methods. You only need to implement the ones you need.
  • Let's implement the following two methods: 
    // called when the user presses Return or similar on the keyboard
func textFieldShouldReturn(_ textField: UITextField) -> Bool

// called after the text field resigns its first repsonder status
func textFieldDidEndEditing(_ textField: UITextField)
  • When a user taps on a text field, it automaticlly becomes the first responder
  • The first responder is the object which is first in line for receiving app events
  • As a result of the text field becoming the first responder, iOS displays the keyboard and begins an editing session for the field. Whatever the user types gets inserted into the text field
  • When the user is finished typing in the text field, the text field needs to resign its first responder status.
  • In ViewController.swift, right above //MARK: Actions, add the following: 
    //MARK: UITextFieldDelegate

// called when the user presses Return or similar on the keyboard
func textFieldShouldReturn(_ textField: UITextField -> Bool
{
    textField.resignFirstResponder()
    return true
}

func textFieldDidEndEditing(_ textField: UITextField)
{
    label1.txt = textField.text
}
