CSS - Layout

There are two primary types of layout for an element -- block-level and inline-level layout.

Block-level Layout

      | | |   padding (bg)   | | |
      | | | +--------------+ | | |
      | | | | content area | | | |
      | | | +--------------+ | | |

      +--------------------------+
  • A block-level box in CSS generates a rectangular box called the element box -- see diagram above.
  • padding defaults to 0 (zero)
  • border defaults to none
  • box-sizing
    • content-box (default value) - the width and height properties define only the width or height of the content area. Any padding, borders or margins are added to it.
    • border-box - the width and height properties define the width and height of the total width of the content, padding and borders.

    Inline Layout

    • an inline-level element generates one or more rectangular boxes called inline boxes -- depending on whether or not the inline element spans a single or multiple lines.
    • All inline elements have a line-height property
    • Line height of non-replaced items is the height of the content area (usually the font size) + leading
    • The height of the content area can be computed via the em-boxes of each character (i.e. the theoretical box around each character) or it's computed via the character glyphs (another measurement). CSS2.1 allows the user agent to choose which method to use.
    • leading -- the height difference between the font-size and the line-height. Half this difference is applied to the top of the content area and the other half is applied to the bottom of the content area. Leading is only applied to non-replaced elements.
    • For replaced elements, the content area is the height of the element + any margins, borders or padding.
    • For non-replaced inline boxes, the width and height properties do not apply
    • line box - the shortest box that bounds the highest and lowest point of the inline boxes which are found in the line.
