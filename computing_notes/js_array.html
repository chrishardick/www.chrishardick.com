JavaScript - Objects

  • In JavaScript, arrays are implemented as objects
  • Arrays are indexed from 0 (zero) 
    var nums = [ 1, 2, 3, 4];

nums.length;  // 4

var empty [];

nums[0] = 5;  // alter an existing value
nums[4] = 6;  // add a new value


// an array of objects
var obj_arr = [
    {x: 0, y: 0}
    ,{x: 0, y: 1}
    ];
  • Arrays may contain any data type (including references to other arrays, objects, or functions)
  • JavaScript is an untyped language, as such, elements of the same array can contain different types
  • Arrays can be created with the Array( ) constructor 
    var x = new Array();
x[0] = 1;
x[1] = true;
x[2] = 1.2;
x[3] = "Hello, World!";
  • If you only pass a single number to Array(), it's interpreted as the length of the array 
    var y = new Array(10); // an array with 10 undefined elements
  • To determine the number of elements the array contains, use the length property
  • Here is an example of looping thru the elements of an array 
    for (i=0;i<x.length;i++)
{
    // code which accesses x[i]
    ...
}
  • push() adds an item to the end of the array. Push returns the new array length. 
    var len = x.push("another item");     // equivalent to x[x.length] = "another item"
  • pop() removes the last item from an array -- returning the removed value 
    var y = x.pop();
  • The shift() method pops the 1st element of the array shifting all subsequent items to a lower index. It returns the element that was removed
  • The unshift() method adds a new element to the beginning of the array. It returns the new array size.
  • The delete() method removes the specified element from the array leaving an undefined item in its place.
  • The splice() method can be used to add items to an array. It accepts a variable number of parameters. The first is the position where the items should be added. The second defines how many elements should be removed. The remaining parameters define the new elements to be added.
  • The concat() method concatenates two arrays. It does not change the existing arrays. It returns a new array containing both sets of items 
    var items = existing_items.concat(new_items); // items will contain the elements from existing_items followed by the elements from new_items
  • The slice() method will create a new array from the specified elements of the exisitng array 
    var sp_items = existing_arr(1,5)
  • Since arrays are objects, the toString method will convert an array to a string of comma delimited values
  • The sort() method will sort the elements of an array (alphabetically by default). You can override this by providing your own compare function. The compare funcdtion should return a negative, zero or positive value depending if the lhs is less than, equal to, or greater than the rhs. 
    var values = [10, 5, 2,  6, 20];
values.sort(funcion(a,b){return a-b}


  • The reverse() method will reverse all the elements of the array
