JavaScript - Cookies

  • See also HTTP Cookies

Setting Cookies

  • You set cookies using the document.cookie property
  • document.cookie seems like a normal text string -- but it's not.
  • When you set document.cookie, it only affects the specified name
  • When you read document.cookie, you read back a list of all applicable cookies
  • name and value are the only required fields
  • If max-age is not specified, it is a transient cookie (expires when browser window is closed) 
document.cookie = "name=value; max-age=seconds; path=path; domain=domain; secure"

// examples

// creating a cookie
document.cookie = "menu_open=true"

// modifying a cookie
document.cookie = "menu_open=false"

// deleting a cookie
// document.cookie = "menu_open=; max-age=0"

Reading Cookies

  • the document.cookie property returns a string containing all the cookies that apply to the current documnt
  • it's a list in the form name=value pairs separated from each other by a semicolon and a space
  • use the string.split() method to break it into individual name=value pairs 
function get_cookies ()
{
    var ret = { }

    var all = document.cookie;  // all cookies. n1=v1; n2=v2; n3=v3; ...

    if (all === "")
    {
        return ret;
    }

    var list = all.split("; ");

    for (var i=0; i < list.length; i++)
    {
        var cookie = list[i];

        var p = cookie.indexOf("=");

        var n = cookie.substring(0,p);
        var v = cookie.substring(p+1);

        ret[n] = v;
    }

    return ret;
}
