C++ for Loops

C++ Range-based for Loops

  • Introduced in C++11 
for (datatype iterator : list)
    // ...
  • If you specify an actual data type (e.g. int) rather than a reference data type (e.g. int&) a copy will be made
  • auto can be used rather than the actual data type
  • auto& can be used rather than a reference data type 
std::vector<int> foo = { 1, 2, 3, 4, 5 };

std::cout << "original vector" << std::endl;

for (int& i : foo)
    std::cout << "i=" << i << std::endl;

std::cout << std::endl;


std::cout << "copy version - values in the vector will not be modified" << std::endl;

for (int i : foo)   // alternately: for (auto i : foo)
    i += 1;

for (int& i : foo)      
    std::cout << "i=" << i << std::endl;


std::cout << "reference version - values in the vector will be modified" << std::endl;

for (int& i : foo)   // alternately: for (auto& i : foo)
    i += 1;

for (int& i : foo)
    std::cout << "i=" << i << std::endl;
