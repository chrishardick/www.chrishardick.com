Xcode - Delegates

  • ObjectA can declare ObjectB as its delegate.
  • This means that ObjectB will receive a message (i.e. one of it's methods will be called) when something happens to ObjectA
  • I.e. a text field can have delegate which takes an action when it receives input
  • Any object can serve as a delegate to another object as long as it confirms to the appropriate protocol.
  • The protocol that defines a delegate for a text field is UITextFieldDelegate.
  • The delegating object keeps a reference to the delegate object and at the appropriate time, it sends a message to the delegate object.
  • A common pattern is to make the view controller the delegate for objects which it manages
