Github Markdown

  • Markdown is a lightweight markup language
  • Websites generally use a Markdown processor to convert Markdown to HTML
  • github uses its own Markdown processor
  • Markdown files generally have a .md extension
  • README.md is the most common example of Markdown found on github. It provides a great place for developers to document their projects.

Headers

  • # - h1
  • ## - h2
  • ...
  • ###### - h6

Unordered List

* Item 1
* Item 2
  * Item 2a
  * Item 2b

Ordered List

1. Item 1
1. Item 2

Text Formatting

  • _italic_ or *italic*
  • __bold__ or **bold**
  • ~~strikethrough~~

Hyperlinks

[link text](https://applicable.web.address)

Recommended Format

  • About
  • How to Build and Test
  • How to Submit a Pull Request
  • How to Deploy
