Python: pandas

  • pandas - a Python libary providing data structures designed to make working with relational or labeled data easy and intuitive
  • In pandas, a data table is called a DataFrame
  • pandas supports many different formats (csv, excel, json, sql, etc.)
  • Importing is provided by functions prefixed with read_
  • Exporting is provided by functions prefixed with to_
  • pandas supports filtering specific rows andor columns
  • pandas supports plotting your data using Matplotlib (you can pick the plot type - scatter, bar, boxplot, etc.)
  • You can easily add new columns to your data
  • You can easily calculate summary statistics on your data
  • You can easily reshape your data
  • You can easily combine data from multiple tables
  • You can easily handle time series

Features

  • Built-in support for missing data
  • Easy to insert or delete columns
  • group by functionality
  • Slicing and subsetting of large data sets
  • Data set merging
  • Data set reshaping and pivoting
  • Robust support for loading data from CSV files, Excel files, databases, etc.

Installing pandas

pip3 install pandas
