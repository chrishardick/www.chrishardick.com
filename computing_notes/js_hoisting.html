JavaScript - Hoisting

  • In JS, a variable or a function can be used before it has been declared
  • This is because JS implicitly moves declarations to the top of the current script or function
  • NOTE: Variables declared with let or const are not hoisted.
  • NOTE: Arrow Functions are not hoisted 
x = 5;

var x;

let

  • let is a new keyword in ES6. It declares a variable with block scope 
var x = 10;

console.log ("x = " + x);       // 10 

{
    let x = 2;                  

    console.log ("x = " + x);   // 2 
}

console.log ("x = " + x)        // 10

const

  • const is a new keyword in ES6. Use it to create immutable variables
  • const is similar to let in that it is block-scoped

Import and Export

  • Use import and export to create reusable components

Promises

  • Promises are new to ES6
  • Promises are a method to write asynchronous code

Classes

class Rectangle
{
    constructor(h,w)
    {
        this.h = h;
        this.w = w;
    }

    area()
    {
        return this.h*this.w;
    }
}

let rect = new Rectangle (5,10);
console.log ("Area = " + rect.area());

Arrow Functions

  • Arrow Functions are a short-hand syntax for writing functions.
  • It eliminates the function and return keywords and the curly brackets 
const mult = (x, y) => x * y

console.log ("x = " + mult(5,10))
