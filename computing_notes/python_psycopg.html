Python: psycopg (PostgreSQL adapter)

  • Accessing PostgreSQL via Python is typically done using the psycopg2 library or psycopg (Psycopg 3) for new projects.
  • It is the most popular PostgreSQL adapter for Python
  • It is a complete implementation of the Python DB API 2.0 specification 
# v3 example

import psycopg

with psycopg.connect("dbname=test user=postgres") as conn:

    with conn.cursor() as cur:

        cur.execute ("CREATE TABLE foo (id serial PRIMARY KEY, num integer, data text")

        cur.execute ("INSERT INTO foo (num, data) VALUES (%s, %s)", (100, "12345"))

        cur.execute ("SELECT * FROM foo")

        for rec in cur:
            print (rec)

        cur.executemany ("INSERT INTO foo (num) values (%s)", [(33,), (66,), (99,)])
        
        for rec in cur:
            print (rec)

    with conn.tranaction as tx:
        # inside a tranaction block, it is not possible to call commit() or rollback()

Connection class

  • The Connection class encapsulates a database session
  • It allows you to create Cursor instances using the cursor() method to execute database queries and commnds
  • It allows you to terminate transactions using the commit() and rollback() methods
  • Using this object as a Context Manager (using the with statement) will ensure connections are closed and resources are freed at the end of the block (available in v3 only)

Connection Methods

connect()

  • Create a new database session returning the new Connection instance.

close()

  • Close the database connection
  • Note - it's better to use the class as a Context Manager - in which case the connection will be closed when the block is exited.

cursor()

  • Create and return a new Cursor object

execute()

  • Execute a query and return a Cursor to its results

commit()

  • Commit any pending transaction to the datbase

rollback()

  • Rollback to the start of any pending transaction

transaction()

  • start a context block with a new transaction or nexted transaction

Connection Properties

  • closed - True if the connection is closed.
  • broken - True if the connection was interrupted. A broken connecdtion is always closed

Cursor class

  • The Cursor class allows interaction with the database
  • It allows you to send commands to the databsase using methods execute or executemany()
  • It allows you retrieve data from the database, iterating on the cursor or using methods such as fetchone(), fetchmany(), or fetchall()
  • Using this object as a Context Manager (with statement) will ensure the cursor is closed and resources are freed at the end of the block

    Cursor Methods

    close()

    • Close the cursor and free any associated resources.
    • Note - it's better to use the class as a Context Manager via with

    execute()

    • Execute the specified query
    • Pass parameters to a SQL statement using %s placeholders in the SQL statement and passing a sequence of values as the second argument
    • Returns the Cursor itself to allow you to chain operations 
      cur.execute("""
    INSERT into foo (bar1, bar_date, bar_timestamp) 
    VALUES (%s, %s, %s);
    """
    ,(10, datetime.date(2026,3,25), NOW())
    )

    executemany()

    • Execute the specified query with a sequence of input data

    fetchone()

    • Return the next record from the current result set returning either the Row or None

    fetchmany(size: int = 0) -> list[+Row]

    • Return the next size records from the current result set

    fetchall() -> list[+Row]

    • Return all remaining records from the current result set

    Cursor Properties

    • connection - the Connection object the cursor is currently using
    • closed - whether or not the cursor is closed.
