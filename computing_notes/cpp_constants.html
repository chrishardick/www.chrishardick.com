C++ Constants

Pointer-To-Constant

  • Prevents you from changing the data which is pointed to
  • const keyword comes before the datatype
  • You are allowed to change the pointer to something else 
int x = 5;
int y = 10;

const int* xx = &x; 

// compilation error - as we cannot change the contents of what is being pointed to
// *xx = y;

// ok - as we can change the pointer to point to something else
xx = &y;

Constant Pointers

  • Prevents you from changing the address stored in the pointer
  • const keyword comes after the datatype 
int x = 5;
int y = 10;

int* const yy = &y;

// compilation error - as we cannot change what we point to
// yy = &x;

// ok - as we can change the contents of what is being pointed to
*yy = x;

Constant Objects & Constant Member Functions

  • You can declare an object to be constant, just as you can any other data type. 
    const double PI = 3.14;                // a constant double precision floating point number
const CBox StdBox(3.0,8.0,10.0);       // a constant object
  • If you declare an object of a class to be constant (a constant object), the compiler will not allow any member functions to be called that might alter it. Therefore, if you wish to use any member function(s) on constant objects, they must be declared as constant member functions.

  • To declare a constant member function, place the keyword const after both the function prototype and the function header. Note that you can only declare class member functions as const; it's the only place in which it makes sense. Remember, its purpose is to denote that the object pointed to by the this pointer is constant. 
    // cbox.h

class CBox
{
     double m_dLength;
     double m_dWidth;
     double m_dHeight;

public:
     CBox() { m_dLength = m_dWidth = m_dHeight = 0.0; }
     CBox(double dLength, double dWidth, double dHeight) { m_dLength = dLength; m_dWidth = dWidth; m_dHeight = dHeight; }
     double Volume() const;
};


// cbox.cpp

// A Constant Member Function (constant this pointer)
double CBox::Volume() const
{
	return m_dLength * m_dWidth * m_dHeight;
}
  • A constant member function cannot call non-constant member functions (since they could potentially modify the object)
  • A function with a const modifier is a different function from one without, even though the name & parameters are exactly the same.
