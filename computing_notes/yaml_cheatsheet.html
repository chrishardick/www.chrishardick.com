YAML

  • A language for data serialization similar to JSON
  • Commonly used for configuration files and and data transmission
  • YAML 1.2 is a superset of JSON
  • YAML supports both
    • Python Style Indentation to indicate nesting
    • JSON format (uses [...] for lists, {...} for maps, etc.
  • File extensions: .yaml or .yml
  • Support for reading and writing YAML is available for many programming languages
  • See also JSON

Python Style Indentation

# map example
john:
    name: John Smith
    addr1: 1313 Mockingbird Lane
    addr2: 
    city: Hollywood
    state: CA
    zip: 90038

# list examples
# - members of a list are lines which begin at the same indentation level and start with "- " (dash followed by a space)

# simple list
- NY
- NJ
- CT

- john:
    name: John Smith
    addr1: 1313 Mockingbird Lane
    addr2: 
    city: Hollywood
    state: CA
    zip: 90038
- jane:
    name: Jane Jones
    addr1: 1919 Outerspace Court
    addr2: 
    city: Hollywood
    state: CA
    zip: 90038

JSON Style Indentation

# map example
john: { 
        name: John Smith
        ,addr1: 1313 Mockingbird Lane
        ,addr2: 
        ,city: Hollywood
        ,state: CA
        ,zip: 90038
      }

# list examples

# simple list
["NY","NJ","CT"]

# list of maps
[
    john:
    {
        name: John Smith
        ,addr1: 1313 Mockingbird Lane
        ,addr2: 
        ,city: Hollywood
        ,state: CA
        ,zip: 90038
    }
    ,jane:
    {
        name: Jane Jones
        ,addr1: 1919 Outerspace Court
        ,addr2: 
        ,city: Hollywood
        ,state: CA
        ,zip: 90038
    }
]
