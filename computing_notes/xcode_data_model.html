Xcode - Data Model

A data model represents the information stored in an app.

To create a new data model class:

  • File > New > File (or press Command-N)
  • Select iOS
  • Select Swift File
  • In the Save As field, enter a name, e.g. DataModel
  • This will create a file (e.g. DataModel.swift) which you should be able to see in the Project Navigator
  • In your new file, change import Foundation to import UIKit. UIKit also gives you access to Foundation.
  • In the file, you can now create your DataModel class 
class DataModel
{
    //MARK: Properties

    var name: String
    var num:  Int


    //MARK: Initialization

    //
    // a failable initializer
    //

    init?(name: String, num: Int)
    {
        if name.isEmpty || num < 0
        {
            return nil
        }

        self.name = name
        self.num  = num
    }
}
