Xcode - Data Model

To create a new data model class:

  • File > New > File (or press Command-N)
  • Select iOS
  • Select Swift File
  • In the Save As field, enter a name, e.g. DataModel
  • This will create a file called Foo.swift which you should be able to see in the Project Navigator
  • In your new file, change import Foundation to import UIKit. UIKit also gives you accss to Foundation.
