Python: String

  • Strings in Python are handled with str objects or strings.
  • Strings are immutable.
  • In Python 2, strings (by default) are ASCII byte strings
  • In Python 3, strings (by default) are Unicode encoded via UTF-8
  • Strings can be defined using either double or single quotes 
    s1 = "Hello, World!"
s2 = 'hello, world!'
  • String literals can also be defined using triple quotes - which make it easier to define multi-line string literals (newlines will be included) 
    print '''line 1
line 2
line 3
line 4'''

    # equivalent
print 'line 1\nline 2\nline 3\nline4'
    both produce: 
    line 1
line 2
line 3
line 4
  • Use the built-in function len() to obtain the length of a string
    • s = "Hello, World!"
print len(s)            # 13
  • You can access individual characters of a string via indexing (square brackets). Like C/C++, indexing starts from 0 (zero) 
    print s[0] # H
  • You can use a for loop to traverse the characters of a string 
    for c in w:
    print c
  • Slicing
    • print s[0:5]    # Hello
print s[:5]     # equivalent
print s[7:13]   # World
print s[7:13]   # equivalent
  • Notice with slicing, the beginning character is included and the last character is excluded
  • Raw strings - treat backslashes as literals - rather than escape characters. Raw strings are prefixed with an 'r' 
    print r'c:\abc\def' # results in 'c:\abc\def'

str Objects

  • Python has a built-in class named str
  • str objects (aka strings)
  • Strings are immutable sequences of Unicode
  • String literals can be written as
      Single quotes: 'allows embedded "double" quotes'
        Double quotes: "allows embedded 'single' quotes"
          Triple quoted: """can span multiple lines""" or '''can span multiple lines'''
        • Strings can also be created from other objects using the str constructor

        str Methods

        • str.isdigit() - return true if all characters in the string are decimal characters. False otherwise. 
          s = "12345"
t = "1234a"
print s.isdigit()   # True
print t.isdigit()   # False
        • str.lower() - return a copy of the string with all uppercase characters converted to lowercase
        • static str.maketrans(x[, y[, z]]) - return a translation table for str.translate(). If there is only one argument, it must be a dictionary mapping input character to output character. If there are two arguments, they must be strings of equal length. E.g. maketrans("abc", "def") will change a's to d's, b's to e's, and c's to f's If there is a third argument, it must be a string, whose characters will be mapped to None in the result
        • str.replace (old, new [,max]) method - returns a copy of the string in which all occurrences of old have been replaced with new, optionally stopping after max replacements.
        • str.split(sep=None,maxsplit=-1) - split the string into a list of sub strings based on given delimiter (which defaults to whitespace if not specified). If maxsplit is specified, at most maxsplits are done. 
          s = "Today is too beautiful a day to be spent inside."
words = s.split() # results in ['Today', 'is', 'too', beautiful', 'a', 'day', 'to', 'be', 'spent', 'inside.']
        • str.translate (table[, deletechars]) method - returns a copy of the string translating characters as specified via the table (use maketrans() to construct the table). Optionally delete all chaters found in the string deletechars.
        • str.rstrip([chars]) - similar to perl chomp(). Returns a copy of the string with trailing characters removed. chars is optional (defaults to whitespace -- SPACE, TAB, NEW LINE (\n), LINE FEED, FORM FEED, CARRIAGE RETURN, etc. if not specified)
        • string.maketrans() method - takes 3 parameters. Each character in the 3rd argument is mapped to None.

        Byte String

        • Sequence of integers in the range of 0-255 which is displayed as ASCII by Python - albeit prefixed with a b
        • For example: b'Hello, World!'
        • The subprocess module returns byte strings for the output of commands
        • Use the following to convert from a byte string to a unicode string encoded with UTF-8 (Python 3 default) b'hello, world!'.decode("utf-8")

        Raw String

        • A Raw String is just like a string except that that escape characters are treated literally.
        • For example r'a\n' is interpreted as the character string a followed by \ followed by n
        • Whereas the string 'a\n' is interpreted as the character string a followed by a newline
