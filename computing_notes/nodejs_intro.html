Node.js - Introduction

  • Runtime JavaScript environment which executes JS outside of a browser
  • Built using Chrome's V8 JS Engine
  • Allows you to write server side JS
  • Uses an event drivern, non-blocking I/O model
  • Open Source
  • Cross Platform
  • Useful for building networking applications
  • https://nodejs.org

// hello_world.js

node hello_world.js



Event Loop


    

  • When Node.js starts, it initializes the event loop, processes the input script and begins processing the event loop

  • The event loop handles poll events, pending callbacks, etc.

  • Each event type (timer events, poll events, pending ballbacks, etc.) has its own FIFO.

  • Each event type is also called a phase

  • When a given FIFO has been exhausted or its callback limit has been reached, the event loop will move on to the next event type





Timers


    

  • This phase of the event loop executes callbacks scheduled by setTimeout() and setInterval()
