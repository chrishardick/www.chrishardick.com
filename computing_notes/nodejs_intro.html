require

  • require - a builtin function which allows you to include modules which are defined in a different file
  • require will read a JavaScript file, execute it and return the exports object

Simple Web Server

const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;

const server = http.createServer((req, res) =>
{
    res.statusCode = 200;
    res.setHeader('Content-Type', 'text/plain');
    res.end('Hello, World!\n');
});

server.listen(port, hostname, () => 
{
    console.log(`Server running at http://${hostname}:${port}/`);
});
  • Save the above as app.js
  • Run node app.js
  • Visit http://localhost:3000

Event Loop

  • When Node.js starts, it initializes the vent loop, procsses the input script and begins processing the event loop
  • The event loop handles poll events, pending callbacks, etc.
  • Each event type (timer events, poll events, pending ballbacks, etc.) has its own FIFO.
  • Each event type is also called a phase
  • When a given FIFO has been exhausted or its callback limit has been reached, the event loop wil move on to the next event type

Timers

  • this phase of the event loop executes callbacks scheduled by setTimeout() and setInterval()
