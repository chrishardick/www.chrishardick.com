HTML: SVG Images

  • Scalable Vector Graphics
  • SVG is written in XML

Rectangle

  • The rect element is used to draw a rectangle
  • x attribute - x coordinate for the left position of the rectangle
  • y attribute - y coordinate for the top position of the rectangle
  • height attribute - height of the rectangle
  • width attribute - width of the rectangle
  • style attribute - CSS style for the rectangle
  • style.fill defines the fill color
  • style.stroke-width defines the width of the border
  • style.stroke defines the color of the border

Circle

  • The circle element is used to create a circle
  • cx - x coordinate for the center of the circle (defaults to 0)
  • cy - y coordinate for the center of the circle (defaults to 0)
  • r - radius of the circle
