HTML: SVG Images

  • Scalable Vector Graphics
  • SVG is an XML based language which can be used to describe/draw 2D vector graphics.
  • It is an open standard
  • SVG images are scalable, zoomable
  • SVG drawings can be manipulated via the DOM interface
  • You can also render SVG files (a file containing SVG) using an <object> element e.g. <object data="foo.svg" type="image/xvg_xml"></object>

svg element

  • The <svg>...</svg> element is a container for SVG graphics
  • Top left corner is (0,0) and the bottom right is (maxX,maxY) - measured in pixels
  • Attributes:
  • height - the displayed height of the rectangular viewpoint specified as a length or percentage (number followed by %)
  • width - the displayed width of the rectangular viewpoint specified as a length or percentage (number followed by %)
  • x - the displayed x coordinate of the svg container
  • y - the displayed y coordinate of the svg container 
<svg width="100" height="100">
...
</svg>

Rectangle - rect element

  • The rect element is used to draw a rectangle
  • Attributes:
  • x - x coordinate for the top left position of the rectangle
  • y - y coordinate for the top left position of the rectangle
  • height - height of the rectangle
  • width - width of the rectangle
  • <rect x="20" y="50" height="50" width="50" fill="none" stroke="black"/>

Circle - circle element

  • The circle element is used to create a circle
  • Attributes:
  • cx - x coordinate for the center of the circle (defaults to 0)
  • cy - y coordinate for the center of the circle (defaults to 0)
  • r - radius of the circle
  • <circle cx="150" cy="100" r="50" fill="none" stroke="black"/>

Ellipse - ellipse element

  • The ellipse element is used to create a circle
  • Attributes:
  • cx - center x-axis coordinate. default=0
  • cy - center y-axis coordinate. default=0
  • rx - x radius of the ellipse. required
  • ry - y radius of the ellipse. required
  • <ellipse cx="275" cy="100" rx="50" ry="25"/> fill="none" stroke="black"

Line - line element

  • Attributes:
  • x1 - x position point 1
  • y1 - y position point 1
  • x2 - x position point 2
  • y2 - y position point 2
  • <line x1="225" y1="100" x2="225" y2="200" stroke="black"/>
  • <line x1="325" y1="100" x2="325" y2="200" stroke="black"/>

Polyline - polyline element

  • A polyline is a group of connected straight lines.
  • Attributes:
  • points - list of points - comma, space, line feed, etc. delimited. each point must contain two numbers (x and y)

Polygon - polygon element

  • A polygon is similar to a polyline except that it's closed. I.e. the last point connects wih the first point creating a closed shape
  • Attributes:
  • points - list of points - comma, space, line feed, etc. delimited. each point must contain two numbers (x and y)

Path

  • The most general shape in SVG.
  • Using the path element, you can draw rectangles, circles, ellipses polylines, and polygons

Path - Line Commands

  • M - move to
    • M x y
    • m dx dy
  • L - line to
    • draw a line from the current position to the specified position
    • L x y
    • l dx dy
  • H - horizontal line
  • V - vertical line
    • draw a horizontal or vertical line from the current position to the specified position
    • H x
    • h dx
    • V y
    • v dy
  • Z - close path
    • draw a straight line from the current position to the first point of the path
    • Z and z are equivalent
    • Z does not accept any parameters

Path - Curve Commands

  • a - arc
    • Draw an ellipse in which the starting position and the given x, y
    • A rx ry x-axis-rotation large-arc-flag sweep-flag x y
    • a rx ry x-axis-rotation large-arc-flag sweep-flag x y
    • rx x-radius
    • ry y-radius
    • x-axis rotation angle to rotate the ellipse around the x axis
    • large-arc-flag a=large arc, 0=small arc
    • sweep-flag which direction the arc is drawn. 1=clockwise, 0=counterclockwise
    • x
    • y

fill and stroke Attributes

  • The fill attribute sets the color inside the object. You can use the value none or transparent to not fill the object
  • The stroke attribute sets the color of the line drawn around the object
  • Colors can be specified via CSS Colors

stroke-width Attribute

  • The stroke-width attribute sets the width of the line

stroke-linecap Attribute

  • butt - closes the line with a straight edge
  • square - similar to butt, but extends the line half the length of the stroke-width
  • round - produces a rounded effect on the end of the line.

stroke-linejoin Attribute

  • The stroke-linejoin attribute controls how the join between two line segments is ddawn
  • miter - a right angle
  • round - a right angle which is rounded
  • bevel - a right angle in which the tip is cut off

stroke-dasharray Attribute

  • The stroke-dasharray attribute is used to create a dashed line
  • It takes a series of numbers as its value (either space or comma delimited)
  • 1st number - distance the filled area
  • 2nd number - distance between the filled areas
  • e.g. stroke-dasharray 5 5 - would produce a dashed line of 5 pixels followed by an blank space of 5 pixels, ...
  • You can specify more numbers to indicate a more complicated dash pattern

paint-order Attribute

  • The paint-order attribute controls the order in which the fill and stroke are painted
  • Specifying fill will cause the fill (inside color) to be drawn first
  • Specifying stroke will cause the stroke (line) to be drawn first

Using CSS

  • E.g. inline CSS <rect x="10" y="10" height="100" width="100" style="stroke: black; fill: yellow;"/>
