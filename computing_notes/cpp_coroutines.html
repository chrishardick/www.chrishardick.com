C++ Coroutines

  • A coroutine is a function that can suspend execution and be resumed later
  • co_await<expr> - if expr has a result value, its value is extraceted and the function continues as normal. If it does not have a result, the current function is suspended.
  • The coroutine attaches itself to expr such that once it does have a value, it should resume the coroutine's execution with the value
