HTML Canvas

  • The HTML Canvas element allows you draw graphics (rectangles, circles, paths, lines, text, images, etc.)
  • The canvas element is a container for your graphics. You must use a script (i.e. JS) to actually draw the graphics
  • The resultant image is a raster graphic (i.e. a bitmap).
  • Once your elements are drawn, they can no longer be manipulated because they cease to be elements 
// supported instructions
rect x y width height
fillRect x y width height
clearRect x y width height
line x1 y1 x2 y2
text x y text
clear
