MySQL / MariaDB: Data Types

Numeric Data Types

SIGNED, UNSIGNED, ZEROFILL

  • SIGNED - default.
  • UNSIGNED
  • ZEROFILL

Here is a table of frequently used numeric data types:

Data Type Description
TINYINT 1 byte integer. Signed by default. Signed range: -128 to 127. Unsigned range: 0 to 255
BOOL, BOOLEAN Synonyms for TINYINT. Values - true, false. A value of zero is considered false. Non-zero values are considered true.
SMALLINT 2 byte integer. Signed by default. Signed range: -32,768 to 32,767. Unsigned range: 0 to 65,535
INT, INTEGER 8 byte integer. Signed by default. Signed range: -2,147,483,648 to 2,147,483,647. Unsigned range: 0 to 4,294,967,295
DECIMAL[(M[,D])], DEC, NUMERIC, FIXED a decimal floating point number. M is the total number of digits (precision) and D is the number of digits after the decimal point (scale). M defaults to 10 and D defaults to 0 (no decimal places). e.g. 1234.567 - M=7 and D=3. Precision and scale are optional.
DOUBLE[(M,D)], REAL a double precision (8 byte) floating point number. M is the total number of digits (precision) and D is the number of digits after the decimal point (scale). If M and D are omitted, they default to the limits allowed by the hardware. Double precision floating point numbers are accurate until 15 significant digits

AUTO_INCREMENT attribute

  • Used to generate unique values per row.
  • When you insert a new record into a table and the auto_increment field is NULL, the value will automatically computed.
  • AUTO_INCREMENT columns start from 1 by default.
  • Each table can have only one AUTO_INCREMENT column and it must be defined as part of a key. If part of a multi-column key, it must be the first column.

String Data Types

Here is a table of frequently used string data types:

Data Type Description
CHAR(n) Fixed length, right space padded character field. n defaults to 1. n range: 0 to 255. CHAR(0) can only store 2 values NULL and an empty string.
VARCHAR(n) Variable length character field (not space padded) where n is the maximum column length. n range: 0 to 65,535. 65,535 is actually the maximum row size in bytes. Hence the effective maximum length of a VARCHAR might be less than 65,535 -- for example UTF8 characters can take up to 3 bytes per character. VARCHAR columns can be indexed as opposed to TEXT fields
TEXT(n) Variable length character field. Maximum size is 65,535 characters. Cannot be indexed

Date and Time Data Types

Here is a table of frequently used string date and time types:

Data Type Description
DATE Stores date values only. Use yyyy-mm-dd format.
TIME Stores time values only. Use hh:mm:ss.mmmmmm format.
DATETIME Stores date/time values. Use yyyy-mm-dd hh:mm:ss.mmmmmm format.
TIMESTAMP (microsecond precision) Used to define a field which is automatically stores the current timestamp when a record was added or updated. If a record has multiple timestamp fields, only the first TIMESTAMP field will be automatically updated. Format: yyyy-mm-dd hh:mm:ss.mmmmmm. The microsecond resolution can be from 0-6 -- 0 (no microseconds) is the default. Values are stored in UTC (although displayed in current time zone) DEFAULT CURRENT_TIMESTAMP and ON UPDATE CURRENT_TIMESTAMP are by default applied to a timestamp field and enable the default behavior
