Databases: SQL Subqueries

  • A subquery (or inner query) is a SQL query nested inside a larger query
  • The inner query is executed before its parent query such that the results can be passed to the outer query
  • subqueries must be enclosed in parentheses

Here is an example:

student table
IDName
1 "AA"
2 "BB"
3 "CC"
4 "DD"
final_exam_grades table
student_IDscore
1 90
2 81
3 74
4 80

Build a query which will yield all student names who did better than student DD

SELECT student.Name 
FROM student,final_exam_grades 
WHERE student.ID = final_exam_grades.student_ID AND final_exam_grades.score > 
(SELECT score FROM student,final_exam_grades 
    WHERE student.ID = final_exam_grades.student_ID AND Name = "DD")
