Redis

  • In memory key-value store
  • Distributed cache
  • Written in ANSI C
  • REmote DIctionary Server
  • Useful when data can be cached (i.e. is essentially static for a period of time) and obtaining or calculating it is expensive (takes a while, etc.)
  • Redis keys are strings

1 Active, N Replicants

  • Typical configuration
  • Data is eventually consistient
  • If an instance fails and is restored, it will catch up
  • Data is asychronously replicated across many machines
  • Data is eventually consistient
  • Data written to active node may be read from any istance after sync
  • Capacity is limited to what can be stored on a single machine
  • Writes may be lost
  • Scalable read throughput, limited write throughput
  • Reads can have datacenter affinity, writes do not
