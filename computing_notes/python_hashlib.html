Python: hashlib

  • Secure hash library
  • Supports multiple secure hash algorithms including:
    • MD5 (insecure)
    • SHA1 (insecure)
    • SHA256 (secure)
    • SHA512 (more secure and generally faster on 64 bit machines)
  • Very useful for passwords
  • See also Cryptographic Hash Functions 
import hashlib

m = hashlib.md5()
m.update ("Hello, World!")
m.update (" It's me, Chris!")       # multiple calls to update will concatenate
d = m.digest()                      # the output to a hash function is called a digest

#
# all the secure hash functions work similarly
# - they just have a different constructor
