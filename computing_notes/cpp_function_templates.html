C++ Function Templates

  • Function templates allow you to parameterize the arguments or return type of a function
  • Function templates are an appropriate choice when you find yourself creating a lot of functions which are identical except they deal with different types (i.e. int, float, double, user-defined types)
  • Another solution is to use Function Overloading, which allows you to have multiple definitions of the same function name which differ only in their parameter list. However, you'd still have to physically code each function.
  • Introduces 2 new C++ keywords: template & typename
  • See also Class Templates which allow you to parameterize class data members


Defining Function Templates

  • Function templates are normally defined within header files, such that they can be used by multiple source files
  • Here's an example of a function template Max( )
  • The keyword class can be substituted for the keyword typename with no change in meaning (see below) 
    template <typename T>              // same as: template <class T> 
const T& Max (const T& T1,
              const T& T2)
{
     if (T1 > T2)
          return T1;

     return T2;
}
  • Within function templates, a typename (e.g. 'T' in the example) may be used to declare new objects 
    template <typename T> 
T Max (T T1,
       T T2)
{
     T T3;

     if (T1 > T2)
          T3 = T1;
     else
          T3 = T2;

     return T3;
}
  • Here's an example of a function template which has more than one parameterized type 
    template <typename T T1, U U1>
const T& Max (const T& T1,
              const U& U1)
{
    ...
}


Function Template Instantiation

                         +-------------------+
                         | function template |
                         +-------------------+
                               |      |
                  +------------+      +----------+  function template instantiation
                  |                              |  (compile time)
                 \ /                            \ /
             +-----------------------+    +-----------------------+
             | fxn template instance |    | fxn template instance |
             +-----------------------+    +-----------------------+
  • Each time you call a function--which is defined as a template--the compiler will check to see if it has already instantiated the appropriate function.
  • If the function has already been instantiated, the existing instance is used
  • If the appropriate function has not already been instantiated, the function instance will be generated (corresponding to the types you specified)
  • you can explicitly state the particular instance to be called by specifying the type after the function within angled brackets (see below)
  • you can force the creation of particular instance(s) of a template by explicitly including a declaration after the template definition (see below)
  • Function Template Specializations allows the programmer to explicitly define a function template instance. This is useful when the implicit instance would not give the desired result (see below)
  • Function templates may increase the size of your executable by creating new function template instances when existing instances have worked just fine (e.g. double to float)
  • Compiler/Linker Note: If multiple source files use the same function template instance, they'll each have their own copy of the instance. The linker normally will remove these redundancies at link time. 
    /*
 * max.h
 * - templates usually go inside header files such that they can be used by multiple source file(s)
 */


/*
 * function template
 */
template <typename T>
const T& max (const T& T1, 
              const T& T2)
{
     if (T1 > T2)
          return T1;

     return T2;
}

/*
 * explicitly force an instantation
 */
const double& max (const double& d1,
                   const double& d2);


/*
 * function template specialization
 * - function template specializations are useful when the implicit instantiation
 *   (done by the compiler) would not have worked as intended
 * - function template specializations are implemented as actual functions. 
 *   therefore if they're defined in a header file, they must be inline
 * - p.s. I see no reason why this is any advantage over using a ordinary inline function
 */

/*
 * function template specialization
 * - c strings
 */
template <>
char const* const& Max (char const* const& sz1,
                        char const* const& sz2)
{
     if (strcmp(sz1,sz2) > 0)
          // sz1 > sz2
          return sz1;

     return sz2;
}




int main (int argc, char** argv)
{
        max (1L,2L);              // compiler will implicitly generate max<long>
        max (1,2);                // compiler will call function template specialization max<int>
        max (2L,3L);              // compiler will use (already instantiated) max<long>
        max<int>(1.0,2.0);        // explicitly state which instance is used (max<int>) - parameter will be typecast to appropriate type

        return 0;
}
