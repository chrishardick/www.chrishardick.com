Xcode - Add View Controller

Add a New View Controller to the Storyboard

  • Open your storyboard - Main.storyboard
  • In the Object Library, type 'view controller' in the filter field
  • Drag a View Controller object onto the canvas.
  • If you'd like to move the View Controller on the canvas, you can click and drag the rectangle above it.

Add a New Swift File for the New View Controller

  • When you create a new app, the default View Contoller automatically comes with a linked Swift file
  • When you add an additional View Controller, you need to manually add and link a new Swift file
  • File > New > File and choose Cocoa Touch Class as the template for your new file and give it a name. I.e. SecondViewController, TableViewController, etc. Ensure to choose UIViewController as the Subclass and your new file should be created.
  • Go back to the Storyboard, and click on the little button on the top left of the new View Controller. Open up the Identity Inspector and in the Class field, enter the name of your newly created Swift file.
  • The View Controller object is now linked to the Swift file.

Add a Seques to link the View Controllers

  • Transitions between scenes are called segues
  • Click on the button on the top left of the View Controller we want to navigate from
  • Control-drag from the button to the other View Controller
  • In the pop-up which is displayed, choose Present Modally
  • Give the seque a name - such that you can refer to it within code. Click on the sqgue and bring up the Attributes Inspector. In the Identifier field, enter a name - e.g. settingsSegue, etc.

Create an Action

  • Recall that an Action links an Event to a Method
  • Open the Assistant Editor, by pressing the button with two circles on the top right (or Editor > Assistant)
  • Control-drag from the Button to its ViewController class, select Action in the Connection dropdown and give it a Name - e.g. onButtonClick and hit Connect
  • The Action Method should be created.
  • Now add the following to the function: 
    performSeque(withIdentifier: "YourSequeName", sender: self)
  • Run your app in the simulator and ensure it works as expected

Add Functional Button to New View Controller To Return

  • Add a button to your new View Controller
  • Control-drag from button to New View Controller class to create an Action. Give it an appropriate name (e.g. onFooButtonClick)
  • Add the following to the function: 
    // dismiss current View Controller
dismiss(animated: true, completion: nil)
