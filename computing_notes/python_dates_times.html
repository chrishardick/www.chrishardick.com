Python: Dates & Times

  • Python supports naive and aware date, time and datetime objects. The former do not have timezone information set, the latter does.

class datetime.datetime

  • Attributes:
    • year
    • month -- 1-12
    • day - 1 - # days in the month
    • hour - 0-23
    • minute - 0-59
    • second - 0-59
    • microsecond 0 - 999,999
    • tzinfo -- instance of tzinfo subclass
  • Constructors:
    • datetime.datetime(year,month,day[,hour[,minute[,second[,microsecond[,tzinfo]]]]])
    • datetime.today() - return datetime object loaded with current date/time with tzinfo equal to None
    • datetime.now(tz) - return datetime object with tzinfo info -- not covered
    • datetime.utcnow() - return datetime object loaded with current UTC date/time with tzinfo equal to None
    • datetime.fromtimestamp(timestamp,tz) - where timestamp is seconds since epoch - as returned from time.time(). If tz is None or not specified, the returned datetime will be in the platform's local date/time and the datetime is naive (tzinfo is not set)
    • datetime.utcfromtimestamp(timestamp) - where timestamp is seconds since epoch - as returned from time.time()
    • datetime.strptime(string,format string) - return datetime corresponding to string in specified format -- see format codes below
  • Methods:
    • strftime (format string) - return string representation of the date controlled by format string -- see format codes below

class datetime.timedelta

  • Constructor: datetime.timedelta([days[,seconds[,microseconds[,milliseconds[,minutes[,hours[,weeks]]]]]]])
  • Only days, seconds and microseconds are stored internally
  • Arguments may be integers or floats and may be positive or negative.

Examples

import datetime

today = datetime.today()

# initializing a datetime object with specified string
dt = datetime.datetime.strptime(str,"%W %Y/%m/%d %H:%M:%S")

# datetime to epochtime
epoch = (datetime.datetime.utcnow() - datetime.datetime(1970,1,1)).total_seconds()

# subtracting a timedelta
dt = datetime.utcnow() - datetime.timedelta(hours=1)

# subtracting 2 dateteimes results in a timedelta
dt1 = datetime.utcnow
dt2 = dt1 - datetime.timedelta(hours=1)

datetime.timedelta td = dt1-dt2

dt_lcl      = datetime.datetime.now()

pytz

  • localize() - used to localize a native datetime. The input is assumed to be a datetime object already in the given timezone. localize simply adds the timezoe information to it. 
    ny = pytz.timezone('America/New_York')
loc_dt = ny.localize(datetime(2017,05,10,17,55,0,0))
print loc_dt
output: 2017-05-10 17:55:00-04:00       # where -04:00 indicates that 4 hours behind gmt
  • astimezone() - convert a localized datetime into a localized datetime in another timezone 
    utc = pytz.utc
utc_td = utc.localize(datetime.datetime.utcnow())

ny_td = utc_dt.astimezone(ny)

# get next ny midnight - in utc

import datetime
import pytz

utc = pytz.utc
ny  = pytz.timezone('America/New_York')

# curr datetime - ny timezone
dt_ny = ny.localize(datetime.datetime.now())

# add a day
dt_ny = dt_ny + datetime.timedelta(days=1)

# adjust to midnight
dt_ny_midnight = dt_ny.replace (hour=0,minute=0,second=0,microsecond=0)

# convert to utc
dt_ny_midnight_utc = dt_ny_midnight.astimezone (utc)

print dt_ny
print 'next ny midnight:', dt_ny_midnight
