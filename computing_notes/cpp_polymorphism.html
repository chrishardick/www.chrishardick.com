C++ Polymorphism

  • Polymorphism (the ability to have many forms) is where different objects share the same external interface.
  • Much in the same way that both a tape player, a CD player, and a DVD player all have PLAY buttons.
  • In C++, polymorphism is supported via virtual functions and abstract base classes

Virtual Functions

  • C++ Keyword: virtual
  • When utilizing inheritance in C++, methods may be overridden (i.e. the derived class can define a function with the same name and parameter list)
  • Virtual functions differ from their non-virtual counterparts when a pointer (or reference) to an object is used to access the method.
  • Non-virtual functions have early (compile time) binding. I.e. the type of the pointer or reference determine which function is called
  • Virtual functions have late (run-time) binding. I.e. the type of the class in which the pointer points to determines which function is called
  • Keep in mind that this is a pointer.
  • Use of the virtual keyword is not mandatory in the derived class. If you override a virtual function, the function in the derived class is also virtual.
  • C++11 introduced the override keyword (technically it's an identifier - not a keyword). It allows you to let the compiler know that you are intending to override a virtual function in a base class. Therefore if you make a mistake and the derived class method does not exactly match that of the parent class, a compile time error will be generated.
  • Constructors cannot be virtual as it does not make much sense. Constructors are used to instantiate new objects
  • Destructors can (and probably should be) virtual. When an object referred to by a pointer or reference is destroyed, you want the class of the object pointed to (rather than the type of pointer), determining which destructor will be called. 
class Rect
{
    public:
        virtual void draw() const; 
};

void Rect::draw() const
{
        std::cout << "+=============+" << std::endl;
        std::cout << "|  RECTANGLE  |" << std::endl;
        std::cout << "+=============+" << std::endl;
}

class Sq : public Rect
{
    public:
        void draw() const override;
};

void Sq::draw() const
{
        std::cout << "+==========+" << std::endl;
        std::cout << "|          |" << std::endl;
        std::cout << "|  SQUARE  |" << std::endl;
        std::cout << "|          |" << std::endl;
        std::cout << "+==========+" << std::endl;
}


Rect    rect;
Sq      sq;

std::vector<Rect*> v;
v.push_back(&rect);
v.push_back(&sq);

for (auto i = v.begin(); i != v.end(); i++)
{
    (*i)->draw();
}

class Foo
{
    public:

        // noo is not virtual
        void noo ()
        {
            voo();
        }

        virtual void voo ()
        {
            std::cout << "Foo::voo" << std::endl;
        }
};

class Bar : public Foo
{
    public:
        void voo ()
        {
            std::cout << "Bar::voo" << std::endl;
        }
};

Abstract Base Classes

  • Abstract base classes are classes which can only be used for deriving other classes. They cannot be instantiated.
  • An abstract base class is a class with a pure virtual function
  • In a class derived from an abstract base class, each pure virtual function must either be defined or re-defined as pure virtual (in which case the class is another abstract base class which cannot be instantiated)
