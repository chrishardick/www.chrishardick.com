C: Bit Operations

  • C supports the manipulation of individual bits.
  • Bit Manipulation is useful to use a variable of an integer type (char, int, long, etc.), which is normally interpreted as an integer or a ASCII value, and instead, interpret it as a set of bits, in which each bit can be a flag indicating whether a condition is true or false (or on or off, etc.).

How Do You Determine If A Particular Bit Is On or Off?

First, some definitions:
Mask
To hide the value of a bit
Filter
To select the value of a bit; the opposite of masking
The basic idea is to create a mask which will hide (mask) all the bits you are not concerned with and filter out all the bits you are concerned with.

Now, some simple rules:

    Masking

  • ANDing any bit (a 0 or a 1) with a 0, always produces a 0 (the bit is masked)
  • ORing any bit (a 0 or a 1) with a 1, always produces a 1 (the bit is masked)

    • Filtering

  • ANDing any bit (a 0 or a 1) with a 1, always produces the bit (the bit is filtered)
  • ORing any bit (a 0 or a 1) with a 0, always produces the bit (the bit is filtered)
Now, lets look at an example that filters out a single bit (let's say bit 4 of a 1 byte integer). Just to avoid confusion, we'll say the right-most bit is the least significant and we'll start counting from 1 (instead of 0)
Variable (containing the flags):  10111101
Mask (to filter out bit 4):       00001000                    
------------------------------------------ 
Result (AND):                     00001000
Now, since the result is NOT 0, we know that bit 4 was ON (1 or TRUE).


Now, here's some C code which implements this frame of thought:

/******************************************************************************
**
**  IsBitActive
**
**  Parameters:          nBit	-->	The Bit to Check
**			lFlag	-->	The Variable Containing the Flags
**
**  Return Values:	-1	-->	Invalid Bit (negative or too large)
**			1	-->	Bit is Active (1)
**			0	-->	Bit is Not Active (0)
**
**  NOTES:              -Be Sure to Include MATH.H
**                      -In Linux, you must link with -lm (the math library)
**                      
**
******************************************************************************/
int IsBitActive (int nBit, long lFlag)
{
	long lMask;	

	/** Check Input Validity **/
	if (nBit > sizeof (long) * 8 - 1 || nBit < 0)
	{
		fprintf (stderr,"ERR: Invalid Bit %d Sent to IsBitActive\n",nBit);
		return -1;
	}

	/** If here, bit is valid **/

	/*
	 * Mask
	 * -all bits except the one in question will be set to 0
	 * -once we perform a BIT AND operation with the mask,
	 *  a value of 0    --> the indicated bit was off
	 *  any other value --> the indicated bit was on
	 *  
	 * REMEMBER: 	BIT AND with a 0 always results in a 0;
	 * 		while BIT AND with a 1, allows the bit
	 *		to "filter" through!
	 */
	 
	lMask = (long) pow(2.0,(double)nBit);
	lFlag = lFlag & lMask;

	if (lFlag == 0)
		return 0;
	else
		return 1;
}
