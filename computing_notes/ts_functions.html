TypeScript Functions

  • TypeScript allows you to add type annotations to each function parameter to declare the types in which the function accepts
  • Parameter type annotations go after the parameter name
  • When a parameter has a type annotations, arguments to that funcdtion will be checked
  • You can also specify return type annotations
  • TypeScript also verifies the number of parameters - regardless if you provide type annotations or not. 
function foo (name: string): string
{
    var str = "Hello, " + name;

    return str;
}
  • You can also specify if a parameter is optional 
function foo (bar?: string): string        // bar is an optional parameter
{
    ...
}
function foo (): string[]
