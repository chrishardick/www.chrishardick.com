Python: struct

  • Useful for handling binary data (stored in files and/or from network connections).
  • Format Strings are used as a schema

Functions

struct.pack(fmt, v1, v2, ...)
return a string containing the values v1, v2, ... packed according to the given format string. The values must match the types required by the format string
struct.unpack(fmt, string)
unpack the given string according to the given format string. return corresponding tuple (immutable list). The string must be valid according to the given format string.

Format Strings

  • By default, structs are stored in the machines native byte order (big endian/little endian) and alignment
  • However byte order, alignment and variable size can be overridden via the first character of the format string
    • @ - native byte order, alignment and variable size
    • = - native byte order, no alignment, standardized variable size
    • < - little endian, no alignment, standardized variable size
    • &rt; - big endian, no alignment, standardized variable size
    • ! - network (big endian), no alignment, standardized variable size -- equivalent to &rt;
    • If the 1st character is not one of the above, @ is assumed

Standard Sizes

  • character types (char, signed char, unsigned char) - 1 byte
  • short integer types (short, unsigned short) - 2 bytes
  • integer types (int, unsigned int, long, unsigned long) - 4 bytes
  • 64 bit integer types (long long, unsigned long long) - 8 bytes
  • float - 4 bytes
  • double - 8 bytes

Examples

import struct

struct.pack('hhl', 1, 2, 3)
'\x00\x01 \x00\x02 \x00\x00 \x00\x03'                       # spaces added for readability

struct.unpack('hhl', '\x00\x01 \x00\x02 \x00\x00 \x00\x03'  # spaces added for readability
(1, 2, 3)

struct.calcsize('hhl')
8
