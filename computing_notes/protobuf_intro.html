Protocol Buffers: Introduction

  • Protocol Buffers (protobuf) allows for platform agnostic serialization of structured data.
  • Forward and Backward compatibility supported
  • Support for many languages Built by www.google.com

Protocol Buffers Definition Syntax

  • Protocol Buffer Definitions are stored in .proto files

Protocol Buffer Compiler protoc

# to generate C++ classes

protoc -I=$PWD --cpp_out=$PWD $PWD/foo.proto

Extending a Protocol Buffer

  • You cannot change the tag number of any existing field
  • you cannot add or delete any required fields. required fields were only valid in proto2
  • you may delete optional ro repeated fields
  • you can add new optional or repeated fields provied you provide brand new tag numbers - tag numbers which were never used in this procol buffer.

Backward and Forward Compatibility

  • Old code can read new messages - ignoring any newly added fields
  • Fields which have been deleted will have default values
  • New code can read old messages - new fields will not be present
