Java: Introduction

  • Source Code > Byte Code > Executable
  • Java Development Kit (JDK)
  • Java Runtime Environment (JRE) - a subset of the JDK. It only contains the tools needed to run a Java application
  • Java classes must be in a file with the same name as the class name with a .java extension
  • By convention, Java class names begin with an uppercase letter
  • J2EE - Java Enterprise Edition - set of tools and libraries to create enterprise-class applications

Hello, World!

  • Create HelloWorld.java 
// HelloWorld.java

public class HelloWorld
{
    public static void main (String... args)
    {
        System.out.println("Hello, World!");
    }
}
  • javac HelloWorld.java
  • java HelloWorld
