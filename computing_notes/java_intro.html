Java: Introduction

Java Basics

  • Java is a true object oriented programming language in that every line of executable code must be inside a class
  • In Java, every class needs to be in a file whose name matches that of the class. E.g. class Foo must be defined in Foo.java
  • The java command is used to launch a Java application. It starts the JRE (Java Runtime Environment), loads the specified class and calls the class' main() method

javac - Java Compiler

  • Compiles Java source code (.java) into bytecode class files (.class)
  • Java classes must be in a file with the same name as the class name with a .java extension
  • By convention, Java class names begin with an uppercase letter

java - Java Launcher

  • The java command starts a Java application.
  • It starts the Java Runtime Environment (JRE), loads the specified class, and calls the class' main() method.
  • main() must be declared public (visible to everyone) and static (e.g. a method belonging to the class - as opposed to any particular object). It must not return any value, and it must accept a String array as a parameter. The method declaration has the following form: public static void main(String[] args) 
# classname 
java [options] classname [args]
java [options] -jar filename [args]

jar - Java Archive Tool

  • The Java Archive Tool (jar) is used to package a group of .class files into a single file for ease of deployment and execution
  • The result is a jar file (with a .jar extension) 
jar cf Foo.jar Foo.class Bar.class FooBar

Comments

  • Java supports both // and /* ... */ - similar to C++

Console Output

  • System.out.println("Hello World"); - prints the specified string followed by a newline
  • System.out.print("Hello World"); - prints the specified string (without a newline) 
// here is an example of printing variables

int i = 5;
String s = "Hello, World!";

System.out.println("i=" + i + " s=" + s);

JDK, OpenJDK, J2EE, Et. Al.

  • JDK (Java Development Kit) is a distribution of Java by Oracle Corporation. JDK normally refers to the Java SE (Standard Edition) Development Kit. There is also an Enterprise Edition (J2EE) and Micro Edition.
  • OpenJDK is a free and open source implementation of the JDK (SE)
  • Development Kits contain JRE - Java Runtime Environment (the environment needed to execute a Java application) along with tools useful to build Java applications

Installation - macOS

  • Download OpenJDK tar file from https://jdk.java.net/, etc.
  • Extract tar file tar -xvf tar_file or similar
  • Move contents of tar file to /Library/Java/JavaVirtualMachines/
  • Set-up Shell Environment. E.g. for Bash - 
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-23.0.2.jdk/Contents/Home
export PATH=$JAVA_HOME/bin:$PATH
