Java: LinkedList

  • Java's linked list implementation. It's implemented as a doubly linked list
  • Found in the java.util package

Adding Elements

  • add(E element) method will append an element to the list
  • add(int index, E element) method will add an element to the specified location
  • addAll(Collection<E> c) method will append all elements of the collection to the list in the order they are returned by the collection's iterator.
  • addAll(int index, Collection<E>) will add add elements of the collection to the list at the specified location.
  • addFirst(E e) inserts the element at the beginning of the list
  • addLast(E e) inserts the element at the end of the list

Accessing Elements

  • get(int index) method returns the element at the specified location
  • getFirst() returns the first element of the list
  • getLast() returns the last element of the list

Removing Elements

  • remove(int index) removes the element at the specified position in the list.
  • remove() or removeFirst() will remove the head (first element) of the list
  • removeLast will remove the last element of the list

Stack Methods

  • push(E e) will push an element to the head of the list
  • pop() will remove the element at the head of the list

Utility Methods

  • size() - will return size (number of elements) of the list
  • toArray() - will return an array containing all elements of the list in the proper order
  • toString() - will return a string of all elements of the list in the proper order. Each element is separated by commas. The entire string will be enclosed in square brackets 
import java.util.LinkedList;

LinkedList<Integer> int_list = new LinkedList<Integer>();

// assigning values
int_list.add(0);
int_list.add(1);
int_list.add(2);

System.out.println (int_list);          // [4,0,1,2,3]

for (int i = 0; i < int_list.size(); i++)
{
    System.out.println ("element " + i + " = " + int_list.get(i));
}

for (Integer i : int_list)
{
    System.out.println(i);
}
