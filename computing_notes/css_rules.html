CSS - Rules

  • Style sheets allow you to specify rules to describe the presentation of your documents
  • Each rule consists of a selector list and a declaration block 
    selector list { declaration list }

Selector Lists

  • Selectors allow you to specify which HTML element(s) a given style should be applied to
  • A selector list is a comma separated list of selectors

Element Selectors

  • Selects elements based on the element name 
    h1,h2 { color:red; font-size:12px; }
  • There are also Pseudo-element selectors.
  • Pseudo elements are elements not specified by the author of the page, but instead are added implicitly by the browser.
  • Common pseudo-element selectors include first-letter and first-line
  • Pseudo-elements are specified via ':first-letter'. For example, the following would apply to the first-letter of all paragraph elements 
    a:first-letter { font-size: 200%; }

id Selectors

  • Selects an element based upon the id attribute
  • The id of an element must be unique within a page.
  • To select based upon an id, the selector is a hash or pound sign (#) followed by the specific element id
  • id's cannot start with numbers
  • The following will select the element on the page with id="my_id" 
    #my_id { color: purple; }

<p id="my_id"> ... </p>
  • id names are case sensitive

Class Selectors

  • Selects elements based upon class attribute
  • To select based on class attribute, the selector is specified as a period followd by the class name
  • The following will select all elements with class="center" 
    .center { text-align: center; }
  • You can also restrict a class selector based on a given element type 
    p.center { color: green; }
  • HTML elements can belong to multiple classes 
    <h1 class="center important">
  • You can also restrict a class selector based on multiple classes 
    .class1.class2 
{
    /* styles to apply to elements with belonging to both class1 and class2 */
}
  • Class names cannot start with numbers
  • Class names are case sensitive
  • There are also Pseudo-Class Selectors. Pseudo-class selectors are classes not specified by the author of the page, but instead are added implicitly by the browser.
  • The most common pseudo class selector is visited. visited is a class added by the browser to a link which has already been visited.
  • pseudo-class selectors are specified using a colon (:) rather than a period 
    a:visited { color: red; }
  • Other pseudo-class selectors include:
    • :focus -- an element that currently has the input focus.
    • :hover -- an element in which the mouse pointer is currently hovering over
    • :active -- an element that has been activated by the use input

Descendant Selectors

  • Descendant selectors allow you to apply style to a document based upon the structure of the document.
  • For example, let's say you wanted to style <em> elements which were desendants of <ul> or <ol> elements
  • Descendant selectors are specified via a space delimited selector list.
  • The following would select based upon the example above 
    ul em, ol em { color: purple; }
  • Keep in mind that descendant (and ancestor) relationships are more generic than child (and parent) relationships and that descendant selectors apply to the more general ancestor/descendant relationship.

Declaration Block

  • Declarations are where you specify which style(s) should be applied to the elements matching the selector (or selector list)
  • Each declaration in the declaration list is of the form property:value;
  • A semi-colon (;) is always required. even if there is only a single declaration
  • If a value has a unit (e.g. 12px), do not put a space between the value and the unit
