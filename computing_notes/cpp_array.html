C++ array

  • Fixed size sequence container
  • Similar to in C, if you declare an array of built-in types without an explicit initializer list, its elements will have indeterminite (garbage) values
  • If you declare an array of objects, its elements will be default initialized. 
#include <array>

template < class T
            ,size_t N
            > class array;

#include <array>

std::array<int, 3> my_arr {1, 2, 3}
