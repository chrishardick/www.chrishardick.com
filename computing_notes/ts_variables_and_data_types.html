TypeScript Variables and Data Types

  • As mentioned before, TypeScript is a strongly typed language 
let x = "foo";
x = 50;     // valid for JavaScript. A compile time error in TypeScript

Primative Types

  • JavaScript has 3 primitive data types: string, number, and boolean and each has a corresponding type in TypeScript
  • Most of the time, the variable type can be inferred 
let f = "foo";  // f is implicitly a string
let n = 5;      // n is implicitly a number
let b = true;   // b is implicitly a boolean
  • TypeScript also supports explicitly specifying the types 
let f: string = "foo";      // explicit
let n: number = 5;          // explicit
let b: boolean = true;      // explicit
