Client Side JS - The Document Object

  • The Window object has a document property. It refers to the Document Object for given window.
  • The Document Object represents the contents of the window.
  • Because window is the global object, you can drop the window prefix and access the Document Object via simply document
  • The Document Object inherits from Node.
  • Node is an interface from which a number of DOM API object types inherit from -- Document, Element, and Text are examples

Document Object Properties

body

  • get or set the document body e.g. html→body

cookie

  • see Cookie Property

head

  • get the document head e.g. html→head

title

  • get or set the document title. e.g. html→head→title

Document Object Methods

getElementById()

  • Obtain an Element Object via id attribute
  • id attributes should be unique per document. However, if a given document contains multiple elements with identical ID attributes, this method will return the first one encountered when traversing the document
  • Returns an Element Object or null if no elements exist with the given id 
    var clock = document.getElementById("clock");

if (clock == null)
{
    throw new Error ("element 'clock' not found");
}

getElementsByName()

  • Obtain Element Objects by Name attribute
  • The original purpose of the name attribute was to name CGI form elements such that the server could parse incoming message.
  • However, you can also select elements of a document by name using JS
  • Keep in mind that name values need not be unique 
    //
// returns a NodeList object (behaves like read-only array of Element Objects)
// - NodeList objects are live. The list of elements they contain will change as the document changes
// - the elements are in document order
// 
var items = document.getElementsByName("breakfast_items");

getElementsByTagName()

  • Obtain Element Objects by Tag Name 
    //
// returns a NodeList object (see above)
// - elements are in document order
// - supports wildcard "*" to return all elements of the document
//
var h2_elements = document.getElementsByTagName("h2");

//
// select 1st h2
var h2_1 = document.getElementsByTagName("h2")[0];

var all_elements = document.getElementsByTagName("*");
  • the Element class also defines a method by the same name (getElementsByTagName). However, it only selects elements that are descendants of the given element

getElementsByClassName()

  • Obtain Element Objects via CSS Class Name
  • The parameter can be a single class name or it can be a space delimted list of class names
  • If a list of class names are specified, only elements which belong to all specified classes will be returned 
    // return Element Objects which belong to the sprite class
var sprite_elements = document.getElementsByClassName("sprite");

// return Element Objects which have both the big and important classes
var big_important_elements = document.getElementsByClassName("big important");
  • The Document Object has a property named 'cookie'
  • Window->Document>cookie
  • cookie is a string property which allows you to create, modify and delete the cookie(s) that apply to the current page
