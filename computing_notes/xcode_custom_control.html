Xcode - Custom Control

To create a subclass of UIStackView

  • File > New > File (or Command-N)
  • Choose iOS
  • Select Cocoa Touch Class
  • In the Class field, enter a class name. E.g RatingControl
  • In the Subclass of field, select UIStackView
  • Choose Swift for the language
  • Click thru the wizard and this will create a swift file for you (e.g. RatingControl.swift) with a definition for your class (which inherits from UIStackView)
  • At the top of your newly defined class, enter the following: 
    // MARK: Initialization

// since we're overriding a method definition of a parent class, we need to use keyword override
override init (frame: CGRect)
{
    super.init(frame: frame)
}

required init (coder: NSCoder)
{
    super.init(coder: coder)
}
