JS Client - Canvas

  • HTML5 provides a canvas element which allows you to draw graphics including rectangles, lines, text, circles, etc.
  • When defining a canvas element, it's always a good idea to specify alternative content (the content between the beginning and ending canvas tags). The alternative content is rendered if the browser is unable to render the canvas. This can happen because JS is disabled, lack of browser support, etc.

Context

  • When dealing with a HTML Canvas, you need to obtain a context object
  • A "2d" context object allows you to draw rectangles, lines, text, circles, etc. on the canvas 
    <canvas id="graph" width="1440" height="500" style="border:1px solid black;"></canvas>

<script>
var graph = document.getElementById("graph");

//
// obtain a 2d context object
//
var context = graph.getContext("2d");
...
</script>

Rectangles

context.rect(x, y, width, height)

  • Draw an unfilled rectangle at the specified coordinates
  • x is the upper left x coordinate
  • y is the upper left y coordinate
  • height and width are specified in pixels
  • A method of the context object

context.fillRect(x, y, width, height)

  • Draw a solid rectangle at the specified coordinates
  • x is the upper left x coordinate
  • y is the upper left y coordinate
  • height and width are specified in pixels
  • A method of the context object

context.clearRect (x,y,width,height)

  • similar to rect() and fillRect() except it clears the specified region

Lines

context.beginPath()

  • Begin a path or reset the current path
  • A method of the context object

context.moveTo(x, y)

  • Move the path to the specified point on the canvas without creating a line
  • A method of the context object

context.lineTo(x, y)

  • create a line from the current point in the path to the specified point
  • A method of the context object

context.stroke()

  • physically draw the specified path
  • A method of the context object

context.fill()

  • Fill in the specified path
  • A method of the context object
  • The default color is black.
  • Use context.fillStyle property to specify a different color, gradient or pattern to use

context.isPointInPath(x, y)

  • Returns boolean
  • A method of the context object

Text

context.font

  • Specify or return the current font proerties for text content on the canvas
  • Accepts the same syntax as the CSS font property
  • Default value: 10px sans-serif
  • A property of the context object

context.fillText(text, x, y)

  • Physically draw the specified text on the canvas with solid characters
  • A method of the context object

context.strokeText(text, x, y)

  • Similar to fillText() except tha the text is not filled in
  • A method of the context object
