MySQL - Table Partitions

Horizontal vs. Vertical Partitioning

  • Horizontal Partioning - partitioning via rows. Different rows can go to different partitions
  • Vertical Partioning - partitioning via columns. Different columns go to different partitions - not supported by MySQL.

Benefits of Partioning

  • The primary purpose people use partitions is efficient deletion. I.e. deleting old records, etc.

Basics

  • To test if your MySQL engine supports partitioning - execute the following SHOW PLUGINS and check for partition is ACTIVE
  • Partitions are always numbered sequentially starting from 0 when created.
  • Partition names are not case sensitive
  • All columns used in a partition expression must be present im every unique key in the table
  • There are 4 partition types available RANGE, LIST, HASH and KEY

RANGE Partioning

  • Assigns rows to partitions based on column values which fall within a specified range. 
PARTITION BY RANGE ( EXTRACT(YEAR_MONTH FROM timestamp) )
