Swift

Introduction

  • statements need not be suffixed by a semi-colon unless you're trying to put multiple statements on a single line
  • both c & c++ style comments are allowed
  • swift is a compiled language
  • everything is an object. in swift, there are no scalers -- all types are objects
  • swift has three types of of object types: classes, structs, and enums
  • in swift, all variables need to be declared -- you do this w/ one of two keywords let or var
  • a variable declared with let is a constant
  • when a variable is declared, its type is established and can never change. 
    var t = 2
t = "hello"    // will not compile as t is an Int
  • By convention, typenames (e.g. String, Int) start with a capital letter
  • A swift program consists of one or many files

Modules

  • A module can be defined in one or more files
  • A module cannot see another module without an import statement. e.g. import UIKit
  • The top-level namespace is a module
  • By default, your app is a module
  • Frameworks are also modules (and hence a namespace)
  • Your code implicitly imports Swift (which contains the println() function)

Object Types

  • Swift has 3 object types: class, struct & enum
  • Swift supports both object properties and class (static) properties
  • The self keyword refers to the current object -- most of the time you need not specify this
  • Here's how you instantiate an object 
    let chris = Parent()

Functions

  • Swift has a unique syntax for defining functions 
    func sum 
    (x:Int, y:Int)      // parameters
    -> Int              // return value
{
    let result = x+y
    return result
}


// calling a function
let a = 5;
let b = 10;
let c = sum (a,b);

func prnt
    (x:String)
    -> Void
{
    println (x)
}

// 3 ways to define a void function
func prnt (x:String) -> Void  { ... }     // equivalent
func prnt (x:String) -> ()    { ... }     // equivalent
func prnt (x:String)          { ... }     // equivalent


// a function without parameters

func prnt_hello
    (Void)              // parameters
    -> Void             // return value
{
    println ("Hello, World!")
}

// You can omit Void when definining a function without parameters
func prnt_hello (Void)  -> Void  { ... }
func prnt_hello ()      -> Void  { ... }
  • Function Signature
    • A signature characterizes all function that has the same number of parameters with the same types and the same return type
    • For example, here is a signature for a function with accepts 2 integers & returns an integer: (Int, Int) -> Int
    • E.g. the type of function
    • Here are 3 equivalent signatures -- all representing a void function without parameters: 
    • Void -> Void
    • () -> Void
    • () -> ()
  • External Parameter Names
    • Forces the parameter names to appear in the call to a function
    • put the external name before the internal parameter name, separated by a space in the function definition
    • Even though external names are used, parameter order must be maintained
    • The external name can be equivalent to the internal name. If it is, you can put a # before the internal name 
      func sum (x x:Int, y y:Int) -> Int { ... }
func sum (#x:Int, #y:Int) -> Int { ... } // equivalent

// calling a function with external parameter names (the external name precedes the argument separated by a colon)
let a = 5;
let b = 10;
let c = sum (x:a, y:b)
    • If a function is a method (e.g. it is declared at the top level of an object type), then by default, the 2nd - nth parameters are implicitly externalized. You can provide your own external names for these parameters, but if you don't, the compiler will do it for you -- just like if you had preceded the 2nd - nth parameters with a #
    • This convention allows Swift functions to interface with Objective-C methods which usually work in this manner. 
      class Date 
{
    func add (d:Int, m:Int, y:Int) { ... }
}

let date = Date();
date.add (5, m:1, y:1970)
  • Function Overloading
    • E.g. multiple functions can have the same name so long as they have different signatures 
      func prnt (s:String) -> Void { ... }
func prnt (i:Int) -> Void { ... }
    • You can also have two functions with the same signature, but different external parameter names
    • Beware C++ programmers, Swift also allows you to overload by return type as well -- so long as the context of the call can resolve the correct function to call.
  • Default Parameter Values 
      func prnt (s:String = "null") -> Void { ... }
    • If you do not supply an external name for a parameter with a default value, the compiler will implicitly provide one for you (just like you had proceeded the parameters with a #). You can suppress the implicit external name by preceding the internal name with an underscore and a spacea
    • If parameters with default values have external names, they need not be in order when you call the function
  • Variadic Parameters
    • The last parameter of a function can be defined as variadic. I.e. the caller can supply as many values of the given type separated by a comma. The function will receive these values as an array
    • To specify that the last parameter is variadic, follow it by three dots 
      func sum (x:Int ...) { ... }

// caller
let x = sum (5, 4, 3, 2, 1)
    • Note: To date, you can not specify an array when calling a function which accepts a variadic parameter, you must pass a comma delimited list

  • Modifiable Parameters & Pass by Reference
    • A parameter is implicitly decalared with let (e.g. it's a constant and you cannot assign to it)
    • If you would like to assign to a parameter within the body of a function, you need to explicitly declare it with var
    • Note: this is still pass by value 
      func sum (var x:Int, var y:Int) -> Int
{
    if (x == 0)
    {
        x=5
    }

    if (y == 0)
    {
        y=20
    }

    return x+y
}

// function call
let a = 0, b = 0


let c = sum (a, b)          // a = 0, b = 0, c = 25
    • If you want to pass by reference, you need to:
      • declare the parameter you wish to alter as inout
      • the passed in parameter must not be constant (i.e. it must be declared with var, not let
      • Instead of passing the variable, you need to pass the address of the variable by preceding its name with an ampersand 
        func sum (inout x:Int, inout y:Int) -> Int
{
    if (x == 0)
    {
        x=5
    }

    if (y == 0)
    {
        y=20
    }

    return x+y
}

// function call
var a = 0, b = 0

let c = sum (&a, &b)      // a = 5, b=20, c=25
    • NOTE: If your parameter is a class instance, the function can modify it even though it was not declared as inout. I.e. it is passed by reference (non-const)
    • Classes are reference types. All other object types are value types. When you pass a struct as an argument to a function, the compiler makes a copy of it & passes that copy to the function. When you pass a class as an argument to a function, you implicitly pass a reference to the class itself.
