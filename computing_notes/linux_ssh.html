Linux - ssh

Changing/Adding SSH Port for a Linux Server

  • Edit /etc/ssh/sshd_config and /modify the Port 22 line or additional lines specifying additional ports
  • Restart service - systemctl restart sshd

SSH With Authentication Key and Optional Passphrase Instead of Password Authentication

On the Client

Basically we're going to generate a public/private key pair and install the private key on the client machine

  1. Generate RSA Public/Private Key Pairs via ssh-keygen. This will generate two files in ~/.ssh (by default) id_rsa - private key. id_rsa.pub - public key. For extra protection, you can enter a passphrase which will encrypt the private key (recommended if not an automated login). Every time you wish to access the private key, you'll have to enter the passphrase. The file will be useless without the passphrase
  2. Install public keys on applicable servers. You can use ssh-copy-id -i ~/.ssh/id_rsa.pub <username@remote_server>. ssh-copy-id is a utility which adds the contents of the given file to the server's ~/.ssh/authorized_keys
  3. verify you can log in to the server using the newly generated keys. ssh user@remote_server

On the Server(s)

Basically we're going to generate a public/private key pair and install the private key on the client machine

  1. Lock the account for password authentication. On linux, this is accomplished via passwd -l <username> -- which will disable log in via password for the given account (key authentication will still be possible). It prepends the user's encrypted password with an explamation point (!). You can use passwd -u <username> to re-enable log in via password for the given account (which will remove the prepended '!')
  2. From the client, verify you can no longer log in via password

How to Terminate an Active SSH Session from Within the Same Session

  • Ensure you're at a new line - e.g. press the Enter key
  • Type the tilde character ~ followed by a period .
