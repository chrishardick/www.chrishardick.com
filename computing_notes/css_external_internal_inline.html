CSS - External, Internal and In-line Styles

External Style Sheets

  • Great for managing style across an entire site
  • External style sheets are specified by a <link> element inside the <head> section
  • The media attribute defines which media the style should be applied to. Common values are: all, screen, and print. You may also specify a comma separated list when you want the style to be applied to multiple (but not all) media 
    <head>
...
<link rel="stylesheet" type="text/css" href="style.css" media="all">
...
</head>

Internal Style Sheets

  • Internal style sheets are used to define style for a single page
  • Internal style sheets are defined within the <style> element inside the <head> section
  • You can also specify mediums via the media attribute 
    <head>
...
<style>
...
</style>
...
</head>

Inline Styles

  • Inline styles are used to define style for a single element 
    <tag style="...">...</tag>
