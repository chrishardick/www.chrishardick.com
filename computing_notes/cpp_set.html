C++ set, multiset

  • set - sorted set of unique elements. No Duplicates.
  • multiset - sorted set of elements. Duplicates allowed. 
#include <set>

template <   class T
            ,class Compare = less<T>   
            > class set;

key_compare() - binary predicate (function which accepts two parameters and returns a boolean) 
as to whether or not lhs is less than rhs

Constructors

set<T> s (const key_compare& comp = key_compare());

  • Default constructor.
  • Creates a set with no elements (size = 0)

set (InputIterator first, InputIterator last, const key_compare& dcomp = key_compare());

  • Range constructor.
  • Creates a set initialized with range [first, last)

set (const set& x);

  • Copy constructor

Destructor (~set)

  • destruct each element and destruct the container

Member Functions

iterator begin();

const_iterator begin() const;

  • Return an iterator pointing to the first element of the set

iterator end();

const_iterator end() const;

  • Return an iterator pointing to the past-the-end element of the set

bool empty() const;

  • Return a boolean as to whether or not the set is empty

size_type size() const;

  • Return the number of elements in the set

pair<iterator, bool> insert (const T& val);

  • Insert single element
  • Return value:
  • pair.first - an iterator pointing to the element (which was either added or already existed).
  • pair.second - boolean - true=element added. false=element was already present

void insert (InputIterator first, InputIterator last);

  • Range Insert

iterator find (const T& val) const;

  • Get iterator to element
  • Returns set::end is not found
