Linux - curl

  • Command-line tool to transfer data to or from a server
  • Typically used for HTTP or HTTPS. However, curl supports other protocols as well - SCP, SFTP, FTP
  • Curl is pretty smart. I.e. the default protocol is HTTP, default request type is GET. However, if you specify --upload-file or -T option, the request type will change to PUT. In addition, Content-length will be calculated for you (along with the proper header added)
  • The request type can be changed via -X option
  • The verbose flag (-v or --verbose) is very useful to see what request was actually sent along with anything else which is going on under the hood. 
# default protocol = HTTP
# default request type = GET
curl www.chrishardick.com

# HTTP, request type = PUT
curl --upload-file hello_world.html www.chrishardick.com
