JavaScript - Numbers

  • All numbers in JavaScript are stored in 64 bit floating point format.
  • In other words, there is no distinction between integers and real numbers.
  • Bitwise operators are an exception -- they are performed on 32-bit integers.
  • Hexadecimal literals begin with 0x or 0X.
  • Floating point literals can be represented using exponential notation (real number followed by E (or e) followed by an integer exponent (which may be negative)
  • JavaScript supports the basic arithmetic operators
    • + for addition
    • - for subtraction
    • * for multiplication
    • / for division
  • In addition, JavaScript supports more complex arithmetic operations as part of the core language. These functions are accessed as methods of the Math class
  • The Math class has a toString( ) method which converts an integer to a string using the base specified by its argument (the base must be between 2 and 36) 
    var x = 6;
var y = x.toString(2); // y is "110"

// you can also invoke the toString method on a literal
// the parenthesis are requird to prevent the period (.) from being interpreted as a decimal point

var y = (6).toString(2);
  • Special Numeric Values
    • Infinity is used to represent a number larger than the largest possible number
    • There's also -Infinity to represent a negative number lower than the lowest possible negative number
    • NaN is used to represent 'not a number'. To test for NaN, use IsNaN( )
    • Use isFinite( ) to test whether a number is not NaN, Infinity, nor -Infinity
