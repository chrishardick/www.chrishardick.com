Python: Base64

Basics

  • Convert binary data into 6-bit segments - 2^6 = 64 possibilities (0-63) - hence Base64
  • A Base64 encoding table is then used to convert each value (0-63) into an ASCII value
  • If the size of the original data is not equally divisible by 3, pad characters must be added - the padding algorithm is beyond the scope of this document
  • The most common use of Base64 is to accurately transfer (or store) binary data as ASCII

Example

import base64

original_data   = "Hello, World!"

encoded_data    = base64.b64encode(original_data)

decoded_data    = base64.b64decode(encoded_data)
