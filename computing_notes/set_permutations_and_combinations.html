Set: Permutations and Combinations

  • Permutations - A selection of items from a collection (or set) in which order matters.
  • Combinations - A selection of items from a collection (or set) in which order does not matter.
  • See also Python: Permutations and Combinations

Formulas and Examples

  • Number of permutations (order matters) of n taken r at a time 
    P(n,r) = n! / (n-r)!
  • Number of combinartions (order does not matter) of n taken r at a time 
    C(n,r) = n! / (n-r)!r!
  • 3 items, 2 at a time (E.g. a, b, c) 
    P(3,2) = 3⋅2 / 1 = 6
1) a b
2) b a
3) a c
4) c a 
5) b c
6) c b

C(3,2) = 3⋅2 / 2 = 3
1) a b
2) a c
3) b c
