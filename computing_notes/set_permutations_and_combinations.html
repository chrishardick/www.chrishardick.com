Set: Permutations and Combinations

  • Permutations - A selection of items from a collection (or set) in which order matters.
  • Combinations - A selection of items from a collection (or set) in which order does not matter.
  • See also Python: Permutations and Combinations

Formulas and Examples

Permutations

  • Number of permutations (order matters) of n taken r at a time
  • E.g. How many ways can you you arrange 6 people in 4 chairs 
    P(n,r) = n! / (n-r)!

E.g.
6 · 5 · 4 · 3


Alternatively:
6!/(6-4)!
6 · 5 · 4 · 3 · 2 / 2
  • 3 items, 2 at a time (E.g. a, b, c) 
    P(3,2) = 3 · 2 / 1 = 6
1) a b
2) b a
3) a c
4) c a 
5) b c
6) c b

Combinations

  • Number of combinations (order does not matter) of n items taken r at a time
  • Similar to permutations, except, we need to subtract out sets with the same values (different order)
  • For our example above, 6 people, 4 chairs, we need to subtract out 4 · 3 · 2 · 1 (the number of ways we can arrange 4 people in different orders) 
    C(n,r) = n! / (n-r)!r!

6!/(6-4)! · 4!
63 · 5 · 4 · 3 · 2 / 2 · 4 · 3 · 2


    C(3,2) = 3 · 2 / 2 = 3
1) a b
2) a c
3) b c

    Algorithm in C++

    // combinations (order does not matter)
// n items taken r at a time
void combo (const std::vector<int>& v, int r)
{
    // 2^v.size()

    if (pow(2,v.size()) > sizeof(unsigned long long))
    {
        std::cout << "too large" << std::endl;
        return;
    }

    unsigned long long max = 1 << v.size();             // 2^v.size()

    for (unsigned long long i=0; i < max; i++)          // 0=000, 1=001, 2=010, ...
    {   
        int cnt = 0;

        std::vector<int> tmp;

        for (unsigned int j=0; j < v.size(); j++)       // traverse as bit map
        {
            if (i & 1<<j) 
            {
                tmp.push_back(v[j]);
                cnt++;
            }
        }

        if (cnt == r)
        {
            std::cout << tmp << std::endl;
        }
    }
}


int main (int argc, const char* argv[])
{
    (void)argc;
    (void)argv;

    std::vector<int> v {1,2,3};

    combo (v, 2);

    return 0;
}
