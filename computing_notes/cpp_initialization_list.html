Initialization Lists

  • A method of specifying initial values for data members of an object using functional notation.
  • Very Important for Inheritance. It's the only way to call a constructor (other than the default constructor) of a base class from a constructor of the derived class
  • When an instance of a derived class is declared, both the constructor of the base class(es) & the constructor of the derived class are called
  • In a constructor for a derived class, an initializaiton list may specify calls to constructors for the base classes
  • If a base class does not have a constructor present in the initialization list of one of its derived classes, its default constructor (w/o any arguments) is automatically called.
  • Base class constructors are called before the constructor of the derived class is executed 
    /*
 * AN EXAMPLE
 */


/*
 * WITHOUT A INITIALIZATION LIST
 */
CBox::CBox (double dX=1.0, double dY=1.0, double dZ=1.0)
{
	m_dX = dX;
	m_dY = dY;
	m_dZ = dZ;
}


/*
 * SAME THING W/ AN INITIALIZATION LIST
 */
CBox::CBox (double dX=1.0, double dY=1.0, double dZ=1.0) : m_dX(dX),m_dY(dY),m_dZ(dZ)
{
	;
}
