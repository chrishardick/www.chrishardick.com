Date and Time Functions

CURDATE()
Returns current date as 'YYYY-MM-DD' or YYYYMMDD depending upon string or numeric context
E.g. SELECT CURDATE() yields 2022-05-10
E.g. SELECT CURDATE()+0 yields 20220510
E.g. SELECT CURDATE()-INTERVAL 1 DAY yields 20220509
Synonyms: CURRENT_DATE()
current_timestamp()
E.g. SELECT current_timestamp()
Return current date and time
DATE_ADD(date,INTERVAL expr unit)
E.g. DATE_ADD('2022-05-10 23:59:59', INTERVAL 1 SECOND) yields 2022-05-11 00:00:00
See Date and Time Units below
DATE_SUB(date,INTERVAL expr unit)
E.g. DATE_SUB('2022-05-09', INTERVAL 1 DAY)
See Date and Time Units below
EXTRACT(unit FROM date)
E.g. EXTRACT (YEAR FROM '2022-05-09'), EXTRACT(YEAR_MONTH FROM '2022-05-09 17:30:00') yields 202205
See Date and Time Units below
UNIX_TIMESTAMP(date)
E.g. UNIX_TIMESTAMP(), UNIX_TIMESTAMP('2022-05-09'), UNIX_TIMESTAMP('2022-05-09 17:30:00')
If called without arguments, returns a Unix timestamp (seconds since epoch) as an unsigned integer
