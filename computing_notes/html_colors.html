HTML - Colors

Colors can be specified as either:

  • a well known name (e.g. Red, Yellow, Green, DarkGreen, Gray, DarkGray, ...)
  • RGB value (red, green, blue) -- where each parameter can have a value from 0-255 in either decimal or hexidecimal format -- see below
  • Colors can also be specified using a RGBA value -- which is an extension of RGB -- see below

RGB

  • rgb(255,0,0) or #FF0000 is red
  • rgb(0,255,0) or #00FF00 is green
  • rgb(0,0,255) or #0000FF is blue
  • rgb(0,0,0) or #000000 is black
  • rgb(90,90,90) or #5A5A5A is dark gray
  • rgb(128,128,128) or #808080 is a ligher shade of gray
  • rgb(200,200,200) or #C8C8C8 is an even ligher shade of gray
  • 255,255,255 or #FFFFFF is white

RGBA

  • RGBA color values are an extension of RBG color values with an alpha channel.
  • The alpha channel specifies the opacity from 0.0 to 1.0 where 0.0 is fully transparent and 1 is fully opaque
