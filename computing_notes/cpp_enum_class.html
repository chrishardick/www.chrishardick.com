enum class

  • Introduced in C++11
  • A strongly typed enumation
  • Enumerator names (e.g. MMkt) are scoped within the the enumerator's name (SecType::Mmkt)
  • Strongly Typed - an enum class is a type and does not implictly convert to an integer type
  • Explicit casts using static_cast is required to convert to an integer
  • You can specify the underlying data type (e.g. char, unsigned int, etc.). The default underlying type is int
  • Forward declarations are supported
  • Similar to traditional enum in that the first item in the list defaults to 0 and each subsequent item without an explicit value is assigned a value one greater than the preceding item
  • Constructors are NOT supported and if you do not provide an initial value for a given enum class, its value will be indeterministic

enum class SecType : short;
