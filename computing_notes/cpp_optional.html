C++ optional

  • A class template which may or may not contain a value
  • If an std::optional contains a value, the value is contained within the std::optional
  • Introduced in C++17 
#include <optional>

template <typename T>
class optional;

Constructors

  • Default Constructor
    • constructs an empty optional 
    optional <T> v;
  • Initialize with a value 
    optional <T> (T&& value);
  • Initialize with a value - type deduced 
    optional (T&& value);

Destructor

  • Destroys the contained value, if there is one 
    ~optional()

Member Functions

  • operator=
    • assign a value
  • value()
    • Returns the contained value
    • Calling value() on an optional which does not contain a value will throw an exception
  • value_or()
    • returns the contained value if available, other value otherwise
  • has_value()
    • Return boolean as to whether or not the optional contains a value

Optional Return Value

std::optional<std::string> foo ()
{
    if (...)
        // a made up condition which will return an empty optional
        return { };

    else
        return ("hello, world");
}
