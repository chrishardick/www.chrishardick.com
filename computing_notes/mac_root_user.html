Mac - Root User

I'm not sure why Apple makes you jump thru so many hoops to enable the root user or change the root password. I guess they're trying to encourage you to use sudo instead. However, I always like to set the root password (just in case). Here is the procedure:

  1. System Preferences → Users & Groups → Login Options
  2. Unlock
  3. Login Options
  4. Click the Network Account Server: "Join..." button
  5. Click on the "Open Directory Utility..." button
  6. Click on the "Directory Editor" icon
  7. Edit → Change Root Password
