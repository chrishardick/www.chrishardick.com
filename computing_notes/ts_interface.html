TypeScript Interfaces

  • An interface is a contract for a given type.
  • It defines a syntax which classes need to obey
  • The TypeScript compiler does not convert interfaces to JavaScript. It uses interfaces for type checking.
  • This is known as duck typing
  • An interface is defined with keyword interface
  • It can include properties and method declarations 
interface Person
{
    id:         number;
    firstName:  string;
    lastName:   string;
    getAge:     (number) => number;  // arrow function
    getFullName (number): string;
}
interface KeyValue
{
    key:    string;
    value:  string;
}

let kv1: KeyValue = { key:"foo" , value:"bar"   };
let kv2: KeyValue = { key:"foo" , val:"bar"     };      // compiler error. 'val' does exist in 'KeyValue'
let kv2: KeyValue = { key:5     , val:"5"       };      // compiler error. 'key' is not of type string

Interface for a Function

  • A TypeScript interface can be used to define a type of function which will ensure the function signature 
interface KeyValueFunc
{
    (key: string, value: string): void;
}

function keyValueFoo (key: string, value, string) : void
{
    console.log("keyValueFoo: key=" + key + ", value=' + value);
}

let kvp: KeyValueFunc = keyValueFoo;

kvp ("foo", "bar");
