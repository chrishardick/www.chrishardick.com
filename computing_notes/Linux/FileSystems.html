File Systems

I. Partitions -- Background Info

  • Hard drives can be divided into one or more partitions (logical hard drives)
  • On the 1st Sector of a hard drive is (1) a Master Boot Record & (2) a Partition Table
  • Although all drives have a Master Boot Record, only the MBR of the 1st hard drive is ever read. At boot-time, it's read to determine where the OS (or OS's) are located (which partitions) so the proper OS can be read into memory.
  • Primary Partitions, Extended Partitions & Logical Partitions
    • A drive may only have 4 Primary Partitions (e.g. /dev/hda1, /dev/hda2, /dev/hda3, /dev/hda4)
    • Extended Partitions allow a drive to have more than 4 Partitions. An extended partition does not hold any data itself. Instead, it acts like a container for Logical Partitions. You may only have 1 Extended Partition / Drive.
  • Some Names
    /dev/hda
    Entire 1st IDE hard drive
    /dev/hda1...hda4
    Primary Partitions 1-4 of 1st IDE hard drive
    /dev/hda6.../dev/hdaN
    Logical Paritions of 1st IDE hard drive
  • fdisk - Partition table manipulator
  • Once you've divided your drive into partitions, it's time to give each partition a filesystem.

    II. What is a File System (fs)?

    • A storage device (or a piece of a storage device) which is formatted to store files.
    • E.g hard drive, CD-ROM, or any storage media that permits random access (a tape drive cannot contain a file system)
    • Examples
      • 2nd Extended File System (ext2fs) - Linux Default
      • MS-DOS File System
      • ISO9660 File Sytem (used by CD-ROMs)
      • VFAT File System (Win9x)
      • NTFS File System (WinNT)
      • /proc File System (virtual - no disk space associated with it

    III. Mounting File Systems

    • In order to access a file system, you must first mount it to a certain directory (the directory must first exist)
    • File Systems are mounted using the mount command 
    • mount -t type device mount-point
mount -t ext2 /dev/hda2 /mnt

    IV. Unmounting File Systems

    • Synchronizes System Buffers with Actual Contents on Disk
    • Makes file system no longer available 
    • umount /mnt       # Unmount file sytem mounted @ given directory
umount /dev/hda2  # or unmount given file system (wherever it's mounted)

    V. Creating File Sytems (mkfs)

    • mkfs command. Make File System
    • Formats a partition
    • All data will be deleted
    • Each File System has it's own mkfs command
      • mkfs.msdos
      • mkfs.ext2 (or mke2fs)
    • mkfs is a front end which executes the correct command 
    • mkfs -t type device blocks

    VI. /etc/fstab

    • @ boot time, the system automatically mounts all file systems listed in /etc/fstab
    • mount: if you only specify a device name or mount point, mount will read the other from /etc/fstab
    • format
      device mount-point type options
    • mount -a
      mounts all filesystems listed in /etc/fstab (just like at boot time)
