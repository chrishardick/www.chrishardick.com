RCS - Revision Control System

ci - check in RCS Revisions

    ci [options] file ...

co - check out RCS Revisions

    co -l [options] file ... ## Checkout w/ lock
    co [options] file ...    ## Checkout w/o lock (copyout)

Other RCS Commands

    rlog    ## Summary of changes to a file
    rcsdiff ## Diff 2 Revisions
