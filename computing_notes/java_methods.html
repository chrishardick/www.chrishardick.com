Java: Methods

  • A method is a block of code which is executed when the function is called
  • You can pass parameters to methods
  • Methods are also called functions
  • In Java, methods must be declared within a class
  • Methods are defined with their name followed by parentheses ((...))
  • Within the parentheses, a comma delimited list of parameters can be passed to the method
  • Methods can be declared as static meaning they belong to the class (as opposed to the objects of the class)
  • Primative types are passed by value. I.e. the primative type is copied and it's the copy of the primative type which is passed to the function
  • Reference types are passed as reference variables.
  • Methods can return values via the return keyword
  • Methods can be overloaded. I.e. multiple functions can have the same name with each definition having a different set of parameter types 
//
// Main.java
//

public class Main
{
    static void foo (   String s        // since String is a reference type, a reference variable is created
                        ,int i
                        )
    {
        s = "foo";      // this creates a new String ("foo") and the reference variable points to it. Note the original string is not modified

        i = 50;         // as this is passed by value, this will not be visible from the caller
    }

    static void main ()
    {
        String s = "main";
        int i = 25;

        foo (s, i);

        System.out.println("s=" + s);       // will print "s=main"
        System.out.println("i=" + i);       // will print "i=25"
    }
}
