The Window Object

  • The Window Object represents the window or frame in which the document is displayed
  • It is the root of the client-side object hierarchy
  • It is the Global Object for client side JavaScript
  • The Window Object defines properties and methods which allow us to manipulate the web browser window
  • Variable Lifetime
    • When a user goes from one page to another, the Window object for the window or frame is restored to its default state

The Document Object

  • Most of the client-side object hierarchy descends from the Document object
  • The most commonly used object in client-side JavaScript programming
  • Defines the document.write( ) method to insert dynamic content into the document while it is being parsed
    • you can only use write ( ) to output HTML to the current document while the document is being parsed
    • if you call write ( ) after the document is parsed and rendered (i.e. in an event handler) you will overwrite the entire document, instead of appending text to it
    • the write ( ) method can take a variable number of arguments -- they will be concatenated together
    • there's also a writeln( ) method which is the same as write( ) excapt it appends a newline character
  • Defines properties which provide information about the document
    • URL
      • string. the URL of the current document
    • lastModified
      • string. last modification date of the document
    • title
      • string. <title>...</title> text
    • bgColor, fgColor
      • string. <title>...</title> text
  • The subtree of the client-side object hierarchy is known as the Document Object Model -- DOM
