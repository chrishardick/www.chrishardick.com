MariaDB

  • Multithreaded DB Engine
  • Seperate threads for each incoming connection
  • Main thread to manage connections
  • A Forking Daemon. As soon as it starts, it forks and exits. Leaving the forked process to run in the background
  • safe_mysql. A script which starts the mysql daemon and continuously verifies that mysqld stays running. If mysqld exits, safe_mysql will restart it. Execute safe_mysql in the background (e.g. safe_mysql &)
  • Databases are simply files in a specific file. You can use the OS to copy and rename databases
  • MySQL Data Structure - depending on the version of MySQL you're running, you may see some variation here. As far as I've seen, MySQL database formats are backward compatible.
    • .isd = Data File
    • .ism = Keys and other internal data
    • .frm = Table Structure Info

MariaDB vs. MySQL

  • MariaDB is a fork of MySQL intended to remain free under the GNU GPL
  • Built by the some of the original developers of MySQL
  • Intended to maintain high compatibility with MySQL -- such that it can be a drop-in replacement
  • Note - these pages were originally written for MySQL

mysql DATABASE

  • Used for security (who is permissioned to do what)
  • contains 5 tables
    1. user
      • sets permissions for the server as a whole
      • Columns (basically all of type enum ('N','Y'))
      • Select_priv -- perform SELECT statements
      • Insert_priv -- perform INSERT statements
      • Update_priv -- perform UPDATE statements
      • Delete_priv -- perform DELETE statements
      • Create_priv -- perform CREATE statements
      • Drop_priv -- perform DROP statements
      • Index_priv -- the ability to create or drop indicies
      • Alter_priv -- perform ALTER TABLE statements
      • Here's a statement to add (a pretty powerful) user 
        INSERT INTO user (Host     ,User           ,Password       ,Select_priv,Insert_priv,Update_priv,Delete_priv,Create_priv,Drop_priv,Index_priv,Alter_priv)
	  VALUES (localhost,chris@localhost,password('xyz'),'Y',       ,'Y'        ,'Y'        ,'Y'        ,'Y'        ,'Y'      ,'Y'       ,'Y'       );
    2. db
      • sets permissions for individual databases
    3. host
    4. tables_priv
    5. colums_priv

Utilities

mysqladmin

  • Client to administer a MariaDB server
  • Set root password 
    mysqladmin -u root password 'newpasswd'

mysql

  • MariaDB SQL client
  • To log in: 
    mysql -u root -p
  • To add a user record to 'user' table and host record to 'host' table
    • log in as mysql user root (see above)
    • add record to user table
    • add record to host table

Porting An Existing MySQL Database

  • Copy directory to /var/lib/mysql
  • Add the following record to the 'db' table 
    insert into db set host='localhost',db='HomeAuto',user='chris',select_pre_priv='y',create_priv='y',drop_priv='y',references_priv='y',index_priv='y',alter_priv='y';
