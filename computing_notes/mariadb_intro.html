MySQL / MariaDB

  • Multithreaded DB Engine
  • Seperate threads for each incoming connection
  • Main thread to manage connections
  • A Forking Daemon. As soon as it starts, it forks and exits. Leaving the forked process to run in the background
  • safe_mysql. A script which starts the mysql daemon and continuously verifies that mysqld stays running. If mysqld exits, safe_mysql will restart it. Execute safe_mysql in the background (e.g. safe_mysql &)
  • Databases are simply files in a specific file. You can use the OS to copy and rename databases
  • MySQL Data Structure - depending on the version of MySQL you're running, you may see some variation here. As far as I've seen, MySQL database formats are backward compatible.
    • .isd = Data File
    • .ism = Keys and other internal data
    • .frm = Table Structure Info

MariaDB vs. MySQL

  • MariaDB is a fork of MySQL intended to remain free under the GNU GPL
  • Built by the some of the original developers of MySQL
  • Intended to maintain high compatibility with MySQL - such that it can be a drop-in replacement
  • These pages were originally written for MySQL
