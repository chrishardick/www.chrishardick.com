JQuery

  • A JavaScript library designed to make it easier to use JS on a webpage
  • The entire library is defined in a single js file which comes in 2 versions (a compressed version and a full version)
  • The 2 versions are identical in functionality, the compressed version simply takes up less space (no comments, extra spaces, etc.)
  • You simply include a link to the file (you can either host it yourself or reference one hosted by a well known source -- i.e. google, etc.
  • jQuery also has a bunch of plugins

$ - The jQuery Fuction

  • JQuery exposes its methods and properties via two properties of the window object -- jQuery and $ ($ is an alias for jQuery)
  • $ is a perfectly valid variable name in JS.
  • In jQuery, $ is a selector function (i.e. a function which returns a set of elements found in the DOM)

The Document Ready Event

  • Normally developers wrap their code in window.onload event such that the code does not execute until the document is done loaded.
  • The onload event does not trigger until the entire page is loaded (including images).
  • On the contrary, the ready event triggers once the document is ready to be manipulated 
    $(document).ready(function() {
    //
});

Selectors

  • Selectors allow you to select HTML elements based on their name, id, classes, types, attributes, values of attributes, etc.
  • Basic Syntax: $(selector).action()
  • Examples: 
    // an element selector
$("p").hide()       // hide all <p> elements

// an id selector
$("#test").hide()   // hide the element with id="test"

// a class selector
$(".test").hide()   // hide all elements with class="test"

// select all p elements with class intro
$("p.intro").hide

// select all elements with abc attribute
$("[abc]").hide()

// select all a elements with target="_blank"
$("a[target='_blank']").hide()

// select the current element
$(this).hide()

Events

Mouse Events

click
the function is executed when the user clicks on the selected element
dblclick
the function is executed when the user double clicks on the selected element
mouseenter
the function is executed when the mouse pointer enters the HTML element
mouseleave
the function is executed when the mouse pointer leaves the HTML element
mousedown
the function is executed whenever any mouse button (left, middle, or right) is pressed down while the mouse pointer is over the HTML element
mouseup
the function is executed whenever any mouse button (left, middle, or right) is released while the mouse pointer is over the HTML element
hover
the hover() method accepts two functions. The 1st is executed when the mouse enters the HTML element and the 2nd is executed whtn the mouse leaves the HTML element.

Keyboard Events

keypress
keydown
keyup

Form Events

submit
change
focus
the function is executed when the form field gets focus
blur
the function is executed when the form field loses focus

Document/Window Events

load
resize
scroll
unload

Examples

    $("p").click( function(){ $(this).hide(); } );


// a method which accepts two functions
$("p").hover( function(){ alert ("Hello"); }, function(){ alert ("Good bye"); } );

// cool ui feature
$("input").focus( function(){ $(this).css("background-color","amber"); } );
$("input").blur ( function(){ $(this).css("background-color","white"); } );

Chaining

  • Chain together multiple actions.
  • You can put separate statements on separate lines 
    $("p").css("color","blue).hide()

// equivalent
$("p").css("color","blue)
    .hide()
