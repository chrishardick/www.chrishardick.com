Xcode - Outlets (Widget ⬌ Variable)

  • Outlets provide a mechanism to link widgets in a storyboard (labels, etc.) to variables in source code
  • Outlets allow you to interact with the widgets programatically. I.e. set the text on a label, etc.

To Create an Outlet

  • This creates a property for the object which allows you to access and manipulate the widget from your source code
  • At the top of your ViewController class, add the following comment - if not already there (this will give you a target for your control-drag): 
    //MARK: Properties
  • Control-drag a widget in your storyboard to a view controller file below the newly added comment
  • A dialog should appear allowing you to enter a name (among other things). Enter a descriptive name (e.g. outletFooLabel)
  • You should see code added similar to the following: 
    @IBOutlet weak var outletFooLabel: UILabel!
  • IBOutlet - Interface Builder Outlet
  • weak - the reference does not prevent the system from deallocating the referenced object. Weak references prevent reference cycles
  • The explanation point (!) at the end of the declaration indicates the type is an implicitly wrapped optional - which means the system will assume it has a valid value and will automatically unwrap it for you. This will cause the app to terminate if the varaible has not been set.
