Linux - su

  • su [options] [username]
  • Change user ID or become superuser
  • Invoked without a username, su defaults to becoming the superuser
  • The optional argument - invokes a login shell after switching users. what the user would expect had the user logged in directly. e.g. su - username. This is equivaent to su -l username
  • If you are not a super user, you will be prompted for the password of the user you're becoming
