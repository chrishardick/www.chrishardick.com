DHCP Server Quick Start

  • Install -- if necessary. On RedHat or Centos systems, yum install dhcp
  • Install dhcpd.conf in /etc/ (e.g. /etc/dhcpd.conf). A sample can be found at /usr/share/doc/dhcp-<version>/dhcp.conf.sample
  • DHCP also uses the file /var/lib/dhcpd/dhcpd.leases to store the client lease database.

dhcpd.conf

default-lease-time  600;
max-lease-time      7200;

# cmd line options
# here we specify the network card connected to the internal network 
DHCPDARGS=eth1

subnet 192.168.2.0 netmask 255.255.255.0
{
    option routers                  192.168.2.1;
    option subnet-mask              255.255.255.0;
    option domain-name-servers      192.168.1.5;        # this is propably an ip address outside of the local subnet

    range 192.168.1.10 192.168.1.100;
}
  • After changing the configuration file, be sure to restart the dhcp server by running service dhcpd restart
  • For more information, man dhcpd.conf, man dhcp-options

Lease Database

  • Stored in file /var/lib/dhcpd/dhcpd.leases
  • ASCII file. Every time a lease is acquired, renewed or released, a new record is written to the end of the file. Therefore, if you find multiple entries, the last one is the one that takes precedence.
  • Do not change this file.
  • Times listed in file are UTC
  • Periodically, the file is re-created by moving the current file to dhcpd.leases~ and then copying active leases to the new file. This is done to prevent the file from growing without bound. If the service or machine crashes during this operation, it's possible that the file is not present whihc will prevent the service from starting. If this is the case, either dhcpd.leases~ needs to be copied to dhcpd.leases or dhcpd.leases needs to be touched -- whichever is the appropriate solution
  • The file also has to be touched before the server can come up for the 1st time.
