Python: argparse - Command Line Parser

  • To use the argparse module, you instantiate a ArgumentParser object

ArgumentParser constructor

class argparse.ArgumentParser(prog=None, usage=None, description=None, epilog=None, ...)
  • prog - name of the program. Defaults to sys.argv[0]
  • usage - the usage string. Default will be generated automatically
  • description - the text to display before the argument help. Defaults to none.
  • epilog - the text to display before the argument help. Defaults to none.

add_argument() method

ArgumentParser.add_argument(name or flags..., )
  • name or flags - either a name or a list of option strings. E.g. 'foo' or '-f', '--foo'
  • action - the number of command-line arguments that should be consumed
    • 'store'. Store the argument's value. This is the default action
    • 'store_const'. Store the value specified by the const keyword. Usually used with an optional argument
    • 'store_true', 'store_false'. Special cases of 'store_const' which store the values True or False
    • 'append'. Append each argument to a list
    • 'append_const'
    • 'extend'
    • 'count'
    • 'help'. Prints help message
    • 'version'. Expects a version= keyword argument
  • nargs - the number of command-line arguments that should be consumed

Sample

import argparse

// constructor

parser = argparse.ArgumentParser(   prog='ProgramName'
                                    ,description='What the program does'
                                    )


parser.add_argument('-f', '--foo')                          # option which may or may not take a value
parser.add_argument('bar')                                  # positional parameter

args = parser.parse_args()

if args.foo:
    print (f"foo={args.foo}")

print (f"bar={args.bar}")
