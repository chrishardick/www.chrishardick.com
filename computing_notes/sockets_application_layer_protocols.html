Sockets - Common Application Layer Protocols

I. Daytime

Client

  • Connect to server
  • Read until EOF (socket closed by server)
  • Print to STDOUT message sent by Server

Server

  • Accept connection from client
  • Get time (in string format) and write to socket
  • Close socket

II. Echo

Client

  • Connect to server
  • Read line from user (from stdin)
  • Write line to server
  • Read line from server
  • Write line to stdout
  • Continue until EOF read from stdin

Server

  • Accept connection from client
  • Read
  • Write data back to socket
  • Continue until client closes socket
