Client Side JavaScript

  • JS is embedded within HTML using the script tag.
  • You can define your code in-line or via an external file.
  • The ending <script> tag is required even for external files and when you use the src tag, all text between the opening and closing tag is ignored.
  • <script> tags can be placed anywhere on a page. Script execution is interleaved with HTML parsing and rendering.
  • You cannot manipulate objects before they have been created.
  • You must make sure any functions which are called in your event handlers have already been defined -- a simple way to guarantee this is to define all of your functions within the <head> section
  • If multiple pages use code in the same JS external file, it only needs to be downloaded once, speeding up loading of subsequent pages 
    <!-- EXTERNAL FILE -->
<script src="script1.js"> This is ignored! </script> 
</head>

<!-- ANOTHER EXTERNAL FILE -->
