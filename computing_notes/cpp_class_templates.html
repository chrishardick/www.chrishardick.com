Class Templates

  • Class templates allow you to parameterize the datatypes of a class
  • Class templates are an appropriate choice when you find yourself creating a lot of classes which are identical except they deal with different types (i.e. int, float, double, user-defined types)
  • Introduces 2 new C++ keywords: template & typename
  • See also Function Templates which allow you to parameterize the parameters and return types of functions


Defining Class Templates

  • Class templates and their methods are normally defined within header files, such that they can be used by multiple source files
  • Here's an example of a class template CList
  • The keyword class can be substituted for the keyword typename with no change in meaning (see below) 
    // clist.h
#ifndef CLIST_H
#define CLIST_H

template <typename T>              // same as: template <class T> 
class CList 
{
     T m_Value[100];
     long m_lNum;

public:
     CList() { m_lNum = 0L; }
     CList(T Value) { m_lNum = 1L; m_Value = Value; }
     CList(const T Value[], long lNum);
 
     ~CList();

     void Add(T Value) { m_Value[m_lNum++] = Value; }
     void Add(const T Value[], long lNum);

     const T& Max() const;
};

template <typename T>
CList<T>::CList (const T Value[], long lNum)
{
     m_lNum = lNum;

     for (int i=0; i< lNum; i++)
          m_Value[i] = Value[i];
}

template <typename T>
CList<T>::~Clist ()
{
     cout << "CList Destructor" << endl;
}

template <typename T>
void CList<T>::Add (const T Value[], long lNum)
{
     m_lNum += lNum;

     for (int i=0; i< lNum; i++)
          m_Value[m_lNum++] = Value[i];
}

template <typename T>
const T& CList<T>::Max() 
{
     T* p_Max = &m_Value[0];

     for (int i=1; i<m_lNum; i++)
         if (m_Value[i] > *p_Max)
              p_Max = &m_Value[i];

     return *p_Max;
}

#endif
  • Here's an example of a class template which has more than one parameterized type 
    template <typename T T1, U U1>
class CMyNewClass
{
    ...
};
  • In addition to parameterizing types, you can also parameterize constants 
    template <typename T, int iSize>
class CList 
{
     T m_Value[iSize];
     long m_lNum;

public:
     CList() { m_lNum = 0L; }
     CList(T Value) { m_lNum = 1L; m_Value = Value; }
     CList(const T Value[], long lNum);

     void Add(T Value) { m_Value[m_lNum++] = Value; }
     void Add(const T Value[], long lNum);

     const T& Max() const;
};


Class Template Instantiation

                         +-------------------+
                         | class template    |
                         +-------------------+
                               |      |
                  +------------+      +----------+  class template instantiation
                  |                              |  (compile time)
                 \ /                            \ /
             +-------------------------+    +-------------------------+
             | class template instance |    | class template instance |
             +-------------------------+    +-------------------------+
  • You can instantiate a class template with the following syntax 
    #include<clist.h>

int main (int argc, char** argv)
{
     CList<int> cMyList;          // instantiate a CList of int's

     cMyList.Add(5);              // instantiate CList::Add<int>
}
  • At the point where a template function is first used, the appropriate function definition is generated and compiled
  • Class Template Specializations allows the programmer to explicitly define a class template instance. This is useful when the implicit instance would not give the desired result or would have been highly ineffecient (see below) 
    /*
 * a trivial example
 * - class template specialization for type double
 */
template <>
class CList<double>
{
     double m_Value[100];
     long m_lNum;

     const double& Max() const;
};
