C++ Class Templates

  • Class templates allow you to parameterize datatype(s) of a class
  • Class templates are an appropriate choice when you find yourself creating a lot of classes which are identical except they deal with different types (i.e. int, float, double, user-defined types)
  • Introduces 2 new C++ keywords: template and typename
  • See also Function Templates which allow you to parameterize the parameters and return types of functions

Defining Class Templates

  • Class templates and their methods are normally defined within header files, such that they can be used by multiple source files
  • Here's an example of a class template CList
  • The keyword class can be substituted for the keyword typename with no change in meaning (see below) 
// clist.h
#ifndef CLIST_H
#define CLIST_H

template <typename T>              // same as: template <class T> 
class CList 
{
    private:

        const int m_maxsize;

        T m_value[100];
        int m_size;


    public:

        // CREATORS

        CList() : 
            m_maxsize(100)
            ,m_size(0)
        { }

        CList(const T& t) : 
            m_maxsize(100)
            ,m_size(1)
        {
            m_value[m_size-1] = t;
        }

        CList(const T& t[], int num) :
            m_maxsize(100)
            ;
 
        ~CList();

        void Add(T& t) 
        { 
            if (m_size < m_maxsize)
            {
                m_value[m_size-1] = t; 

                m_size++;
            }
        }

        void Add(const T& t[], int num);

        const T& Max() const;
};

// CONSTRUCTOR (CREATOR)
template <typename T>
CList<T>::CList (const T& t[], int size)
{
    if (size > m_maxsize)
        return;

    m_size = size;

    for (int i=0; i< m_size; i++)
        m_value[i] = t[i];
}

template <typename T>
CList<T>::~Clist ()
{
    std::cout << "CList Destructor" << std::endl;
}

template <typename T>
void CList<T>::Add (const T& t[], int num)
{
    if (m_size + size > m_maxsize)
        return;

    for (int i=0; i< size; i++)
    {
        m_Value[m_size-1] = t[i];
        m_size++;
    }
}

  • In addition to parameterizing types, you can also parameterize constants 
template <typename T, int SIZE>
class CList 
{
    private:
        T m_value[SIZE];
        int m_size;

    public:

        // CREATORS

        CList() :
            m_size(0)
        { }

        CList(const T& t) : 
            m_size (1)
        {
            m_value[0] = t;
        }

        CList(const T& t[], int size);

        void Add(const T& t);
        void Add(const T& t[], int size);

        const T& Max() const;
};

Class Template Instantiation

                              +-------------------+
                              | class template    |
                              +-------------------+
                                    |      |
                  +-----------------+      +--------------------+
                  | class template instantiation (compile time) |
                 \ /                                           \ /
             +-------------------------+    +-------------------------+
             | class template instance |    | class template instance |
             +-------------------------+    +-------------------------+
  • You can instantiate a class template with the following syntax 
#include<clist.h>

int main (int argc, char** argv)
{
     CList<int> cMyList;          // instantiate a CList of int's

     cMyList.Add(5);              // instantiate CList::Add<int>
}
  • At the point where a template function is first used, the appropriate function definition is generated and compiled

Class Template Specialization

  • Class Template Specializations allows the programmer to explicitly define a class template instance.
  • This is useful when the implicit instance would not give the desired result or would have been highly ineffecient 
//
// a trivial incomplete example
// - class template specialization for type double
//
template <>
class CList<double>
{
    private:

        const int m_maxsize;

        double m_value[100];
        int m_size;


    public:

        // CREATORS

        CList() : 
            m_maxsize(100)
            ,m_size(0)
        { }

        // ...
};

// CONSTRUCTOR (CREATOR)
template <>
CList<T>::CList (const double& t[], int size)
{
    if (size > m_maxsize)
        return;

    m_size = size;

    for (int i=0; i< m_size; i++)
        m_value[i] = t[i];
}

Templates and Static Variables
  • Each instantiation of a class template has its own copy of member static variables
