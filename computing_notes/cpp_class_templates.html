C++ Class Templates

  • Class template - a template from which classes can be generated
  • Class templates allow you to parameterize datatype(s) of a class
  • Class templates are an appropriate choice when you find yourself creating a lot of classes which are identical except they deal with different types (i.e. int, float, double, user-defined types)
  • 2 C++ keywords: template and typename
  • See also Function Templates which allow you to parameterize the parameters and return types of functions

Terminology

  • Class Template - a template from which classes are generated 
template <typename T>
class Foo
{
    ...
};
  • Template Class - a class generated from a class template 
Foo<int> foo_int

Defining Class Templates

  • Class templates and their methods are normally defined within header files, such that they can be used by multiple source files
  • Here's an example of a class template List
  • The keyword class can be substituted for the keyword typename with no change in meaning (see below) 
template <typename T>              // same as: template <class T> 
class List 
{
    private:

        const int m_maxsize;

        T m_value[100];
        int m_size;


    public:

        // CREATORS

        List() : 
            m_maxsize(100)
            ,m_size(0)
        { }

        List(const T& t) : 
            m_maxsize(100)
            ,m_size(1)
        {
            m_value[m_size-1] = t;
        }

        List(const T& t[], int num) :
            m_maxsize(100)
            ;
 
        ~List();

        void Add(T& t) 
        { 
            if (m_size < m_maxsize)
            {
                m_value[m_size-1] = t; 

                m_size++;
            }
        }

        void Add(const T& t[], int num);

        const T& Max() const;
};

// CONSTRUCTOR (CREATOR)
template <typename T>
List<T>::List (const T& t[], int size)
{
    if (size > m_maxsize)
        return;

    m_size = size;

    for (int i=0; i< m_size; i++)
        m_value[i] = t[i];
}

template <typename T>
List<T>::~Clist ()
{
    std::cout << "List Destructor" << std::endl;
}

template <typename T>
void List<T>::Add (const T& t[], int num)
{
    if (m_size + size > m_maxsize)
        return;

    for (int i=0; i< size; i++)
    {
        m_Value[m_size-1] = t[i];
        m_size++;
    }
}

Class Template Instantiation

                              +-------------------+
                              | class template    |
                              +-------------------+
                                    |      |
                  +-----------------+      +--------------------+
                  | class template instantiation (compile time) |
                 \ /                                           \ /
             +-------------------------+    +-------------------------+
             | class template instance |    | class template instance |
             +-------------------------+    +-------------------------+
  • You can instantiate a class template with the following syntax 
#include<list.h>

int main (int argc, char** argv)
{
     List<int> cMyList;           // instantiate a List of int's

     MyList.Add(5);                     // instantiate List::Add<int>
}
  • At the point where a template function is first used, the appropriate function definition is generated and compiled

Class Template Specialization

  • Class Template Specializations allows you to explicitly define a class template instance.
  • This is useful when the implicit instance would not give the desired result or would have been highly ineffecient 
//
// a trivial incomplete example
// - class template specialization for type double
//
template <>
class List<double>
{
    private:

        const int m_maxsize;

        double m_value[100];
        int m_size;


    public:

        // CREATORS

        List() : 
            m_maxsize(100)
            ,m_size(0)
        { }

        // ...
};

// CONSTRUCTOR (CREATOR)
template <>
List<T>::List (const double& t[], int size)
{
    if (size > m_maxsize)
        return;

    m_size = size;

    for (int i=0; i< m_size; i++)
        m_value[i] = t[i];
}

Templates and Static Variables

  • Each instantiation of a class template has its own copy of member static variables

Virtual Template Functions

  • C++ does not allow virtual template functions 
template <typename T>
class Foo
{
    public:

        virtual void moo (T& t)     // a virtual template function - not allowed
        {
            ...
        }
};
