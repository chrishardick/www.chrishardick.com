Python: Context Managers

  • Context Managers allow you to easily allocate and release resources.
  • This is how Python supports RAII (Resource Allocation is Initialization)
  • This is accomplished via the with statement as is frequently used with file streams and locks
A File Stream example: 
with open ('filename', 'w') as file
    file.write ("Hello, World!")

file = open ('filename', 'w')

# equivalent without using with statement
try:
    file.write("Hello, World!")
finally:
    file.close()
A Lock example: 
with some_lock:
    # do something


# equivalent without using with statement
some_lock.acquire()
try:
    # do something
finally:
    some_lock.release()

Implementing a Context Manager as a Class

  • To use the with statement in user defined objects, you need to define __enter__() and __exit__() methods.
  • The with statement will cause the object's constructor (__init__()) to be called immediately followed by the object's __enter__() method
  • When you leave the block, the __exit__() method will automatically be called.
  • __exit__() accepts three arguments - type, value, and traceback - they are used for exception handling. I.e. if an exception occurs within the block, the exception type, value and traceback will be passed into __exit__()
  • If __exit__() returns True, it signals to the Python run-time environment that the exception was gracefully handled. Otherwise, the exception will be unhandled.
  • In the example below, None is implicitly returned. Therefore, if an exception occurred, it would not be handled. 
class File(object):
    def __init__(self, filename):
        print "__init__"
        self.filename = filename
        self.file = open(filename, 'w')

    def __enter__(self):
        print "__enter__"
        return self

    def write (self, s):
        self.file.write(s)

    def __exit__(self, type, value, traceback):
        print "__leave__"
        self.file.close()
