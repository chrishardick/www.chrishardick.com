Python: Context Managers

  • Context Managers allow you to easily allocate and release resources.
  • This is how Python supports RAII (Resource Allocation is Initialization)
  • It is accomplished via the with statement as is frequently used with file streams and locks
A File Stream example: 
with open ('filename', 'w') as file
    file.write ("Hello, World!")


# equivalent without using with statement
# - NOTE: there is a finally block, but no except block. Hence the exception 
#       is not caught - at least not at this level in the call stack. In 
#       this case, the finally statement is [always] executed (irregardless 
#       of an exception occurring). However, if the exception is not caught
#       higher up the call stack, the exception will remain unhandled and 
#       the program will terminate.
file = open ('filename', 'w')
try:
    file.write("Hello, World!")
finally:
    file.close()
A Lock example: 
with some_lock:
    # do something


# equivalent without using with statement
some_lock.acquire()
try:
    # do something
finally:
    some_lock.release()

Implementing a Context Manager as a User Defined Class

  • To use the with statement with user defined objects, the following two methods need to be defined:
    • __enter__()
    • __leave__()
  • When execution enters the block, the object's constructor (__init__()) will be called
  • The constructor will be immediately followed by the object's __enter__() method
  • Upon leaving the block, the __exit__() method will automatically be called.
  • __exit__() accepts three arguments - type, value, and traceback - which are used for exception handling. If an exception occurs within the block, the exception type, value and traceback will be passed into __exit__()
  • If __exit__() returns True, it signals to the Python run-time environment that the exception was gracefully handled. Otherwise, the exception will be unhandled.
  • In the example below, None is implicitly returned. Therefore, if an exception occurred, it would not be handled. 
# Here is an example which can be helpful when designing unit tests for methods which invoke the subprocess module

import sys

#
# define context manager class
#

class MyContextManager():

    # constructor
    def __init__(self):
        print ("MyContextManager::init (CONSTRUCTOR) called")

    def __enter__(self):
        print ("MyContextManager::enter called")

    def __exit__(self, exc_type, exc_value, traceback):
        print ("MyContextManager::exit called")


#
# use context manager class
#

with MyContextManager():
    foo()
