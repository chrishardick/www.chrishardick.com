Arithmetic

  • Bash supports integer arithmetic, floating point arithmetic is not supported.
  • The shell interprets words surrounded by $(( and )) as arithmetic expressions. Variables in arithmetic expressions do not need to be preceded by dollar signs, although doing so is not an error.
  • Arithmetic expressions are NOT evaluated inside of single quotes

Declaring Integer Variables

Bash allows you to declare integer variables with the following syntax: 

declare -i IntegerVariable
This allows you to explicitly state that a variable is to hold integer values. Any expression which is assigned to an integer variable is assumed to be arithmetic. For example: 
declare -i Integer

x=2+5
Integer=2+5

echo "x = $x"
echo "Integer = $Integer"

Produces the following output:
x = 2+5
Integer = 7
You can also force an expression to be arithmetic using the 'let' statement. 'let' causes the expression following the assignment to be interpreted as an arithmetic expression. For example: 
let AVariable=5+2

echo "AVariable = $AVariable"

Produces the following output:
AVariable = 7
