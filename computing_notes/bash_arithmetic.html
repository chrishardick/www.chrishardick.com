Bash: Arithmetic

  • Bash supports integer arithmetic
  • Bash does NOT support floating point arithmetic
  • The shell interprets expressions surrounded by double parenthesis ((...)) as arithmetic expressions.
  • If you prefix the double parenthesis with a dollar sign ($), its output will be produced. Otherwise, only the arithmetic will be performed - with no output.
  • Variables in arithmetic expressions do not need to be preceded by dollar signs, although doing so is not an error.
  • Arithmetic expressions are NOT evaluated inside of single quotes 
i=5

((i+1))         # performs arithmetic - no output

echo ${i}       # prints 6

echo $((i+1))   # prints 7 - perform arithmetic and produce output

Declaring Integer Variables

Bash allows you to declare integer variables with the following syntax: 

declare -i IntegerVariable
This allows you to explicitly state that a variable is to hold integer values. Any expression which is assigned to an integer variable is assumed to be arithmetic. For example: 
declare -i Integer

x=2+5
Integer=2+5

echo "x = $x"                   # produces: x = 2+5
echo "Integer = $Integer"       # produces: Integer = 7
You can also force an expression to be arithmetic using the 'let' statement. 'let' causes the expression following the assignment to be interpreted as an arithmetic expression. For example: 
let AVariable=5+2

echo "AVariable = $AVariable"

Produces the following output:
AVariable = 7
