display

  • specifies the type of box used for a given HTML element
  • Valid values:
    • none - the element will not be displayed. Frequently used in conjunction with javascript to allow an element to appear/disappear
    • block - display element as a block element. Block elements implicitly have a break added before and after the element. Examples include h1, h2, p. div is a block element in which browsers do not implicitly add any other style.
    • inline - display element as an inline element. Inline elements do not have an implicit break before and after the element. Examples include strong, em, a. span is an inline element in which browsers do not implicitly add any other style.

  • Valid values:
      left right

overflow

  • what happens if the content overflows an elements box.
  • Valid values:
    • visible - the default value. The overflow is not clipped. It renders outside the element's box.
    • hidden - the overflow is clipped. Clipped content will not be invisible
    • scroll - the overflow is clipped, but a scroll bar is added allowing the user to see the clipped content
    • auto - if the overflow is clipped, a scroll bar will be added allowing the user to see the clipped content

white-space

  • determines how whitespace inside an element is handled.
  • Valid values:
    • normal - sequences of whitespace are collapsed. Newlines are handled the same as other whitespace. Lines are broken as nessary
    • nowrap - collapse whitespace as normal, but suppress newlines (implicit and explicit)
    • pre - sequences of whitespace are preserved. Lines are broken at explicit newline characters and at <br> elements
    • pre-wrap - sequences of whtespace are preserved. Lines are broken at explicit newline characters, at <br>, and as necessary
    • pre-line - sequences of whitespace are collapsed. Lines are broken at newline characters, at <br>, and as necessary
