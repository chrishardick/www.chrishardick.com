Swift - Introduction

  • A compiled (not interpreted) language

main.swift File

  • Special file which can have executabe code outside any function body
  • It is this code which runs when your program starts
  • Xcode also allows you to create playgrounds
  • A playground file is similar to a main.swift file in that executable code can be placed at the top level of file (outside of any function body)

Comments

  • Both C and C++ style comments are allowed

Statements

  • Semi-colons are not nessary unless you're trying to put multiple statements on a single line

Files and Modules

  • A module can consist of one or multiple files
  • The files within a module can all see other automatically
  • A module cannot see another module without an import statement 
    import UIKit
