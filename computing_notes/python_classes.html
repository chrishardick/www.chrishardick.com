Python: Classes

  • Unlike other languages (e.g. C++, etc.), Pythnon does not support different levels of access to variables. All class members are public
  • Per class variables are declared within the class definition and are referenced by using the class name as a prefix (e.g. Class.num_instances in the example below)
  • Per instance variables should be declared within the __init__() method.
  • Note that instance variables can be defined in other class methods. However, doing so probably makes your code less readable. It probably also makes the code more complex, as you need to ensure the method which defined the members is called prior to the members being accessed.
  • Unused objects are cleaned up via garbage collection. Objects are cleaned up when their reference count goes to 0 (zero)
  • self
    • Unlike C++, you must use self to reference an object methods and data members from its methods
    • self must be explicitly defined as the 1st parameter of every class method - including __init__().
    • You do not need to explicitly pass self when you call an object method, it will implicitly passed for you.
    • It's worth noting that self need not be named self, it's only by convention 
# class definition

class Class():
    '''a demonstrative class'''

    # class variables go here
    
    num_instances = 0
    num_foo_calls = 0

    #==========
    # __init__()
    # 
    # - constructor
    # - Python does not support multiple constructors, but you can define default parameters
    #  
    #==========
    def __init__(self,val=0):         # __init__() is the constructor

        # instance variables go here

        print "Class constructor called. val=", val

        self.i = val

        Class.num_instances += 1

    def bar(self):

        print "bar!"


    def foo(self):

        self.i += 1

        self.bar()

# class instantiation

a = Class(100)
b = Class(200)
c = Class(300)

print "a.i=", a.i
print "b.i=", b.i
print "c.i=", c.i

a.foo()

print "a.i=", a.i

print "# class instances: ", Class.num_instances
print "# foo calls:, Class.num_foo_calls

Inheritance

  • All methods are virtual
  • Multiple base classes are supported
  • Constructors of base classes are not implicitly called for you.
