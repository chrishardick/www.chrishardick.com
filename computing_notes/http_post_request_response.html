HTTP - POST Request/Response

  • POST requests are used to send data to a web server
  • Similar to PUT requests. Except PUT requests are idempotent (i.e. invoking it once or multiple times results in the same effect)
  • Multiple POST requests may or may not be idempotent. I.e. you could be updating the same database records or each request could create a database record

REQUEST

POST /update.py HTTP/1.1
Host: www.chrishardick.com
Content-Type: application/x-www-form-urlencoded
Content-Length: 27

field1=value1&field2=value2

RESPONSE

HTTP/1.1 200 OK
Date: Wed, 10 Apr 2019 12:56:51 GMT
Content-Length: 88
Content-Type: text/html
Connection: Closed

<html>
<body>
<h1>Hello, World!</h1>
</body>
</html>
