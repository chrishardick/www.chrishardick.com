Java: Dates and Times

  • Java does not have a built in Date class, but you can import the java.time package
  • The LocalDate class represents a date (year, month, day)
  • The LocalDate class represents a date (year, month, day)
  • The LocalDateTime class represents both a date and a time
  • The DateTimeFormatter allows you to display and parse date and time objects

LocalDate

import java.time.LocalDate;

...
LocalDate lclDate = LocalDate.now();    // create a LocalDate object set to the current date
System.out.println(lclDate);            // print current date

LocalTime

import java.time.LocalTime;

...
LocalTime lclTime = LocalTime.now();    // create a LocalTime object set to the current time
System.out.println(lclTime);            // print current time

LocalDateTime

import java.time.LocalDateTime;

...
LocalDateTime lclDateTime = LocalDateTime.now();    // create a LocalDateTime object set to the current date and time
System.out.println(lclDateTime);                    // print the current date and time

DateTimeFormatter

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

...
LocalDateTime lclDateTime = LocalDateTime.now();    // create a LocalDateTime object set to the current date and time

System.out.println(lclDateTime);                    // print the current date and time - unformatted


DateTimeFormatter dtFormat = DateTimeFormatter.ofPattern("dd-MM-yyyy HH:mm:ss");

String formattedDateTime = lclDateTime.format(dtFormat);

System.out.println(formattedDateTime)               // print the current date and time - formatted
