Vim Introduction

  • Fundamentally, Vim has different modes.
  • Normal Mode - this is the default mode and allows for navigation, etc. Press the Esc key to enter normal mode. From normal mode, you can switch to Insert and Comand Modes
  • Insert Mode - used to insert text. From Normal mode, press i to enter insert mode. When in insert mode, -- INSERT -- will be displayed on the bottom left of the screen
  • Command Mode - used to save, save and exit, etc. From normal mode, you can switch to command mode by pressing :

Command Mode Commands

  • :x - save and exit. will save changes to the file and exit
  • :q - quit. Will only work if you have not made any changes to the file
  • :q! - quit without saving. Any changes made to the file since last saving it will be lost
  • :w - save changes.
  • :/<search text> - search for the specified text. Use n to find the next match and p to find the previous match (both from Normal mode)
  • :set number - display line numbers
  • :set nonumber - do not display line numbers
  • :<line-number> - go to specified line number. Use $ to go to the last line

Normal Mode Commands

  • u - undo the last command - probably the most important command for new users!
  • 0 - go to the beginning of the current line
  • $ - go to the end of the current line
  • yy - copy the current line to the clipboard
  • p - paste the clipboard comments to the current position

Split Window Mode

  • Split window mode splits the screen in two allowing you to view/edit two files at once, or two locations of the same file at once
  • Use :sp [file] to enter split window mode
  • Once you're in split window mode, you can use CTRL-W up-arrow and CTRL-W down-arrow to switch between windows
  • You can use CTRL-W +5 or any number you'd like to increase the size of the current window by 5 lines
