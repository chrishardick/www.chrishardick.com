Redis Commands

Generic Key Management

  • DEL: delete a key
  • EXISTS: check if a key exists
  • EXPIRE: set a time-to-live timeout on a key
  • TTL: return the remaining time-to-live of a key
  • SCAN: iterate through keys without blocking the server

Strings (Text and Numbers)

  • SET: store a key/value pair
  • GET: retrieve the value of the given key
  • MGET: retrieve the value of multiple keys at once
    • You should be careful when using MGET to request large amounts of data at once
    • Fetching keys in batches is a great way to cut down on network round-trip times, asking for too many keys can create bottlenecks for the server
    • Fundamentally, Redis is single threaded. Asking for a large amount of keys at once, can cause other requests to be blocked and timeouts to occur
  • INCR, DECR: atomically increment or decrement an integer value. If key does not exist, 0 be stored. If the value is not an integer, an error will be returned.
