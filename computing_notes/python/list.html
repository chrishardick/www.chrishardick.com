List

    days = ['Sunday','Monday','Tuesday','Wednesday','Thursday','Friday','Saturday']
  • Similar to a vector in C++ -- I believe look-up is in constant time
  • A list is written as a list of comma separated values between square brackets
  • You can access individual elements via indexing (square brackets). Lists are indexed from 0 (zero) 
    days[3]='Humpday'
  • You can get the length of a list using the len function. 
    print len(days)    # would print out 7

List methods

  • list.append(x) - add an item (or items) to the end of the list
  • list.clear() - remove all items from list
  • list.insert(i,x) - insert an item (or items) to the list at position i. All subsequent items are moved down
  • list.remove(x) - remove the 1st item from the list whose value is x
  • list.pop([i]) - remove the item at the specified position in the list and return it. i defaults to the last item in the list
