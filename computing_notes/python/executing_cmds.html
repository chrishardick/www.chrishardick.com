Executing Commands

Executing External Commands

  • subprocess module 
    import subprocess
  • run the command specified by args, returning the process return code 
    subprocess.call(args, stdin=None,stdout=None,stderr=None,shell=False)

# e.g.
print subprocess.call(["echo" "hello, world!"])

# produces
0
  • run the command specified by args, returning its output as a byte string 
    subprocess.check_output(args, stdin=None,stderr=None,shell=False,universal_newlines=False)

# e.g.
print subprocess.call(["echo" "hello, world!"])

# produces
hello, world!
