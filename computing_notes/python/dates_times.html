Dates & Times

  • Python supports naive and aware date, time and datetime objects. The former do not have timezone information set, the latter does.

class datetime.datetime

  • attributes:
    • year
    • month -- 1-12
    • day - 1 - # days in the month
    • hour - 0-23
    • minute - 0-59
    • second - 0-59
    • microsecond 0 - 999,999
    • tzinfo -- instance of tzinfo subclass
  • Constructors:
    • datetime.datetime(year,month,day[,hour[,minute[,second[,microsecond[,tzinfo]]]]])
    • datetime.today() - return datetime object loaded with current date/time with tzinfo equal to None
    • datetime.now(tz) - return datetime object with tzinfo info -- not covered
    • datetime.utcnow() - return datetime object loaded with current UTC date/time with tzinfo equal to None
    • datetime.fromtimestamp(timestamp,tz) - where timestamp is seconds since epoch - as returned from time.time(). If tz is None or not specified, the returned datetime will be in the platform's local date/time and the datetime is naive (tzinfo is not set)
    • datetime.utcfromtimestamp(timestamp) - where timestamp is seconds since epoch - as returned from time.time()
    • datetime.strptime(date_string,format) - return datetime corresponding to date_string in specified format
  • Example(s): 
    import datetime

today = datetime.today()

dt = datetime.datetime.strptime(str,"%W %Y/%m/%d %H:%M:%S")

class datetime.timedelta

  • Constructor: datetime.timedelta([days[,seconds[,microseconds[,milliseconds[,minutes[,hours[,weeks]]]]]]])
  • Only days, seconds and microseconds are stored internally
  • Arguments may be integers or floats and may be positive or negative.
  • Example(s): 
    import datetime

dt = datetime.utcnow() - datetime.timedelta(hours=1)
