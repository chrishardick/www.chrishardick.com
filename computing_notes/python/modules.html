  • E.g. a library
  • The filename is the module name with the .py suffix
  • A module can contain executable statements as well as function definitions. The statements are intended to initialize module. They are executed only the 1st time the module is enountered in an import statement.
  • Each module has its own private symbol table
  • You can use the import statement to import a module.
  • Once you import a module, you can access the module's functions and global variables, by using the 'module.' prefix
  • Module Search Path
    • When a module is imported, the interpreter 1st searches for a built in module with the given name. If not found, it searches for the module in the directories listed in sys.path.
    • You may have to modify the contents of sys.path -- see example above
