Python

Introduction

  • Like most scripting languages, variables in Python are untyped
  • Unlike most computer languages, white space matters. Rather than using brackets to denote the beginning and end of control structures, functions, classes, etc. the body of the block in question is denoted via indention 
    if today == 'Wednesday':
    print "Today is Hump Day"
else:
    print "Today is ", today
  • Unlike most computer languages, noticeably missing are the semi-colons to denote the end of statements. Instead, the end of each statement is denoted by a newline
  • One of the criticisms of Perl was that once written, it was very hard to read -- which proved a barrier for new developers. The things that are different about Python (e.g. whitespace, newlines, etc), seem to address this criticism

    List

      days = ['Sunday','Monday','Tuesday','Wednesday','Thursday','Friday','Saturday']
    • Similar to a vector in C++ -- I believe look-up is in constant time
    • A list is written as a list of comma separated values between square brackets
    • You can access individual elements via indexing (square brackets). Lists are indexed from 0 (zero) 
      days[3]='Humpday'
    • You can get the length of a list using the len function. 
      print len(days)    # would print out 7

    List methods

    • list.append(x) - add an item (or items) to the end of the list
    • list.clear() - remove all items from list
    • list.insert(i,x) - insert an item (or items) to the list at position i. All subsequent items are moved down
    • list.remove(x) - remove the 1st item from the list whose value is x
    • list.pop([i]) - remove the item at the specified position in the list and return it. i defaults to the last item in the list

    Tuple

    • A tuple is an immutable sequence of objects
    • Similar to lists -- but immutable
    • Anytime you specify a comma separated list, you're defining a tuple. E.g. x = 1, 2, "abc", "def"
    • Optionally, you can surround the list with parenthesis. E.g. x = ( 1, 2, "abc", "def")
    • Empty tuple. E.g. x = ( )
    • A tuple with a single element -- you need to specify the comma. E.g. x = (1, )
    • You access individual elements the same way you access elements in lists (square brackets). Tuples (like lists) are indexed from 0 (zero)

    File Object Methods

    • read(size) - reads size bytes and returns a string. size is optional, if not specified, the entire file will be read. Will return empty string when EOF has been reached.
    • readline() - reads a single line from the file including the '\n'. In other words the new line will be present in the returned string.
    • For reading lines from a file, you can also loop over the file object. For example: 
      for foo in f:
    print foo
    • readlines() - similr to readline(), but will reads all lines of the file into a list.
    • Examples: 
      s = f.read(500)     # read next 500 bytes from file
t = f.read()        # read entire file
u = f.readline()    # read next line from file. returned string contains '\n'
v = f.readlines()   # read entire file. v will contain a list of all lines of the file
    • write(string) - write the specified string to a file 
      f.write ("Hello, World!\n")
    • close() - close a file. A good idea when you're done working with your file. frees up any resources taken up by the open file

    Regular Expressions

    • re module 
      import re

    meta characters

    • * - 0 or more of the preceding RE
    • + - 1 or more of the preceding RE
    • ? - 0 or 1 of the preceding RE
    • Greedy vs. Non-greedy - By default, '*', '+', '?' are greedy (longest match possible). Appending a ? after '*', '+', '?' produces a non-greedy match. E.g. '*?', '+?', '??'
    • (re) -- groups and saves matched text
    • a|b -- matches either a or b
    • {n} -- matches exactly n occurrences of the preceding expression
    • {n,} -- matches n or more occurrences of the preceding expression
    • {n,m} -- matches at least n and at most m occurrences of the preceding expression

    character classes

    • [abcd] -- matches a, b, c, or d
    • [^abcd] -- matches anything but a, b, c, d
    • [a-z] -- matches any lowercase character
    • [A-Z] -- matches any uppercase character
    • [0-9] -- matches a digit

if match:
    print match.group()         # "Cats are cool!" 
    print match.group(1)        # "Cats"
    print match.group(2)        # "cool!"
    print match.groups()        # ("Cats", "cool!")
else:
