Dynamic Programming

  • Dynamic Programming refers to optimizing an algorithm of a problem which has overlapping sub-problems.
  • Top-Down Dynamic Programming is an optimization (usually over recursion) in which repeated calls for the same input are cached - such that they do not need to be re-calculated.
  • This is also known as memoization
  • A typical example is computing factorials - in which we can cache results rather than re-calculating
  • Another example is calculating the fibonacci sequence using recursion and caching prior results
  • Calculating the fibonacci sequence using iteration (e.g. starting at fib(0) and iterating until fib(N)) is an example of Bottom-Up Dynamic Programming
