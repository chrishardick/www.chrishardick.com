Python: List

  • A dynamically sizing array (similar to a vector in C++)
  • A Python list is actually implemented as an array of pointers (using re-allocation) if additional size is necessary
  • A list in Python is denoted as comma separated list of values between square brackets
  • You can access individual elements via indexing (square brackets).
  • Lists are indexed from 0 (zero)
  • You can get the length of a list using the stand-alone len() function. 
# index:          0         1       2           3           4       5           6
days        = ['Sunday','Monday','Tuesday','Wednesday','Thursday','Friday','Saturday']
weekdays    = days[1:6]    # start:end - note that end is not included

print ("#days=%d" % (len(days)))                # 7
print ("#weekdays=%d" % (len(weekdays)))        # 5

list methods

  • list.append(x) - add an item (or items) to the end of the list
  • list.clear() - remove all items from list
  • list.insert(i,x) - insert an item (or items) to the list at position i. All subsequent items are moved down
  • list.remove(x) - remove the 1st item from the list whose value is x
  • list.pop([i]) - remove the item at the specified position in the list and return it. i defaults to the last item in the list
  • list.sort(reverse=True, key=Func) - sort the list, in-place - ascending by default. Reverse=True for descending. key is an optional sorting function. There is also a stand-alone function sorted - see below - which behaves similarly, but does not modify the original list. Instead, it returns a new list 
# a dictionary
dict_js = {
             "fname":       "John"
            ,"lname":       "Smith"
            ,"address":     "1 Smith Street"
            }

dict_jj = {
             "fname":       "Jane"
            ,"lname":       "Jones"
            ,"address":     "9 Jones Lane"
            }

# a list of dictionaries
lst = []
lst.append(dict_js)
lst.append(dict_jj)

#
# sorted() function
# - stand-alone function which returns a sorted list
# - similar to list.sort() noted above - which sorts in place
# - returns a sorted list of the specified iterable object
# - sorted(iterable, key=key, reverse=False)
# - key and reverse are same as for list.sort()
#

# sorting a list of objects
# - custom sort function
import operator
lst_srt = sorted(lst, key=operator.itemgetter('lname','fname')

# same thing - in place
lst.sort(key=operator.itemgetter('lname','fname'))


# sorting a list of dictionaries
# - custom sort function
lst_srt = sorted(lst, key=lambda x: (x['make'], x['model']))

# same thing - in place
lst.sort(key=lambda x: (x['make'], x['model']))

Sub-lists

# l[ix0:ixN] -- will create a list from index 0 thru indexN-1 of list l
# note the value at the beginning index is included, the value at the ending index is not
a = [1, 2, 3, 4, 5]

b = a[1:4]                  # [2, 3, 4]

Arrays

  • An array can be thought of a statically sized list
  • You can simulate an array in Python using the following syntax: array = [None] * 7 - which creates a list of None of size 7
