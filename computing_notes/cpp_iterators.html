C++ Iterators

  • In C++, an iterator is an object which has the ability to iterate through a range of elements in a container
  • There are 5 categories of iterators based on the functionality they support:
  • input iterator - reads elements sequentially
  • output iterator - writes elements sequentially
  • forward iterator - can move forward and read/write elements
  • bidirectional iterator - can move forward, backward and read/write elements
  • random access iterator - provides direct access to any element
  • input and output iterators are the most restricted.
  • forward iterators have all the functionality of input and output iterators
  • bidirectional iterators have all the functionality of forward iterators, but can also be iterated backwards
  • random access iterators have all the functionality of bidirectional iterators, but also have the ability to direcdtly access any element
