Binary Tree - Breadth First Traversal

  • Breadth First Traversal starts at the root and visits all nodes at the same depth before moving on to the nodes at the next depth level

Applications

  • Breadth First Traversal / Search is usually used to determine the shortest path between two nodes.
  • Examples include (albeit not binary trees, but the concept is the same): Social Networks (difference in depth between 2 individuals), GPS Navigation Systems, etc.

Algorithm

//
// breath first traversal is usually implemented with a queue
//
void breath_first_traversal (Node* head)
{
    std::list<Node*> q;

    if (!head)
        return;

    q.push_back(head);

    while (!q.empty())
    {
        Node* n = q.front();

        q.pop_front();

        // e.g. visit
        std::cout << n->value << " ";
    
        if (n->left)
            q.push_back(n->left);
        
        if (n->right)
            q.push_back(n->right);
    }
}
