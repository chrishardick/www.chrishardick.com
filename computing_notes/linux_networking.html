Linux - Networking

/etc/network/interfaces

  • man interfaces
  • Lines starting with # are ignored -- NOTE that end of line comments are not supported. Comments must be on their own line
  • Lines may extend across multiple lines by escaping the newline (making the last character a backslash (\))
  • Lines beginning with the word "auto" are used to identify the physical interfaces which are brought up when ifup is run with the -a option -- which is used when the machine boots up
  • There can be multiple auto lines. ifup brings up the named interfaces up in the order listed
  • Stanzas defining local interfaces start with a line consisting of the word "iface" followed by the name of the logical interface followed the the address family "inet" for TCP/IP, "inet6" for IPv6 networking. Following that is the name of the method used to configure the interface
  • Additional options can be given on subsequent lines in the stanza.
  • Options are indented for clarity -- but are not required to be. 
# bring up eth0 at boot-time
auto eth0

# static ip address
iface eth0 inet static
    address 192.168.1.6
    netmask 255.255.255.0
    gateway 192.168.1.1

# dhcp
auto eth1
allow-hotplug eth1
iface eth1 inet dhcp
