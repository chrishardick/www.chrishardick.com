Git

Configuration

  • ~/.gitconfig
  • ~/.gitignore_global

git init

  • Create git repository
  • git init [--bare]
  • Use the bare option to create a bare repository (as opposed to a working repository)
  • Central repositories should be created as bare repositories. Bare directories do not contain working (i.e. checked out) versions of the files. They also store the git revision history in the root folder rather than in the .git subdirectory. By convention, bare repositories are normally named with .git extension

git clone

  • git clone <url>
  • Clone repository (will make directory for you)
  • You will have one branch (master). run git branch to verify
  • You never want to work in the master branch -- you essentially want to treat it as read-only
  • Examples: 
    git clone ssh://john.smith@smith.com:[port]/dir

git remote [-v]

  • To see which remote servers you have configured, run git remote -- if you've cloned your repository, you should see at least origin. This will display the shortname for the remote server
  • Use the -v option to also see the actual URL of the remote server
  • To see which remote servers you have configured, run git remote

git remote add <remote_name> <url>

  • Add a new remote
  • git add remote blah chris@blah.com:[port]/dir
  • To see which remote servers you have configured, run git remote -- if you've cloned your repository, you should see at least origin. This will display the shortname for the remote server
  • Use the -v option to also see the actual URL of the remote server
  • To see which remote servers you have configured, run git remote

git checkout

  • Switch branches or restore working tree files
  • git checkout -b new_branch - create a new branch and switch to it
  • git checkout branch - switch to an existing branch
  • git checkout commit_hash - restore to previous commit - use git log for a list of commit hashes
  • Always create a branch rather than working in master. I.e. dev
  • Before switching branches, make sure all your changes are committed. If not, you will be warned that changes will be lost.
  • For example: git checkout -b dev

git branch

  • display a list of all branches

git status

  • display a list of all branches

Diffs

  • To get a list of files which changed 
    git diff --name-only tag_or_branch1 [tag_or_branch2]
  • Diff against master -- see handy script listed below 
    git difftool --extcmd="diff -w" --no-prompt master <file> >file.diff 2>&1

git add

  • mark files in which changes will be committed upon a git commit

git rm

  • remove files from the index and the working directory. History will remain as the file will remain in the object store

git commit

  • commit changes (marked via git add) to the local repository

Updating Remote Repositories

  • BEFORE ATTEMPTING TO UPDATE REMOTE BRANCHES, ALL CHANGES MUST HAVE 1ST BEEN COMMITTED TO THE LOCAL REPOSITORY DEVELOPMENT BRANCH(ES)

Bring Local Master Up-to-Date

  • this is only necessary if the remote master branch is ahead of our local master branch
  • git checkout master # make master the current branch (Make sure all your changes have been committed to local development branches (otherwise you will not be permitted to switch branches)
  • git pull origin master # bring local master up-to-date with remote repo

Merge Changes -- Development Branch

  • git checkout <branch> # e.g. dev. switch to your development branch
  • git rebase master # merge changes into your dev branch

Merge Changes -- Master Branch

  • git checkout master; # switch to master branch
  • git merge <branch>

Push Changes to Remote Repository

  • git push [origin master]
  • specify origin master for 1st push

Show History

  • git log [-p] - lists commits in reverse chronological order. -p shows diffs

Appendix

  • Handy diff script -- mygitdiff.sh 
    for file in $@
do
    if [ -f ${file}.diff ]; then
        cmd="mv ${file}.diff ${file}.diff.sav.`date +%Y%m%d%H%M%S`"
        echo "${cmd}"
        echo ""
        $cmd
    fi

echo "==================================================" >$file.diff
date                                                      >>$file.diff
echo ""                                                   >>$file.diff
echo "$file.diff"                                         >>$file.diff
echo ""                                                   >>$file.diff
echo "DIR: $PWD"                                          >>$file.diff
echo ""                                                   >>$file.diff
echo "OUTPUT BY ${0}"                                     >>$file.diff
echo ""                                                   >>$file.diff
echo "==================================================" >>$file.diff
echo ""                                                   >>$file.diff

git difftool --extcmd="diff -w" --no-prompt master $file >>$file.diff 2>&1
done
