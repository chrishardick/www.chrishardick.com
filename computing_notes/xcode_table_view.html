Xcode - Table View

  • UITableView - class designed to display a scrolling list of items. It must be added to an existing scene.
  • A Table View Controller (UITableViewController (a subclass of UIViewController) is a full scene. It includes both tht table view and the view controller that manages it.
  • You can configure a table view to display static data (supplied in the storyboard) or dynamic data (programmatically supplied).

Adding a Table View Scene to your Storyboard

  • Open the main storyboard (Main.storyboard)
  • In the Object Library, find the Table View Controller object
  • Drag a Table View Controller object on to the canvas. If you drag it to the wrong spot, you can move it by clicking and dragging the rectangle on top of it.
  • You should now have an additional scene.
