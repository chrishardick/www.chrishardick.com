CSS - Table Properties

Borders

  • table, th, td {border: 1px solid black;} /* double border */

border-collapse

  • Use the border-collapse property to set whether or not table borders should be collapsed into a single border
  • table { border-collapse: collapse;}

Borders

  • border: 1px solid black;

text-align

  • Sets the horizontal alignment (left, right, center) for the contents of <th> and <td> elements.
  • Values: left, right, center, justify
  • Default value: center (<th> elements), left (<td> elements)

vertical-align

  • Sets the vertical alignment (top, bottom, middle) for the contents of <th> and <td> elements.
  • Values: top, bottom, middle.
  • See text properties for more values
  • Default value: middle

border-bottom

  • e.g. 1px solid #ddd

:hover

  • Dynamically style of elements in which the mouse point is currently hovering over
  • e.g. tr:hover background-color: #f5f5f5

:nth-child(even|odd)

  • For striped tables, use nth-child()
  • e.g. tr:nth-child(even) background-color: #f2f2f2

background-color & color

  • e.g. th {background-color: black; color: white;}

Responsive Tables

  • To have tables display a scrollbar if they do not fit, surround the table with a <div> element with style="overflow-x:auto;"
  • e.g. th {background-color: black; color: white;}
