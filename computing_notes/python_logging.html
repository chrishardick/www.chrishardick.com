Python: Logging

  • logging module

Quick Start

import logging

# init logging

logging.basicConfig (   filename=logfile
                        ,level=logging.INFO     # logging threshold level. everything info or above will be logged (debug will not be logged)
                        ,format='%(asctime)s %(process)s:%(thread)s %(filename)s:%(lineno)s %(levelname)s %(funcName)s %(message)s')


# logging examples

logging.debug ("%s, %s",s1,s2)
logging.info ("%s, %s",s1,s2)
logging.warning ("%s",s)
logging.error ("%s",s)
logging.critical ("%s",s)

Basic Classes

  • Loggers - expose the interface which application code uses
  • Handlers - send log records to the appropriate destination
  • Filters - filter out which log records to output
  • Formatters - specify the layout of log records in the final output

logging.Logger Objects

Logger: Attributes and Methods

Logger.propagate

  • If true, logging events will be passed to the handlers of higher level (ancestor) loggers in addition to any handlers attached to this logger
  • Events will be passed directly to the ancestor logger handlers without considering filters or levels
  • Default value - True

Logger.setLevel(level)

  • Set threshold for this logger to level
  • Log messages which are less severe than level will be ignored
  • Default value - NOTSET
  • Level - Numeric value
  • CRITICAL 50
  • ERROR 40
  • WARNING 30
  • INFO 20
  • DEBUG 10
  • NOTSET 0

Logger.debug(msg, *args, **kwargs)

  • Log a message with level DEBUG on this logger

Logger.info(msg, *args, **kwargs)

  • Log a message with level INFO on this logger

Logger.warning(msg, *args, **kwargs)

  • Log a message with level WARNING on this logger

Logger.error(msg, *args, **kwargs)

  • Log a message with level ERROR on this logger

Logger.critical(msg, *args, **kwargs)

  • Log a message with level CRITICAL on this logger
