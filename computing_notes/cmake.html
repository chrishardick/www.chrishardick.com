CMake

  • A Makefile generator
  • Useful when the build process becomes too complicated - i.e. programs need to built across several platforms, etc.

Basic Procedure

  • Create CMake configuration file - CMakeLists.txt - see examples below
  • Execute cmake .
  • Execute make
  • Executable or Libary should be built

Hello, World!

  • Create file CMakeLists.txt in your project directory with the following contents: 
    cmake_minimum_required(VERSION 3.0.0)
project (hello_world)
add_executable (hello_world main.cpp)
  • Execute cmake .
  • Execute make
  • Execute ./hello_world

Multiple Source, Standard Include Directory

  • Create file CMakeLists.txt in your project directory with the following contents: 
    cmake_minimum_required(VERSION 3.0.0)
project (exec_name)

include_directories(include)

file (GLOB SOURCES "src/*.cpp")

add_executable (exec_name ${SOURCES})
  • Execute cmake . - must be re-run after each change
  • Execute make
  • Execute ./exec_name

Static Library

  • Create file CMakeLists.txt in your project directory with the following contents: 
    cmake_minimum_required(VERSION 3.0.0)
project (lib_name)
set (CMAKE_BUILD_TYPE Release)

include_directories(include)

file (GLOB SOURCES "src/*.cpp")

add_library (lib_name ${SOURCES})
  • Execute cmake . - must be re-run after each change
  • Execute make
  • Execute ./exec_name

Linking With a Static Library

  • Create file CMakeLists.txt in your project directory with the following contents: 
    cmake_minimum_required(VERSION 3.0.0)
project (executable_name)

set (PROJECT_LINK_LIBS libch.a)
link_directories (/cmake/lib)

include_directories (~/cmake/lib/include)

add_executable (executable_name main.cpp)
target_link_libraries (executable_name ${PROJECT_LINK_LIBS})
  • Execute cmake . - must be re-run after each change
  • Execute make
  • Execute ./exec_name

Installing CMake

apt-get install cmake
