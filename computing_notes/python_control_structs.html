Python: Control Structures

Truth

The following are considered False

  • False
  • None
  • Any numeric value with equates to 0 (zero). E.g. 0
  • A string (or any other sequence) with length 0. e.g. '' (zero length string), [] (empty list), () (empty tuple)
  • An empty dictionary
  • An empty set
  • An instance of a user-defined class in which the class defines a __nonzero__() or __len__() method and the method returns the integer 0 (zero) or the boolean False

All other values are considered True

Conditionals

  • The syntax in Python is different than other programming languages. Notably missing are parenthesis and like most definitions in Python, the statement ends with a colon (:) 
    i = 5
if i == 5:
    print "i equals 5"
elif i == 6: 
    print "i equals 6"
else:
    print "i equals ", i

  • For both while and for loops, Python provides the familiar break and continue statements to break out of a loop or skip the remaining processing of the current loop iteration and continue with the next loop iteration, respectively
  • Python also supports a pass statement which is used when a statement is required, but you do not want a command to execute. It is a null operation

break, continue and pass

  • continue -- just like in C. Terminate the current loop iteration and resume execution at the beginning of the loop
