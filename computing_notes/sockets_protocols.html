Sockets - Protocols

  • an agreement as to how two entities are going to communicate across a computer network
  • There are many different types of protocols
    • datalink layer protocols (i.e. ethernet protocol)
    • network layer protocols (i.e. IP)
    • transport layer protocols (i.e. TCP and UDP)
    • application layer protocols
