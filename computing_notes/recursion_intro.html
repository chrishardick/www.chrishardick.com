Recursion

  • Recursion - defining a problem in terms of itself
  • Recursion can be a powerful tool when writing algorithms
  • Recursion works because it saves part of the problem in the progam's call stack
For example, let's solve the problem of "find your way home" as the following:
  • If you're home, you're done!
  • Take one step torward home
  • "find your way home"
  • Base Case (when you stop)
  • Work toward Base Case - make the problem simpler. E.g. divide list in 2, etc.
  • Recursive Call (call ourselves)

Well Known Examples

  • Fibonacci Sequence - F(i) = F(i-1) + F(i-2) 
# python example

# add_numbers (1,2,3,4) 
# results in the following call stack:

# add_numbers (1,2,3,4)
#   return add_numbers (1,2,7)
#       return add_numbers (1,9)
#           return 10

def add_numbers(*args):

    v = list(args)      # tuple to list

    l = len(v)

    if l == 2:            # base case

        return (v[0] + v[1])

    elif l > 2:           # work toward base case

        x = v[l-1] + v[l-2]

        v.pop()
        v.pop()

        return (add_numbers (x,*v))     # *v expands the list to individual parameters


    raise RuntimeError ("Invalid Length")

# call stack:
# factorial(5)
#   return 5*factorial(4)
#       return 4*factorial(3)
#           return 3*factorial(2)
#               return 2*factorial(1)
#                   return 1*factorial(0)
#                       return 1

def factorial(n):

    if (n==0)
        return 1

    return n*factorial(n-1)
