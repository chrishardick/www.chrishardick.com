Python: HTMLParser

  • The HTMLParser class allows you to parse HTML and XHTML files
  • HTMLParser is defined in module html.parser.
  • A HTMLParser instance is fed HTML data and calls handler methods when start tags, end tags, text, comments and other markup elements are encountered. The user should subclass HTMLParser and override its method to implement the desired behavior 
from html.parser import HTMLParser

class FooHTMLParser (HTMLParser):

    def handle_starttag (self, tag, attrs):
        print ("START TAG - %s" % (tag))

    def handle_endtag (self, tag)
        print ("END TAG - %s" % (tag))

    def handle_data (self, data):
        print ("DATA: %s" % data)

parser = FooHTMLParser()

parser.feed ('<html><head><title>Test</title></head><body><h1>HEADING!</h1></body></html>')
Produces the following output: 
START TAG - html
START TAG - head
START TAG - title
DATA: Test
END TAG - title
END TAG - head
START TAG - body
START TAG - h1
DATA: HEADING!
END TAG - h1
END TAG - body
END TAG - html
