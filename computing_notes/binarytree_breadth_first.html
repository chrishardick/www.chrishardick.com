Binary Trees - Breadth First Traversal and Search

Applications

  • Breadth First Traversal / Search is usually used to determine the shortest path between two nodes.
  • Examples include (albeit not binary trees, but the concept is the same): Social Networks (difference in depth between 2 individuals), GPS Navigation Systems, etc.

Breadth First Traversal (BFT)

  • BFT starts at the root and visits all nodes at the same depth before moving on to the nodes at the next depth level

Algorithm

//
// breath first traversal is usually implemented iteratively with a queue
//
void bft (Node* head)
{
    std::list<Node*> q;

    if (!head)
        return;

    q.push_back(head);

    while (!q.empty())
    {
        Node* n = q.front();

        q.pop_front();

        // e.g. visit
        std::cout << n->value << " ";
    
        if (n->left)
            q.push_back(n->left);
        
        if (n->right)
            q.push_back(n->right);
    }
}

Breadth First Search (BFS)

  • BFS starts at the root and visits all nodes at the same depth before moving on to the nodes at the next depth level until the target value is found

Algorithm

//
// bfs is usually implemented iteratively with a queue of queues
//
std::list<Node*> bfs (Node* head, int value)
{
    std::list<std::list<Node*>> path_q;

    if (!head)
        return std::list<Node*>

    std::list<Node*> p;
    p.push_back(head);

    path_q.push_back(p);

    while (!path_q.empty())
    {
        std::list<Node*> path = q.front();

        q.pop_front();

        Node* nn = path.back();

        if (nn->value == value)
        {
            // found target. return path
            return path;
        }

        if (nn->left)
        {
            std::list<Node> p_left = path;

            p_left.push_back(nn>left);

            path_q.push_back(p_left);
        }

        if (nn->right)
        {
            std::list<Node> p_right = p;

            p_right.push_back(nn>right);

            path_q.push_back(p_right);
        }
    }

    // if here, path not found

    return std::list<Node*>
}
