Java: Packages

  • In Java, a package is used to group related classes
  • Remember that each class in Java needs to be defined in a file with a matching name
  • You can place all files of a package in the same directory
  • In the files of the package, you need to use the package keyword to specify the files are part of the package
  • In the calling code, you can then use the import statement to import the entire package or a single class e.g. import package.name.* to import the entire package or import package.name.ClassName to import a single class
  • There are Built-in Packages and User-Defined Packages

Built-in Packages

  • The Java API is a library of packages and classes included in the Java Development Environment
  • The complete list of available packages and classes can be found at https://docs.oracle.com/javase/23/docs/api" - as of this writing 23 was the latest version. Alter the URL if you're interested in a different version

User-Defined Packages - An Example

  • Let's say we have two related classes Foo and Bar
  • Since they're related, we want to put them in the same package - package foobar
  • At the top of both Foo.java and Bar.java we use the package keyword
  • Let's say they're in the foobar directory
  • You can import the entire package via import foobar.* or you can import individual classes import foobar.Foo 
// foo.java

package foobar;

public class Foo
{
    // constructor
    public Foo()
    {
    }
}

// bar.java

package foobar;

public class Bar
{
    // constructor
    public Bar()
    {
    }
}
