Java: Packages

  • Similar to a namespace in C++
  • Library > Package > Classes
  • I.e. the Java API is a library. It contains multiple packages. Each package contains classes

import

  • import package_name.Class; // import a single class
  • import package_name.*; // import the entire package 
import java.util.Scanner;       // import Scanner class

import java.util.*              // import all classes in java.util
