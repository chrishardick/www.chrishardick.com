CSS - Font Properties

font-family

  • Values: font-family list [serif, sans-serif, monospace, cursive, fantasy, specific font name]
  • serif
  • sans-serif
  • monospace
  • cursive
  • fantasy
  • Times

font-weight

  • Values: lighter, normal, bold, bolder, ligher
  • lighter
  • normal
  • bold

font-size

  • Values: xx-small, x-small, small, medium, large, x-large, xx-large, smaller, larger, <length>, <percentage>
  • xx-small

  • medium
  • large
  • x-large
  • xx-large
  • smaller
  • larger

font-style

  • Values: italic, oblique (slanted only), normal
  • Default value: normal
  • italic
  • oblique

font-variant

  • Values: normal, small-caps
  • Default value: normal
