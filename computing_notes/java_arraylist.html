Java: ArrayList

  • ArrayList is a resizable array
  • It's found in the java.util package
  • To append an element to an ArrayList use the add(E element) method. There is also another version of add(int index, E element) which allows you to specify a location. This version inserts the element at the specified location and shifts the element at that location (if any) and all subsequent locations by one to the right
  • To access an element in an ArrayList use the get() method
  • To modify an element in an ArrayList use the set() method
  • To remove an element from an ArrayList use the remove() method
  • To clear all elements from an ArrayList use the clear() method
  • To find out how many elements are in an ArrayList use the size() method
  • Elements in an ArrayList must be objects. You cannot have an ArrayList of primitives. You can have an ArrayList of the equivalent wrapper class 
import java.util.ArrayList;

ArrayList<Integer> int_list = new ArrayList<Integer>();

// assigning values
int_list.add(0);
int_list.add(1);
int_list.add(2);
int_list.add(3);

int_list.add(0,4);

System.out.println (int_list);          // [4,0,1,2,3]
System.out.println (int_list.get(0));   // 4
System.out.println (int_list.size()));  // 5

for (int i = 0; i < int_list.size(); i++)
{
    System.out.println ("element " + i + " = " + int_list.get(i));
}

int_list.set(0,5);

System.out.println (int_list);          // [5,0,1,2,3]

for (Integer i : int_list)
{
    System.out.println(i);
}

int_list.remove(0);

System.out.println (int_list);          // [0,1,2,3]
System.out.println (int_list.size()));  // 4

int_list.clear();

System.out.println (int_list);          // []
System.out.println (int_list.size()));  // 0

Copying Arrays

  • The System.arraycopy() method allows you to efficiently copy data from one array to another 
public static void arraycopy (Object src        // in:      source array
                            ,int srcPos         // in:      starting position
                            ,Object dest        // in/out:  destination array
                            ,int destPos        // in:      destination position
                            ,int length         // in:      # of elements to copy
