PostgreSQL: Data Types

Data Type Description
BOOL, BOOLEAN true, false. Implicit conversions are also done. E.g. 1, yes, y, t are converted to true. 0, no, n are converted to false
CHAR(n) Fixed length, space padded character field. If you insert a longer string, PostgreSQL will return an error.
VARCHAR(n) Variable length character field. Not space padded. You cannot store more than n characters
TEXT Variable length character field with unlimited length
SMALLINT 2-byte signed integer. Range -32,768 to 32,767
INT 4-byte signed integer. Range -2,147,483,648 to 2,147,483,647
SERIAL The same as INT except that PostgreSQL will automatically populate values on inserts. Similar to AUTO_INCREMENT in MySQL
REAL or FLOAT8 a double precision (8 byte) floating point number
NUMERIC(precision, scale) a decimal floating point number where precision is the total number of digits and scale is the scale is the number of digits to the right of the decimal. e.g. 1234.567 - precision=7 and scale=3. Precision and scale are optional. If omitted, they default to the max values. Attempting to store a value with more digits to the right of the decimal point than the field allows will result in PostgreSQL rounding the value. Attempting to store a value with more total digits than the field allows will result in an error
DATE Stores date values only. Stored using 4 bytes. Use yyyy-mm-dd format.
TIME Stores time values only. Stored using 8 bytes. Use the following formats: hh:mm[.pppppp], hh:mm:ss[.pppppp], hhmmss[.pppppp]
TIMESTAMP Stores both date and time values. Stored using 8 bytes. Use format 'YYYY-MM-DD HH:MM:SS-pppppp'.
TIMESTAMPZ Stores both date and time values - timezone aware. Stored using 8 bytes. Value is stored in UTC. Use format 'YYYY-MM-DD HH:MM:SS-pppppp'.
INTERVAL Stores periods of time in years, months, days, hours, minutes, seconds, etc. Stored using 16 bytes.
UUID A Universally Unique Identifier. E.g. GUID (globally unique Identifier). A 128-bit (16 byte) value. A better alternative to SERIAL. PostgreSQL provides storage and comparision functions for UUID's, but does not include a function for generating UUID's. Usually written using 32 hexadecimal digits with 4 dashes (36 characters in total) e.g. 01234567-0123-0123-0123-012345678901.
ARRAY Used for storing arrays
