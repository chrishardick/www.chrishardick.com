Storage Classes

Regardless of the type, Sqlite stores your values using one of the following storage classes:
  • NULL - NULL value
  • INTEGER - signed integer
  • REAL - 8 bytes IEEE floating point
  • TEXT - text string using the database encoding (UTF-8, UTF-16BE or UTF-16LE)
  • BLOB - stored exactly as it was input

Datatypes

    Datatypes are more specific than storage classes
  • Datetimes are stored as either integers or reals. They're stored as integers so long as there is not a loss of precision. Otherwise, they're stored as reals

Date & Time Functions

  • date(timestring, modifier, modifier, ...) -- returns a date in the format YYYY-MM-DD
  • time(timestring, modifier, modifier, ...) -- returns a time in the format HH:MM:SS
  • datetime(timestring, modifier, modifier, ...) -- returns a datetime in the format YYYY-MM-DD HH:MM:SS
  • julianday(timestring, modifier, modifier, ...) -- returns the Julian day (# days since noon in Greenwich on November 24, 4714 B.C.
  • strftime(format string, timestring, modifier, modifier, ...) -- returns the date/time according to the format string

Format Strings

  • Format strings can be used with strftime()
  • a subset of ISO-8601 date and time formats
  • %Y year 0000-9999
  • %m month 01-12
  • %d day of month 00
  • %H hour 00-24
  • %M minute 00-59
  • %S seconds 00-59
  • %f fractional seconds SS.SSS
  • %j day of year -- 000-366
  • %J Julian day number
  • %s seconds since epoch
  • %w day of week 0-6 0 is Sunday
  • %W week of year 00-53

Time Strings

  • The following time string formats are supported:
  • YYYY-MM-DD
  • YYYY-MM-DD HH:MM
  • YYYY-MM-DD HH:MM:SS
  • YYYY-MM-DD HH:MM:SS.SSS
  • YYYY-MM-DDTHH:MM
  • YYYY-MM-DDTHH:MM:SS
  • YYYY-MM-DDTHH:MM:SS.SSS
  • HH:MM
  • HH:MM:SS
  • HH:MM:SS.SSS
  • HH:MM:SS.SSS
  • now -- UTC

Modifiers

  • Modifiers alter the date, time, or datetime. I.e. you can add or subtract days, minutes, etc.
  • Results will be normalized -- i.e. if the calculation results in an invalid date, the result will be normalized into a valid date
  • NNN days - add/subtract days
  • NNN hours - add/subtract hours
  • NNN minutes - add/subtract minutes
  • NNN.NNNN seconds - add/subtract seconds
  • NNN months - add/subtract months
  • NNN years - add/subtract years
  • start of month - reduce date to 1st of month
  • start of year - reduce date to 1st of year
  • start of day - reduce time to midnight
  • weekday N - advance date forward until the next given day (0=Sunday, 1=Monday, ...)
  • unixepoch - interpret the datetime as sec since UNIX epoch
  • localtime -- assumes the datetime is in UTC and adjusts it to localtime
  • utc -- assumes the datetime is in localtime and adjusts to UTC

Examples

  • SELECT date('now')
  • SELECT date('now', 'start of month', '+1 month' '-1 day')
  • SELECT datetime(1092941466,'unixepoch')
  • SELECT strftime('%s','now')
  • SELECT strftime('%s','now') - strftime('%s','20170210 18:12:00')
