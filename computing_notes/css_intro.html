CSS - Cascading Style Sheets

Introduction

  • HTML defines the content and structure of a document. CSS defines the presentation for a document (or set of documents)
  • One advantage of CSS is that it easily allows you to have the same formatting across an entire website and to easily change it.
  • There is also a lot of formatting which is only supported via CSS
  • CSS is intended for use by graphic designers.
