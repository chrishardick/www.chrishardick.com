Python: UUID (GUID)

  • UUID is an acronym for Universally Unique Identifier
  • GUID is an acronym for Globally Unique Identifier
  • 128 bit (16 byte) integer
  • 32 hex digits
  • usually represented using 36 characters. 32 alphanumeric characters and 4 hyphens in the following format
  • <8 hex digits>-<4 hex digits>-<4 hex digits>-<4 hex digits><12 hex digits>
