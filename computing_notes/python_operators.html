Arithmetic Operators

  • + - Addition
  • - - Subtraction
  • * - Multiplication
  • / - Division
  • % - Mod (modulus)
  • ** - Exponent
  • // - Floor division. Similar to integer division except if one of the operands is negative, the result is floored (rounded down -- towards negative infinity)

Comparison Operators

  • == - equal
  • != or <> - not equal
  • > - greater than
  • < - less than
  • ≥ - greater than or equal to
  • ≤ - less than or equal to

Assignment Operators

  • =
  • +=
  • -=
  • *=
  • /=
  • %=
  • **=
  • //=

Logical Operators

  • and - a short circuit operator. The 2nd operand is only evaluated if the first one is true.
  • or - a short circuit operator. The 2nd operand is only evaluated if the first one is false.
  • not

Bitwise Operators

  • & - binary AND
  • | - binary OR
  • ^ - exclusive OR
  • ~ - binary one's complement (reverses all bits)
  • << - binary left shift
  • >> - binary right shift

Membership Operators

test for ownership in a list, dictionary, etc. I.e. is the given value present in the list or not

  • in
  • not in

Identity Operators

Compares the memory location of two objects

  • is - true if two operands point to the same object. false otherwise
  • is not - true if the two operands do not point to the same object. false otherwise

Operator Precedence

From highest to lowest

  • ** (exponent)
  • ~ + - (unary operators - complement, +, -)
  • * / % // (multiply, divide, modulus, floor division)
  • + - (binary operators)
  • >> << (bit shift)
  • & (bitwise and)
  • ^ | (exclusive or regular bitwise OR)
  • ≤ < ≥ > (comparison operators)
  • == != <> (comparison operators for equivalence)
  • = %= /= //= -= += *= **= (assignment operators)
  • is, is not (identity operators)
  • in, not in (membership operators)
  • not or and (logical operators)
