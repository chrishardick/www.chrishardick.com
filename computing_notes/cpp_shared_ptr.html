C++ shared_ptr

  • Shared ownership of an object through a pointer
  • Several shared_ptr objects may own the same object
  • The object is destroyed and its memory deallocated when the last remaining shared_ptr which owns the object is destroyed, assigned another pointer via operator= or reset
  • A shared_ptr which does not own any objects is called empty

Constructors

  • Default Constructor
    • Create empty shared_ptr (no managed object) 
          std::shared_ptr<T>::shared_ptr()
  • Construct a shared_ptr with a managed object 
          std::shared_ptr<T>::shared_ptr(T*)
