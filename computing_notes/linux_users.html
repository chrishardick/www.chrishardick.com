  • Both adduser and addgroup share the same configuration file - /etc/adduser.conf

adduser

Add a Normal (Login) User

  • By default, each user is assigned to a group with the same name
  • By default, will create a home directory
  • By default, will copy files from SKEL into the home directory
  • Use --disabled-login option to create an account which is disabled until a password is set
  • Use --disabled-password option to create an account without a password, however login is possible (e.g. with SSH RSA keys) 
# run the following
# - you will then be prompted for questions about the user: password, etc.
adduser <username>

Add a System User

  • Group: By default, system users are placed in the nogroup group
  • Home Directory: A home directory is created by the same rules as for normal users
  • Login Shell: /bin/false - unless overridden via --shell option and will have logins disabled
  • Files from SKEL are not copied 
adduser --system --shell /usr/bin/git-shell git

Low Level Utilities - useradd, groupadd, usermod

#
# add the user 
# -M - do not create a home directory
# -s - shell (in this case, the user will not have a shell)
#
useradd -M -s /bin/false <username>

Delete User

userdel -r <username>
