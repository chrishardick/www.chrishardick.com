Client Side JavaScript - Window, Document and Element Objects

  • A web browser instance running on a client PC may contain several tabs. Each tab has its own Window object and can be thought of multiple browser instances.
  • The Window, Document & Event objets have event handler properties which allow you to specify functions to be envoked when events occur. Event handler functions begin with 'on.' E.g. onclick, onload, etc.

The window object

  • The window object is the global object -- i.e. its properties and methods are effectively globals.
  • You need not prefix window object properties & methods with window. You can for clarity, but it is not required.

window Object Properties

document Property

  • refers to the Document object which represents the content displayed in the window -- see below
  • has methods like getElementById() 
    var nav_element = document.getElementById("nav");

history Property

  • allows you to move thru the browser history

navigator Property

  • allows you to obtain browser vendor and version information

location Property

  • Refers to a Location object which represents the current URL and allows you to load a new URL.
  • Equivalent to the location property of the Document object 
    location = "www.chrishardick.com"

location = "www.chrishardick.com#id"

screen Property

  • allows you to query the size of the desktop

window Property

  • refers to itself

Methods

alert()

  • displays a message in a dialog box -- great for debugging!

confirm()

prompt()

onerror()

  • register a handler to be called when an uncaught JavaScript exception occurs

  • the onload() handler is triggered when the content of document has finished loading.

  • registers a function to be invoked repeatedly at a specified interval

setTimeout()

  • registers a function to be invoked after a specified number of milliseconds elapse 
    var rc = setInterval(update_clock, 1000 /* ms */);

Timers

/*
 * setTimeout
 *
 * schedules function f to run after ms milliseconds elapse
 * returns a value that can be passed to clearTimeout to cancel the scheduled execution
 * any additional arguments are passed to f
 */
setTimeout(f, ms, ...);

/*
 * setInterval
 *
 * schedules function f to run repeatedly at the specified interval (# ms)
 * returns a value that can be passed to clearTimeout to cancel the scheduled execution
 * any additional arguments are passed to f
 */
setInterval(f, ms, ...);

history Property

  • Refers to the History object for the window.
  • back() and forward() methods behave as the browser's back and forward buttons do.
  • go() accepts an argument and allows you to move forward (positive integer) or back (negative integer) in the browser history
  • If a window contains iframes, the browsing history of the child windows will be chronologically interleaved.

navigator Property

  • A Navigator object which contains browser vendor and version information.
  • appName -- property which contains the full name of the web browser
  • appVersion -- property which contains the version of the web browser
  • userAgent -- property which contains the browser sends in the USER-AGENT HTTP header
  • platform -- property which identifies the OS/platform in which the browser is running
  • onLine -- property which specifies whether the browser is currently connected to the network
  • geolocation -- a Geolocation object for determining the user's geographical location.

screen Property

  • A Screen object that provides information about the size of the user's display (# pixels) and the number of colors available on it.
  • height and width properties specify the size of the physical display in pixels
  • availWidth and availHeight properties specify the size in pixels that is available to the browser. They exclude space occupied by widgets the browser cannot occupy -- i.e. the taskbar, etc.
  • The colorDepth property specifies the # of bits per pixels

Dialog Boxes

  • The alert() method displays a [usually] modal dialog box with the specified text string (not HTML) and an OK button
  • The confirm() method displays a modal dialog box with the specified text string (not HTML) -- with OK or Cancel buttons. It returns a boolean.
  • The prompt() method displays a modal dialog box with the specified text string (not HTML). It allows the user to enter a string. It returns the string.
  • The showModalDialog() method displays a HTML formatted modal dialog box. The 1st parameter is the URL. The additional paramters are beyond the scope of this document.

Document Elements as Window Properties

  • document elements which specify an id attribute -- so long as it does not conflict with a pre-existing Window object property -- becomes a non-enumerable property of the Window object whose name is the value of the id attribute whose value is the HTMLElement object that represents the element. However -- for all of the same reasons to avoid global variables -- it's a better idea to use var foo = document.getElementById(id) to access the given element.

document Property

  • The document property refers to a Document object which represents the current document being displayed
  • See Document object below.

Misc Properties and Methods

  • onload
    • an event handler. it is called when the content of the document has been displayed
  • write("abc")
    • write text to the window

document object

  • Every window object has a document object which represents the content of the window.
  • Your gateway to the DOM (Document Object Model)
  • Client-side JS usually manipulates one or more elements of the DOM.
  • In order to manipulate the elements, they first must be accessed
    • Via id attribute
    • Via name attribute
    • Via tag name -- i.e. select all h1 tags
    • Via specified CSS class
    • Via CSS selector
  • The Document Object has a property named 'cookie'
  • Window->Document>cookie
  • cookie is a string property which allows you to create, modify and delete the cookie(s) that apply to the current page

The document Object Methods

getElementById()

  • ID attributes must be unique per document.
  • Always selects at most one element 
    var clock = document.getElementById("clock");

getElementsByName()

  • The original purpose of the name attribute was to name CGI form elements such that the server could parse incoming message.
  • However, you can also select elements of a document by name.
  • Keep in mind that name values need not be unique 
    /*
 * returns a NodeList object (array like object)
 * - the elements are in document order
 */
var items = document.getElementsByName("breakfast_items");

setTimeout()

  • registers a function to be invoked after a specified amount of time 
    var rc = setTimeout(function() { alert("Hello, World!"); }, 2000 /* ms */);

// cancel execution of scheduled function
clearTimeout(rc);

getElementsByTagName()

    /*
 * returns a NodeList object (array like object)
 * - the elements are in document order
 * - tag names are not case sensitive
 * - supports wildcard "*" to return all elements of the document
 */
var sub_headings = document.getElementsByTagName("h2");

var h2_1 = document.getElementsByTagName("h2")[0];

var all_elements = document.getElementsByTagName("*");
  • the Element class also defines a method by the same name (getElementsByTagName). However, it only selects elements that are descendants of the given element
