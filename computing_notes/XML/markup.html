XML Markup

I. Elements

  • Element Names
    • Element Names must follow the rules of XML names - which apply for element names, attribute names, etc
    • XML names can contain alphanumeric characters, hyphens, underscrores and periods.
    • XML names are case sensitive

    Container Elements

      <name attribute1 attribute2 ... > 
content
...
</name>

<p>paragraph text</p>
    • Container elements may contain elements, character data, or both
    • <name> - element start tag
    • </name> - element end tag

    Empty Elements

    <name attribute1 attribute2 ... /> 

<link rel="stylesheet" type="text/css" href="http://www.chrishardick.com/default.css" media="all" />

II. Attributes

  • Attributes define properties of elements
  • Attributes are placed within element start tags
  • name="value"
  • Either single (') or double (") quotation marks may be used (so long as they match)
  • There is no limit to the number of attributes you can have, so long as no two attributes for the same element have the same name 
    <!-- invalid xml --> 
<p class="warn" class="caution">

III. Entities

1. Entity References

  • Entity references - do just that, they refer to the entity
  • Syntax - an ampersand (&) followed by the entity name and a semi-colon (;)
    • &gt;

2. Character Entities

  • Refer to a single character

    • Predefined Character Entities

    • Some characters cannot be used in an XML document because they have special meaning (i.e. < >, etc.)
    • The XML Specification provides the following predefined character entities, so that you can easily express these characters
      • EntityValue
      amp &
      apos '
      lt <
      gt >
      quot "

    Numeric Character Entities

    • XML supports Unicode - which defines 10,000+ different characters
    • &# unicode # (decimal format) ;
    • &#x unicode # (hexadecimal format) ;

    Named Character Entities

    • Numeric character references are hard to remember
    • You have to declare named character entities
