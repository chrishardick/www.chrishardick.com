Xcode - Action (Event ⮕ Method)

  • An action links an event on a UI widget to an object method in source code.
  • When the event occurs, the method will be called

To Create an Action

  • In a class (usually a ViewController class), usually at the bottom, add the following comment - if not already there (this will give you a target for your control-drag) 
    //MARK: Actions
  • In the storyboard, select a UI Object
  • Control-drag from the Storyboard Object to the line right below the newly added comment
  • In the dialog which appears, for Connection, select Action
  • For Name, enter an appropriate name
  • For Type, select the appropriate type
  • Click Connect to create the action - similar to below 
    @IBAction func setFoo(_ sender: UIButton) // sender: the UI Object responsible for triggering the action
{
}
  • sender is the object responsible for triggering the action
  • The IBAction attribute indicates that the method is an action which connects from the storyboard in the Interface Builder
