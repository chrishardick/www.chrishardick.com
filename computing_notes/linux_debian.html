Linux - Debian

Debian Packages

  • Frequently used debian packages
  • apt-get update - update packages lists to get information on the latest versions and their dependencies
  • apt-get upgrade - will instll newer versions of any packages you have (useful when installing a new system)
  • Use apt-get install <pkg> to install
Package Notes
apache2 Apache HTTP Server
git git
inotify-tools inotify-tools - includes inotifywait which allows you to wait for changes to files using inotify
ipset IP sets - used by iptables to store IP addresses, port numbers, IP and MAC address pairs
iptables-persistent Package to save firewall rules and have them automatically applied at boot time
net-tools ifconfig. However, ifconfig has been deprecated. try ip a
openssh-server ssh server
python-netaddr Python - manipulation of various network address notations. E.g. is a given IP address part of a given sub-net
python-tz Python version of the Olson timezone database
sqlite3 SQLite 3
tcpdump Network Packet Analyzer
vim Vim

Change System Timezone

dpkg-reconfigure tzdata
Curses based program to change system timezone.
