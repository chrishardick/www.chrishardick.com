mDNS

  • Multicast DNS
  • Resolves host names to IP addresses within small networks without a name server

Protocol Overview

  • mDNS client needs to resolve a host name, it sends out an IP multicast query asking the host with the given name to identify itself
  • mDNS server (target machine) multicasts a message which includes its IP address
  • All machines in the subnet can then update their mDNS cache
  • Any host can relinquish its host name by sending a response packed with a TTL equal to zero
  • By default, mDNS only resolves host names ending with the .local top level domain (TLD)
  • A mDNS message is a multicast UDP packet send to IPv4 address 224.0.0.251 port 5353

Implementations

  • Linux - Avahi daemon
  • Apple - Bonjour

Avahi

mDNS Across Multiple Subnets

# install avahi package and utilities
apt-get install avahi-daemon avahi-utils 

# configure avahi
# - eth0,eth1,eth2,eth3 should be changed to match your interface names
edit /etc/avahi/avahi-daemon.conf and make the following changes:

[server]
allow-intefaces=eth0,eth1,eth2,eth3

[reflector]
enable-reflector=yes


# restart avahi 
systemctl restart avahi-daemon
