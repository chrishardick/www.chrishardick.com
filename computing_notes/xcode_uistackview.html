Xcode - UIStackView

  • Allows you to layout a collection of views in either a column or a row
  • Allows you to leverage the power of Auto Layout which lets you to create user interfaces which dynamically adapt to the device orientation, screen size, or any change in available space.
  • Manages the layout of all the views in its arrangedSubViews property (array)
  • The views are displayed in the order they appear in the array and are arranged along the stack view's axis
  • the exact layout varies depending on the stack view's axis, distribution, alignment, spacing, etc.

Declaration

class UIStackView : UIView
