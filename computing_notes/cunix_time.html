C/UNIX: DATES & TIMES

Definitions

Start of the Epoch
Midnight GMT (a.k.a UTC-Coordinated Universal Time) of January 1st, 1970. All times in UNIX are ultimately measured as seconds since the Start of the Epoch. NOTE: MS-DOS Programs Use 1980.
time_t
Datatype large enough to contain dates & times. Defined in time.h 
struct tm
{
         int         tm_sec;          /** Seconds (0-61) to allow for leap second or double leap second) **/
         int         tm_min;          /** Minute (0-59) **/
         int         tm_hour;         /** Hour (0-23) **/
         int         tm_mday;         /** Day of Month (1-31) **/
         int         tm_mon;          /** Month of Year (0-11) **/
         int         tm_year;         /** Years Since 1900 **/
         int         tm_wday;         /** Day of Week (0-6) 0 -> Sunday) **/
         int         tm_yday;         /** Day of Year (0-365) **/
         int         tm_isdst;        /** Daylight Savings in Effect **/
};

Y2K & UNIX

32 Bit UNIX Machines will have a problem with Y2K in 2038 (GMT 03:14:07, Tuesday, January 19, 2038 - to be exact). They will run out of time.

Functions

FOR # OF SECONDS TO ELAPSE SINCE THE START OF THE EPOCH

	#include <time.h›

	time_t	time	(time_t* tloc);

		Returns the # of Seconds since Start of the Epoch.  If you pass
		a time_t ptr (instead of NULL), it will also fill the variable
		with the same value.

GET # OF SECONDS TO ELAPSE BETWEEN 2 TIMES

	#include <time.h›
	
	double	difftime (time_t time1, time_t time2);

SEPERATE time_t INTO STRUCTURE OF INDIVIDUAL ELEMENTS

	#include <time.h›
	
	struct tm* gmtime (const time_t time);

	NOTE: Returns Time in GMT

SAME AS gmtime - EXCEPT CONVERT TO THE USER'S LOCAL TIME

	#include <time.h›
	
	struct tm* localtime (const time_t* time);

	NOTE: Exactly the same as gmtime, except converts for user's local time & day-light savings.

tm structure -> time_t

  • converts the broken down (struct) time - expressed in local time into a time_t (sec since start of epoch)
  • the original values of tm_wday & tm_yday are ignored
  • the original values of the other struct members are not restricted to their normal values
  • local time zone info of the tm struct are set (as though mktime() called tzset()
  • on error, mktime() returns -1 
	#include <time.h›
	
	time_t mktime (struct tm* timeptr);

	NOTE: Will return -1 if unable to convert.

CONVERSION TO STRINGS

	#include <time.h›

	char* asctime (const struct tim* timeptr);
	char* ctime   (const time_t*     timeptr);

	NOTE: Both functions always return a Fixed Format (26 characters long including NULL Ptr)

	e.g. Sun Jun 16 12:30:43 2001\n\0
