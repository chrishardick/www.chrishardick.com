Mac - Parallels

  • Parallels allows you to install a virtual machine

Networking

Shared Network

  • Shared Network allowes your virtual machine to share the host machine's internet connection and local network access seemlessly.
  • Parallels acts as avirtual router
  • The virtual machine gets its own IP address on a private virtual subnet

Sharing Data

  • Directories on your Mac which are shared can be found mounted at /media/psf on the virtual machine
