Content Area

width

  • Specify the width of the content area
  • Values: auto, <length>, <percentage>
  • Default value: auto
  • Applies to: block-level and replaced elements

height

  • Specify the height of the content area
  • Values: auto, <length>
  • Default value: auto
  • Applies to: block-level and replaced elements

Padding

  • The space immediately around the content area
  • Background extends into the padding, but not the margins

padding

    padding: 10px;
padding 5px 10px;
padding 5px 10px 15px 20px;
  • Values: <length>, <percentage>
  • Default value: not defined
  • Applies to: all elements
  • Negative values are not allowed

Borders

  • Borders surround the padding of an element

border-style

    p {border-style: solid;}
  • If you do not specify a border style, the other border properties will have no effect.
  • Values: solid, dotted, dashed, none, hidden

border-width

    p {border-style: solid; border-width: 5px; }
  • border-width can be set via the border-width property

border-color

border

  • allows you to set all border properties in a single declaration
  • property order: border-width, border-style, border-color 
    border: 20px solid red;
  • you can also specify separate values for each side: 
    border-bottom: 20px solid red;
border-top: 20px solid red;
border-left: 20px solid red;
border-right: 20px solid red;

border-radius

  • allows you to add rounded corners
  • border-radius: 1-4 lengths
  • if 1 length is specified, the value is used for all 4 corners
  • if 2 lengths are specified, top-left/bottom-right top-right/bottom-left
  • if 3 lengths are specified, top-left top-right/bottom-left bottom-right
  • if 4 lengths are specified, top-left top-right bottom-right bottom-left

    border_radius: 5px;

    border_radius: 5px 10px;

    border_radius: 5px 10px 15px;

    border_radius: 5px 10px 15px 20px;

Margins

  • The margin is the area surrounding the borders
  • The background does not extend into the margins

margin

margin: 5px 10px 15px 20px; /* top, right, bottom, left */
margin: 5px 10px 15px; /* top, right/left, bottom */
margin: 5px 10px; /* top/bottom, right/left */
  • Default value: 0
  • NOTE: negative values are allowed

Box Sizing

  • specifies whether or not padding and border should be included in the element's total width and height

box-sizing

  • border-box - the given elements should have padding and border included in the elements total width and height
