CSS - Cursor Properties

cursor

  • Specifies the mouse cursor to be displayed when hovering over an element
  • Hover over the value cell for demonstration
ValueDescription
autodefault value (the browser will choose the proper cursor)
defaultThe default cursor
noneNo Cursor
context-menuIndicates a context menu is available
helpIndicates help is available
pointerIndicates a clickable element
progressIndicates the program is busy
waitIndicates the program is busy
cellIndicates the element is a cell which may be selected
crosshairCrosshair cursor
textIndicates the text of the element may be selected
vertical-textIndicates vertical-text which may be selected
aliasIndicates an alias of something is to be created
copyIndicates something is to be copied
moveIndicates the element can be moved
no-dropIndicates the dragged item cannot be dropped here
not-allowedIndicates the requested action will not be executed
all-scrollIndicates something can be scrolled in any direction
col-resizeIndicates the column can be resized horizontally
row-resizeIndicates the row can be resized vertically
n-resizeIndicates the top of the element can be moved up
e-resizeIndicates the right side of the element can be moved to the right
s-resizeIndicates the bottom of the element can be moved down
w-resizeIndicates the left side of the element can be moved left
ns-resizebidirectional resize cursor
ew-resizebidirectional resize cursor
ne-resizebidirectional resize cursor
nw-resizebidirectional resize cursor
se-resizebidirectional resize cursor
sw-resizebidirectional resize cursor
nesw-resizebidirectional resize cursor
nwse-resizebidirectional resize cursor
