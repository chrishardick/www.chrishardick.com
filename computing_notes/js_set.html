JavaScript - Set

  • The Set object allows you to perform the usual set operations

Instance Methods

  • Set.prototype.add(value) - add value to the Set object. Returns the Set with the added item
  • Set.prototype.delete(value) - remove value from he Set object. Returns a boolean as to whether or not the item was successfully removed or not.
  • Set.prototype.has(value) - returns a boolean as to whether or not value is present in the Set object Returns a boolean as to whether or not the item was successfully removed or not.
  • Set.prototype.clear() - remove all items from the Set objecdt

Instance Properties

  • Set.prototype.size - returns the number of values in the Set object

Basic Usage

let set1 = new Set();

set1.add(1);
set1.add(2)
set1.add("hello, world!");

const obj = {a: 1, b: 2};
set1.add(obj);

set1.size;      // 5

set1.has(2);    // true
set1.delete(2);

Iterating Over the Set

for (let i of set1)
{
    console.log(i);
}

Set Intersection

let set_intersection = new Set(set1.filter(x=>set2.has(x)));

Set Difference

let set_difference = new Set(set1.filter(x=>!set2.has(x)));
