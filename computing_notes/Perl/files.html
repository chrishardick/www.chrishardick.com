PERL - FILES

OPEN A FILEHANDLE

  • a filehandle is another datatype in Perl 
    open (FH,"filename");   # open file for reading
open (FH,"<filename");  # open file for reading (a little more explicit)
open (FH,">filename");  # create file & open for writing
open (FH,">>filename");  # open file for appending
