PERL - SCOPE/LIFETIME

AUTOMATIC VARIABLES: my

  • my is an operator which declares variables to be automatic (same as in C/C++) -- they're automatically allocated & deallocated @ scope entry & exit
  • automatic variables have block scope & lifetime. They only exist (and are visible) w/i the innermost enclosing block, subroutine, eval or file
  • automatic variables are also called lexical scoped variables
  • if not initialized @ time of declaration, scalers are initialized to undef, arrays & hashes are empty
  • Examples: 
    my ($a $b $c) = @_
my @array
my %hash

PACKAGES

  • a package is a namespace
  • there is always a 'current package'
  • by default, you're in the package 'main'
  • @ anytime, you can switch the current package by using the package declaration 
    package chris;

MODULES

  • allows for re-usability in Perl. e.g. you define a module w/ functions that you want to call from other files
  • to import a module (functions & variables) into your file use the 'use' declaration 
    use HTML; # import the HTML interface (this is an interface that I made w/ some helpful fxns)
  • a package which is entirely contained w/i one file
  • the file name is the module name
  • the file extension is .pm (perl module)
