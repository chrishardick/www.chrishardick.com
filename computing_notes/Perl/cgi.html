PERL - CGI MODULE

  • http://search.cpan.org/dist/CGI.pm/
  • CGI.PM supports both object oriented and function oriented programming

Object Oriented Programming w/ CGI.PM

  • With OOP, you create one or more CGI objects and use object methods to create elements of the page

Function Oriented Programming w/ CGI.PM

  • With Procedural (function) Oriented Programming, there is only 1 CGI object which you rarely deal with directly.
  • You import a set of functions (usually the standard functions) into the namespace 
    use CTI qw/:standard/;
  • You simply call functions
  • No need to instantiate a CGI object
  • There is only 1 CGI @ a time
