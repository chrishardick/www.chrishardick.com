Swift - Operatorss

!
Negation operator (unary). false to true and vice-versa
&&
Logical and (binary). Returns true only if both operands are true. false otherwise. Short-circuit evaluation is perfomed. I.e. If the first operand is false, the second operand is not evaluated.
||
Logical or (binary). Returns true if either operand is true. false otherwise. Short-circuit evaluation is performed. I.e. if the first operand is true, the second operand is not evaluated.
