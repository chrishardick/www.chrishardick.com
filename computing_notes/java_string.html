String methods

  • length()
  • toUpperCase()
  • toLowerCase()
  • indexOf() - returns the index of the 1st occurrence of the specified text in the string
  • concat() - concatenate specified string returning the resultant string 
String s = "Hello, World!";

System.out.println ("s.length=" + s.length());
System.out.println ("s.indexOf(\"W\")=" + s.indexOf("W"));      // 7

String ss = s.concat(" Welcome Everyone!");
