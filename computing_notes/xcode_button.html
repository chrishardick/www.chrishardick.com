Xcode - Buttons

Adding a Button

  • In the Object Library, type 'button' in the filter field
  • Drag a Button object on to your scene.
  • Double click the button and or use the Attributes Inspector to add text for your button

Create a Button Click Action

  • An action links an event on a UI widget to a method in your code. An action is also called an action method.
  • At the bottom of the ViewController class in the ViewController.swift file, add the following (if not already there): 
    //MARK: Actions
  • In the storyboard, select the button
  • Control-drag the button in the storyboard to the view controller file right below the comment
  • In the pop-up which appears, enter the following:
    • Connection: Action
    • Object: View Controller
    • Name: enter an appropriate name - e.g. fooButtonClick
    • Type: UIButton
  • Let's start by adding a adding a line of trace which will print out when the user clicks on the button 
    print ("fooButtonClicked")
