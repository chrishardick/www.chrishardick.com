Java: Hello, World!

// HelloWorld.java

public class HelloWorld
{
    public static void main (String[] args)
    {
        System.out.println("Hello, World!");
    }
}
  • javac HelloWorld.java - this will produce a bytecode file HelloWorld.class
  • java HelloWorld - this will start the Java Runtime Environment (JRE), loads the specified class (HelloWorld) and calls the main() method on the class - which must be declard public and static
