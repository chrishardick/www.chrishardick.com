C++ map

  • Associative, ordered containers which hold key value pairs
  • Associative - elements are referenced by their key
  • Ordered - elements are ordered
  • Unique Keys 
#include <map>

template < class Key
            ,class T
            ,class Compare = less<Key>
            > class map;

typedef pair<const Key, T> value_type;

Constructors

map <Key, T> m;

  • Default Constructor
  • Creates a map with no elements (size = 0)

Destructor (~map())

  • destruct each element and destruct the container

Member Functions

pair<iterator, bool> insert(const valiue_type& val)

  • insert elements into the container
  • see also operator[]
  • Return Value
  • pair.first - iterator pointing either to newly inserted element or element with equivalent key (if item was already present in map)
  • pair.second - whether or not an item was added to the map

Common Operations

Insertion

map<int,string> my_map;

my_map[1] = "chris";
my_map[2] = "hardick";

Traversal

for (map<int,string>::const_iterator i = my_map.begin(); i != my_map.end(); i++)
{
    cout << "LHS=" << i->first << endl;
    cout << "RHS=" << i->second << endl;
}

Overloading < (Less Than Operator)

class Player
{
    public:
        
        std::string name;
        int score;

        Player ()
        {
            score = 0;
        }

        bool operator< (const Player& rhs) const
        {
            if (score < rhs.score)
                return true;

            if (score == rhs.score && name < rhs.name)
                return true;

            return false;
        }
};
