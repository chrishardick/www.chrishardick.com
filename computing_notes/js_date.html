JavaScript - Date Class

Constructors

  • new Date() -- initialized to current date and time.
  • new Date(milliseconds) -- as returned by getTime() -- number of milliseconds from minight January 1, 1970 (UTC)
  • new Date(datestring) -- in the format accepted by Date.parse()
  • new Date(year,month,day,hours,minutes,seconds,ms) -- only year and month are required. 4 digit year, month is from 0-11, day is from 1-31, hours is from 0-23, minutes is from 0-59, milliseconds is from 0-999

Methods

Most methods have two versions -- one that operates using localtime and one that operates using UTC.

  • get[UTC]Date() - return the day of the month for the given Date object
  • set[UTC]Date() set the day of the month in the given Date object
  • get[UTC]Day() - return the day of the week for the given Date object
  • get[UTC]FullYear() - return the four digit year for the given Date object
  • set[UTC]FullYear() - set the four digit year for the given Date object
  • get[UTC]Hours() - return the hours for the given Date object
  • set[UTC]Hours() - set the hours for the given Date object
  • get[UTC]Milliseconds() - return the milliseconds for the given Date object
  • set[UTC]Milliseconds() - set the milliseconds for the given Date object
  • get[UTC]Minutes() - return the minutes for the given Date object
  • set[UTC]Minutes() - set the minutes for the given Date object
  • get[UTC]Month() - return the minutes for the given Date object
  • set[UTC]Month() - set the minutes for the given Date object
  • get[UTC]Seconds() - return the seconds for the given Date object
  • set[UTC]Seconds() - set the seconds for the given Date object
  • getTime() - return the number of milliseconds from UNIX epoch for the given Date object
  • setTime() - set the number of milliseconds from UNIX epoch for the given Date object
  • getTimezoneOffset() - return the difference in minutes between the local and UTC representations of this date - takes DST into account
  • toLocaleDateString() - return a string that represents the date portion of the Date in local timezone using the local date formatting conventions.
  • toDateString() - return a string that represents the date portion of the Date in local timezone.
  • toLocaleTimeString() - return a string that represents the time portion of the Date in local timezone using the local date formatting conventions.
  • toTimeString() - return a string that represents the time portion of the Date in local timezone.
  • toLocaleString() - return a string that represents the date in local timezone using the local date formatting conventions.
  • toString() - return a string that represents the date in local timezone.
  • toUTCString() - return a string that represents the date in UTC timezone
  • toISOString() - return a string that represents the date in ISO-8601 format in UTC timezone
  • toJSON() - serializes a Date object using toISOString()
  • valueOf() - returns the internal millisecond format for the date (i.e. ms since UNIX epoch)

Static Methods

  • Date.now() - returns the current time, as milliseconds since the UNIX epoch.
  • Date.parse() - parses a string representation of a date and time and returns the internal millisecond format (ms since UNIX epoch).
  • Date.UTC() - returns the internal millisecond representation of the date and time (assumed to be in UTC timezone)
