HTTP - Cookies

  • A cookie is a small amount of data stored by the web browser and associated with a particular web site or web page
  • Cookies are implemented as part of the HTTP protocol
  • Cookies are usually transmitted from the server to the client via a HTTP header.
  • The client stores the cookie (either in memory, in a file or both -- dependant upon the value of 'expires')
  • All cookies associated with the particular web page are automatically transmitted from client to server
  • Each cookie has the following components
    • name
    • value
    • expires
      • optional. default = transient (it lasts until the user closes the browser)
      • specifing an expiration date, causes the browser to store the cookie in a local file
      • once the expiration date expires, the browser should no longer communicate the cookie to the server, and the file may be deleted
    • path
      • optional. default = the web page that created it and any other web page in the same directory or subdirectory
      • If you would like your cookie to be accessible to web pages in a higher directory on the same web server (i.e. / for all pages on the web server), you can specify a path (e.g. "/")
    • domain
      • optional. default = cookie is only accessible only to pages on the same web server
      • If you'd like your cookie to be accessible across multiple web servers (i.e. chris1.chrishardick.com and chris2.chrishardick.com), you can set your domain to .chrishardick.com
    • secure
      • optional. boolean. default = false
      • If a cookie is marked secure, it will only be transmitted when the browser and server are connected via HTTPS or another secure protocol
