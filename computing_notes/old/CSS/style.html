Adding Style To Your Documents

There are three ways in which you can add style to your HTML documents:

  1. External Style Sheets - <link> tag
  2. Embedded Style Sheets - <style> tag
  3. Inline Styles

1. External Style Sheets - <link> tag

    <link rel="stylesheet" type="text/css" href="default.css" media="all" />
  • External Style Sheets allow you to create a consistent look for an entire web site
  • Link elements must be placed inside the head element, but not inside any other element (i.e. title)
  • Attributes:
    • rel: relation - i.e. the type of link. In this case it's a stylesheet
    • type: further classification as to the type of the link. In this case we're defining the stylesheet as a CSS stylesheet. In the future, there may be many different types of stylesheets (i.e. XSL, etc.)
    • media: media in which the stylesheet should be applied. Valid values include: all (all mediums), handheld (handheld devices), print (print mediums including print preview, screen (screen mediums - usually a computer monitor), etc.
  • you can specify as many external style sheets as you like, the browser will load all style sheets combining the rules from each

2. Embedded Style Sheet - <style> tag

    <style type="text/css">

/* h1 style */
h1   {	
          color: gray;
     }

</style>
  • The <style> tag allows you to embed CSS rules directly in your HTML document
  • Style elements must be placed inside the head element - I've never seen them defined anywhere else
  • Allow you to create a style for a single web page which is different than the rest of the site
  • Attributes:
    • type attribute - required
    • media attribute

3. Inline Styles

    <p style="color=red;">This is red</p>
  • Inline styles are defined using the style attribute - which can be associated with any HTML tag inside the body
  • Inline styles are useful if you want to give a style to a single element without affecting any other elements
  • Should no longer be used. Deprecated by XHTML 1.1.
