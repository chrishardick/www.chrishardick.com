  • Separating Content from Presentation
  • XHTML defines the content
  • CSS defines the presentation (style)
  • Different presentation mediums can use different styles (but the content remains the same)
  • XHTML tags which violate this principle (i.e. define presentation rather than content) will soon be deprecated
    • font, br, b, i, etc.
