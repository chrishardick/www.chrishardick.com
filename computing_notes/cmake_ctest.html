CMake: CTest

  • CTest is a testing tool distributed as part of CMake

Basic Procedure

  • Add enable_testing command to your CMakeLists.txt
  • You can then use the add_test command to add tests to the project
  • Execute make test to execute all tests. Internally, this runs ctest. Therefore, you could also execute ctest from the binary directory 
# adds a build target 'test' which will execute all tests
enable_testing()

add_test(testname executable arg1 arg2 ...)
