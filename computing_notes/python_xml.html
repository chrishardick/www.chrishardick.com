Python: ElementTree XML API

  • The xml.etree.ElementTree module implements an API for parsing and creating XML data. 
import xml.etree.ElementTree as et

# parse a file
# - returns an ElementTree class
tree = et.parse('my_xml_file.xml')

# root is an Element object
# Element objects have:
# - tag 
# - dictionary of attributes
root = tree.getroot()

# similar - parse a string
root = et.fromstring(xml_string)

# root element has a tag
print root.tag)

# root element has a dictionary of attributes
print (root.attrib)

# root element has a list of child nodes (each one is an Element object)

ElementTree Objects

Element Objects

  • tag - the element type. I.e. a string identifying the type of data
  • attrib - dictionary containing the element attributes
  • get(key, default=None) - get the element attribute named key. Return the attribute value or default if the attribute was not found.
  • items() - return the element attributes as a sequence of (name,value) pairs
  • keys() - return the element names as a list
  • findall(match,namespaces=None) - return all matching subelements. Return a list containing all matching elements in document order. See below for usage examples

Element.findall Examples

# All top-level elements
Element.findall(".")

# All sub-elements on all levels beneath the current element
Element.findall("//")

# All 'egg' elements on all levels beneath the current element
Element.findall(".//egg")

# generates XML string
et.tostring(root)
