Python: ElementTree XML API

  • The xml.etree.ElementTree module implements an API for parsing and creating XML data.

String to Element Object

import xml.etree.ElementTree as et

# parse a file
tree = et.parse('my_xml_file.xml')

# root is an Element object
root = tree.getroot()

# similar - parse a string
