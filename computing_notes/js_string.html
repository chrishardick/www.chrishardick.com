JavaScript - Strings and Regular Expressions

Strings

  • A sequence of zero or more Unicode characters enclosed by single or double quotations
  • JavaScript strings (and arrays) are indexed from zero (0)
  • Integer to String Conversion
    • parseInt(string, radix)
    • A function which accepts a string and returns an integer in the specified base.
    • Radix (e.g. base) is an optional parameter. Valid values are from 2-36. It defaults to 10.
    • Only the first number of the string is returned
    • Leading and trailing spaces are ignored
    • If the 1st character cannot be converted to a number, NaN is returned
  • Concatenation
    • Built into the core JavaScript language is the ability to concatenate strings via the + operator 
      var s = "Hello" + " World"
  • Length
    • To determine the length of a string, use the length() method of the String class 
      var len_x = x.length();
  • Substrings
    • To extract a substring, use the substring() method of the String class 
      var s1 = x.substring(1,5);
    • To find the position of the first occurance of a substring use the indexOf() method of the String class 
      var pos = indexOf('W');
  • Unlike other languages if the backslash is followed by any character other than the ones noted in the above table, it's simply ignored
  • Escape Sequences
    SequenceInterpretation
    \0 NULL character
    \b Backspace
    \t Tab
    \n Newline
    \v Vertical tab
    \f Form Feed
    \r Carriage Return
    \" Double Quote
    \' Single Quote
    \\ Backslash
    \xXX Latin-1 character specified by hexadecimal # XX
    \uXXXX Unicode character specified by XXXX

Regular Expressions

  • JavaScript RegExp class represents regular expressions
  • JS is fairly consistient with Perl 
// creates a RegExp object
var reg_exp = /^Chris/;

// equivalent using RegExp() constructor
var reg_exp = new RegExp("^Chris");

String Methods Which Support Regular Expressions

  • search(reg-exp) accepts a regular expression and returns the either the character position of the of the 1st matching substring or -1 if no match. If the argument to search() is not a regular expression, it is 1st converted to one by calling the RegExp constructor. search() does not support global searches.
  • replace(reg-exp, string) accepts a regular expression and a string. replace() searches the string for the specified pattern. If found, it replaces the first match. If the g flag is specified, all instances all matches. If the first parameter is a string (rather than a reg-exp), replace() searches for the string literal rather than converting the specified string to a regular expression via the RegExp() constructor
