C++ Destructors

  • Basically, a function to destroy an instance of an object.
  • The name of a Destructor is ALWAYS the name of the class prefixed with a tilde (~). It CANNOT accept parameters (therefore it can't be overridden) and does not specify a return type
  • Every class has its own destructor. If you do not provide one, the C++ Compiler will provide a default destructor for you.
  • DATA MEMBERS which are of AUTOMATIC STORAGE CLASS are taken care of automatically; while dynamically allocated data members MUST be explicitly handled using the DELETE Operator.
  • You usually do not have to explicitly call the destructor. For OBJECTS of AUTOMATIC STORAGE CLASS, the destructor is called automatically when the object goes out of scope; while for dynamically allocated objects, the destructor is automatically called when the object's memory is deallocated using the DELETE Operator.
  • See also Inheritance for discussion on destructors and inheritance
  • See also Virtual Functions for discussion on why destructors should be virtual 
class Foo
{
    public:
        Foo () { }  // default constructor
        ~Foo () { } // destructor
};
