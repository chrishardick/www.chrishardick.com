Destructors

  • Basically, a function to destroy an instance of an object.
  • The NAME of a Destructor is ALWAYS the name of the Class prefixed with a tilde (~). It CANNOT Accept Parameters (therefore can't be overridden) & Always Has a void return type
  • Every class has its own destructor. If you do not provide one, the C++ Compiler will provide a DEFAULT DESTRUCTOR
  • DATA MEMBERS which are of AUTOMATIC STORAGE CLASS are taken care of automatically; while dynamically allocated data members MUST be explicitly handled using the DELETE Operator.
  • YOU NEVER EXPLICITLY CALL THE DESTRUCTOR. For OBJECTS of AUTOMATIC STORAGE CLASS, the destructor is called automatically when the object goes out of scope; while for dynamically allocated objects, the destructor is automatically called when the object's memory is deallocated using the DELETE Operator.

  • See also Virtual Functions for discussion on why all destructors shhould be virtual
