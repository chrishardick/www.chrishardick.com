JavaScript - ES6

  • a.k.a. ECMAScript 6, ECMAScript 2015, JavaScript 6

let

  • let is a new keyword in ES6. It declares a variable with block scope
  • NOTE: variables declared with let are not hoisted 
var x = 10;

console.log ("x = " + x);       // 10 

{
    let x = 2;                  

    console.log ("x = " + x);   // 2 
}

console.log ("x = " + x)        // 10

const

  • const is a new keyword in ES6. Use it to create immutable variables
  • const is similar to let in that it is block-scoped
  • NOTE: variables declared with const are not hoisted

Import and Export

  • Use import and export to create reusable components

Promises

  • Promises are new to ES6
  • Promises are a method to write asynchronous code

Classes

  • Use the keyword class to define a class
  • Properties are assigned inside a constructor() method 
class Rectangle
{
    constructor(h,w)
    {
        this.h = h;
        this.w = w;
    }

    area()
    {
        return this.h*this.w;
    }
}

let rect = new Rectangle (5,10);
console.log ("Area = " + rect.area());

Default Parameter Values

  • ES6 supports default values for function parameters 
function sum (x, y=0)
{
    return x+y;
}

console.log ("sum=" + sum(5))   // will print 5

Arrow Functions

  • Arrow Functions are a short-hand syntax for writing functions.
  • It eliminates the function keyword
  • It can also eliminate the return statement and the curly brackets if the function is a single statement
  • Arrow functions are not hoisted. They must be defined before they are used.
  • Arrow functions do not have their own this. Hence, they are not well suited for defining object methods. 
const mult = (x, y) => x * y

console.log ("x = " + mult(5,10))
