Java: Classes

  • Java is a true object oriented programming language.
  • Every line of executable code must be inside a class
  • In Java, every class needs to be in a file whose name matches that of the class. E.g. class Foo must be defined in Foo.java
  • You can refer to classes defined within the same directory without using an import statement

Defining a Class

public class Foo
{
    public int d_x;
    public int d_y;
    public int d_z;

    // constructor
    public Foo(int x, int y, int z)
    {
        d_x = x;
        d_y = y;
        d_z = z;
    }

    public void setX(int x)
    {
        d_x = x;
    }

    public void setY(int y)
    {
        d_y = y;
    }

    public void setZ(int z)
    {
        d_z = z;
    }

    public int bar()
    {
        return d_x + d_y + d_z;
    }

Creating an Object

// f is a reference which points to the newly created Foo objecdt
Foo f = new Foo();

Access Modifiers - Classes

  • public - the class is accessible to any other class
  • default - the class is sonly accessible to classes in the same package. This is in effect when you do not specify an access modifier.

Non-Access Modifiers - Classes

  • final - the class can not be inherited by other classes
  • abstract - the class can not be used to create objects

Access Modifiers - Methods and Attributes

  • public - the method or attribute is accessible everywhere
  • private - the method or attribute is only accessible within the class
  • default - the method or attribute is only accessible within the same package. This is in effect when you do not specify an access modifier.
  • protected - the method or attribute is accessible in the same package and subclasses

Non-Access Modifiers - Methods and Attributes

  • final - the method can not be overridden or the attribute cannot be modified
  • static - the method or attribute belongs to the class rather than the individual objects of the class and can be accessed without creating an objecdt of the class
  • abstract - can only be used in an abstract class and can only be used on methods. The given method does not have a body.
  • transient - the attribute can be skipped when serializing the object
  • synchronized - the method can only be accessed by one thread at a time. If a thread is currently executing a synchronized function, if another thread attempts to execute the same function, it will be blocked until the first thread exits the function.

Object class

  • Every class in Java is directly or indirectly derived from the Object class
  • I.e. if the class does not extend any other class, it's a directly derived; otherwise it's indirectly derived
  • The Object class provides several methods:
    • hashCode() - for every object, the JVM generates a unique hashcode. I believe it's basically a cryptographic hash of the object's address. In Java, you cannot access addresses.
    • toString() - usually overridden. The default toString() method returns a string consisting of the name of the object's class followed by @ followed by the hash code of the object (in hex)
    • equals(Object obj) - compares the two objects. Usually overridden. In the default method, the hash codes of the two objects are compared
    • finalize() - the method called right before an object is garbage collected. You should override the finalize() method when you need to dispose of system resources, etc.
    • getClass() - returns the class of the "this" object
    • clone() - creates and returns a new object which is a copy of the current object
    • wait()
    • notify()
    • notifyAll()

Java Wrapper Classes

  • Wrapper classes provide a way to use primitive data types (int, double, etc.) as objects
  • Sometimes, you must use wrapper classes, for example when working with ArrayList which can only store objects
