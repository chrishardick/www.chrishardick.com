XML

  • Extensible Markup Language
  • XML is typically used to store and transport data
  • XML documents are hierarchical and can be represented as a tree
  • XML documents start with a root element
  • XML documents can optionally start with a prolog which defines the XML version and character encoding used for the document. 
    <?xml version="1.0 encoding="UTF-8"?>

XML Elements

XML elements can contain:
  • a value (text)
  • attributes
  • other elements 
<tag attribute1="v1" attribute2="v2" ...>tag value</tag>
All elements require a closing tag or the start tag must be self-closing. A self-closing element does not have a value. 
<!-- closing tag example -->

<tag> ... </tag>


<!-- self closing tag -->

<tag />

Element Names

  • Element names are case-sensitive
  • Element names must start with either a letter or an underscore
  • Element names can contain only letters, digits, hyphens, underscores and periods
  • Element names cannot start with the letters xml (regardless of the case)

Attributes

  • An element may contain one or more attributes
  • Attribute values must be quoted with either single or double quotes

Attribute vs. Child Element

  • When designing an XML schema, one is normally left with a choice of creating an attribute or a child element.
  • Some things to keep in mind...
  • Attributes cannot contain multiple values
  • Attributes are not easily extensible

Comments

  • XML documents can contain comments 
<!-- this is an xml comment -->

Namespaces

  • Namespaces help to avoid element name conflicts
  • Namespaces are defined via xmlns attribute(s) in the start tag of an element
  • An element may define more than one namespace
  • When an element defines a namespace, all child elements with the given prefix are associated with the namespace
  • Namespace syntax: 
    xmlns:prefix="URI"
  • The URI of the namespace is for uniqueness. It it not parsed or used in any other manner. It can be used to store information about the namespace - although in practice, I'm not sure how often this is actually done.
  • When using prefixes in XML, a namespace for the prefix must be defined
  • You can also define a default namespace for a given element. A default namespace will also be applied to all child elements 
<ch:table xmlns:ch="http://www.chrishardick.com" xmlns:blah="http://blah">
<blah:row> <ch:col>xxx</ch:col> <blah:row>
...
</ch:table>
