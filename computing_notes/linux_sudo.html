sudo

  • Originally named for 'superuser do'
  • Allows you to execute a command as another user
  • As opposed to su, users specify their own password, as opposed to the password of the user they're acting on behalf of
  • The sudo config file is /etc/sudoers
  • As a correct sudoers file is very important for the system, you should edit the sudoers file with visudo. It insures correctness before applying changes.
  • By default, visudo uses the nano editor. run update-alternatives --config editor to change
  • If your sudoers file utilizes includes, you can modify the included files by using: visudo -f file_name

sudoers File

  • Typically /etc/sudoers
  • Use visudo to edit. It insures correctness before applying changes
  • 1st - set up aliases
  • 2nd - set up user specifications
  • If there are multiple matches, the last match takes affect.

Aliases

  • There are 4 types of aliases
    • User_Alias
    • Runas_Alias
    • Host_Alias
    • Cmd_Alias
  • They all have the form: Alias_Type NAME = item1, item2, ...
  • You can put several aliases of the sam type on the same line separated by a colon:
  • Alias_Type NAME1 = item1, item2 : NAME2 = item3 : ...

User Aliases

  • Used to specify a group of users
  • You can specify a UNIX user group by prefixing the name with a %.
  • E.g. %users is the users UNIX users group
  • You can exclude a group by prepending the name with a !.
  • E.g. !ADMINS excludes the ADMINS group 
    User_Alias ADMINS = chris, tom, ed

# regular users -- %users = th
User Alias REG_USERS = %users, !ADMINS

Runas Aliases

  • Specified similar to user aliases except you're allowed to specify users by UID

Host Aliases

  • List of host names, IP addresses, networks

Command Aliases

  • List of commands, directories
  • If you specify a directory, it will include any file in that directory, but not any sub directories.

User Specifications

  • Where you specify who can run what as which user
  • <user list> <host list> = <operator list> <tag list> <command list>
  • An operator is the user you're taking the action on behalf of.
  • You can use a Runas Alias to specify an operator
  • The Tag List allows you to specify options. Here are some supported options:
    • PASSWD - require password
    • NOPASSWD - do not require password
    • NOEXEC - prevent shell launching

Typical Sudoers File

# reset terminal environment after switching to root
(Defaults env_reset)

# root can run anything on any host - password required
root ALL = (ALL) ALL

# similar for admins
%admin ALL = (ALL) ALL

apache ALL = (ADMIN) NOPASSWD,NOEXEC /path/to/script
