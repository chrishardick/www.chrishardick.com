Bubble Sort

  • Simple Sorting Algorithm. However, it's usally inefficient.
  • Swap adjacent elements
  • Keep going until you make an entire pass without swapping

Complexity

  • Worst Case: O(n2)
  • Best Case: O(n)

Algorithm

// try this example: [ 6 2 5 3 9 ]

void swap (int& a, int& b)
{
    int t = a;

    a = b;

    b = t;
}

void bubble_sort (std::vector<int>& v)
{   
    for (int i=0; i<v.size()-1; i++)
    {
        bool sorted = true;

        for (int j=0; j<v.size()-1; j++)
        {
            if (v[j] > v[j+1])
            {
                swap (v[j], v[j+1])
                sorted = false;
            }
        }

        if (sorted)
            return;
    }
}
