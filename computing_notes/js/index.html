JavaScript (JS)

  • The de-facto programming language of the web.
  • One of the largest uses of JS is client-side web development.
  • One of the 3 technologies all client web developers must learn -- HTML, CSS, JS
  • Like most scripting languages, JS is an interpreted language
  • JS is case sensitive
  • JS supports both C++ and C style comments 
         /* c style comment */

     // c++ style comment
  • The core JS language defines only a minimal set of libraries. The majority of the libraries you will use (i.e. I/O, etc.) will be provided by the host environment (i.e. web browser, etc.)
  • Virtually every web browser today contains a JS interpreter. V8 is Google's JS interpreter

Embedding JS in HTML Files

  • JS is embedded within HTML using the script tag.
  • You can define your code in-line or via an external file. They work similarly.
  • Script execution is interleaved with HTML parsing and rendering.
  • You cannot manipulate objects before they have been created. 
    <html>
<head>
<!-- an external file -->
<script src="script1.js"> 
</head>

<body>
...
<!-- another external file -->
<script src="script2.js> 
...
<script>
// an inline script
document.write ("Hello, World!");
</script> 
...
</body>
</html>

Data Types

  • JavaScript--like most scripting languages--is an untyped language. In other words, a variable is a variable and it can hold any data type. It's perfectly legal to declare a variable, assign a string to it and later assign a numerical value to it. JavaScript will automatically convert from one type to another as necessary
  • JavaScript supports 3 primitive data types
    1. number
    2. string
    3. boolean
  • JavaScript supports objects (composite datatype)
    • In JavaScript, arrays and functions are implemented as objects
    • The core JavaScript language defines numerous pre-defined object classes inclding: Date, RegExp, and Error
  • Primitive Data Type Class Wrappers
    • JavaScript predefines class wrappers for each of the primitive data types (numbers, strings, and boolean types) named Number, String, and Boolean -- respectively
    • The wrapper contains the same primitive data value, but also defined properties and methods that can be used to manipulate the data
    • When you use a primitive type in an object context, JavaScript implicitly creates a wrapper object for the value. The object created is temporary, it's created such that you can access the given property, then it's marked for deletion (such that it can be reclaimed by the system)
    • If you wish to create an non-temporary primitive data type object, you can create one just as you'd create any object 
      var ex = new String("Hello World");
    • NOTE: the reverse is also true, when you use a primitive type object in primitive type context, a temporary primitive type is created
  • Some JavaScript types are Reference Types. I.e. the actual variable contains only a pointer (reference) to the actual data. The data is dynamically allocated. Dynamically allocated data which is no longer referenced is cleaned up by the system via Garbage Collection
  • Strings, Objects, and Arrays are Reference Types

NUMBERS

  • All numbers in JavaScript are stored in 64 bit floating point format. In other words, there is no distinction between integers and real numbers
  • Bitwise operators are an exception -- they are performed on 32-bit integers
  • Hexadecimal literals begin with 0x or 0X
  • Floating point literals can be represented using exponential notation (real number followed by E (or e) followed by an integer exponent (which may be negative)
  • JavaScript supports the basic arithmetic operators
    • + for addition
    • - for subtraction
    • * for multiplication
    • / for division
  • In addition, JavaScript supports more complex arithmetic operations as part of the core language. These functions are accessed as methods of the Math class
  • The Math class has a toString( ) method which converts an integer to a string using the base specified by its argument (the base must be between 2 and 36) 
    var x = 6;
var y = x.toString(2); // y is "110"

// you can also invoke the toString method on a literal
// the parenthesis are requird to prevent the period (.) from being interpreted as a decimal point

var y = (6).toString(2);
  • Special Numeric Values
    • Infinity is used to represent a number larger than the largest possible number
    • There's also -Infinity to represent a negative number lower than the lowest possible negative number
    • NaN is used to represent 'not a number'. To test for NaN, use IsNaN( )
    • Use isFinite( ) to test whether a number is not NaN, Infinity, nor -Infinity

STRINGS

  • A sequence of zero or more Unicode characters enclosed by single or double quotations
  • TIP: In client-side JavaScript programming, JavaScript code often contains strings of HTML code, and HTML code often contains strings of JavaScript code. Therefore, it's recommended to use one style of quotes for the HTML code (either single or double) and the other type for your JavaScript code
  • JavaScript strings (and arrays) are indexed from zero (0)
  • Escape Sequences
    SequenceInterpretation
    \0 NULL character
    \b Backspace
    \t Tab
    \n Newline
    \v Vertical tab
    \f Form Feed
    \r Carriage Return
    \" Double Quote
    \' Single Quote
    \\ Backslash
    \xXX Latin-1 character specified by hexadecimal # XX
    \uXXXX Unicode character specified by XXXX
    Unlike other languages if the backslash is followed by any character other than the ones noted in the above table, it's simply ignored
  • Concatenation
    • Built into the core JavaScript language is the ability to concatenate strings via the + operator 
      var szX = "Hello" + " World"
  • Length
    • To determine the length of a string, use the length method of the String class 
      var lLenX = x.length();
  • Substrings
    • To extract a substring, use the substring method of the String class 
      var szY = x.substring(1,5);
    • To find the position of the first occurance of a substring use the indexOf method of the String class 
      var lPosW = indexOf('W');

BOOLEAN

  • Boolean variables can have only two possible values: true and false

OBJECTS

  • In JavaScript, an object is simply an associative array (hash map).
  • Objects are collections of variables (the properties of the object).
  • Object properties can contain any data type (primitive, functions, other objects, etc.)
  • Methods are function properties
  • You can access and/or update the properties of an object using either associative array notation (e.g. box["width"]) or dot notation (box.width). If you assign a value to a previously noh-existent property, the new property is created for you.
  • Objects are always passed by reference. They are never copied
  • Even assignment is by reference 
    let x = { name: "Chris" };

let y = x;

y.name = "Christopher";

document.write(x.name); // results in Christopher being displayed

The new operator

  • the new operator
    1. creates a new object
    2. invokes a constructor function to initialize the object
  • Syntax 
    new constructor(arguments)
  • If there are no arguments, JavaScript allows the parenthesis to be omitted
  • The new operator can also be used to create arrays using the new Array( ) syntax

The Date Object

  • JavaScript provides built-in support for an object type to store dates and times 
    var Today = new Date( ); // date w/ current date and time
var MyFirstChristmas = new Date(1975,11,25);  // months are 0 based

The RegExp Object

  • JavaScript provides built-in support for regular expressions via the RegExp object
  • JavaScript uses the same syntax as Perl to express regular expressions
  • Text between a pair of slashes is a regular expression literal 
    /^Chris Hardick/

Error Objects

  • JavaScript defines a number of classed that represent errors
  • The JavaScript interpreter, throws an object of one of these types when a runtime error occurs
  • Each error class has a message property that contains a descriptive error message
  • Error, EvalError, RangeError, ReferenceError, SyntaxError, TypeError, URIError

Functions

  • In JavaScript, functions are implemented as objects 
    function square (x)
{
     return x*x;
}
  • Primative parameters (even the primative data type wrappers) are always passed as values. Objects are always passed by reference.
  • Functions are called just like they are in C/C++, following their name w/ an comma separated list of arguments enclosed in parentheses
  • In JavaScript, functions are a data type. This means that functions may be stored in variables and passed as arguments to other functions
  • When a function is assigned to a property of an object, it is refered to as an object method

Arrays

  • In JavaScript, arrays are implemented as objects
  • Arrays in JavaScript are indexed from 0 (zero)
  • Arrays may contain any data type (including references to other arrays, objects, or functions)
  • JavaScript is an untyped language, as such, elements of the same array can contain different types
  • Arrays are created with the Array( ) constructor 
    var x = new Array( );
x[0] = 1;
x[1] = true;
x[2] = 1.2;
x[3] = "Hello, World!";
  • If you only pass a single number to Array( ), it's interpreted as the length of the array 
    var y = new Array(10); // an array with 10 undefined elements
  • To determine the number of elements the array contains, use the length property

Variables

    var i,j,k;
var a=0, b="abc", c=5.2;
  • Before you use a variable in JavaScript, you must be declared
  • Variables are explicitly declared with keyword var
  • If you don't explicitly declare a variable (with var), JavaScript will implicitly declare it for you
  • Remember, JavaScript is an untyped language, so there's no need to associate a type with a variable
  • If you don't specify an initial value for a variable w/i the var statement, the variables value is undefined until you initialize it
  • Variables declared w/ var are permanent -- they cannot be deleted

VARIABLE SCOPE/LIFETIME

  • Variables defined within a function and function parameters have local scope. Their scope and lifetime is from point of declaration to the end of the function
  • Local variables (defined within a function), must be declared using var
  • let specifies block scope. However, it is not supported by all browsers
  • Local variables take precedence (i.e. hide) global variables of the same name
  • Global variables have file scope. Their scope and lifetime is from point of declaration to the end of the file.

The Global Object

  • When the JavaScript interpreter starts up, before executing any code, it instantiates the Global Object
  • When you declare a global variable, what you're actually doing is defining a property of the Global Object
  • In code which is not contained within a function block, you can use the keyword this to refer to the global object (within functions, this has a different meaning)

The Call Object

  • Local variables (declared within a function) are also properties of an object -- the Call Object
  • When you call a function, you implicitly instantiate a Call Object
