JavaScript - Control Structures

if statement

    if (expression)
     statement

[else if (expression)
     statement]

[else
     statement]

switch statement

    switch (expression)
{
     case value:
     case value:
          statements
          break;

     case value:
          statements
          break;

     default:
          statements
          break;
}

while loop

  • pre-test loop 
    while (expression)
     statement

do/while loop

  • post-test loop 
    do
     statement
while (expression);

for loop

    for (initialize; test; increment)
     statement

for/in loop

  • loop thru the properties of an object 
    for (variable in object)
     statement

break statement

  • causes control to exit from the innermost enclosing bracket or switch statement 
    break;

continue statement

  • used within loops, it causes a loop to begin the next iteration 
    continue;
