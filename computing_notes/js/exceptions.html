JavaScript - Exceptions

  • In JavaScript, exceptions are thrown whenever a runtime error occurs or when a program explicitly throws one
  • When an exception is thrown, control immediately jumps to the nearest exception handler (catch statement)

Throw Statement

    throw expression;
  • use throw to signal an exception

Try Block

    try
{
     statement(s)
}
  • a try block defines a block of code in which exception(s) are to be handled
  • a try block is followed by a catch block
  • a catch block is followed by a finally block
  • both the catch block and the finally block are optional - however @ least one of them MUST be specified

Catch Block

    catch (identifier)
{
     statement(s)
}
  • The statement(s) within a catch block are executed only if the try block throws an exception
  • the identifier is like a function argument. Its scope and lifetime exist only within the block of the catch block
  • JavaScript assigns the exception object or value that was thrown to it

Finally Block

    finally
{
     statement(s)
}
  • The statements within the finally block are always executed (regardless if an exception was thrown or not)
  • It's generally used to clean up any code within the try block
  • Normally the try block completes execution (by hitting the last curly bracket, via a return statement, etc. and control is transfered to the finally block which performs cleanup
