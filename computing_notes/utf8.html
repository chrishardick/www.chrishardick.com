UTF-8

  • Variable width character encoding of all Unicode characters
  • Designed for backward compatibility with ASCII
  • The first 128 characters (7 bits) of UTF-8 correspond 1:1 with ASCII
  • A valid ASCII string is a valid UTF-8 string
  • Each character is 1-4 bytes
