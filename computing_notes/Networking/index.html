Networking Notes

I. IP Addresses

IPv4

  • Each address = 4 bytes (32 bits)
  • Addresses are usually denoted in dotted decimal format: 10.0.0.1
  • Each byte is known as an octet
  • 4,294,967,296 possible addresses
  • Network Mask: Bitwise-AND w/ the IP Address to yield the given network
IPv4 Address Classes
Class A Networks
0.0.0.0 ... 127.255.255.255
Network Mask: 255.0.0.0
Each Class A Network = 3 bytes of hosts (255*255*255-1 = 16,581,374)
125 Public Class A Networks + 1 Private Class A Network
Leftmost Bits: 0xxx
0.0.0.0 ... 0.255.255.255 Zero Addresses - Should not be used
10.0.0.0 ... 10.255.255.255 Private Class A Network
127.0.0.0 ... 127.255.255.255Loopback Addresses - Used for Testing
Class B Networks
128.0.0.0 ... 191.255.255.255
Network Mask - 255.255.0.0
Each Class B Network = 2 bytes of hosts (255*255-1 = 16,581,374)
Public Class B Networks + 1 Private Class B Network
Class C Networks
192.0.0.0 ... 223.255.255.255
Network Mask -
Each Class C Network = bytes of hosts (255*255-1 = 16,581,374)
Public Class B Networks + 1 Private Class B Network
