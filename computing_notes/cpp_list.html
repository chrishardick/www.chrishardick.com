C++ List

  • Doubly linked list
  • constant time insertion and deletion
  • Like any list, lacks random access

Header File

#include <list>

using namespace std;

Constructors

  • Default Constructor
    • Create an empty list 
    list<T> lst;
  • Copy Constructor
    • Copy supplied list 
    list lst(const list<T>& rhs);
  • Range [first,last) 
    list lst(InputIterator first, InputIterator last);

Destructor

  • Destruct all elements (destructor called for each) and destruct the container itself 
    ~list()

Member Functions

  • begin() 
    iterator begin();
const_iterator begin() const;
    • Returns an iterator to first element
  • end() 
    iterator end();
const_iterator end() const;
    • Returns an iterator just past last element
  • front() 
    reference front();
const_reference front() const;
    • Similar to begin() - except returns a reference rather than an iterator
    • Undefined behavior if called on an empty list
  • back() 
    reference back();
const_reference back() const;
    • Similar to end(). However, returns a reference to the last element, rather than an iterator just past the last element.
    • Undefined behavior if called on an empty list
  • empty() 
    bool empty()
    • Boolean method - is this list is empty.
  • size() 
    size_type size() const;
    • returns # of elements
  • push_back() 
    void push_back(const T&iamp; t);
    • add element to the end of the list
    • t - value to be copied to the new element
  • push_front() 
    void push_frontk(const T&iamp; t);
    • add element to the front of the list
    • t - value to be copied to the new element
  • pop_back() 
    void pop_back();
    • delete last element -- destructing the removed element
  • pop_front() 
    void pop_front();
    • delete first element -- destructing the removed element
  • insert() 
    void insert(iterator position, InputIterator first, InputIterator last);
    • insert range [first,last) into the list @ position
  • erase() 
    iterator erase(iterator position);
    • erase the element located at position
    • returns iterator to 1 position past where the element was erased or end() if the last element was erased
  • erase() 
    iterator erase(iterator first, iterator last);
    • erase range [first,last) into the list @ position
    • returns iterator to 1 position past the last element erased or end() if the last element was erased
  • clear() 
    void clear();
    • erase all elements in the list
    • equivalent to list.erase(list.begin(), list.end());
