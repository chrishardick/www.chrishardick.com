Python: time Module

  • This module provides time-related functionality - see also Python datetime, et. al

# sleep()
# - suspend execution of the calling thread for the given number of seconds
# - the argument may be a floating point number to indicate a more precise sleep time
# - can sleep for shorter time if interrupted by a signal
# - can sleep for a longer time due to os scheduling
#
