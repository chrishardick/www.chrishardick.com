Swift - Xcode

  • Xcode is an IDE (Integrated Development Environment).
  • It's the application used to develop iOS apps

New Project

  • Start up Xcode
  • File → New → Project
  • Under iOS, choose 'Application'
  • Select 'Single View Application'
  • Enter a name for your project - e.g. "hello_world"
  • For the Company Identifier field, choose something like com.hardick.chris
  • Make sure the Devices pop-up menu is set to iPhone
  • Make sure 'Use Code Data' is not checked
  • Product → Build - to build
  • Product → Run (will automatically build first if necessary)

Run Project in Simulator

  • To run your project in a simulator, press the run button (looks like a play button) on top right corner

Source Code

AppDelegate.swift

The AppDelegte.swift file has two primary purposes:

  1. Defines your AppDelegate class.
    • The AppDelegate class has a single property - window.
    • window represents the root of your app's view hierarchy. It is where all of the app content is drawn
    • AppDelegate also contains stub implementations for the delegate methods listed below. During app state transition, the application object calls the relevant delegate method, allowing your app to take the appropriate action. Each delegate method has a default implementation - which will be invoked if you do not specify one 
          func application(_ application: UIApplication
                    ,didFinishLaunchingWithOptions launchOptions: [UIApplicationLaunchOptionsKey: Any]?
                    ) -> Bool

    func applicationWillResignActive    (_ application: UIApplication)
    func applicationDidEnterBackground  (_ application: UIApplication)
    func applicationWillEnterForeground (_ application: UIApplication)
    func applicationDidBecomeActive     (_ application: UIApplication)
    func applicationWillTerminate       (_ application: UIApplication)
  2. Creates an entry point to your app and a run loop which delivers input events to your app
    • This is via the UIApplicationMain attribute (@UIApplicationMain) - equivalent to calling UIApplicationMain()
    • This will cause the system to create an application object which is responsible for managing the app life cycle
    • The system will creates an instance of your AppDelegate class and assigns it to the application object
    • The system will launch your app

ViewController.swift

Storyboard

  • A visual representation of the app's user interface - showing screens of content (scenes) and the transactions between them
  • You use storyboards to lay out the flow for your app
  • To open your storyboard, in the project navigator, select Main.storyboard
  • Xcode will open the storyboard in Interface Builder - its visual interface editor
  • The arrow that points to the left side is the Storyboard Entry Point (the scene which is loaded when the app startes)

Object Library

Add a Text Field

  • View → Libraries → Show Libary or click the Show Object Library icon (it looks like a circle with a square in the middle)
  • In the Object Library, type 'text field' in fhe filter field
  • Drag a Text Field object on to your scene.
  • You can zoom in via: Editor → Zoom
  • With the Text Field selected, open the Attributes Inspector (the icon looks like a downward facing arrow) and enter text for your text field
  • In the Attributes Inspector, find 'Return Key' and select 'Done.' This will make the return key into a 'Done' key
  • In the Attributes Inspector, select 'Auto-enable Return Key' checkbox. This will prevent the user to click 'Done' before typing text into the text field
  • You can also add a label (UILabel)

Add a Label

  • View → Libraries → Show Libary or click the Show Object Library icon (it looks like a circle with a square in the middle)
  • In the Object Library, type 'label' in fhe filter field
  • Drag a Text Field object on to your scene.
  • Either double click on the label or use the Attributes Inspector to add text to your label

Add a Button

  • View → Libraries → Show Libary or click the Show Object Library icon (it looks like a circle with a square in the middle)
  • In the Object Library, type 'label' in fhe filter field
  • Drag a Button object on to your scene
  • Double click the button and or use the Attributes Inspector to add text for your button

Auto Layout

  • A Stack View (UIStackView) is one of easiest ways to define your layout.
  • It allows you to lay out a collection of views in either a column or a row.
  • To add a Stack View, while pressing the Shift key, select the fields you want to include in the stack view
  • On the bottom right of the canvas, click the 'Embed in' icon' and choose 'Stack View') or choose Editor → Embed In → Stack View
  • On the bottom right, open the 'Add New Constraints' menu - it looks like a square with a vertical line on each side
  • The constraints menu allows you to specify the spacing to the nearest leading, trailing, top and bottom neighbors

Building a Basic UI

  • Xcode provides a library of objects you can add to a storyboard file.
  • There are UI (View) components.
    • E.g. buttons, text fields
    • All View objects are of type UIView or one of its subclasses
    • UITextField - a text field is a sub class of UIView
    • To add a text field: Editor → Canvas → Show Bounds Rectangles - make sure it's selected This will cause Interface Builder to drawn a bulue box around all views in the canvas
  • There are View Controllers.

Project Window

The Project Window usually consists of 4 panes. You can toggle their visibility via the View menu.

  • Navigator Pane
  • Editor Pane
  • Utilities Pane
  • Debugger Pane

Navigator Pane

  • Basically, what you select in the Navigator Pane is diplayed in the Editor Pane
  • The Navigator Pane can display different types of information which you can access via the icons on the top of the pane

Editor Pane

  • Self explanatory

Utilities Pane

  • Usually on the right of the Project Window.
  • It contains information about the current selection or its settings
  • It will also display help

Debugger Pane

  • Self explanatory
