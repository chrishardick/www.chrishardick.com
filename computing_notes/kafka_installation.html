Kafka: Installation

Add kafka User

  • sudo adduser kafka
  • sudo adduser kafka sudo - add the kafka user to the sudo group
  • sudo -l kafka - log in as kafka user

Installing

  • Execute the following to download the gzipped tarball: curl -o kafka_2.13-3.3.1.tgz https://dlcdn.apache.org/kafka/3.3.1/kafka_2.13-3.3.1.tgz
  • Extract: tar -xvzf kafka_2.13-3.3.1.tgz
