Kafka: Installation

Consumers

  • Consumers label themselves with a consumer group name
  • Each record published to a topic is delivered to one consumer instance within a subscribing consumer group - allowing for load balancing the consumers

Installing

  • Execute the following to download the gzipped tarball: curl -o kafka_2.13-3.3.1.tgz https://dlcdn.apache.org/kafka/3.3.1/kafka_2.13-3.3.1.tgz
  • Extract: tar -xvzf kafka_2.13-3.3.1.tgz
