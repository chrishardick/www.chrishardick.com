CSS - Display Properties

display

  • Specifies how an element should be displayed
  • Valid values:
    • none
      • The element will not be displayed
      • Frequently used in conjunction with javascript to allow an element to appear/disappear
      • Similar to visibility: hidden except that an element with display: none will not allocate any physical space on the screen whereas an element with visibility: hidden will have space allocated for the element -- it just will not be visible
    • block
      • display element as a block element.
      • Block elements implicitly have a break added before and after the element.
      • Examples include: h1, h2, p.
      • div is a generic block element. i.e. a block element without any other added style.
      • block elements respect height and width settings
    • inline
      • display element as an inline element.
      • Inline elements do not have an implicit break before and after the element.
      • Examples include: strong, em, a.
      • span is a generic inline element. i.e. an inline element without any other added style.
      • inline elements do not respect height and width settings
    • inline-block
      • inline elements which can have a width and height -- normally only block level elements can have a height and width
      • creates a rectangular region without any newlines
      • allows you to create a grid of boxes which fill up the browser width and wraps nicely when the browser is resized
      • see example below

    • list-item - the element is displayed as a li element
    • run-in - ???
    • table - the element is displayed as a table element
    • table-caption - the element is displayed as a caption element
    • table-column-group - the element is displayed as a colgroup element
    • table-header-group - the element is displayed as a thead element
    • table-footer-group - the element is displayed as a tfoot element
    • table-row-group - the element is displayed as a tbody element
    • table-cell - the element is displayed as a td element
    • table-column - the element is displayed as a col element
    • table-row - the element is displayed as a tr element
    • initial - set property to default value
    • inherit - inherit property from parent element

visibility

  • Specifies whether or not an element is visible
  • Valid values: hidden, visible
