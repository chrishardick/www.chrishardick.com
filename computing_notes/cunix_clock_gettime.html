}

SUPPORTED CLOCKS

CLOCK_REALTIME
wall clock. This clock is affected by discontinuous jumps in the system time (e.g. manual changes, ntp, etc.)
CLOCK_REALTIME_COARSE
similar to CLOCK_REALTIME except faster, but less precise.
CLOCK_MONOTONIC
Cannot be set. Represents monotonic time since some unspecified starting point. Not affected by discontinuous jumps in the system time (e.g. manual changes, ntp, etc.). Useful for metrics -- i.e. elapsed # of nanoseconds, etc.
See man page for other valid values
