Set Theory

  • A branch of mathematics which studies sets - which are collections of objects

Union

  • The union of two sets A and B (denoted A ∪ B) is the set of elements which are in set A, set B or both Set A and B.

Intersection

  • The intersection of two sets A and B (denoted A ∩ B) is the set of elements which are in both set A and set B.

Not (Complement)

  • The complement of set A refers to elements not in set A.

Difference

  • The difference of two sets A and B (denoted A - B) is the set of elements in set A which are not in set B.
