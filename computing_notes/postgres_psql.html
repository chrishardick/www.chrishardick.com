PostgreSQL: psql / Other Utilities

psql

  • Terminal based PostgreSQL front-end. It is a regular PostgreSQL client application
  • All SQL statements entered into psql must be terminated via a semicolon(;). This allows statements to span multiple lines
  • psql [options] [dbname [username] [host] [port]]
  • Arguments
    • dbname
    • username - defaults to current user's user name
    • host
    • port
  • Options
    • -l - list all available databases and then exit
    • -U username
    • -d dbname
    • -h hostname - specifies the host name of the machine in which he server is running
    • -H - turn on HTML tabular output
    • -V - print psql version information and exit

psql - Internal Commands

  • Internal Commands are non-SQL statements which begin with backslash and do not need to be terminated by a semicolon
    • \h - help
    • \? - show more internal commands
    • \q - quit
    • \dt - display list of tables in the current datbase
    • \d+ table - display table definition
    • \du - display list of roles
    • \connect database_name - switch databases
    • \H - turn on HTML tabular output
    • \conninfo - show connection information
  • SQL statemenets in psql can be multi-line and must always be terminated by a semi-colon

Other PostgreSQL Utilities

  • createdb [-U username] [dbname] - create a database
  • dropdb [demodb] - remove a database
