Client Side JS - The Node Object

  • The Node Object is an interface in which a number of other classes inherit from.
  • The Document Object, Element Object and Text Object all inherit from the Node Object

Node Object Properties

parentNode

  • The parent node for the given Node Object
  • null for nodes (like the Document Object) which do not have a parent

childNode

  • A NodeList object
  • live -- i.e. it will automatically update as the document changes

firstChild, lastChild

  • The Node Object of the first or last child node
  • null for nodes which do not have children

nextSibling, previousSibling

  • The Node Object of the next or previous sibling node
  • Sibling nodes have the same parent

nodeType

  • The type of node this is
  • 9 = Document node
  • 1 = Element node
  • 3 = Text node
  • 8 = Comment node

nodeValue

  • The text content of a Text or Comment node

nodeName

  • The tag name of the element - converted to uppercase
