Python: Set

  • A set is similar to a dictionary -- except it contains only keys (no values)
  • A set is written as a comma separated list of keys surrounded by curly braces
  • Use the set() function to create an empty set -- see below
  • Use the add() method to add a single element to a set
  • Use the update() method to add multiple elements to a set
  • Use the discard() method to remove an item from a set. remove() is similar except it will throw an exception if the key does not exist
  • Use the clear() method to remove all items from a set
  • Sets are mutable 
    states = {   'NY'
            ,'NJ'
         }

# add an entry
states.add('CO')

# add multiple entries
states.update(['OH','CA'])

# an empty set
# - reminder: empty curly braces creates a dictionary (not a set)
a = set()


# iterating thru a set
# - note: will not print in any particular order
for x in a:
    print x

# same thing -- but sorted
for x in sorted(a):
    print x

Set Operations

  • union (or) |
  • intersection (and) &
  • difference - 
    a = {1, 2, 3, 4, 5}
b = {5, 6, 7, 8, 9}

print "union: " + str((a | b))      # 1, 2, 3, 4, 5, 6, 7, 8, 9
print "union: " + str(a.union(b))   # 1, 2, 3, 4, 5, 6, 7, 8, 9

print "a: " + str(a)                # 1, 2, 3, 4, 5
print "b: " + str(b)                # 5, 6, 7, 8, 9

print "intersection: " + str(a & b)                     # 5
print "intersection: " + str(a.intersection(b))         # 5

print "a: " + str(a)                # 1, 2, 3, 4, 5 
print "b: " + str(b)                # 5, 6, 7, 8, 9

print "difference: " + str(a - b)                       # 1, 2, 3, 4
print "difference: " + str(a.difference(b))             # 1, 2, 3, 4

print "a: " + str(a)                # 1, 2, 3, 4, 5 
print "b: " + str(b)                # 5, 6, 7, 8, 9
