HTTP - GET Request/Response

  • The GET method should be used to retrieve information from the given server.
  • GET requests should not modify data
  • In a GET request, you can pass parameters as part of the query string

REQUEST

GET / HTTP/1.1
User-Agent: Mozilla/4.0
Host: www.chrishardick.com
Accept-Language: en-us
Connection: Keep-Alive

RESPONSE

HTTP/1.1 200 OK
Date: Wed, 10 Apr 2019 12:56:51 GMT
Content-Length: 88
Content-Type: text/html; charset=utf-8
Connection: Closed
Last-Modified: Wed 03 Apr 2019 12:56:51 GMT
ETag: "11111111-2222-3333333333333"

<html>
<body>
<h1>Hello, World!</h1>
</body>
</html>
