CSS - Positioning Properties

Types of Positioning

  • static
    • normal. positioned with the normal flow of the page.
    • not affected by top, bottom, left and right properties
  • relative
    • the element is positioned relative to its normal position
    • the element will be adjusted away from its normal position by the values set in the top, bottom, left and right properties
  • fixed
    • the element is positioned relative to the viewport. Therefore regardless of window resizing or scrolling, it will stay in the same place with respect to the viewport.
    • the element's box is removed entirely from the flow of the document.
  • absolute
    • the element's box is removed entirely from the flow of the document and positioned with respect to its containing block

position

  • Values: static, relative, fixed, absolute
  • Default value: static

top

  • set top margin edge for a positioned element
  • Values: auto, <length>
  • Default value: auto

bottom

  • set bottom margin edge for a positioned element
  • Values: auto, <length>
  • Default value: auto

left

  • set left margin edge for a positioned element
  • Values: auto, <length>
  • Default value: auto

right

  • set right margin edge for a positioned element
  • Values: auto, <length>
  • Default value: auto

z-index

  • When elements are positioned, they can overlap each other
  • The element with the higher z-index will be positioned in front of an element with a lower z-index
  • If two elements overlap without a z-index specified, element positioned later will appear in front of those positioned earlier
