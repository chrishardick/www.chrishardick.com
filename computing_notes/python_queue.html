Python: queue Module

  • Thread and Process safe (i.e. use across multiple threads and/or processes is supported)
  • Supports multi-producer, multi-consumer queues
  • Implemented via Queue class
  • Implements three types of queues - LIFO, FIFO (stack), Priority Queue (items are sorted and the lowest valued entry is retrieved first)
  • Not Re-enterant Safe

Constructors

queue.Queue(maxsize=0)
queue.LifoQueue(maxsize=0)
queue.PriorityQueue(maxsize=0)
Construct a FIFO, LIFO, or Priority Queue of given maximum size. Once maxsize has been reached, insertion wil block until queue items have been consumed. If maxsize is less than or equal to zero, there is no maximum size.
For PriorityQueue, lowest valued entries are retrieved first (i.e. the one returned via sorted(list(entries)))

Methods

Regardless of type, each Queue object supports the following methods:
queue.qsize()
Return the size of the queue
queue.empty()
Return True if the queue is empty. False otherwise.
queue.put(item, block=True, timeout=None)
Put item in queue. By default, will block if queue is full. If timeout is a positive number, block at most timeout seconds and raise a Full exception if space did not become available. If block is False, it will put an item on queue if space is available otherwise a Full exception is raised (timeout is ignored)
queue.put_nowait(item)
Equivalent to put(item, False)
queue.get(block=True, timeout=None)
Remove and return an item from the queue. By default, will block until an item is available. If timeout is a positive number, blocks at most timeout seconds and raises an Empty exception if an item did not become available. If block is False, an item will be returned if available otherwise an Empty exception is raised (timeout is ignored)
queue.get_nowait()
Equivalent to get(False)
queue.task_done()
Called by consumer to signal to the queue that processing of the item is complete.
queue.join()
Blocks until all items in the queue have been removed and processed. Processed is indicated by the consumer calling task_done()
