HTML: Forms

<form> Element

<form action="doit.py">
...
elements making up the form
...
</form>
  • Defines a form which is used to collect user input
  • Attributes:
  • action - the action to be taken when the form is submitted. Can be either a server side script or a client side function
  • method - GET (default) - will transform inputted data into a query string; or POST in which the users input will not be passed via query string. POST also has no size restrictions - so it's better when transmitting large amounts of data.

<input> Element

input type Attribute Values

  • text - 1 line text input field 
    <input type='text' name='demo_txt'></input>

  • radio - radio button (allowing for selection of a single choice) 
    <input type='radio' name='demo_radio' value='value0' checked>Value0</input> 
<input type='radio' name='demo_radio' value='value1'>Value1</input>

    Value0 Value1

  • checkbox - checkbox button (allowing for selection of zero or more choices) 
    <input type='checkbox' name='demo_checkbox' value='value0' checked>Value0</input> 
<input type='checkbox' name='demo_checkbox' value='value1' checked>Value1</input>

    Value0 Value1

  • file - widget allowing user to specify a filename 
    <input type='file' name='demo_file'></input>

  • password - defines a password field 
    Password: <input type='password' name='demo_password'></input>

  • range - range widget 
    <input type='range' name='demo_range' min=1 max=100></input>

  • submit - submit button (for submitting the form) 
    <input type='submit' name='demo_submit'></input>

  • reset - reset button (to reset all form values to default values 
    <input type='reset' name='demo_reset'></input>

  • number - defines a numeric input field 
    <input type='number' name='demo_number'></input>

  • date - defines a date input field 
    <input type='number' name='demo_number'></input>

  • month - defines a month input field 
    <input type='number' name='demo_number'></input>

  • week - defines a week input field 
    <input type='number' name='demo_number'></input>

  • time - defines a time input field 
    <input type='number' name='demo_number'></input>

  • datetime-local - defines a date/time input field (w/o time zone) 
    <input type='number' name='demo_number'></input>

  • url - defines a url input field 
    <input type='url' name='demo_url'></input>

  • email - defines a e-mail input field 
    <input type='email' name='demo_email'></input>

  • color - defines a color input field 
    <input type='color' name='demo_color'></input>

  • search - defines a search field 
    <input type='search' name='demo_search'></input>

input Attributes

  • value - initial value for the field
  • name - field identifier
  • readonly - if present, field is read-only (cannot be changed)
  • disabled - if present, field is disabled
  • size - size (in characters) of the field
  • maxlength - maximum allowable text length for the field
  • autocomplete - on/off. whether or not the browser should automatically complete input values based on previous user input
  • autofocus - when present, specifies that the field should get focus when the page loads
  • min and max - minimum and maximum values for the element
  • multiple - specifies that the user should be allowed to enter more than one value - i.e. e-mail addresses, files
  • pattern - allows you to specify a regular expression in which the input is checked against.
  • placeholder - specifies a hint displayed in the field before the user enters a value
  • required - specifies the field must be filled out before submitting the form
  • step - specifies the valid number intervals. can be used with min and max
  • checked - specifies the valid number intervals. can be used with min and max
