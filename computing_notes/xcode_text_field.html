Xcode - Text Field

Adding a Text Field

  • In the Object Library, type 'text field' in the filter field
  • Drag a Text Field object on to your scene.

Create an Outlet

  • The outlet will link the text field widget to a data member in your ViewController class
  • See Outlets
  • You'll need to enter a name - E.g. textFieldFoo

Creating a Text Field Delegate

  • A Delegate is an object which receives a message when an event occurs on another object
  • A common pattern is to declare a ViewController as a delegate for a UI Widget (e.g. a text field)
  • In order to be a delegate, the delegate class needs to implement the appropriate protocol
  • In this case, we're going to modify ViewController to specify it implements the UITextFieldDelegate protocol
  • The UITextFieldDelegate protocol defines eight optional methods. As they're optional, you only need to implement the ones you need.
  • We're going to implement the following two methods: 
    // called when the user presses Return or similar
func textFieldShouldReturn(_ textField: UITextField) -> Bool

// called after the text field resigns its first repsonder status
func textFieldDidEndEditing(_ textField: UITextField)
  • When a user taps on a text field, it automaticlly becomes the first responder
  • The first responder is the object first in line for receiving app events
  • As a result of the text field becoming the first responder, iOS displays the keyboard and begins an editing session for the field. Whatever the user types gets inserted into the text field.
  • When the user is finished typing in the text field, the text field needs to resign its first responder status.
  • Last, but not least, we need to formally declare that ViewController is a delegate for the text field
  • Here are the steps to create a Text Field Delegate:
  1. Enhance the ViewController class to specify it implements the UITextFieldDelegate protocol as follows: 
    class ViewController: UIViewController, UITextFieldDelegate
  2. Define the textFieldShouldReturn() and textFieldDidEndEditing() methods as follows: 
    //MARK: UITextFieldDelegate

// called when the user presses Return or similar on the keyboard
func textFieldShouldReturn(_ textField: UITextField) -> Bool
{
    textField.resignFirstResponder()
    return true
}

// called after the text field resigns its first repsonder status
func textFieldDidEndEditing(_ textField: UITextField)
{
    // normally, this is where you capture textField.text, etc. 
}
  3. Assign ViewController as a delegate for your text field by modifying the viewDidLoad() of the ViewController object as follows: 
    override func viewDidLoad()
{
    super.viewDidLoad()

    textFieldFoo.delegate = self       // where textfieldFoo is the outlet you created above
}
