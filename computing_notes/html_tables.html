HTML - Tables

Basic Elements

<table>...</table>
Defines a table
<tr>...</tr>
Defines a table row
<th>...</th>
Defines a table header cell
<td>...</td>
Defines a table data cell

Borders

  • Borders are defined for HTML tables using the CSS border property
  • Borders are usually defined for the table, th and td elements
  • Borders are usually collapsed into a single border using the CSS border-collapse property 
<style>
table, th, td
{
    border: 1px solid black;
    border-collapse: collapse;
}
</style>
