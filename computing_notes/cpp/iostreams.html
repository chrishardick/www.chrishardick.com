adjustfield

  • 3 bits compose adjustfield
  • how a printed value is positioned within its field
  • ios::left
    • left justification
    • normally used for text
  • ios::right
    • right justtification
    • normally used for numerical values
  • ios::internal
    • causes a sign or base indication (leading 0, 0x, or 0X) to be left justified and the rest of the number to be right justified

basefield

  • 3 bits compose basefield
  • If none of the bits are set, values are printed in decimal notation and read according to standard C++ integer constant conventions
    • leading 0 indicates octal
    • leading 0x or 0X indicates hexadecimal
  • ios::dec
    • integer values will be printed in decimal notation
    • when reading integer values decimal notation will be assumed
  • ios::oct
    • integer values will be printed in octal notation
    • when reading integer values octal notation will be assumed
  • ios::hex
    • integer values will be printed in hexadecimal notation
    • when reading integer values hexadecimal notation will be assumed

floatfield

  • Determine how floating point values are printed
  • If neither flag is set (default), the position of the decimal point determines whether conventional or scientific notation is used
  • ios::scientific
    • If set, floating point values are printed in scientific notation
  • ios::fixed
    • If set, floating point values are printed in conventional notation (e.g. 3.14)

Other Flags

  • ios::showbase
    • Octal numbers are printed with a leading 0 (zero)
    • Hexadecimal numbers are printed with a leading 0x or 0X -- depending on ios::uppercase
  • ios::showpos
    • Positive integer valuse are printed with a plus sign
  • ios::uppercase
    • Uppercase letters are used for the E (exponential notation) and when printing hexadecimal numbers
  • ios::showpoint
    • This flag only applies when ios::scientific and ios::fixed are cleared
    • When cleared, trailing zeros to the right of the decimal place are omitted
    • When set, trailing zeros to the right of the decimal place are not omitted
