Inheritance

  • Inheritance allows a new class to be defined by extending or modifying one or more existing classes
  • The new class is called a derived class
  • The existing class(es) are called base class(es)
  • Inheritance allows us to avoid re-inventing the wheel. Instead of starting from scratch to define a new class, we can build on already existing classes
  • Single Inheritance is when a derived class has only one base class
  • Multiple Inheritance is when a derived class has more than one base class
  • the only members of a base class which are not inherited are:
    • the destructor
    • the constructor(s)
    • member function(s) overloading the assigment operator
  • all other members (data and functions) will be inherited by a derived class

Constructors and Destructors

  • if you do not specify the base class constructor to call in your derived class constructor (via an initialization list), the compiler will call the default base class constructor
  • the base class constructor is always called prior to the derived class constructor
  • destructors are called when it's time to clean up the object (out of scope, deleted, program termination, etc. depending upon how it was allocated). Destructors for base classes are always called after destructors for derived classes
  • It's a good practice to declare your base class destructor as virtual when using inheritance, to insure the correct destructor is called when it's time to clean up the object
  • You can also explicitly declare derived class destructors as virtual (although this is not necessary)

Public & Private Base Classes

  • To specify inheritance, in the class definition, follow the class name with a colon (:) followed by a list of base classes.
  • Each base class can be either public or private

Public Base Classes

  • Private Members are inaccessible in the derived class
  • Protected & Public Members retain the respective attributes
  • Accessible methods inherited from a base class may be overridden
  • In order to override an inherited method, it must have the same argument list (otherwise your overloading NOT overriding) 
    class CParent
{
protected:
     int i1, i2;
};

class CChild : public CParent
{
protected:
     int i3, i4;
};

Private Base Classes

  • Private Members are inaccessible in the derived class
  • Protected & Public Members become Private Members 
    class CParent
{
protected:
     int i1, i2;
};

class CChild : private CParent
{
protected:
     int i3, i4;
};
