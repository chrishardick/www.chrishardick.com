Static Class Members

Both data members & member functions can be declared as static.

Static Data Members

  • Defined only once
  • Shared between all objects of the class
  • Per class variables. As opposed to per object variables
  • One possible use: count the number of objects which exist
  • To initialize a static data member:
    int CBox::ObjectCount = 0;
  • static members exist prior to any objects being created. They are automatically created when the program begins & will be initialized to 0 (zero) unless you initialize them with some other value.
  • static members can be referred to either through
    • objects of the class
    • the class itself

Static Member Functions

  • By declaring a member function static, you make it independent of any particular object of the class.
  • Referencing members of the class from within a static function must be done using qualified names.
  • Static member functions have the advantage that they exist (and can therefore be called), even if no objects of the class exist. 
// A Coding Example

class CBox
{
	public:
		static int ObjectCount;

		CBox (double dL = 0.0, double dW = 0.0, double dH = 0.0)
		{
			m_dLength = dL; m_dWidth = dW; m_dHeight = dH;

			ObjectCount++;
		}

	private:
		double m_dLength, m_dWidth, m_dHeight;
};

void main ()
{
	cout << "# of CBox Instances: " << CBox::ObjectCount << endl;

	CBox MyBox1;

	cout << "# of CBox Instances: " << MyBox1.ObjectCount << endl;
}
