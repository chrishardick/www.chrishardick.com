Inline Functions

  • The compiler will attempt to expand the code in the body of the function in place of the call to the function
  • Inline functions avoid the overhead of calling a function & yield the advantages of macros (without all of the disadvantages)
  • The compiler may not always be able to expand the code (such as with recursion), but generally it will
  • It's best for short, simple functions
  • Any function can be explicitly defined as inline by placing the keyword inline at the beginning of the function header
  • Any function whose definition is contained within a class definition, is implicitly defined as inline 
    inline double CBox::Volume ()
{
	return m_dLength * m_dWidth * m_dHeight;
}

inline void PrintHello ()
{
	cout << "HELLO, WORLD!" << endl;
}
