Function Overloading

  • C++ allows you to define multiple functions with the same name, so long as they all have different parameter lists. When you call the function, the parameter list is used to determine which function should be used.
  • Each function in a set of overloaded functions, is said to have a unique signature, which is determined by its parameter list 
    // An Example. 
// - Max ()

double Max (double dA[], int nLength); 
float  Max (float  dA[], int nLength); 
short  Max (short  dA[], int nLength); 
long   Max (long   dA[], int nLength);
  • Member functions can be overloaded by the keyword const. In other words you could have two member functions with the same name & parameter lists with one defined as a constant member function & one as just a member function.
