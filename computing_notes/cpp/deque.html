STL - Deque

  • in terms of functionality, deques are very similar to vectors
  • the main difference is that insertions and erasures @ the beginning take constant time (rather than linear time for the vector)
  • memory allocation is handled automatically
  • provides random access iterators
  • constant time insert and erase operations at the beginning and at the end
  • insert and erase at any other position (middle) takes linear time
  • the sequence container of choice when the majority of insertions and erasures occur @ either the beginning or end of the sequence
  • validity of iterators: do not write code which depends on iterators remaining valid. Deques do not provide the same guarantees as vectors (albeit limited) as to the validity of iterators when insertions and deletions are occuring
  • Basically has the same interface as vector without reserve() nor capacity() and the additions of push_front() and pop_front()
  • Internal Representation
    • Deques are usually implemented via a 2 level storage structure (see picture below)
    • data blocks are of a fixed size
    • the 1st entries of the directory block which are utilized are the middle
    • when a directory boundary is hit, realloation occurs (i.e. the directory block is swapped for a larger one)

    I. Files

    #include <deque>

    II. Constructors

    • Default Constructor
      • Size: 0 
      deque <T> deque1;
    • A Dector of Size n 
      deque <T> deque1(n);
    • A Dector of Size n each initialized to value 
      deque <T> deque1(n, value);
    • Copy Constructor 
      deque (const deque <T>& deque1);
    • Range [first,last) 
      deque (InputIterator first, InputIterator last);

    III. Destructor

    • release any allocated space for the given deque 
      ~deque()

    IV. Member Functions

    • begin() 
      iterator begin();
const_iterator begin() const;
    • end() 
      iterator end();
const_iterator end() const;
    • operator[]
      • returns the nth element from the beginning of the deque
      • undefined if deque is empty
      • unlike vectors, it does not look like bounds checks are performed 
      reference operator[](size_type n);
const_reference operator[](size_type n) const;
    • size()
      • returns # of elements 
      size_type size() const;
    • max_size()
      • returns max # of elements that could ever be stored in the deque 
      size_type size() const;
    • empty()
      • returns true if the deque contains no elements (size == 0 or begin() == end()), false otherwise 
      bool empty() const;
    • push_front()
      • standard function to add 1 element to the deque at the beginning (front) 
      void push_back(const T& x);
    • push_back()
      • standard function to add 1 element to the deque at the end 
      void push_back(const T& x);
    • insert()
      • insert 1 element to any position within the deque
      • returns iterator to position where the element was added 
      iterator insert(iterator position, const T& x);
    • insert()
      • insert range [first,last) into the deque @ position 
      void insert(iterator position, InputIterator first, InputIterator last);
    • pop_front()
      • standard function to erase 1 element from the deque (from the beginning) 
      void pop_back();
    • pop_back()
      • standard function to erase 1 element to the deque (from the end) 
      void pop_back();
    • erase()
      • erase the element located at position
      • returns iterator to 1 position past where the element was erased or end() if the last element was erased 
      iterator erase(iterator position);
    • erase()
      • erase range [first,last) from the deque @ position
      • returns iterator to 1 position past the last element erased or end() if the last element was erased
      • linear time 
      iterator erase(iterator first, iterator last);
    • clear()
      • erase all elements in the deque
      • equivalent to deque.erase(deque.begin(), deque.end()); 
      void clear();
