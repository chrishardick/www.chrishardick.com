Operator Overloading

  • Enables you to make standard operators (+, -, *, etc) work with objects of your classes
  • You write a function which redefines a particular operator when its used w/ objects of your class
  • Can't create new operators
  • Can't change the precedence of the operator
  • There's only a few operators that you can't override (scope resolution operator ::, conditional operator ?:, sizeof operator sizeof, and a few others)
  • new & delete are operators which can be overloaded
  • Introduces a new keyword: operator
  • define function w/ keyword operator followed by the operator you wish to overload
  • whitespace following the keyword operator is optional unless an ambuigity arises (e.g. new & delete would not make sense: operatornew(), operatordelete() which would be valid function names)

Operator Overload Function as a Member Function

  • left operand of operator is implicitly defined by the this pointer
  • right operand of operator is defined by the passed in parameter

Operator Overload Function as an Ordinary (Non-Member) Function

  • left operand of operator is 1st parameter
  • right operand of operator is 2nd parameter
  • you can also make an operator overload function a friend function, if it needs access to private members of the class 
/*
 * operator overloading example
 */

class CBox
{
	private:
		double m_dLength, m_dWidth, m_dHeight;

	public:
		double Volume() const { return m_dLength * m_dWidth * m_dHeight; }

		bool operator> (const CBox& RHS) const;
};

// operator overload function as a member function
inline bool CBox::operator> (const CBox& RHS) const
{
	return this.Volume() > RHS.Volume();
}

// operator overload function as an ordinary (non-member) function
bool operator> (const double& LHS, const CBox& RHS)
{
	return (LHS > RHS.Volume);
}

Overloading the Assignment Operator (=)

  • If you do not provide an overloaded assignment operator for your class, the compiler will provide a default; it will utilize memberwise initialization (similar to a copy constructor)
  • Don't get confused between the default copy constructor and the default assigment operator
  • The default copy constructor is called when the declaration of a new object is initialized with an existing object of the same class 
    CObj cObj1 = cObj2; // default constructor called
  • The assigment operator is called when the LHS and RHS of an assigment operator are objects of the same class 
    cObj1 = cObj2; // assigment operator called
  • Like any other Operator Overload Function which is a Member Function, the LHS is implicitly defined by the this pointer
  • The assigment operator accepts a const reference and returns a reference
  • Special care must be taken if the class utilizes dynamic memory allocation 
    // an example

CObj& operator= (const CObj& cObj)
{
	if (&CObj == this)
	{
		// addresses equal...nothing to do
		return *this;
	}

	// delete any dynamically allocated memory (prevent memory leaks)
	delete this.abc;

	this.def = cObj.def;
	this.hij = cObj.hij;

	this.abc = new char[strlen(cObj.abc) + 1];

	strcpy (this.abc,cObj.abc);

	return *this;
}

Inheritance, Virtual Functions & Overloading <<

  • Problem: You're using inheritance, you have a base class reference type (e.g. a pointer or a reference) and you want << to utilize dynamic binding to print out the correct object type
  • Solution: Since you cannot make operator<< virtual (the 1st parameter is an ostream reference), you instead have operator<< call a virtual function to take advantage of dynamic binding 
class Parent
{
    public:

        virtual void print_self (ostream& os) const
        {
            os << "Parent";
        }
};

class Child : public Parent
{
    public:

        virtual void print_self (ostream& os) const
        {
            os << "Child";
        }
};


ostream& operator<< (ostream& os, const Parent& p)
{
    p.print_self();

    return os; 
}
