NAMESPACES

  • provide a mechanism to separate the names used in 1 part of a program from those used in another part of the program. I.e. different programming groups can both have a function named foo() or a class named Coo without interfering with each other.
  • everything within a namespace block is implicitly qualified with the namespace name.
  • in order to refer to a name defined within a namespace, the name must be qualified with the namespace name using the scope resolution operator (::) -- unless you use a using directive -- see below
  • inside the namespace, any of the entities declared within the namespace can be referred to without qualification
  • the using directive makes all the names in a given namespace visible without qualification.
  • you can have multiple declarations of a namespace & each namespace will concatenate together. I.e. you will have one big namespace. you can reference names declared in another block without using qualification, etc. 
    
//MyMathStuff.h

namespace MyMathStuff
{
// my math stuff -- functions, variables, classes, templates, anything
}


//myprog.cpp

#include <iostream>
#include <MyMathStuff.h>

using namespace std;
using namespace MyMathStuff;
