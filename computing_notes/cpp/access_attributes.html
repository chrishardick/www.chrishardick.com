Access Attributes

  • public
    • Default access attribute for a struct
    • Class members which are public are accessable to all
  • protected
    • Like private, class members which are protected can only be accessed by member functions of the class
    • Protected members of a base class become private members of a derived class under public inheritance
  • private
    • Default access attribute for a class
    • Class members which are private, can, in general, only be accessed by member functions of the class
    • The exception to this are friend functions--which have access to all members of a class
