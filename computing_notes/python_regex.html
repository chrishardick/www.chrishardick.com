Python: Regular Expressions

  • re module 
    import re

meta characters

  • * - 0 or more of the preceding RE
  • + - 1 or more of the preceding RE
  • ? - 0 or 1 of the preceding RE
  • Greedy vs. Non-greedy - By default, '*', '+', '?' are greedy (longest match possible). Appending a ? after '*', '+', '?' produces a non-greedy match. E.g. '*?', '+?', '??'
  • (re) -- groups and saves matched text
  • a|b -- matches either a or b
  • {n} -- matches exactly n occurrences of the preceding expression
  • {n,} -- matches n or more occurrences of the preceding expression
  • {n,m} -- matches at least n and at most m occurrences of the preceding expression

character classes

  • r'[abcd]' - matches a, b, c, or d
  • r'[^abcd]' - matches anything but a, b, c, d
  • r'[a-z]' - matches any lowercase character
  • r'[A-Z]' - matches any uppercase character
  • r'[0-9]' - matches a digit

Match Object

  • Match objects are returned by successful matches or searches. Otherwise, I believe None is returned
  • Methods:
  • group(0) - returns the entire match
  • group(1) - returns the 1st parenthesized subgroup - assuming subgroups were specified
  • group(2) - returns the 2nd parenthesized subgroup - assuming subgroups were specified
  • start([group]) - return the index of the beginning of the substring matched by group; group defaults to 0 (zero) e.g. entire match
  • end([group]) - return the index of the end of the substring matched by group; group defaults to 0 (zero) e.g. entire match

re.finditer()

  • re.finditer(pattern,string, flags=0)
  • Return an iterator yielding Match objects over all non-overlapping matches for the RE pattern in string
  • The string is scanned left-to-right and matches are returned in the order found
  • Empty matches may be included inthe result
  • flags is a bitmap and multiple flags can be specified by using the bitwise OR operator (| 
res = re.finditer(pattern,str)
if res:
    for match in res:
        idx = match.start()

search Function

# returns: a Match Object on success, none on failure
# 
# use group(num=0) to return the matched portion of the string or specify a number to return a specific saved string (see () above)
#
# modifiers
# re.I -- case insensitive matching
# re.M -- makes ^ and $ match the beginning and end of a line, respectively. Default is for ^ and $ match the beginning end end of a string
# re.S -- makes . match any character (including a newline)
# re.U -- interprets letters according to unicode character set

re.search(  re              # the regular expression to be matched
            ,string         # the string be searched to match the pattern at the beginning of the string
            ,flags=0        # set of flags which can be combined using bitwise OR (|)
            )

Example

str = "Cats are cool!"
match = re.search(r'(.*) are (.*)', str, re.M|re.I)

if match:
    print match.group()         # "Cats are cool!" 
    print match.group(1)        # "Cats"
    print match.group(2)        # "cool!"
    print match.groups()        # ("Cats", "cool!")
else:
    print "NOT A MATCH"
  • The match() function is similar except that that the match must start at the beginning of the string
