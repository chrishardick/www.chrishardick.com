Regular Expressions

  • re module 
    import re

meta characters

  • * - 0 or more of the preceding RE
  • + - 1 or more of the preceding RE
  • ? - 0 or 1 of the preceding RE
  • Greedy vs. Non-greedy - By default, '*', '+', '?' are greedy (longest match possible). Appending a ? after '*', '+', '?' produces a non-greedy match. E.g. '*?', '+?', '??'
  • (re) -- groups and saves matched text
  • a|b -- matches either a or b
  • {n} -- matches exactly n occurrences of the preceding expression
  • {n,} -- matches n or more occurrences of the preceding expression
  • {n,m} -- matches at least n and at most m occurrences of the preceding expression

character classes

  • [abcd] -- matches a, b, c, or d
  • [^abcd] -- matches anything but a, b, c, d
  • [a-z] -- matches any lowercase character
  • [A-Z] -- matches any uppercase character
  • [0-9] -- matches a digit

search Function

    # returns: a MatchObject on success, none on failure
# 
# use group(num=0) to return the matched portion of the string or specify a number to return a specific saved string (see () above)
#
# modifiers
# re.I -- case insensitive matching
# re.M -- makes ^ and $ match the beginning and end of a line, respectively. Default is for ^ and $ match the beginning end end of a string
# re.S -- makes . match any character (including a newline)
# re.U -- interprets letters according to unicode character set

re.search(  re              # the regular expression to be matched
            ,string         # the string be searched to match the pattern at the beginning of the string
            ,flags=0        # set of flags which can be combined using bitwise OR (|)
            )

    Example

str = "Cats are cool!"
match = re.search(r'(.*) are (.*)', str, re.M|re.I)

if match:
    print match.group()         # "Cats are cool!" 
    print match.group(1)        # "Cats"
    print match.group(2)        # "cool!"
    print match.groups()        # ("Cats", "cool!")
else:
    print "NOT A MATCH"
  • The match() function is similar except that that the match must start at the beginning of the string
