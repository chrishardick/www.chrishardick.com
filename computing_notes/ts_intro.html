TypeScript (TS)

  • TypeScript is typed JavaScript.
  • It adds a type system which essentially makes the normal dynamic typing in JavaScript illegal
  • TypeScript uses the JavaScript syntax and adds additional syntaxes for supporting types
  • It is a superset of JavaScript
  • TypeScript code > TypeScript Compiler (tsc) > JavaScript Code > ...
  • TypeScript files use the .ts extenstion 
let x = "foo";
x = 50;     // valid for JavaScript. A compile time error in TypeScript

TypeScript Setup

  • Install Node.js - e.g. via nodejs.org or similar
  • Install TypeScript compiler (tsc) - npm install --global typescript
  • If you want to execute TypeScript directly from Node.js (via ts-node) without precompiling ts into js, you can use the ts-node module - npm install -g ts-node

TypeScript Types

  • JavaScript has 3 primitive data types: string, number, and boolean and each has a corresponding type in TypeScript
  • Most of the time, the variable type can be inferred 
let f = "foo";  // f is implicitly a string
let n = 5;      // n is implicitly a number
let b = true;   // b is implicitly a boolean
  • TypeScript also supports explicitly specifying the types 
let f: string = "foo";      // explicit
let n: number = 5;          // explicit
let b: boolean = true;      // explicit
