Google Test

  • Google Test is a C/C++ testing framework
  • Similar to JUnit or PyUnit

Test Macros

TO VERIFY NON-FATAL CHECK (EXPECT) FATAL CHECK (ASSERT)
a == b EXPECT_EQ (a, b) ASSERT_EQ (a, b)
a != b EXPECT_NE (a, b) ASSERT_NE (a, b)
a < b EXPECT_LT (a, b) ASSERT_LT (a, b)
a <= b EXPECT_LE (a, b) ASSERT_LE (a, b)
a > b EXPECT_GT (a, b) ASSERT_GT (a, b)
a >= b EXPECT_GE (a, b) ASSERT_GE (a, b)
c strings equivalent EXPECT_STREQ(a, b) ASSERT_STREQ (a,b)
c strings not equivalentEXPECT_STRNE(a, b) ASSERT_STRNE (a,b)
c strings equivalent - case ignored EXPECT_STRCASEEQ(a, b) ASSERT_STRCASEEQ (a,b)
c strings not equivalent - case ignored EXPECT_STRCASENE(a, b) ASSERT_STRCASENE (a,b)
condition is true EXPECT_TRUE (cond) ASSERT_TRUE (cond)
condition is false EXPECT_FALSE (cond) ASSERT_FALSE (cond)

Installation Instructions



    

  • git clone https://github.com/google/googletest

  • cd googletest

  • cmake .

  • make

  • sudo make install - this istalled /usr/local/include/gtest/gtest.h and /usr/local/lib/libgtest.a (among other things) for me
