Elementary Socket Functions

  • The purpose of this page is to describe the elementary socket functions:
    1. socket( )
    2. connect( )
    3. bind( )
    4. listen( )
    5. accept( )


  • Typical server:
    1. socket ( ) - create socket (active by default)
    2. bind( ) to well known port
    3. listen( ) - convert to passive socket
    4. accept( ) - blocking function (returns w/ next completed connection)
    5. read( )/write( ) - according to protocol
    6. [close( )] - according to prototocol


  • Typical client:
    1. socket( ) - create socket (active by default)
    2. connect( ) - blocking function (returns either when connection is established or error)
    3. read( )/write( ) - according to prototcol
    4. [close( )] - according to protocol


I. socket ( )

  • create socket (endpoint for communication)
  • returns a socket descriptor
  • called by both client & server
  • by default, the socket is active (i.e. a client socket). An active socket will call connect( ) to connect to a server
  • listen( ) (called only by the server) is used to convert an active socket to a passive socket (waits for incoming connections)
  • family (domain)
    • AF = Address Family
    • AF_INET = IPv4 protocols
    • AF_INET6 = IPv6 protocols
    • AF_LOCAL = UNIX domain protocols
  • type
    • SOCK_STREAM = stream socket (byte stream)
    • SOCK_DGRAM = datagram socket
  • protocol
    • set to 0 for system default for the given family and type 
    /*
 * SOCKET ( )
 *
 * RETURN
 * ======
 * non-negative socket descriptor (sockfd) = success
 * -1 on error (check errno)
 */
#include <sys/socket.h>

int socket (int family,      // AF_INET|AF_INET6|AF_LOCAL
            int type,        // SOCK_STREAM|SOCK_DGRAM
            int protocol);   // 0 = system default for given family & type



/*
 * CODE 
 */
int iListenFD = socket (AF_INET,        // in: address family: IPv4
                        SOCK_STREAM,    // in: socket type
                        0);             // in: protocol - 0 = system default for given family & type

if (iListenFD < 0)
{
        cerr << "ERR: CREATING SOCKET. RC: " << iListenFD << ". STRERROR: " << strerror(errno) << endl;

        exit (-1);
}


II. connect ( )

  • called by a TCP client to establish a connection with a TCP server
  • blocking function. returns only when there is an established TCP connection or an error occurs
  • if connect( ) fails, the socket is no longer usable and must be closed 
    /*
 * CONNECT ( )
 *
 * RETURN
 * ======
 *  0 = success
 * -1 on error (check errno)
 */
#include <sys/socket.h>

int connect (int sockfd,                         // in: socket descriptor returned by socket( )
             const struct sockaddr* servaddr,    // in: socket address structure
             socklen_t addrlen);                 // in: socket address structure length


III. bind ( )

  • Assigns a IP address and/or port to a socket
  • Usually called by a server to bind to its well known port
  • If a client (or server) does not call bind and specify a port #, the kernel will assign an ephemeral port # when either connect( ) (called by the client) or listen( ) (called by the server) is called
  • Normally servers call bind( ) to bind to their well-known port # (servers are known by their well-known port #), while clients let the kernel choose an ephemeral port
  • If a process (either server or client) binds to a specific IP address, the IP address MUST belong to an interface of the host
  • If a server binds to an IP address, it restricts the socket to receiving incoming connections only to that IP address
  • If a client binds to an IP address, the assigned IP address will be used for messages sent from the server 
    /*
 * BIND ( )    
 *
 * RETURN
 * ======
 *  0 = success
 * -1 on error (check errno)
 */
#include <sys/socket.h>

int bind (int sockfd,                         // in: socket descriptor returned by socket( )
          const struct sockaddr* servaddr,    // in: protocol specific socket address structure
          socklen_t addrlen);                 // in: sizeof(servaddr)


/*
 * CODE 
 */

int iRC;
struct sockaddr_in servaddr;            // IPv4 socket address struct

memset (&servaddr,0,sizeof(servaddr));  // init 

servaddr.sin_family             = AF_INET;
servaddr.sin_addr.s_addr        = htonl (INADDR_ANY);   // wildcard address
servaddr.sin_port               = htons (5001); 

iRC = bind (    iListenFD,                      // in: socket descriptor returned from socket()
                (struct sockaddr*) &servaddr,   // in: protocol specific socket address structure
                sizeof(servaddr));              // in: sizeof(servaddr)

if (iRC != 0)
{
        cerr << "ERR: BINDING TO WELL KNOWN PORT. RC: " << iRC << ". STRERROR: " << strerror(errno) << endl;

        exit (-1);
}


IV. listen ( )

  • Called by a TCP server to convert an active socket (socket that will issue a connect( )) to a passive socket (socket that accepts incoming connection requests) 
    /*
 * LISTEN ( )    
 *
 * RETURN
 * ======
 *  0 = success
 * -1 on error (check errno)
 */
#include <sys/socket.h>

int listen (int sockfd,      // in: socket descriptor returned by socket( )
            int backlog);    // in: max # of connections that the kernel should queue for this socket

/*
 * CODE
 */

iRC = listen (  iListenFD,      // in: socket descriptor returned from socket()
                1024);          // in: backlog (max # of connections kernel should queue for this socket)

if (iRC != 0)
{
        cerr << "ERR: LISTEN ERROR. RC: " << iRC << ". STRERROR: " << strerror(errno) << endl;

        exit (-1);
}


V. accept ( )

  • called by TCP server to return the next completed connection
  • blocking function. returns only when there is an established TCP connection or an error occurs 
    /*
 * ACCEPT ( )    
 *
 * RETURN
 * ======
 * non-negative connected socket descriptor (sockfd) = success
 * -1 on error (check errno)
 */
#include <sys/socket.h>

int accept (int sockfd,                     // in:     listening socket descriptor
            struct sockaddr* client_addr,   // out:    socket address structure (protocol independent) of client (pass null if n/a)
            socklen_t* sizeof_client_addr,  // in/out: pass null if n/a
                                                       in:  sizeof struct passed in
                                                       out: sizeof client socket address structure
