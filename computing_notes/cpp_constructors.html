C++ Constructors

  • A Special Member Function automatically called when an object of a class is declared.
  • Provides an opportunity to initialize an object at creation time. Thereby ensuring valid objects (i.e. data members contain only valid data)
  • Constructors ALWAYS have the same name as the class and have NO return type. It is a syntax error to give a constructor a return type (even void)
  • Constructors may be overloaded
  • Constructors (like other functions) may have Default Parameters
    • class Box 
{
	public:
		// Constructor(s)
		Box (double dL=1.0, double dW=1.0, double dH=1.0);

	private:
		double m_dLength, double m_dWidth, double m_dHeight;

};

Default Constuctor

  • A Constructor which is able to accept 0 (NO) Arguments.
  • If you do NOT supply any constructors, the C++ Compiler will provide you with a default constructor which does NOTHING 
    Object::Object() {}  // default constructor equivalent to the one provided by the compiler

Copy Constuctors

  • A copy constructor is a constructor which accepts a constant reference to an object of the same type, for the purpose of initializing the new object (the job of all constructors) with the inputted object
  • If you do not provide a copy constructor for your class, the compiler will provide you with a default copy constructor which calls the copy constructors of the object's members which are classes. For any non-class members (e.g. int, double, pointer), assignment is performed. 
    Object::Object (const Object& rhs) 
{ 
     // copy constructors for class types
     // assignment operators for non-class types
}
  • Passing a const reference avoids an infinite loop. 
    Object x = y;
  • Assuming y is a Object instance, the copy constructor will be called (y will have to be passed in--if it's passed in by value, the copy constructor needs to be called...)

Overriding the Default Copy Constructor

  • Sometimes, you need to override the default copy constructor.
  • Any time your class involves dynamic memory allocation, you need to implement your own copy constructor.
  • Keep in mind, the rule of three. The rule of three states that any time you need to define any of the following: copy constructor, assignment operator, or destructor, you probably need to define all three.
  • Take a look at the following example: 
    class Object 
{
	char* m_szMsg;

    // CONSTRUCTORS
	Object (char* szMsg) { m_szMsg = new char[strlen(szMsg) + 1]; strcpy (m_szMsg, szMsg); }
	Object (const Object& rhs) { m_szMsg = new char[strlen(rhs.m_szMsg) + 1]; strcpy (m_szMsg, rhs.m_szMsg); }

    // assignment operator omitted (breaking the rule of three)

    ~Object () { delete m_szMsg; }
};

Object x = y;   // if we did not provide a copy constructor, the c string inside x and y would be pointing to the same memory
  • Keep in mind that any time you pass an object by value, the copy constructor is called

Preventing Object Copy

  • Sometimes, you want to prevent an object from being copied.
  • To prevent an object from being copied, you declare the copy constructor and assignment operator to be private
  • You do not even need to implement them 
class Foo
{
    private:

        Foo (const Foo& foo);   // private copy constructor

        Foo& operator= (const Foo& foo); // private assignment operator

    ...
};

III. Declaring An Arrays of Objects And Calling A Non-Default Constructor

  • You declare an array of objects exactly the same as you declare an array of scalers
  • Each element of the array causes the default constructor to be called
  • If you would like to use another constructor, the following syntax can be used: 
    Cat myCats[4] = {
	Cat ("Chris",GRAY),
	Cat ("Charles",ORANGE),
	Cat ("Showball",WHITE),
	Cat ("SOCKS",BLACKANDWHITE)
};
  • If you're dynamically allocating an array of objects, the above syntax is not supported. 
    Cat* myCats = new Cat[4];  // default constructor called 4 times
