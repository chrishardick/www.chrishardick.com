Formatting

  • Output streams have member variables which control what ther output will look like
  • Most of these variables can be controlled by either a member function or using special objects called manipulators
  • Most (but not all) of these variables will retain their values.
  • I.e. setting these variables will have a permanent effect on the stream until the values are changed again.
  • Some manipulators are defined in iostream. Some manipulators are defined in iomanip (header files).

Field Width

  • Setting the Field Width allows you to control the width of the subsequent field.
  • Leading blanks will be added to fill up the field.
  • If the content does not fit, the extra characters will be printed regardless of the width
  • You can set the width of the subsequent field by using the setw() manipulator
  • You can also change the field width using a member function
  • Setting the field width is always temporary. I.e. it only affects the next field
  • You can use the setfill(char c) manipulator to change the fill character. The fill character defaults to a blank (' ') 
std::cout << | << std::setw(4) << 55 << | <<std::endl;

// produces
|  55|  

// similar - using the member function
std::cout << |;
cout << width(4)
std::cout << 55 << | <<std::endl;

// leading zeros
std::cout << std::setfill('0');
std::cout << | << std::setw(4) << 55 << | <<std::endl;

// produces
|0055|

Precision

  • Precision is the maximum number of significant digits used to display a floating point number
  • This is the number of digits used to display the number.
  • It includes numbers to the left and the right of the decimal point.
  • If a number cannot be represented with the given precision to the left of the decimal point, the number will be displayed using scientific notation with the specified precision.
  • Precision is a permanent property of the stream.
  • If you make a change, the change remains in affect until another change is made
  • The default precision is 6.
  • Setting the precision to 0 (zero) restores the default precision (6) 
#include <iomanip>    // setprecision

double d = 12345.12345;

std::cout << "|" << d << "|" << std::endl;      // |12345.1|

d = 1234567.123;

std::cout << "|" << d << "|" << std::endl;      // |1.23457e+06|

Fixed Format

  • In fixed format, precision specifies the number of digits to the right of the decimal point
  • In fixed format, a precision of zero means zero digits to the right of the decimal point (e.g. whole numbers) 
// set fixed format - manipulator
std::cout << std::fixed;

// set fixed format - member function
std::cout.setf(std::ios::fixed, std::ios::floatfield);

...

// restoring default
std::cout.setf(0, std::ios::floatfield);


// combining fixed format and precision for fixed number of decimal places
std::cout << std::fixed << std::setprecision(5);

double d(12345.123);

std::cout << d << std::endl;

Width + Fixed Format + Precision = Pretty Display

double d (1234567.123);
double e (12345.1234);

std::cout << std::fixed << std::setprecision(7);

std::cout << "|" << std::setw(15) << d << "|" << std::endl;
std::cout << "|" << std::setw(15) << e << "|" << std::endl;

// output
|1234567.1230000|
|  12345.1234000|
