HTML Introdution

Semantic Elements

  • HTML has semantic elements
  • A semantic element is an element which has a meaning. I.e. header, footer, etc.
  • This is useful because it helps search engines and other automated engines parse web pages in a meaningful way
  • The alternative is everybody coming up with their own tag names which would be difficult for automated engines.

Tags

<a>
anchor - e.g. hyperlink. href attribute - a link beginning with a slash is relative to the base element (e.g. assuming the current page is www.chrishardick.com/dir1/page1.html), href="/dir2/page2.html" would point to www.chrishardick.com/dir2/page2 whereas href="dir2/page2.html" would point to www.chrishardick.com/dir1/dir2/page2.html"
<a> href='http://www.chrishardick.com/interesting_page.html#interesting_id'>An Interesting Page.ID</a>
<div>
A generic block element. I.e. provides no default style.
<link>
A link defines a link between a document and an external resource (i.e. a style sheet). See note above re: href attribute.
<span>
A Generic inline element. I.e. provides no default style.

JavaScript

  • external scripts -- tag can be placed in the body or head sections 
    <script src="script.js">
  • inline scripts -- script tag (can be placed in the body or head sections) 
    <script>...</script>
  • accessing elements 
    var obj = getElementById("MyElement");

Canvas

  • used to draw graphics on a web page on the fly via scripting
  • canvas tag 
    <canvas id="myCanvas" width="200" height="100"</canvas>
  • always specify id, width & height attributes
  • well suited for graphic intensive games
  • you can save the resulting image as .png or .jpg
  • canvas

SVG -- Scalable Vector Graphics

  • SVG element
  • SVG is a language for describing 2D graphics in XML
  • SVG elements are available via DOM. You can attach event handlers to elements
  • If an attribute of a SVG object are changed, the browser will automatically re-render the shape
  • not well suited for game applications
  • good for applications with large rendering areas (e.g. maps)

Video

  • If your site will serve video, mp4 is the suggested format for HTML5
  • video element

Audio

  • If your site will serve audio, mp3 is the suggested format for HTML5
  • audio element
