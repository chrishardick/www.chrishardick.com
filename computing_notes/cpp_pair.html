C++ Pair

  • A simple class template that can store two arbitrary types 
#include <utility>

namespace std
{

template <class T1, class T2>
class pair
{
    public:

        T1 first;
        T2 second;

    // CONSTRUCTOR(S)
    pair () : first(T1()), second(T2()) { }
    pair (const T1& t1, const T2& t2) : first(t1), second(t2) { }
};

}

// e.g.

std::pair <int, double> my_pair(5, 5.1);

cout << "first=" << my_pair.first << endl;
cout << "second=" << my_pair.second << endl;

make_pair()

  • A convenience
  • You need not specify the template parameters, as they are deduced from the function arguments 
template <class T1, class T2>
pair<T1,T2> make_pair (const T1& t1, const T2& t2)


// equivalent statements
pair<int, double> (5, 3.14)
// make_pair(5, 3.14)

std::get() (C++11)

  • In C++11 (and onward), you can use std::get() with an integer template argument to access the elements of a pair 
std::cout << "first=" << std::get<0>(p) << std::endl;
std::cout << "second=" << std::get<1>(p) << std::endl;

Structured Bindings (C++17)

  • Structured Bindings allow you to unpack the elements of the pair into separate variables using square brackets 
auto [x, y] = p;

std::cout << "x=" << x << " y=" << y << std::endl;
