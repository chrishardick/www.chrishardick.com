Java Wrapper Classes

  • Wrapper classes provide a way to use primitive data types (int, double, etc.) as objects
  • Sometimes, you must use wrapper classes, for example when working with ArrayList which can only store objects
  • Like any other object, the variables which point to them are references. Hence, if you do not initialize them, they default to null
  • Each wrapper object has a toString() method - which allows you to obtain the string representation of the object
Primitive Wrapper
byte Byte
short Short
int Integer
long Long
float Float
double Double
boolean Boolean
char Character
Integer i = 5;
Double d = 6.5;
Character c = 'a';
Float f;                // null

System.out.println (i);     // 5
System.out.println (d);     // 6.5
System.out.println (c);     // a
System.out.println (f);     // compiler error
