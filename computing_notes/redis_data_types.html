Redis Data Types

Strings

  • Redis keys are strings
  • Redis values can also be strings
  • Sequence of bytes - text, serialized objects, json strings, binary arrays, jpeg image, etc.
  • Max value size is 512 MB
  • Strings can be used as counters using the INCR, INCRBY, DECR, DECRBY commands which atomically get and increment/decrement a value

List

  • Linked list of string values
