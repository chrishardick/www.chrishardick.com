Redis Data Types

Strings and Integers

  • In Redis, Keys must be strings. More specifically, binary-safe strings
  • A binary-safe string is any arbitrary sequence of bytes - which can include null characters (binary 0 or \0).
  • In other words, in Redis, a string is simply any arbitrary sequence of bytes
  • Plain text, json strings, jpeg images, binary structures, binary arrays, etc. are all valid strings in Redis
  • The maximum string size which Redis supports is 512 MB
  • Redis Values can also be strings
  • Caveat for Values: whereby Redis Keys are always stored as the keys themselves, if a Redis Value is a valid integer, Redis recognizes this and stores it as a 64-bit signed integer.
  • This is how Redis Commands INCR and DECR - which atomically increment or decrement a given value work
