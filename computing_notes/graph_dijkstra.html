Graph - Dijkstra's Algorithm

  • Allows you to determine the shortest path from a given node to every other node
  • The shortest path is the path with the minimum possible sum of weights between 2 verticies in a weighted graph 
A to every other node
Visited Nodes: [A]
Unvisited Nodes: [B,C,D,E,F]
Find distance to all unvisited neighbors
Put a in visited visited notes, remove it from unvisited nodes

Pick a new current node [shortest distance of all unvisited nodes] - B
Find distance from current node to all unvisited neighbors
Mark B as visited (also remove from unvisited)
Visited: [A,B]
Unvisited: [C,D,E,F]

Pick a new current node [shortest distance of all unvisited nodes] - D
Find distance from current node to all unvisited neighbors
Visited: [A,B,D]
Unvisited: [C,E,F]

Pick a new current node [shortest distance of all unvisited nodes] - E
Find distance from current node to all unvisited neighbors
Visited: [A,B,D,E]
Unvisited: [C,F]

Pick a new current node [shortest distance of all unvisited nodes] - F
Find distance from current node to all unvisited neighbors
Visited: [A,B,D,E,F]
Unvisited: [C]

Visited: [A,B,D,E,F,C]
Unvisited: []

We now know the min distance from A to every other node in the graph

For instance, if we wanted to go from  A - C. It would have a cost of 12
Working backward...
C < F  (cost=3)
F < D  (cost=2)
D < B  (cost=5)
B &lr; A  (cost=2)
