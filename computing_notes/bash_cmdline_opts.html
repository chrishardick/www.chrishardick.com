Command-Line Options

Typical UNIX commands have the form command [-options] args, where args are Positional Parameters (see section on Variables). This section is where we discuss processing the -options portion (more commonly called Command-Line Options).

shift
accepts an argument as to the number of positions to shift the command line args to the left (1 is the default value). 
Examples:
         shift   # 1=$2, 2=$3, etc.
         shift 3 # 1=$4, 2=$5, etc.
getopts
  • A Built-In Command similar to Standard C Library Routine getopt ().
  • Takes two arguments: (1) string containing letters and colons, (2) variable name
  • Argument 1: letters => acceptable options. Colon after an option means requires a argument. If string starts with a colon, suppress automatically generated error message.
  • Argument 2: variable to use in the while loop iteration
  • Standard Usage: 
    while getopts ":ab:c" opt; do
     case $opt in
          a  )  process option -a ;;
          b  )  process option -b 
                $OPTARG contains b's argument;;
          c  )  process option -c ;;
          \? )  Usage 
                exit 1
     esac
done
