JavaScript - Objects

  • Objects in JavaScript are implemented as associative arrays (hash maps)
  • Objects are a composite datatype. They allow you to group together variables and functions.
  • As in strongly typed languages (e.g. C++), the variables can be known as properties and the functions as methods.
  • Objects in JS are dynamic -- meaning you can create an empty object followed by adding properties.
  • Since objects are associative arrays, you can access the properties of an object using either dot (.) notation (e.g. box.width) or square bracket ([]) notation (e.g. box["width"]). Square bracket notation is more useful when you want to dynamically construct a property name. Dot notation is useful when accessing static properties (i.e. properties which are not dynamically added/removed, properties known when you're writing the code)
  • If you assign a value to a previously non-existent property, the new property is created for you.
  • All objects have a toString() method which will convert the object to a string
  • Objects are always passed by reference. They are never copied
  • Even assignment is by reference 
    let x = { name: "Chris" };

let y = x;

y.name = "Christopher";

document.write(x.name); // results in Christopher being displayed

Object Literals

    var x = { };    // an empty object
var p1 = {  "fname": "John"
            ,"lname": "Smith"
};
  • An object literal is the simplest way to create an object in JS.
  • It is simply a comma delimited list of properties -- where a property is a colon separated name value pair.
  • If property names contain spaces or any other characters which may be interpreted to have other meaning, they need to be quoted. Hence, It's a good idea to quote your property names
  • Property values are any valid JS expresssion

Creating Objects with new()

  • creates a new object
  • invokes a constructor function to initialize the object
  • Syntax 
    new constructor(arguments)
  • If there are no arguments, the parenthesis can be omitted 
    var o = new Object(); // Create an empty object: equivalent to var o = {}. 
var a = new Array(); // Create an empty array: same as []. 
var d = new Date(); // Create a Date object initialized to the current time 
var r = new RegExp(); // Create a regular expression object for pattern matching.

Arrays

  • In JavaScript, arrays are implemented as objects
  • Arrays in JavaScript are indexed from 0 (zero)
  • Arrays are represented using square brackets. Keep in mind that you can also reference elements of an object (associative array) using square brackets 
    var nums = [ 1, 2, 3, 4];

nums.length;  // 4

var empty [];

nums[0] = 5;  // alter an existing value
nums[4] = 6;  // add a new value


// an array of objects
var obj_arr = [
    {x: 0, y: 0}
    ,{x: 0, y: 1}
    ];
  • Arrays may contain any data type (including references to other arrays, objects, or functions)
  • JavaScript is an untyped language, as such, elements of the same array can contain different types
  • Arrays can be created with the Array( ) constructor 
    var x = new Array();
x[0] = 1;
x[1] = true;
x[2] = 1.2;
x[3] = "Hello, World!";
  • If you only pass a single number to Array(), it's interpreted as the length of the array 
    var y = new Array(10); // an array with 10 undefined elements
  • To determine the number of elements the array contains, use the length property
  • Here is an example of looping thru the elements of an array 
    for (i=0;i<x.length;i++)
{
    // code which accesses x[i]
    ...
}
  • push() adds an item to the end of the array. Push returns the new array length. 
    var len = x.push("another item");     // equivalent to x[x.length] = "another item"
  • pop() removes the last item from an array -- returning the removed value 
    var y = x.pop();
  • The shift() method pops the 1st element of the array shifting all subsequent items to a lower index. It returns the element that was removed
  • The unshift() method adds a new element to the beginning of the array. It returns the new array size.
  • The delete() method removes the specified element from the array leaving an undefined item in its place.
  • The splice() method can be used to add items to an array. It accepts a variable number of parameters. The first is the position where the items should be added. The second defines how many elements should be removed. The remaining parameters define the new elements to be added.
  • The concat() method concatenates two arrays. It does not change the existing arrays. It returns a new array containing both sets of items 
    var items = existing_items.concat(new_items); // items will contain the elements from existing_items followed by the elements from new_items
  • The slice() method will create a new array from the specified elements of the exisitng array 
    var sp_items = existing_arr(1,5)
  • Since arrays are objects, the toString method will convert an array to a string of comma delimited values
  • The sort() method will sort the elements of an array (alphabetically by default). You can override this by providing your own compare function. The compare funcdtion should return a negative, zero or positive value depending if the lhs is less than, equal to, or greater than the rhs. 
    var values = [10, 5, 2,  6, 20];
values.sort(funcion(a,b){return a-b}


  • The reverse() method will reverse all the elements of the array

The RegExp Object

  • JavaScript provides built-in support for regular expressions via the RegExp object
  • JavaScript uses the same syntax as Perl to express regular expressions
  • Text between a pair of slashes is a regular expression literal 
    /^Chris Hardick/

Error Objects

  • JavaScript defines a number of classed that represent errors
  • The JavaScript interpreter, throws an object of one of these types when a runtime error occurs
  • Each error class has a message property that contains a descriptive error message
  • Error, EvalError, RangeError, ReferenceError, SyntaxError, TypeError, URIError

Prototypes

  • Pretty much every object has an associated prototype object (named prototype). Each prototype oobject may also have its own prototype, and so on, and so forth, until an object with a null protototype property is encountered (Object.prototype has a null prototype property)
  • All objects of the same type share the same prototype
  • E.g. all objects of type Rectangle share the same Rectangle.prototype 
    var o = new Object(); // prototype = Object.prototype
var a = new Array(); // prototypes = Array.prototype, which has prototype Object.prototype

  • When you query a property of an object, if the object does not have a property of the given name, its prototype object is checked. If its prototype object does not have the property, the prototype of the prototype is checked, and so on, and so forth.

Constructors Other Than Object( ) - A Better Way to Create Objects

  • In JavaScript a contructor is any function which is invoked via the new operator
  • Contructors are implicitly passed a reference to a newly created empty object -- via the this keyword 
    // Rectangle constructor
function Rectangle (width, height)
{
     this.m_width  = width;
     this.m_height = height;
}

Methods

  • A method is nothing more than a function which is a property of an object
  • When methods are called, they are implicitly passed a reference to their object -- via the this keyword
  • Note that this is a very loose way to create an object -- but remember, this is simply a scripting language 
    function Rectangle_area()             { return this.m_width * this.m_height; }
function Rectangle_set_width(width)   { this.m_width = width; }
function Rectangle_set_height(height) { this.m_height = height; }

// Rectangle constructor
function Rectangle (width, height)
{
     // properties
     this.m_width  = width;
     this.m_height = height;

     // methods
     this.area       = function() { return this.m_width * this.m_height; }
     this.set_width  = function(width) { this.m_width = width; }
     this.set_height = function(height) { this.m_height = height; }
}

Prototype Property - An Object

  • Using a constructor to assign methods is ineffecient - everytime you instantiate an object, it gets a fresh copy of each method - increasing the memory required for each instance (which is usually not what you want)
  • The better method to define object methods is via the prototype property
  • In JavaScript, every object has a prototype property
  • Since constructors are functions and functions in JavaScript are implemented as objects, every constructor has a prototype property
  • All properties and methods of the prototype object are shared between all instances of the object
  • This makes the prototype object an ideal place for object methods and any other constant properties - i.e. do not need to be object specific 
    // Rectangle contructor
function Rectangle (width, height)
{
     // properties
     this.m_width  = width;
     this.m_height = height;

     // methods
     this.prototype.area       = Rectangle_area;
     this.prototype.set_width  = Rectangle_set_width;
     this.prototype.set_height = Rectangle_set_height;
  • Prototype properties are accessed just like they're properties of the object (i.e. in the above example, you'd reference the area( ) method using 'r.area( )' -- not 'r.prototype.area', assuming r is an instance of class Rectangle
  • Scope Resolution. I.e. if you have both a property and a prototype property with the same name, and you're reading, the property takes precedence over the prototype property (i.e. it masks the prototype property).
  • You can never write to a prototype property -- only read. If you attempt to write to a prototype property, you will be creating a new property directly in the object (rather than writing to the prototype property
