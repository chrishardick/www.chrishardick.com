Python: Socket

  • This page attempts to document the socket and asyncode modules
  • The socket module provides low-level access to the BSD socket interface. There is basically a one-to-one relationship to the standard C interface
  • The asyncore module provides a basic interface for writing asynchronous socket clients and servers
  • As of now, I basically only document using the socket module to build a client and the asyncore module for building a server.

socket module

Functions

socket.socket(family,type,proto)
Create a new socket using the given address family, socket type and protocol number.
Address family: AF_INET (default), AF_INET6, AF_UNIX
Socket type: SOCK_STREAM (default), SOCK_DGRAM
Protocol number -- usually 0 (default)

Socket Objects

Socket Object methods

socket.accept()
blocking call. returns upon successfully completing connection. returns a pair (conn, address) where conn is the new socket object and address is the address on the other end of the socket
socket.bind()
socket.close()
socket.connect(address)
socket.listen(backlog)
socket.recv(bufsize[, flags])
i.e. read(). returns the string representing the data received. Bufsize is the maximum amount of data to be received at once. It is recommended to use a relatively small power of 2 (i.e. 4096).
socket.send(string[, flags])
send data to the socket. returns the number of bytes sent.
socket.sendall(string[, flags])
send data to the socket. Unlike send(), this method continues to send data from string until either all data has been sent or an error occurs. None is returns on success. An exception is raised on an error.
