Swift - Objects

Swift objects come in three flavors

  • enum
  • struct
  • class

As in most other programming languages, objects have properties and methods. There are two flavors of each. There are instance properties and methods. There are also instance methods and static/class methods.

Structs and Clases

Structs and Classes in Swift both

  • Support properties
  • Support methods
  • Support subscripts
  • Support initializers
  • Can be extended
  • Support protocols

Classes have additional capabilities:

  • Support inheritance
  • Support type casting
  • Support deinitializers to free resources
  • Support reference counting
  • All built-in object types are structs. E.g. String, Int, Array, etc.
  • As a general guideline, prefer structures when you do not need the added complexity of classes 
struct Struct
{
}

Value Types

  • A Value Type is a type whose value is copied when it is assigned to a variable or constant or when it is passed to a function
  • Structures and Enumerations are Value Types 
struct Foo
{
    var fooVar = 0
}

Foo foo1
Foo foo2 = foo1     // foo1 and foo2 are separate instances

Reference Types

  • A Reference Types is a type whose value is NOT copied when it is assigned to a variable or constant or when it is passed to a function
  • Classes are Reference Types
class Foo { var fooVar = 0 } Foo foo1 Foo foo2 = foo1 // foo1 and foo2 point to the same instance

Identify Operators

  • Since classes are reference types, it's possible for multiple variables to point to the same instance of a class. (this is not possible for structures and enumerations - because each assignment, function call, etc. results in a copy)
  • Swift provides two operators to determine whether or not two constants or variables refer the the same exact class
  • === - identical to operator. Returns true if the two operands point to the same instance of a class.
  • !== - not identical to operator. Returns true if the two operands do not point to the same instance of a class.

Initializers

  • Constructors in other languages
  • Specified by the keyword init followed by a parameter list, followed by curly braces containing the code
  • Initializers can be overloaded by providing a different parameter list
  • All instance properties must be initialized before an instance comes into existence. Otherwise you will receive a compile time error 
class Person
{
    var name = ""
    var age = 0

    init (name:String, age:Int)
    {
        self.name   = name
        self.age    = age
    }

    init (name:String)
    {
        self.name   = name
    }

    // default initializer
    init ()
    {
    }
}

Failable Initializers

  • An initializer which returns an optional wrapping up the new instance is called a Failable Initializer
  • This allows you to return nil to indicate failure
  • To mark an initialier as failable when declaring it, place a question mark after the keyword init
  • You can also place an exclamation mark after keyword init to retrun in implicitly unwrapped Optional
  • Then to return failure to the caller, simply return nil

Subscript Methods

  • A subscript method is a method which called by appending square brackets to an instance reference
  • The square brackets can contain arguments which are passed to the subscript method 
struct Foo

Protocols, Generics, Extensions

Protocols

  • Similar to an abstract base class in C++
  • A protocol defines a blueprint of methods, properties and other requirements
  • A protocol can be implemented by a class, struct, or enum. I.e. they provide a concrete implementation for the requirements
  • Any type which satisfies the requirements of a protocol is said to conform to the protocol 
protocol FooProtocol
{
    var fooVar: String { get }      // must have a gettable instance property of type string named fooVar

    func fooMethod() -> String   // must have a fooMethod method which returns a String
    ...
}

// The FooStruct structure confirms to the FooProtcol
// - multiple protocols can be specified (separated by commas)
struct FooStruct: FooProtocol
{
   ...
}

Generics

  • Similar to templates in C++
  • Array and Dictionary are generics 
func swap<T> (_ a: inout T            // 
                    , _ b: inout T
                    )
{
    let temp = a
    a = b
    b = temp
}
