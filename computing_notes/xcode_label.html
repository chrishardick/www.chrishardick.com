Xcode - Labels

Add a Label

  • In the Object Library, type 'label' in the filter field
  • Drag a Label object on to your scene.
  • Double click the label or use the Attributes Inspector to add text for your label

Create an Outlet for a Label

  • An outlet links a widget in a storyboard to an object property in source code.
  • You can use an outlet to programatically set the text (or any other property) for a label
  • See Xcode Outlets for instructions on how to create an outlet
