C++ Vector

  • basically, a dynamically sizing array
  • memory allocation is handled automatically
  • provides random access iterators
  • amortized constant time insert and erase operations at the end
  • insert and erase at any other position (beginning or middle) takes linear time
  • the sequence container of choice when the majority of insertions and erasures occur @ the end of the sequence
  • inserts can cause reallocation
    • all elements of a vector are stored in a contiguous block of memory
    • if you insert more items than the current capacity of the vector can handle, a larger block is allocated, the elements of the vector are copied from the old vector to the new vector, and the old block is deallocated.
    • reallocation invalidates all iterators and references to elements within the vector
  • erasures invalidate all iterators to positions past the point of erasure (those pointing to previous locations remain valid)

Constructors

  • Default Constructor
    • Size: 0
    • Capacity: Usually 0 (Implementation Specific) 
    vector <T> v;
  • A Vector of Size n 
    vector <T> vector1(n);
  • A Vector of Size n each initialized to value 
    vector <T> v(n, value);
  • Copy Constructor 
    vector (const vector <T>∓ v);
  • Range [first,last) 
    vector (InputIterator first, InputIterator last);

Destructor

  • release any allocated space for the given vector 
    ~vector()

Member Functions

  • begin() 
    iterator begin();
const_iterator begin() const;
  • end() 
    iterator end();
const_iterator end() const;
  • operator[]
    • returns the nth element from the beginning of the vector
    • Bounds checking is not performed.
    • Calling this with an argument n which is out of range produces undefined behavior 
    reference operator[](size_type n);
const_reference operator[](size_type n) const;
  • size()
    • returns # of elements 
    size_type size() const;
  • max_size()
    • returns max # of elements that could ever be stored in the vector 
    size_type size() const;
  • empty()
    • returns true if the vector contains no elements (size == 0 or begin() == end()), false otherwise 
    bool empty() const;
  • capacity()
    • returns largest # of elements the vector can store without reallocation
    • see also reserve() 
    size_type capacity() const;
  • reserve()
    • insures that after the call, the capacity() of the vector is >= n
    • see also capacity() 
    void reserve(n);
  • push_back()
    • standard function to add 1 element to the vector (to the end) 
    void push_back(const T& x);
  • insert()
    • insert 1 element to any position within the vector
    • returns iterator to position where the element was added 
    iterator insert(iterator position, const T& x);
  • insert()
    • insert range [first,last) into the vector @ position 
    void insert(iterator position, InputIterator first, InputIterator last);
  • pop_back()
    • standard function to erase 1 element to the vector (from the end) 
    void pop_back();
  • erase()
    • erase the element located at position
    • returns iterator to 1 position past where the element was erased or end() if the last element was erased 
    iterator erase(iterator position);
  • erase()
    • erase range [first,last) into the vector @ position
    • returns iterator to 1 position past the last element erased or end() if the last element was erased 
    iterator erase(iterator first, iterator last);
  • clear()
    • erase all elements in the vector
    • equivalent to vector.erase(vector.begin(), vector.end()); 
    void clear();
