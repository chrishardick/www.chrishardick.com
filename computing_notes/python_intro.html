Python: Introduction

  • Like most scripting languages, variables in Python are untyped -- they can hold integers, floating point numbers, strings, booleans, etc.
  • Unlike most computer languages, white space matters.
  • Rather than using brackets to denote the beginning and end of control structures, functions, classes, etc., the body of the block is denoted via indention 
    if today == 'Wednesday':
    print "Today is Hump Day"
else:
    print "Today is ", today
  • Unlike most computer languages, noticeably missing are the semi-colons to denote the end of statements. Instead, the end of each statement is denoted by a newline
  • One of the criticisms of Perl was that once written, it was very hard to read -- which proved a barrier for new developers.
  • The things that are different about Python (e.g. whitespace, newlines, etc), seem to address this criticism

Hello, World!

  • As always, the best way to start any new computing language is with a "Hello, World!" program 
    #!/usr/bin/python

print "Hello, World!"

Comments

  • start with a pound sig (#) and continue until the end of line

Import Modules

  • Similar to #include in C/C++
  • import module_name 
    import sys

sys.exit(0)
  • import module_name.member_name 
    import sys.exit

sys.exit(0)
  • from module_name import member_name 
    from sys import exit

exit(0)     # notice we do not need to specify the sys prefix

    from sys import *       # import all functions and constants using * wildcard

exit(0)

2to3

  • 2to3 will convert a python 2 file to python 3
  • Use -w switch to write the file back 
    2to3 -w foo.py

    Misc

    • sys.exit([arg]) - exit script. arg is usually an integer to return to the os; it defaults to 0 - which usually indicates success. If an object is passed, it is printed to stderr and results in an exit code of 1. e.g. sys.exit("bad argument"). sys.exit() throws a SystemExit exception -- so it's possible to catch the exception and handle any clean-up operations which may need to be accomplished prior to script termination
