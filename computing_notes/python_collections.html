deque

  • Double-ended queue
  • Allows adding and removing elements from both ends efficiently.
  • Supports LIFO and FIFO operations
  • append(x) - add x to the right end of the deque
  • appendleft(x) - add x to the left end of the deque
  • pop() - remove and return element from the right end of the deque
  • popleft() - remove and return item from the left end of the deque
  • clear() - remove all items from the deque

deque as a Queue

import collections

q = collections.deque()

q.append('a')
q.append('b')
q.append('c')

while q:
    print (q.popleft())

print ("q is empty")

defaultdict

  • defaultdict is similar to a Python Dictionary - except the defaultdict never raises a KeyError.
  • Instead, it provides a default value if the key does not exist.
  • defaultdict is a subclass of Dictionary. It overrides the __missing__ method to provide a default value for missing keys

E.g. defaultdict with default value of an empty list

from collections import defaultdict

# create a defaultdict with a default value of an empty list
ddict = defaultdict(list)

ddict["A"].append("hello")
ddict["A"].append("world")
ddict["B"].append("happy")
ddict["B"].append("friday")

for d in ddict:
    for i in ddict[d]:
        ...

E.g. defaultdict with default value of an integer

from collections import defaultdict

# create a defaultdict with a default value of an integer
# - integer by default is 0
ddict = defaultdict(int)

ddict["foo"] += 1
ddict["bar"] += 2

for d in ddict:
    print (ddict[d])        

# result:
# 1
# 2
