C++ Function Objects (Functors)

  • Similar in nature to a function pointer
  • The typical use of a function pointer is let another function know how you want something done. I.e. how should sorting occur, or similar
  • Functors do the same thing. However, since they're objects, they can also store state information which makes them more powerful
  • Functors are created by overloading operator()
  • See also std::transform for an example of using an stl transform to call a functor on a container and storing the results in a resultant container 
#include <iostream>

using namespace std;

//==========
// AddX -- a function object which always adds X (set at construction) to the passed in number
//==========
class AddX
{
    private:
        int d_x;

    public:
        AddX (int x) : d_x(x) { }

        int operator() (int y) { return d_x + y; }
};

// using a function object
AddX add10(10);

cout << add10(5) << endl;
