Python: Sqlite

  • sqlite3 module from Python standard library 
    import sqlite3

# create Connection object
# - if the db does not yet exist, it will be created for you
# - use ':memory:' for in memory database
conn = sqlite3.connect('demodb')

# create Cursor object
c = conn.cursor()

# use c.fetchone() to retrieve the next row of a query set result as a tuple or None when no more data is available
# use c.fetchall() to get a list of all (remaining) rows -- returns a list of tuples. An empty list is returned when no rows are available

# you can also treat the cursor as an iterator

for row in c.execute('select a,b,c from foo'):
    print row
   
# commit changes
conn.commit()

# close the connection
conn.close()

sqlite3.connect(database[, timeout, detect_types, isolation_level, check_same_thread, factory, cached_statements])

  • timeout - how long a connection should wait for the lock to be released before raising an exception. Default is 5 (seconds)
  • isolation_level - DEFFERRED (default), IMMEDIATE, EXCLUSIVE. Set to None if you want autocommit mode. This controls which type of begin statement sqlite3 implicitly executes (BEGIN, BEGIN IMMEDIATE, BEGIN EXCLUSIVE or none)

Transactions

  • By default, sqlite3 implicitly opens a transaction before a modification statement (i.e. INSERT/UPDATE/DELETE/REPLACE) and implicitly commits transactions before a non-modification, non-query (i.e. not select) statement
  • In other words, if you are within a transaction and execute a CREATE TABLE
