Python: Exceptions

Handling Exceptions

  • Exceptions are handled via a try/except block
  • If an exception is not handled, the program will immediately terminate 
try:
    // code which might raise an exception
    ...
    
except ExceptionTypeI as eI:                        # catch ExceptionTypeI
    
    print ("ExceptionTypeI Occurred |%s|" % (eI))

except ExceptionTypeII as eII:                      # catch ExecptionTypeII
    
    print ("ExceptionTypeII Occurred. |%s|" % (eII))

except:                                             # catch all other exeptions

    print ("Unknown Exception Occurred")

else:       # executed if no exceptions trigger - you cannot use both else and finally

finally:    # always executed - you cannot use both else and finally 
            # NOTE: finally is always executed (regardless if exception was thrown or not)
            #       However it does not handle the exception. In other words, if an exception
            #       is thrown and you have a finally block without handling the exception 
            #       (no except block(s)), and the exception is not caught higher up the
            #       stack, the exception will be unhandled and the program will terminate

Raising Exceptions

  • You can raise an exception via the raise statement

Syntax

raise [Exception [,args [, traceback]]]
  • An exception can be a string or an object 
// Exception Object 
if input > 500:

    raise RuntimeError("sorry -- that's too large :-(")


// Exception string
if input > 500:

    raise "Invalid Input", input
