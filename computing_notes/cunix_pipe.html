C/UNIX: Pipes

  • A pipe is a connection between two processes. E.g. the standard output of one process becomes the standard input of another process.
  • Pipes are unidirectional. E.g. only one process can write to the pipe and only one process can read from the pipe.
  • Pipes are FIFO (first in, first out). E.g. standard queue
  • Pipes are usually used together with fork() to communicate between parent and child processes.
  • Reading from a pipe is a blocking call. I.e. if no data is available, a call to read() will block until data is available
  • The size of read() and write() calls do not need to match. For instance, you could write in 1024 byte blocks and read in 256 byte blocks (or even 1 byte at a time), or vice versa. 
#include <unistd.h>

//
// pipefd[0] = read
// pipefd[1] = write
//
// RETURN
// ======
//  0 = success
// -1 on error (ERRNO will be set to indicate the error)
//

int pipe (int pipefd[2] /* out */);
