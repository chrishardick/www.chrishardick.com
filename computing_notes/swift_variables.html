Swift - Variables

  • All variables need to be declared using either let or var
  • let declares constant variables
  • var declares normal variables (i.e. non-constant)
  • By convention, type names begin with a capital letter and variable names start with a lower-case letter

Variable Types

Int
Bool
Double
  • The type of a variable is determined when it is declared and can never change
  • The type of a variable can be specified explicitly or implicitly
  • Define the variable type explicitly by adding a colon and the type after the variable declaration 
    // explicitly declaring x to be an Int
var x : Int
  • If you do not specify a type, Swift will infer a type based on the initialization value 
    var i = 1           // i is implicitly defined as an integer
i = 2               // ok
i = "Hello, World"  // compilation error. can't assign a String to an integer

var j : Int = 5
  • Everything in Swift is an object

Global Variables

  • A variable declared at the top level of a file is a global variable. It lives as long as the program runs.
  • It's visible throughout the entire file
  • It's also visible to all other files of the same module
