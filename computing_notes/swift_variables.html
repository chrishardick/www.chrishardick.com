Swift - Variables

  • All variables need to be declared using either let or var
  • let declares constant variables
  • var declares non-constant variables
  • By convention, type names begin with a capital letter and variable names start with a lower-case letter

Variable Types

Int
Bool
Double
Character
String
  • The type of a variable is determined when it is declared and can never change
  • The type of a variable can be specified explicitly or implicitly
  • Define the variable type explicitly by adding a colon and the type after the variable declaration 
    // explicitly declaring x to be an Int
var x : Int
  • If you do not specify a type, Swift will infer a type based on the initialization value 
    var i = 1           // i is implicitly defined as an integer
i = 2               // ok
i = "Hello, World"  // compilation error. can't assign a String to an integer

var j : Int = 1     // declaration and initialization in one step
  • Everything in Swift is an object

Built-In Simple Types

Bool

  • true, false
  • In Swift, nothing is false but false. Nothing is true but true
  • This differs from other languages in which only zero (0) is false and any other number is true

Int

  • The Int object type (a struct)
  • Represents an integer between Int.min and Int.max inclusive.

Integer Literals

  • Any numeric literal without a decimal is an Int by default
  • Internal underscores are allowed (useful for thousands separators)
  • Leading zeros are allowed
  • Scientific notation is supported (everything after e is the exponent of 10 - e.g. 3e2 equates to 3*10^2)
  • Numeric literals can also be specified in binary, octal or hexadecimal by prefixing with 0b, 0o, or 0x respectively

Double

  • The Double object type (a struct) represents a floating point number to a precision of about 15 decimal places (64 bit)

Double Literals

  • Any numeric literal with a decimal is a Double by default
  • Internal underscores are allowed (useful for thousands separators)
  • Leading zeros are allowed
  • Scientific notation is supported (everything after e is the exponent of 10 - e.g. 3.2e2 equates to 3.2*10^2)
  • A Double literal may NOT begin with a decimal point.

Coercion

  • Conversion from one type to another 
let i = 10
let d = Double(i)
println(d)              // 10.0

let dd = 3.4
let ii = Int(dd)        // truncation
println(ii)             // 3

Other Numeric Types

  • Cocoa is full of other numeric types and Swift has types which match each one
  • E.g. Int8, Int16, Int32, Int64
  • UInt8, UInt16UInt32UInt64
  • Float - provides 6-7 decimal places of precision
  • Float80 - extended precision
  • Core Graphics framework CGFloat
  • Types from the C Languages - CDouble, CLong, etc.

Global Variables

  • A variable declared at the top level of a file is a global variable. It lives as long as the program runs.
  • It's visible throughout the entire file
  • It's also visible to all other files of the same module

Local Variables

  • A.k.a. automatic variables
  • Declared inside a function body or within a curly-brace scope
  • Local variables can be seen only by subsequent code within the same scope

Computed Variables

  • Rather than being a stored variable, Swift variables also supports computed variables
  • Rather than having a value, computed variables have two functions - a getter and a setter
  • The setter is called when the variable is assigned to
  • The setter is called set. It takes one parameter. It arrives into the function with the local name newValue
  • The getter is called when the variable is referenced
  • The getter is called get. It must return a value of the same type as the variable
  • The variable must not be a constant. I.e. it must be defined as var and its type must be explicitly dealared
  • There must always be a getter. However, the setter is optional. This is how you create a read-only variable 
var now : String
{
    get
    {
        return NSDate().description
    }
    set
    {
        println(newValue)
    }
}

Setter Observer Variables

  • Functions called just before and just after other code sets a stored variable
  • You can write a willSet function, a didSet function, or both
  • The variable cannot be a constant (i.e. it needs to be defined with var 
var s : String = "blah"
{

    // receives the incoming new value as newValue

Lazy Initialization

  • When a stored variable is assiged an initial value as part of its declaration, and it uses lazy initialization, the initial value is not evaluated and assigned until the variable is accessed
  • There are three types of variables which can utilize lazy initialization: global variables, static properties, and instance properties
  • Global variables and static properties are automatically lazy
  • Instance properties are not lazy by default, but can be lazy using the using keyword lazy. lazy cannot be specified on on a constant. I.e. it can only be declared on a variable declared via var
