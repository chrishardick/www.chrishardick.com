shutdown

shutdown [OPTIONS] <TIME> [MESSAGE]

# options
# -r - request reboot after system has been brought down
# -H - request HALT after system has been brought down
# -P - request POWER OFF after system has been brought down
# -c - cancel a shutdown. time is not specified.
# -k - only send out warning messges and disable logins. do not bring the system down
#
# examples
shutdown now        # shutdown now
shutdown +5         # shutdown in 5 minutes
shutdown 23:59      # shutdown at 11:59 pm
  • Bring the system down.
  • Notify all users
  • Prevent new logins within last 5 minutes
