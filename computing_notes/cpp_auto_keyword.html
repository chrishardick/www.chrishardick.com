C++ - auto keyword

  • Type inference
  • Automatic data type deduction of an expression
  • Types are deduced at compile time
  • The type of the variable which is being declared will be automatically deduced from its initializer 
auto a = 4;             // integer
auto b = 4.2            // double
auto ptrA = &a;         // ptr-to-integer

vector<int> v;

for (auto i = v.begin(); i != v.end(); i++)     // vector<int>::iterator
    cout << *i << endl;
