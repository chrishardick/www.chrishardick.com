1) Private Key Generation

Private Key files have a .key extension

Key Algorithms

  • OpenSSL supports RSA, DSA and ECDSA keys
  • For web server keys, everyone uses RSA
  • For SSH, DSA and RSA are widely used

Key Size

  • The default key sizes might not be secure
  • RSA default size is 512 bits (insecure)
  • 2048 RSA keys are considered secure
  • 2048 bit DSA keys are considered secure
  • 256 bits ECDSA keys are considered secure

Passphrase

  • Private keys with a passphrase will be encrypted
  • Passphrases should be viewed as a mechanism for protecting privatre keys when they are not in production machines
  • Optional, but strongly recommended
  • Useful for storing and transporting a private key
  • However, it's generally considered ok to store passphrases on a production machine
  • For example, the alternative is having to type in your passphrase every time you need to restart your web server
  • This is because once activated, private keys will be kept unprotected in program memory

2) Create a Certificate Signing Request (CSR) and Send it to a CA

CSR files usually have a .csr extension

  • Once you have a private key, you can create a CSR (Certificate Signing Request)
  • A CSR is a formal request to a CA to sign a certificate
  • It contains the public key and some auxiliary information 
# private key to CSR
openssl req -new -key foo.key -out foo.csr

# to check a CSR
openssl req -text -in foo.csr -noout

2a) Signing Your Own Certificate

# .csr to .crt (certificate)
openssl x509 -req -days 365 -in foo.csr -signkey foo.key -out foo.crt

# .key to .crt
openssl req -new -x509 -days 365 -key foo.key -out foo.crt

2b) Creating Certificates Valid for More Than One Hostname

  • E.g. www.chrishardick.com and chrishardick.com
  • There are two ways to accomplish this by using a X.509 extension called SAN (Subject Alternative Name) [recommended] or using wildcards 
# create the following file (foo.ext)
subjectAltName = DNS:*.chrshardick.com, DNS:chrishardick.com

# when using the x509 command to issue a certificate, specify the extension file
openssl x509 -req -days 365 -in foo.csr -signkey foo.key -out foo.crt -extfile foo.ext
