Databases: SQL OVER() clause

  • When using a group by clause in SQL, you can only include columns in your select clause that are also in your group by clause.
  • The over() clause and the over() clause with partition by subclause address this problem
  • The over() clause and the over() clause with partition by subclause produce aggregated columns with each record
  • as opposed to the group by clause which only yields a single row per group in the resultant set
GIVEN:
TABLE: transactions
iddate fld1 fld2 qty
120230601"aaa""bbb"1.1
220230601"bbb""ccc"1.1
320230602"ccc""ddd"6.2
420230602"ddd""eee"6.2

Example using group by

# VALID SQL STATEMENT

SELECT date, sum(qty)
FROM transactions
GROUP BY date

# INVALID SQL STATEMENT - fld1 IS NOT PART OF GROUP BY clause

SELECT date, fld1, sum(qty)
FROM transactions
GROUP BY date

over() clause

SELECT id, date, fld1, fld2, SUM (qty) OVER() as daily_sum
FROM transactions
WHERE date = 20230601
produces the following result: 
1|20230601|aaa|bbb|2.2
2|20230601|bbb|ccc|2.2

PARTITION BY subclause

SELECT id, date, fld1, fld2, SUM (qty) OVER(partition by date) as daily_sum
FROM transactions
produces the following: 
1|20230601|aaa|bbb|2.2
2|20230601|bbb|ccc|2.2
3|20230602|ccc|ddd|12.4
4|20230602|ddd|eee|12.4
