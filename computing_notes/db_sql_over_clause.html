TABLE: transactions

iddate fld1 fld2 qty
120230601"aaa""bbb"1.1

over() clause

SELECT id, date, fld1, fld2, SUM (qty) OVER() as daily_sum
FROM transactions
WHERE date = 20230601
produces the following result: 
1|20230601|aaa|bbb|2.2
2|20230601|bbb|ccc|2.2

PARTITION BY subclause

SELECT id, date, fld1, fld2, SUM (qty) OVER(partition by date) as daily_sum
FROM transactions
produces the following: 
1|20230601|aaa|bbb|2.2
2|20230601|bbb|ccc|2.2
3|20230602|ccc|ddd|12.4
4|20230602|ddd|eee|12.4
