Python: Dictionary

  • A dictionary is written as key:value pairs surrounded by curly braces
  • Keys must be an immutable data type (i.e. strings, numbers, or tuples) -- remember that a tuple is an immutable list 
    states = {   'NY': "New York"
            ,'NJ': "New Jersey"
         }

states['CO'] = "Colorado"

#==========
# loop thru a dictionary
#==========
for abbr in states:
    print abbr, '-->', states[abbr]

#==========
# loop thru a dictionary - sorted keys
#==========
for abbr in sorted(states):
    print abbr, '-->', states[abbr]

# remove an item 
del states['CO']

# prints out the entire dictionary
print states

# check if key exists 
# - use 'in' keyword
if 'NY' in states:
    print "Wooh!"
else:
    print "Boo!"

# dictionary with tuple as key
# i.e. a,b,c --> value
complex_dict = { 
                     (1,2,3): "123"
                    ,(2,3,4): "234"
                    ,(1,5,9): "159"
               }

Dictionary methods

  • dict.clear() -- remove all items from the dictionary

Length

You can use the len() method to obtain the length of a dictionary 
print "length=%d" % len(states)
