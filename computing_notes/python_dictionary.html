Python: Dictionary

  • A Python Dictionary is a mutable collection of key-value pairs
  • Dictionaries are implemented as hash tables
  • A dictionary is written as key:value pairs surrounded by curly braces - see below
  • Keys must be an immutable data type (i.e. strings, numbers, tuples, etc.)
  • Prior to version 3.7, the elements in a dictionary were unordered
  • Starting at version 3.7, dictionaries maintain insertion order 
states = {   'NY': "New York"
            ,'NJ': "New Jersey"
            ,'CT': "Connecticut"
         }

states['CO'] = "Colorado"

# loop thru a dictionary
# - prior to 3.7, this would print out in random order
# - 3.7+, this will print out in insertion order 

for abbr in states:
    print (abbr, states[abbr])


# loop thru a dictionary - sorted keys

for abbr in sorted(states):
    print (abbr, states[abbr])


# remove an item 
del states['CO']


# prints the entire dictionary
print (states)


# check if key exists 
# - use 'in' keyword

if 'NY' in states:
    print ("Wooh!")
else:
    print ("Boo!")

# dictionary with tuple as key
# i.e. a,b,c --> value
complex_dict = { 
                     (1,2,3): "123"
                    ,(2,3,4): "234"
                    ,(1,5,9): "159"
               }

Functions and Statements

Here is a list of stand-alone functions and statements which work on dictionaries

del()

  • The del(dict[key]) statement will remove a dictionary entry with the specified key
  • E.g. del states['NJ']

len()

  • The len(dict) function will return the number of entries in the dictionary
  • E.g. print ("length=%d" % len(states))

str()

  • The str(dict) function will return a string representation of the dictionary

Dictionary Methods

clear()

  • dict.clear() - remove all items from the dictionary

copy()

  • dict.copy() - returns a shallow copy of the dictionary 
d1 = {   1:    'a'
        ,2:    [2]
        ,3:    {4:5}
     }

d2 = d1.copy()

d1[1] = 'aa'        # will only affect d1 - strings are immutable
d1[2][0] = 3        # will affect d1 and d2 - lists are mutable
d1[3][4]=6          # will affect d1 and d2 - dictionaries are mutable

get()

  • Use the get(key,value=None) method to obtain the value for the given key in the dictionary.
  • If the key is not present, None or the value specified will be returned

keys()

  • The keys() method returns an object which is essentially a list of all the keys in the dictionary

pop()

  • The pop(key,default) method removes and returns the value of the specified key from the dictionary.
  • If the key is not found, the default parameter will be returned.
  • If the default parameter was not specified, a KeyError Exception is generated
  • key is required
  • You can use your_dict.(pop(next(iter(your_dict))) to remove the 1st item from the dictionary
  • See also popitem()

popitem()

  • The popitem() method removes and returns the last key-value pair added to the dictionary
  • The removed item is returned as a tuple
  • Prior to 3.7, popitem returned a random item

setdefault()

  • The setdefault(key,default=None) method returns the value of the specified key - if it exists. Otherwise, an entry is added to the dictionary with the specified key and default value
  • The corresponding value is returned. I.e. either the value which existed in the dictionary or the default value - which was just added

values()

  • The values() method returns an object which is essentially a list of all the values in the dictionary

update()

  • The update() method updates the dictionary with elements from another dictionary or iterable of key/value pairs
