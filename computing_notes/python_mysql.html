MySQLCursor Class

import mysql.connector

#
# MySQLConnection.cursor()
# - returns a MySQLCursor object or a subclass object (e.g. MySQLCursorBuffered, MySQLCursorRaw, MYSQLCursorBufferedRaw) - depending on passed in parameters
# - optional parameters
#   buffered - boolean. fetch all rows from the server. useful when queries return small data sets
#   raw - boolean. raw = skip conversion from MySQL data types to Python data types. 
#   dictionary - boolean. whether or not the cursor will return rows as dictionaries
#

cursor = db_conn.cursor()

MySQLCursor Methods

cursor.execute(operation, parms=None, multi=False)
Execute the given database operation.
operation - db query or command. Parameters can be specified using eiher %s or %(name)s
parms - parameters bound to the variables in operation.
multi - allows you to specify multiple operations in operation (seperated with semicolons) 
cursor.execute ("SELECT * FROM foo WHERE foo_id=%(foo_id)s", { 'foo_id': 12345 })
row = cursor.fetchone()
Retrieve the next row of a query result. Returns a tuple or None if no more rows are available. By default, the data is converted to Python objects
rows = cursor.fetchmany(size=1)
Retrieve the next set of rows of a query result. Fewer rows may be returned if fewer rows are available than what was specified. Returns a list of tuples or an empty list if no more rows are available. By default, the data is converted to Python objects
rows = cursor.fetchall()
Fetch all (or all remaining) rows of a query result. Returns a list of tuples or an empty list if no more rows are available. By default, the data is converted to Python objects. This method simply calls fetchone in a loop.
cursor.close()
Use close() when you are done with the cursor.

Create Database

import mysql.connector

host    = "localhost"
user    = "blah"
passwd  = "blah"

db_conn = mysql.connector.connect (host=host, user=user, passwd=passwd)

#
# all DDL (Data Definition Language) statements are executed using a cursor (a handle data structure)
# - DDL statements implicitly xecute commit 
# - a DDL statement is a statement which alters the structure of the database itself 
# - e.g. CREATE, ALTER, DROP
#

db_cursor = db_conn.cursor()

db_cursor.execute ("CREATE DATABASE foo")

db_cursor.execute ("USE foo")

db_cursor.execute ("CREATE TABLE bar (bar1 VARCHAR(255), bar2 VARCHAR(255))")

db_cursor.execute ("USE blah")

Insert Data

import mysql.connector

host    = "localhost"
user    = "blah"
passwd  = "blah"
dbname  = "foo"

# connection object
db_conn = mysql.connector.connect (host=host, user=user, passwd=passwd, database=dbname)

db_cursor = db_conn.cursor()

sql = "INSERT INTO table (f1, f2, f3, f4) VALUES (%(f1)s, %(f2)s, %(f3)s, %(f4)s)"
sql_data = { }
sql_data['f1'] = "v1"
sql_data['f2'] = "v2"
sql_data['f3'] = "v3"
sql_data['f4'] = "v4"

db_cursor.execute (sql, sql_data)

db_conn.commit()

db_cursor.close()
db_conn.close()
