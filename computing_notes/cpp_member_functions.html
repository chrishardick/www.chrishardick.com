C++ Member Functions

  • A function which has its definition or prototype within the class definition.
  • If a member function has its definition within the class, it is implicitly declared as inline
  • It's a good practice to declare all member functions which do not alter the object as constant member functions, which is accomplished by placing the keyword const after both the function prototype and header. Declaring a member function as constant, ensures that it does not modify any of the object's data members. Well, almost all of the objects data members -- constant functions can still modify data members declared as mutable
  • A typical example of a data member you'd declare as mutable is a mutex.
  • See also Virtual Member Functions

// Box class

class Box
{
    double d_length, d_width, d_height;

    public:

        //
        // CONSTRUCTOR
        // - implicitly inline
        //

        Box (   double l=0.0        // default parameters
                ,double w=0.0
                ,double h=0.0
                ) :
                d_length(l)
                ,d_width(w)
                ,d_height(h)
        {}


        //
        // volume() 
        // - constant member function
        // - implicitly inline 
        //

        double volume () const 
        {
            return length * width * d_height; 
        }

        void print_self (std::ostream& os) const;
};

void Box::print_self (std::ostream& os) const
{
    os  << d_length 
        << " " << d_width
        << " " << d_height
        ;
}


std::ostream& operator<< (std::ostream& os, const Box& box)
{
    box.print_self(os);

    return os;
}
