XML Schema - XSD

  • XSD - XML Schema Definition (also known as XML Schema Language) allows you to describe the structure of an XML document
  • Unlike DTD (another schema language), XSD is XML based
  • This means you can parse it using XML parsers, edit it using your favorite XML editor, transform it using XSLT, etc.
  • Furthermore, since it's XML, it's easily extensible

Sample XSD Schema

<?xml version="1.0" encoding="utf-8">
<xs:schema
    xmlns:xs="http://www.w3.org/2001/XMLSchema"        <!-- xs namespace -->
    xmlns:ch="http://www.chrishardick.com"             <!-- ch namespace -->
    xmlns="http://www.w3.org/2001/XMLSchema"           <!-- default namespace (prefix not specified) -->
    elementFormDefault="qualified"                     <!-- all elements in a document following this schema must be ns qualified -->
    targetNamespace="ch">                              <!-- all unqualified elements in this document will be in the ch namespace
                                                            e.g. person will be ch.person -->

<xs:element name="person">
    <xs:complexType>
        <xs:sequence>
            <xs:element name="lastname" type="xs:string"/>
            <xs:element name="firstname" type="xs:string"/>
            <xs:element name="address1" type="xs:string"/>
            <xs:element name="address2" type="xs:string"/>
            <xs:element name="city" type="xs:string"/>
            <xs:element name="state" type="xs:string"/>
            <xs:element name="dob" type="xs:date"/>
            <xs:element name="favorite_number" type="xs:integer" default="7"/>
            <xs:element name="weighting" type="xs:decimal" fixed="1.0"/>
        </xs:sequence>
    </xs:complexType>
</xs:element>

</xs:schema>

Defining An XSD (XML Schema)

The <schema> Element

  • The <schema> element must be the root of an XML Schema
  • The <schema> element can contain attributes - such as the following:
  • xmlns:xs="http://www.w3.org/2001/XMLSchema" (xs namespace)
  • xmlns="http://www.w3.org/2l01/XMLSchema" (default namespace - as a prefix is not specified)
  • elementFormDefault="qualified" - specifies that any elements in an XML document following this schema MUST be namespace qualified

Referencing an XSD (XML Schema)

<?xml version="1.0" encoding="utf-8">

<mail 
    xmlns:ch="https://chrishardick.com"     <-- ch namespace -->
    xsi:schemaLocation="https://chrishardick.com person.xsd"  < namespace followed by schema >
>

...

</mail>

XSD Simple Elements

  • A simple element contains only text.
  • IMPORTANT: It cannot contain other elements or attributes.
  • A simple element is defined as follows: 
    <element name="element_name" type="element_type" />
  • Simple elements can have a default value - a value automatically assigned when a value is not specified
  • Simple elements can also have a fixed value defined. A fixed value is automatically assigned. The user cannot specify another value

Common Simple Types

  • xs:boolean
  • xs:date
  • xs:decimal
  • xs:integer
  • xs:string
  • xs:time

Restrictions

  • Restrictions define acceptable values for XML elements or attributes
  • XSD has robust support for restrictions - the majority of which are not covered by this document 
    <xs:element name="age">
    <xs:simpleType>
        <xs:restriction base="xs:integer">
            <xs:minInclusive value="0"/>
            <xs:maxInclusive value="150"/>
        </xs:restriction>
    </xs:simpleType>
<xs:element>

<xs:element name="stateType">
    <xs:simpleType name="stateType">
        <xs:restriction base="xs:string">
            <xs:enumeration value="Alabama">
            <xs:enumeration value="Alaska">
            <xs:enumeration value="Arizona">
            <xs:enumeration value="Arkansas">
            <xs:enumeration value="California">
            ...
        </xs:restriction>
    </xs:simpleType>
</xs:element>

XSD Attributes

  • Simple elements cannot have attributes
  • If your element requires attributes, it must be a complex element 
    <attribute name="attribute_name" type="attribute_type">
  • Attribute types are the same as those of simple elements
  • Attributes can also have default and fixed values
  • By default, attributes are optional
  • To specify that an attribute is required, set the use attribute to required 
    <attribute name="my_required_attribute" type="xs:string" use="required">

XSD Complex Elements

  • A complex element can contain other elements and/or attributes
  • Complex elements use indicators to specify how elements are allowed to be arranged to construct a valid element
  • Order indicators - sequence, choice, all
  • Occurrence indicators - minOccurs, maxOccurs
  • Group indicators - not covered by this document

Order Indicators

sequence

  • The sequence indicator specifies the child elements must appear in a specific order

choice

  • The choice indicator is similar to a union in that it specifies only one element can be specified

all

  • The all indicator is similar to the sequence indicator, however the elements can appear in any order and each element must appear only once.

Occurrence Indicators

minOccurs

  • specifies the minimum number of times an element can occur
  • the default value is 1
  • minOccurs="0" can be used to specify an optional value

maxOccurs

  • specifies the maximum number of times an element can occur
  • the default value is 1
  • minOccurs="unbounded" can be used to specify a dynamic array
