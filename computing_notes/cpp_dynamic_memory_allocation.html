Dynamic Memory Allocation: new and delete

  • The new operator allocates memory from the heap
  • The delete operator de-allocates memory from the heap so that it can be used for other purposes within the program
  • when calling delete on an array, the following sytax is used 
    double* dArray = new double[5]; 
...
delete[] dArray;
  • when callling new to create objects, the constructor will automatically be invoked
  • when calling delete on objects, the destructor will automatically be invoked
  • See also Inheritance for a discussion on constructors and destructors in the relm of inheritance
  • some examples... 
    double* dPtr = new double(5.5); 
...
delete dPtr;

    char* szStr = new char[20+1];
....
delete[] szStr;
