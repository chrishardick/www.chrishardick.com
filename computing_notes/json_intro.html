JSON

  • JavaScript Object Notation
  • A data format useful for interprocess communication - intra or inter-node
  • Text based
  • Language Independent
  • Commonly used for asynchronous browser to server communication
  • Does not support comments
  • If stored in a file, json files usually have .json extension

Object

  • an unordered set of name/value pairs
  • an object begins with a beginning curly brace ({) and ends with an ending curly brace (})
  • each name/value pair is separated by a comma (,) 
    { string1 : value1, ..., stringN : valueN }

Array

  • an ordered list of values
  • an array begins with a beginning square brace ([) and ends with an ending square brace (])
  • values are separated by a comma (,) 
    [ value1, ..., valueN ]

Value

  • a value can be a string enclosed in double quotes, a number, a boolean (e.g. true or false), null (indicating the absence of a value), an object or an array 
    "Hello World!"

String

  • strings in JSON must be enclosed in double quotes.
  • The following can be escaped (i.e. \")
    • " (quotation mark)
    • / ([forward] slash)
    • \ (back slash)
    • t (tab)
    • n (newline)
    • u 4 digit hexadecimal number
    • f (formfeed)
    • r (carriage return)
    • b (backspace) 
    "Hello World!"

Number

  • numbers in JSON must be in decimal (i.e. octal and hexadecimal formats are not supported). Other than that, numbers can either have a decimal point (i.e. floating point) or an integers. Exponential notation is also supported (i.e. 1.5E4)
