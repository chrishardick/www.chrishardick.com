C++ Default Parameters

  • Specify default parameters ONLY in the function prototype (not the header)
  • Allow you to specify default values for function parameters
  • If you've specified a default parameter & then call the function without specifying the parameter, the default value is used
  • If you want to omit more than one argument, all assignments to the right of the leftmost argument that you omit, must also be left out.
  • As a conclusion, you need to put all arguments which have default values in the function prototype together @ the end of the parameter list, with the most likely to be omitted appearing last. 
    // An Example. 
// - default parameters only specified in the prototype

void showit (const char szMsg[] = "Hello, World", int nX = 5, double dY = 10.0);

void showit (char szMsg[], int nX, double dY)
{
	cout << szMsg << nX << dY << endl;
}
