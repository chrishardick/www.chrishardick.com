JS Client - Debugging

Window Object

  • Each browser tab has its own Window object (named window).
  • It is the global object. Hence you need not prefix its methods and properties with window. -- although you can for clarity.
  • The Window object has the alert() method which is probably the simplest way to debug. It displays a modal pop-up with the passed in string

Console Object

  • The global property console refers to a Console object
  • The Console object has methods which aid in debugging.
  • The most commonly used methods are console.log(), console.info(), console.debug(), console.warn() and console.error() -- which are useful for producing log, info, debug, warning and error trace to the browser console.
