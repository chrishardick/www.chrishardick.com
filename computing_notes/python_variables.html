Python: Variables

  • Like most scripting languages, variables in Python are untyped -- they can hold integers, floating point numbers, strings, booleans, etc.

Strings

  • Strings can be defined using either double or single quotes 
    s = "Hello, World!"
s1 = 'hello, world!'
  • String literals can also be defined using triple quotes -- which make it easier to define multi-line string literals (newlines will be included) 
    print '''line 1
line 2
line 3
line 4'''

# equivalent
print 'line 1\nline 2\nline 3\nline4'

both produce:
line 1
line 2
line 3
line 4
  • You may be access individual characters of a string via indexing (square brackets). Like C/C++, indexing starts from 0 (zero) 
    print s[0] # H
  • Slicing
    • print s[0:5]    # Hello
print s[:5]     # equivalent
print s[7:13]   # World
print s[7:13]   # equivalent
  • Notice with slicing, the beginning character is included and the last character is excluded
  • Raw strings. Treat backslashes as literals -- rather than escape characters. Raw strings are prefixed with an 'r' 
    print r'c:\abc\def' # results in 'c:\abc\def'

String Methods

  • string.isdigit() - return true if all characters in the string are decimal characters. False otherwise. 
    s = "12345"
t = "1234a"
print s.isdigit()   # True
print t.isdigit()   # False
  • string.lower() - return a copy of the string with all upper case characters converted to lowercase
  • string.split(sep=None,maxsplit=-1) - split the string into a list of sub strings based on given delimiter (which defaults to whitespace if not specified). If maxsplit is specified, at most maxsplits are done. 
    s = "Today is too beautiful a day to be spent inside."
words = s.split() # results in ['Today', 'is', 'too', beautiful', 'a', 'day', 'to', 'be', 'spent', 'inside.']
  • string.translate (table[, deletechars]) method - returns a copy of the string translating characters as specified via the table (use maketrans() to construct the table). Optionally delete all chaters found in the string deletechars.

String Constants

string.ascii_lowercase
'abcdefghijklmnopqrstuvwxyz'
string.ascii_uppercase
'ABCDEFGHIJKLMNOPQRSTUVWXYZ'
string.ascii_letters
the concatenation of ascii_lowercase and ascii_uppercase
string.digits
'0123456789'
string.hexdigits
'0123456789AaBbCcDdEeFf'

Built-in Constants

  • False - The false value of the bool type
  • True - The true value of the bool type
  • None - Used to represent the absence of a value
