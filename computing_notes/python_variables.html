Python: Variables

  • Like most scripting languages, variables in Python are untyped - they can hold integers, floating point numbers, strings, booleans, etc.
  • It's usually not recommended, but a single variable can hold different types of values at different points of the program execution.
  • It's perfectly legal to assign an integer to a variable i and later assign a dictionary to it
  • In Python, there are no declarations.
  • To create a new variable, simply assign a value to it 
// i as an integer with value of 0 (zero)
i = 0

// i as an empty dictionary
i = { }

Key Concept - Mutability

  • In Python, all variables are references to objects in memory
  • In other words, when you assign a variable, you are not creating a copy of the data.
  • Instead, you are creating a new variable which points to the existing object
  • This applies to all data types
  • In Python, the key concept is mutability.
  • Mutability affects how assignments affect references to the same object

Variable Types

Python supports the following basic variable types:
  • Numbers - immutable
  • Strings - immutable
  • Booleans - immutable
  • List. Denoted via [ ... ] - mutable
  • Tuple. An immutable list. Denoted via ( ... )
  • Dictionary E.g. { 'key1':'value1', 'key2':'value2', ... } - mutable
  • Set { 'name1', 'name2' } - mutable

Numbers

Python supports the following numerical types:

  • int (signed integer). E.g. 314
  • long (long integer) denoted via L or l. E.g. 51435912L
  • float (floating point). E.g. 3.14, 3.5e10 (3.5 * 10^10)
  • complex (complex numbers) - not covered

None

Python supports the Built-in Constant None to represent the absence of a value.

Booleans

Python supports the following Built-in Constants to represent the boolean values of true and false:

  • True
  • False

Truth

The following are considered False

  • False
  • None
  • Any numeric value with equates to 0 (zero). E.g. 0
  • A string (or any other sequence) with length 0. e.g. '' (zero length string), [] (empty list), () (empty tuple)
  • An empty dictionary
  • An empty set
  • An instance of a user-defined class in which the class defines a __nonzero__() or __len__() method and the method returns the integer 0 (zero) or the boolean False

All other values are considered True

Data Type Conversion

  • int (x) - convert x to an integer
  • long (x) - convert x to a long integer
  • float (x) - convert x to a floating point number
  • str (x) - convert x to a string
  • hex (x) - convert integer x to a hexadecimal string
  • oct (x) - convert integer x to a octal string

Variable Scope and Lifetime

Local Variables

  • A variable defined inside a function is local to that function
  • It is visible (i.e. its scope) is from the point at which its defined to the end of the function
  • Parameters are similar to local variables 
    // global variables
x = 1
y = 2
z = 3

def foo():

    print x         # 1 will print out. in other words, it's possible to access global variables inside of functions

    y = 20          # by default, assignment will create a new local variable

    print y         # 20 will print out

    global z        # using the global keyword to specify that we want to use the global variable z (rather than create a new local variable)

    z = 30

    print z         # 30 will print out


# back in main
print x             # 1 will print out

print y             # 2 will print out -- foo() did not update the global variable

print z             # 30 will print out -- foo() did update the global variable
