BASH

Command Line - Vi Editing Mode

  • Create/append the following to ~/.bashrc - executed for interactive non-login shells 
    set -o vi
  • Create/append the following to ~/.bash_profile - executed for login shells 
    if [ -f $HOME/.bashrc ]; then
    source $HOME/.bashrc
fi
