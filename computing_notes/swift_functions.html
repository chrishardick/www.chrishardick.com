Argument Labeles (External Parameter Names)

func concatenate (  ext1 s:String       # external name: ext1, internal name: s
                    ,ext2 t:String      # external name: ext2, internal name: t
                    ) -> String
{
    var result = ""

    result = s + t

    return result
}

let str = concatenate (ext1:"Hello, ", ext2:"World!")

//
// use # syntax when external parameter name is the same as the internal parameter name
//
func concatenate (  #s:String           # external name = internal name = s
                    ,#t:String          # external name = internal name = t
                    ) -> String
{
    var result = ""

    result = s + t

    return result
}

let s = concatenate (s:"Hello, ", t:"World!")
  • A function can externalize the names of its parameters
  • This forces the callers to specify the external names when calling the function
  • External names are part of the function signature
  • To externalize a parameter name, put the external name before the internal parameter separated by a space
  • The external name can be the same or different than the internal name
  • If the external name is the same, a shorthand can be used - place a # before the internal name (space is optional)
  • Even if external names are used, correct parameter order must be maintained.
  • A frequent occurence is for the first parameter to not have an external name because it's usually apparent what the first parameter is. In addition, Objective-C methods typically work this way.
  • To call a function with externalized names, you specify the external name followed by a colon followed by the actual value
  • TIP: To denote that a paramter does not have an external name, an underscore can be specified. 
    func swap ( _ a: inout int      // explicitly specifying no external name
            ,_ b: inout int     // explicitly specifying no external name
            )
{
    ....
}

// equivalent
func swap ( a: inout int      // no external name (implicit)
            ,b: inout int     // no external name (implicit)
            )
{
    ....
}

Function Overloading

  • Same function name, different signatures
  • Unlike C/C++, functions can be overloaded by return type. However, the context of the call must be clear - otherwise you'll get a compile-time error

Function Signatures

// function signature for a function which accepts two integers and returns an integer
(Int, Int) -> Int

// function signature for a function which accepts no parameters and returns nothing
Void -> Void

// an equivalent function signature
() -> ()
  • External parameter names are part of a function signature

Variadic Parameters

  • The last parameter can be variadic
  • I.e. The caller can supply as many values as they'd like separated by a comma
  • The function will receive these values as an array
  • This is specified via an elipse 
func printStrings (l:String ...) 
{
    for s in l
    {
        println (s)
    }
}

printStrings (  "Hello, "
                ,"World!"
                )

Modifiable Parameters

  • By default, parameters are constants (similar to as if it was declared with let)
  • You can override this by explicitly declaring the variable with var
  • This change is local to the function - i.e. any new value is not visible outside of the function 
func foo (var s:String)
{
    s = "Hello, World!"
}

Output or Input/Output Parameters - (inout)

  • Declare the variables as inout
  • Pass in variables defined via var, not let
  • Pass the address of the argument by preceding its name with an ampersand (&) 
func changeString ( s: inout String
                    ) -> Void 
{
    s = "Goodbye"
}

var s = "Hello"

changeString (&s)

println (s)         // "Goodbye" will print out

Function In Function

  • A function can be declared within another function
  • In which case it can be used after its been defined
  • It's scope (visibility) is limited to the block in which it was defined
  • Useful for helper functions

Recursion

  • Swift supports recursion

Function as Value

  • A function can be used anywhere a value can be used

Closures

  • A self-contained block of functionality which can be passed around your code.
  • Note - the start of the closure's body begins with the keyword in
  • Note - the parameters and return type are written inside the curly braces 
    { ( parameters ) -> return type in
    statements
}

// e.g. 
reversedNames = names.sorted(by: { (s1: String, s2: String) -> Bool in
    return s1 > s2 })
  • If the parameter types and return type can be inferred, they can be omitted 
    // e.g. omitting parameter and return types
reversenames = names.sorted(by: { s1, s2 in return s1 > s2 } )
  • Single Expression Closures can omit their return 
    // e.g. omitting parameter and return types along with return statement
reversenames = names.sorted(by: { s1, s2 in s1 > s2 } )
  • Swift provides default parameter names $0, $1, $2, etc. such that you need not specify parameter names. NOTE: the keyword in can also be omitted since the closure expression consists only of its body 
    // e.g. omitting parameter and return types, return statement, using default parameter names
reversenames = names.sorted(by: { $0 > $1 } )

Capturing Values

  • A closure can capture contants and variables from the surrounding context in which it is defined
  • The closure has access and can modify the values of these constants/variables from within its body 
func makeIncrementer (forIncrement amount: Int)         // external-name internal-name
                    -> () -> Int                  // returns a function which returns an Int
{
    var runningTotal = 0

    func incrementer() -> Int
    {
        runningTotal += amount
        return runningTotal
    }

    return incrementer
}

let incrementByTen = makeIncrementer(forIncrement: 10)

incrementByTen()        // returns 10
incrementByTen()        // returns 20
incrementByTen()        // returns 30

Closures Are Reference Types

  • This means if you assign a closure to two different variables, they will both refer to the same closure 
let incrementByTen2 = incrementBy10

incrementByTen2()       // returns 40
incrementByTen()        // returns 50

Anonymous Functions

  • An anonymous function is a function without a name
  • It's defined the same way a named function is
  • Except the function's parameter list and return type are declared inside the curly brackets followed by the keyword in
  • If the return type can be gleened from the context, the arrow operator and return type can be omitted
  • If the anonymous function takes no parameters and the return type can be omitted, the in line can be omitted entirely
  • If the anonymous function takes parameters and their types can be gleened from the context, their types can be omitted. If their types can be gleened, the parentheses around the paramter list can also be omitted
  • If the return type can be omitted and the parameter types can be gleened from the context, you can omit the in line and refer to the paramters directly within the body of the function using names $0 for the first parameter, $1 for the second parameter, and so on 
{
    () -> () in
    println ("Hello, World!")
}
