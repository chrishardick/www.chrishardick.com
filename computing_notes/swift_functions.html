External Parameter Names

  • To externalize a parameter name, put the internal parameter name separated by a space in the function declaration
  • The external name can be the same or different than the internal name
  • If the external name is the same, a shorthand can be used - place a # before the internal name (space is optional)
  • Even if external names are used, correct parameter order must be maintained.
  • A frequent occurence is for the first parameter to not have an external name because it's usually apparent what the first parameter is. 
function concatenate (#s:String, #t:String) -> String
{
    var result = ""

    result = s + t

    return result
}

let s = concatenate (s:"Hello, ", t:"World!")

Function Overloading

  • Same function name, different signatures
  • Unlike C/C++, functions can be overloaded by return type. However, the context of the call must be clear - otherwise you'll get a compile-time error

Function Signatures

  • External parameter names are part of a function signature 
// function signature for a function which accepts two integers and returns an integer
(Int, Int) -> Int

// function signature for a function which accepts no parameters and returns nothing
Void -> Void

// an equivalent function signature
() -> ()

Variadic Parameters

  • The last parameter can be variadic
  • I.e. The caller can supply as many values as they'd like separated by a comma
  • The function will receive these values as an array
  • This is specified by an elipse 
func printStrings (l:String ...) 
{
    for s in l
    {
        println (s)
    }
}

printStrings ("Hello", ", ", "World!")

Modifiable Parameters

  • By default, parameters are constants (similar to as if it was declared with let)
  • You can override this by explicitly declaring the variable with var
  • This change is local to the function - i.e. any new value is not visible outside of the function 
func foo (var s:String)
{
    s = "Hello, World!"
}

Output or Input/Output Parameters - (inout)

  • Declare the variables as inout
  • Pass in variables defined via var, not let
  • Pass the address of the argument by preceding its name with an ampersand (&) 
func changeString (input s:String) -> Void 
{
    s = "Goodbye"
}

var s = "Hello"

changeString (&s)

println (s)         // "Goodbye" will print out

Function In Function

  • A function can be declared within another function
  • In which case it can be used after its been defined
  • It's scope (visibility) is limited to the block in which it was defined
  • Useful for helper functions

Recursion

  • Swift supports recursion

Function as Value

  • A function can be used anywhere a value can be used

Anonymous Functions

  • An anonymous function is a function without a name
  • It's defined the same way a named function is
  • Except the function's parameter list and return type are declared inside the curly brackets followed by the keyword in
  • If the return type can be gleened from the context, the arrow operator and return type can be omitted
  • If the anonymous function takes no parameters and the return type can be omitted, the in line can be omitted entirely
  • If the anonymous function takes parameters and their types can be gleened from the context, their types can be omitted. If their types can be gleened, the parentheses around the paramter list can also be omitted
  • If the return type can be omitted and the parameter types can be gleened from the context, you can omit the in line and refer to the paramters directly within the body of the function using names $0 for the first parameter, $1 for the second parameter, and so on 
{
    () -> () in
    println ("Hello, World!")
}
