Xcode - Build a Basic UI

Storyboard

  • The Storyboard is a visual representation of the app's user interface - showing screens of content (scenes) and the transactions between them
  • You use storyboards to lay out the flow for your app
  • To open your storyboard, in the Project Navigator, select Main.storyboard
  • Xcode will open the storyboard in Interface Builder (its visual interface editor) in the Editor Pane
  • The arrow that points to the left side is the Storyboard Entry Point (the scene which is loaded when the app starts)
  • Scenes contain UI Objects (e.g. Text fields, labels, buttons, etc.)

Add a Text Field

  • Click on the Storyboard and then click on the Library icon (top right hand corner). The Library icon is text sensitive, it displays different libraries depending on the part of the screen which has focus. iIf you click on the Storyboard, it will display an icon with a circle with a square in the middle - which I guess is the UI Object Library.
  • In the Object Library, type 'text field' in the filter field
  • Drag a Text Field object on to your scene.
  • You can zoom in via: Editor → Zoom
  • With the Text Field selected, open the Attributes Inspector (the icon looks like a downward facing arrow) and enter text for your text field
  • In the Attributes Inspector, find 'Return Key' and select 'Done.' This will make the return key into a 'Done' key
  • In the Attributes Inspector, select 'Auto-enable Return Key' checkbox. This will prevent the user to click 'Done' before typing text into the text field

Add a Label

  • In the Object Library, type 'label' in the filter field
  • Drag a Text Field object on to your scene.
  • Either double click on the label or use the Attributes Inspector to add text to your label

Add a Button

  • In the Object Library, type 'button' in the filter field
  • Drag a Button object on to your scene.
  • Double click the button and or use the Attributes Inspector to add text for your button

Add an Image

  • In the Object Library, type 'image view' in the filter field
  • Drag an Image View object on to your scene.
  • With the Image View selected, open the Size Inspector (looks like a ruler)
  • In the Intrinsic Size field, select Placeholder
  • Enter a value for both the Width and Height fields (e.g. 320)
  • With the Image View selected, click the 'Add Constraint' button and check the 'Aspect Ratio' checkbox
  • With the Image View selected, in the Attributes Inspector, select 'User Interaction Enabled'
  • In the Project Navigator, select Assets.xcassets to view the asset catalog. The asset catalog is a place to store and organize the image assets for your app.
  • On the bottom left corner, of the Project Navigator, click the plus (+) button and select 'New Image Set' and the Image Set will display in the Editor Pane
  • Create an Outlet (outlets connect Storyboard Objects to a variable)
    • Display ViewController.swift in an additional editor window
    • Click and drag a picture from your computer onto the 2x slot
    • Display the Storyboard and select the Image View
    • Control-drag from the Image View to ViewController.swift - just below the existing outlets
    • In the dialog which appears, enter a name, and click 'Connect'
  • A Image View is not normally an object which responds to user events
  • A Gester Recognizer is an object which you can attach to another object which allows the object to respond to user events
  • You can use an Action which is called when a Gester Recognizer recognizes a gester (e.g. swipe, pinch, rotation, etc.)
  • To attach a Tap Gester Recognizer (UITapGesterRecognizer) an Image View:
    • In the Object Library, type 'tap gesture' in the filter field
    • Drag a Tap Gester Recognizer on top of the Image View
    • The Tap Gesture Recognizer object wil apprea in the scene dock. The scene dock is the bar above your story board
  • To connect the Gester Recognizer to code:
    • Control-drag from the Gester Recognizer in the scene dock to the code display right next to the other actions
    • Choose a name
    • For Type, select UITapGestureRecognizer
    • Press 'Connect'
  • To create an image picker to respond to user taps
    • When a user taps on an image, we would like the user to be able to choose an existing photo or take a new one.
    • The UIImagePickerControllerDelegate protocol supports this
    • We'll also need the UINavigationControllerDelegate protocol
    • We'll specify that the ViewController supports these protocols

Auto Layout

  • A Stack View (UIStackView) is one of easiest ways to define your layout.
  • It allows you to lay out a collection of views in either a column or a row.
  • To add a Stack View, while pressing the Shift key, select the fields you want to include in the stack view
  • On the bottom right of the canvas, click the 'Embed in' icon' and choose 'Stack View') or choose Editor → Embed In → Stack View
  • On the bottom right, open the 'Add New Constraints' menu - it looks like a square with a vertical line on each side
  • The constraints menu allows you to specify the spacing to the nearest leading, trailing, top and bottom neighbors
