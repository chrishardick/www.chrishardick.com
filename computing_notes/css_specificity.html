CSS - Specificity

  • It is possible that the same element is selected by two or more conflicting rules.
  • When an element has two or more conflicting rules, the one with the highest specificity according to the following rules is the one which is applied.
  • inline styles (styles specified within the tag itself) have the highest specificity (priority)
  • ID selectors have the 2nd highest specificity (priority)
  • class selectors have the 3rd highest specificity (priority)
  • element selectors have the least specificity (priority)
  • When evaluating specificity, the html rendering engine will split declarations apart.
  • For example: 
    h1.em { color: white; background: black; }
  • is treated as if it was two separate rules: 
    h1.em { color: white; }
h1.em { background: black; }

Inheritance

  • Inheritance is the method by which style is applied not only to a given element, but also its depenedants 
    body { color: red; }
  • Inherited values have no specificity
  • Most box model properties (margins, borders, and padding) are not inherited.

Cascade

  • The cascade rule states that for rules of equal specificity, the later the rule appears in the document or style sheet, the higher its precedence
