CSS - Cascading Style Sheets

Introduction

  • Cascading style sheets describe the presentation of an HTML document
  • Whereas HTML defines the structure of a document, CSS defines the presentation
  • Before CSS, if you managed a large site (or multiple sites) and wanted to universally change the formatting, you would have had to modify each page individually. With CSS, this task becomes greatly simplified

Comments

  • Only C style comments are supported 
    /* a css comment */

External Style Sheets, Internal Style Sheets, and Inline Styles

External Style Sheets

  • Great for managing style across an entire site
  • External style sheets are specified by a <link> element inside the <head> section
  • The media attribute defines which media the style should be applied to. Common values are: all, screen, and print. You may also specify a comma separated list when you want the style to be applied to multiple (but not all) media 
    <head>
...
<link rel="stylesheet" type="text/css" href="style.css" media="all">
...
</head>

Internal Style Sheets

  • Internal style sheets are used to define style for a single page
  • Internal style sheets are defined within the <style> element inside the <head> section
  • You can also specify mediums via the media attribute 
    <head>
...
<style>
...
</style>
...
</head>

Inline Styles

  • Inline styles are used to define style for a single element 
    <tag style="...">...</tag>

HTML Elements

  • Replaced elements are elements which are completely replaced by other content. An example of a replaced element is the img element.
  • Non-replaced elements are all the other elements. E.g. h1, h2, p, etc.
  • Block elements are elements in which a break is implicitly added before and after the element. Block level elements cannot have additional content to the left and right of the element. Examples include: h1, h2, p, and div. Div is a block level element in which browsers (and other html rendering engines) do not implicitly add any other style.
  • Inline elements do not implicitly add a break before and after the element. Examples include: strong, a, span. Span is an inline element in which browsers (and other html rendering engines) do not implicitly add any other style.

Rules

  • Style sheets allow you to specify rules to describe the presentation of your documents
  • Each rule consists of a selector list and a declaration block 
    selector list { declaration list }

Selector Lists

  • A selector is how you specify which html element(s) a given style should be applied to
  • A selector list is a comma separated list of selectors

Declaration Block

  • Declarations are where you specify which style(s) should be applied to the elements matching the selector
  • Each declaration in the declaration list is of the form property:value;
  • The semi-colon (;) is always required. even if there is only a single declaration
  • If a value has a unit (e.g. 12px), do not put a space between the value and the unit

Element Selectors

  • Selects elements based on the element name 
    h1,h2 { color:red; font-size:12px; }
  • There are also Pseudo-element selectors.
  • Pseudo elements are elements not specified by the author of the page, but instead are added implicitly by the browser.
  • Common pseudo-element selectors include first-letter and first-line which apply to the first level
  • Pseudo-elements are specified via ':first-letter'. For example, the following would apply to the first-letter of all paragraph elements 
    a:first-letter { font-size: 200%; }

id Selectors

  • Selects elements based upon the id attribute of an HTML element
  • The id of an element should be unique within a page.
  • To select based upon an id, the selector is a hash or pound sign (#) followed by the specific element id
  • id's cannot start with numbers
  • The following will select the element on the page with id="my_id" 
    #my_id { color: purple; }

<p id="my_id"> ... </p>
  • id names are case sensitive

Class Selectors

  • Selects elements based upon class attribute
  • To select based on class attribute, the selector is specified as a period followd by the class name
  • The following will select all elements with class="center" 
    .center { text-align: center; }
  • You can also restrict a class selector based on a given element type 
    p.center { color: green; }
  • HTML elements can belong to multiple classes 
    <h1 class="center important">
  • Class names cannot start with numbers
  • Class names are case sensitive
  • There are also Pseudo-Class Selectors. Pseudo-class selectors are classes not specified by the author of the page, but instead are added implicitly by the browser.
  • The most common pseudo class selector is visited. visited is a class added by the browser to a link which has already been visited.
  • pseudo-class selectors are specified using a colon (:) rather than a period 
    a:visited { color: red; }
  • Other pseudo-class selectors include:
    • :focus -- an element that currently has the input focus.
    • :hover -- an element in which the mouse pointer is currently hovering over
    • :active -- an element that has been activated by the use input

Descendant Selectors

  • Descendant selectors allow you to apply style to a document based upon the structure of the document.
  • For example, let's say you wanted to style <em> elements which were desendants of <ul> or <ol> elements
  • Descendant selectors are specified via a space delimited selector list.
  • The following would select based upon the example above 
    ul em, ol em { color: purple; }
  • Keep in mind that descendant (and ancestor) are more generic than child (and parent) and that descendant selectors apply to the more general ancestor/descendant relationship.

Generated Content

  • Let's say you wanted to suffix every h2 element with the paragraph symbol -- ¶ similar to the Python web-site, you could use the following: 
    h2:after { content: " ¶;" }
  • Similarly, if you wanted a prefix: 
    h2:before { content: " ¶;" }

Specificity, Inheritance, and Cascade

Specificity

  • It is possible that the same element is selected by two or more conflicting rules.
  • When an element has two or more conflicting rules, the one with the highest specificity according to the following rules is the one which is applied.
  • inline styles (styles specified within the tag itself) have the highest priority
  • ID selectors have the 2nd highest priority
  • class selectors have the 3rd highest priority
  • element selectors have the least priority
  • When evaluating specificity, the html rendering engine will split declarations apart.
  • For example: 
    h1.em { color: white; background: black; }
  • is treated as if it was two separate rules: 
    h1.em { color: white; }
h1.em { background: black; }

Inheritance

  • Inheritance is the method by which style is applied not only to a given element, but also its depenedants 
    body { color: red; }
  • Inherited values have no specificity
  • Most box model properties (margins, borders, and padding) are not inherited.

Cascade

  • The cascade rule states that for rules of equal specificity, the later the rule appears in the document or style sheet, the higher its precedence

CSS Properties

Fonts

font-family

  • Values: font-family list [serif, sans-serif, monospace, cursive, fantasy, specific font name]
  • Default value: html rendering agent specific
  • Applies to: all elements
  • font-family: "Times New Roman", Times, serif;

font-weight

  • Values: normal, bold, bolder, ligher
  • Default value: normal
  • Applies to: all elements

font-size

  • Values: xx-small, x-small, small, medium, large, x-large, xx-large, smaller, larger, <length>, <percentage>
  • Default value: medium
  • Applies to: all elements

font-style

  • Values: italic, oblique (slanted only), normal
  • Default value: normal
  • Applies to: all elements

font-variant

  • Values: normal, small-caps
  • Default value: normal
  • Applies to: all elements

Text Properties

text-align

  • Horizontal alignment
  • Values: left, center, right, justify
  • Default value: html rendering agent specific
  • Applies to: block-level elements

line-height

  • Line height
  • Values: normal, <length>, <percentage>, <number>
  • Default value: normal
  • Applies to: all elements

vertical-align

  • Vertical alignment (e.g. subscript, superscript)
  • Values: baseline, sub, super, top, text-top, middle, bottom, text-bottom, <length>, <percentage>
  • Default value: baseline
  • Applies to: inline elements and table cells

text-transform

  • Adjust capitalization
  • Values: none, uppercase, lowercase, capitalize
  • Default value: none
  • Applies to: all elements

text-decoration

  • Text decoration
  • Values: none, underline, overline, line-through, blink
  • Default value: none
  • Applies to: all elements

Background

background-color

Like all color properties, you can set this via either of the 3 color specification types:
  • a valid color name (e.g. red, green, etc.)
  • a hex value (e.g. #00ff00)
  • a rgb value (e.g. rgb (0,255,0))

Content Area, Padding, Borders, and Margins

Content Area

width
  • Specify the width of the content area
  • Values: auto, <length>, <percentage>
  • Default value: auto
  • Applies to: block-level and replaced elements
height
  • Specify the height of the content area
  • Values: auto, <length>
  • Default value: auto
  • Applies to: block-level and replaced elements

Padding

  • The space immediately around the content area
  • Background extends into the padding, but not the margins
padding
  • Values: <length>, <percentage>
  • Default value: not defined
  • Applies to: all elements

Borders

  • Borders surround the padding of an element
border-style
    p {border-style: solid;}
  • If you do not specify a border style, the other border properties will have no effect.
  • Values: solid, dotted, dashed, none, hidden
border-width
    p {border-style: solid; border-width: 5px; }
  • border-width can be set via the border-width property
border-color
border

Margins

  • The margin is the area surrounding the borders

Colors & Backgrounds

color

  • Foreground color
  • Values: <color>
  • Default value: html rendering agent dependant
  • Applies to: all elements

background-color

  • Background color
  • Values: transparent, <color>
  • Default value: transparent
  • Applies to: all elements

background-image

  • Set backgound image
  • Values: none, <url>
  • Default value: none
  • Applies to: all elements

background-repeat

  • Background repeat
  • Values: no-repeat, repeat, repeat-x, repeat-y
  • Default value: no-repeat
  • Applies to: all elements

background-position

  • Control the placement of the background image
  • Values: left, center, right
  • Default value:
  • Applies to: block-level and replaced elements

background-attachment

  • Values: scroll, fixed
  • Default value: scroll
  • Applies to: all elements

Positioning

Types of Positioning

  • static
    • normal
  • relative
    • the element's box is offset
  • absolute
    • the element's box is removed entirely from the flow of the document and positioned with respect to its containing block
  • fixed
    • like absolute, except that instead of the containing block, the element's box is positioned with respect to the viewport

position

  • Values: static, relative, absolute, fixed
  • Default value: static
  • Applies to: all elements

top, bottom, left, right

  • Values: auto, <length>, <percentage> (refer to the height of the containing block)
  • Default value: auto
  • Applies to: all elements
