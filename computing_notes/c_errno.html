C: errno

  • errno.h is a header file of the standard C library
  • As a standard rule, traditional UNIX C functions return 0 on success and -1 on error.
  • If you received a return code of -1, you could check errno for more information on what the actual problem was.
  • If you're in a multi-threaded environment, errno is usually stored in thread specific storage

strerror

  • strerror() and related functions are used to convert an errno integer into a meaningful string 
//
// string.h
//

char* strerror(int errnum);     // not guaranteed to be thread-safe

int strerror_r (int errnum, char* buf, size_t buflen);  // thread-safe

//
// An example
//

#include <errno.h>
#include <string.h>   // strerror, strerror_r()

//
//
//

int rc = foo();

if (rc == -1)
{
    printf ("Error calling foo. %s", strerror(errno));
}
