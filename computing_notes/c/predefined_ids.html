Predefined Identifiers

__LINE__
Current Line # Being Compiled 
__FILE__
Name of Current Source Code Being Compiled 
__DATE__
Date of Compile: Mmm dd yyyy 
__TIME__
Time of Compile: hh:mm:ss 
__STDC__
Defined as 1 if compiler confirms to ANSI Standard


EXAMPLE: 
fprintf (stderr,"Line:%d File:|%s| Compiled:%s @ %s. ANSI: %d\n",__LINE__,__FILE__,__DATE__,__TIME__,__STDC__);
