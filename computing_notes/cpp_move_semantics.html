C++ Move Semantics

  • C++11 introduced move semantics
  • Attempts to solve the problem of temporary object creation - which is wasteful
  • Allows the contents of objects to be moved between objects - rather than copied

lvalue

  • You can make assignments to a lvalue
  • LHS (left hand side) of assignment
  • An expression whose address can be taken 
int g_int = 5;



//
// global_ref() is a lvalue
//
int& global_ref()      // returns a reference to a global variable
{
    return g_int;
}

rvalue

  • A rvalue is an expression which results in a temporary object 
string g_str ("foo");

//
// global_int() is an rvalue
//
int global_int()      // returns a temporary object
{
    return g_int;
}

//
// likewise, global_string() is an rvalue - it returns a temporary object
//
string global_string ()
{
    return g_str;
}

rvalue reference

  • rvalue reference a reference which can only bind to a temporary object
  • An rvalue reference is denoted as type&& 
string&& str = global_string(); // str is an rvalue reference

Move Constructors and Move Assignment Operators

  • A Move Constructor (same as a copy constructor) accepts an instance of the object as its argument and creates a new instance based on the passed in object. However, since its argument is (by definition) a temporary object, it can avoid the memory allocation by transferring the fields from the temporary object to the newly constructed object
  • Move Assignment Operators are similar 
class Array
{
    private:
        int* d_vals;
        int d_size;

    public:
        Array (int n) :
            d_vals(new int[n])
            ,d_size(n)
        { }

        int size () const       { return d_size; }
        int& size ()        { return d_size; }

        int* vals ()            { return d_vals; }

        // copy constructor
        // - deep copy
        Array (const Array& a) :
            d_vals (new int[a.size()])
            ,d_size (a.size())
        {
            for (int i = 0; i < size(); i++)
            {
                d_vals[i] = a.vals()[i];
            }
        }

        // assignment operator
        Array& operator= (const Array& rhs)
        {
            // similar logic
        }

        // move constructor
        // - shallow copy
        Array (Array&& a) :
            d_vals (a.vals())
            ,d_size (a.size())
        {
            // invalidate temp object
            a.vals() = 0;
            a.size() = 0;
        }

        // move assignment operator
        Array& operator (Array&& rhs)
        {
            // similar logic
        }

        ~Array ()
        {
            delete [] d_vals;
        }
};
