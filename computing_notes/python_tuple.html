Python: Tuple

  • A tuple is an immutable sequence of objects
  • Similar to lists -- but immutable
  • Anytime you specify a comma separated list, you're defining a tuple. E.g. x = 1, 2, "abc", "def"
  • Optionally, you can surround the list with parenthesis. E.g. x = ( 1, 2, "abc", "def")
  • Empty tuple. E.g. x = ( )
  • A tuple with a single element -- you need to specify the comma. E.g. x = (1, )
  • You access individual elements the same way you access elements in lists (square brackets). Tuples (like lists) are indexed from 0 (zero)
