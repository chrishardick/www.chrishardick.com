C++ - std::bind and std::function

std::bind

  • std::bind allows for partial function specialization
  • I.e. It allows you to bind one or more parameters to values and to specify placeholders for others
  • Returns a function object based on Fn with its arguments bound to Args
  • Each argument may be bound to a value or bound to a placeholder 
#include <functional>

//
// where 
// Fn is a function object, pointer to a function, pointer to member function, etc.
// Args is a list of arguments to bind - either values or placeholders
//
template <class Fn, class... Args>
    bind (Fn&& fn, Args&&... args);

//
// an example where all parameters are bound to values
//

double divide (double x, double y) { return x / y; }

auto d1 = std::bind (divide, 10, 2);

std::cout << d1() << std::endl; // 5


//
// an example using a placeholder
//

using namespace std::placeholders; // _1, _2, ...

auto divide_by_2 = std::bind (divide, _1, 2);

std::cout << divide_by_2(10) << std::endl;


//
// binding member functions
// - a non-static member function must be called with an object
//

struct Pair 
{
    double a, b;

    double multiply () { return a*b; }
};

Pair p1 { 10, 2 }; 

auto m1 = std::bind (&Pair::multiply, _1)   // where _1 is the object instance

std::cout << m1(p1) << std::endl;  // 20

std::function

  • A wrapper for storing any type of function, lambda function, functor, or function pointer
  • The idea behind std::function is to be able to refer to all callable objects in an interchangeable manner.
  • Requires you to specify the exact types of the argument list and the return value
  • You can test if it has been set by checking for 0 (NULL) 
#include <functional>

template <class Ret, class... Args> 
    class function <Ret(Args...)>;

std::function<bool (const std::string&)> func;
