Java: Variables

  • In Java, you cannot use a variable before it's initialized
  • Instance variables of a class are automatically initialized to default values - 0 (zero) for numeric types, false for boolean, or null for reference types if you do not explicitly initialize them.
  • Local variables - defined within a method - are NOT automatically initialized. Attempting to use a local variable before it is initialized results in a compiler error

In Java, there are:

  • Instance Variables - non-static member variables unique to each class instance
  • Class Variables - static members - in which there is exactly one copy per class
  • Local Variables - temporary variables declared within a method

Primative Variables

  • Java is statically-typed (all variables must be declared - along with their type - before they can be used).
  • However, starting with Java SE 10, you can use the var identifier to declare a local variable allowing the compiler to determine the type
  • byte - 8 bit two's complement integer [-128, 127].
  • short - 16 bit two's complement integer [-32,768, 32,767].
  • int - 32 bit two's complement integer [-231, 2-32-1]
  • long - 64 bit two's complement integer [-263, 2-64-1].
  • float - 32 bit IEEE floating point.
  • double - 64 bit IEEE floating point.
  • boolean - has only two possible values true and false. The size of boolean is not precisely defined.
  • char - 16 bit Unicode character. 
int i = 5;

// var example
var str = "Hello, World!";

Final Variables

  • Variables declared as final are constant. I.e. their value cannot be changed 
final int pi = 3.14159;

Reference Variables (References)

  • In Java, a reference variable points to an object
  • Whereby a primative variable holds the data itself, a reference variable holds a reference (e.g. the address) to an object
  • A reference variable can also point to a special value - null - which indicates that the reference is currently pointing to nothing
  • You can create multiple reference variables which point to the same object
  • This is similar to when you pass an object to a method. 
// f is a reference 
Foo f; 

// f points to the newly created object
f = new Foo();

// same thing - single line - f is a reference variable which points to a newly created Foo object
Foo f = new Foo();

// f1 and f both point to the same object
Foo f1 = f;
