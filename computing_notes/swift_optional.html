Swift - Optionals

  • E.g. Nullable
  • Represented via Optional<Type>. E.g. Optional<Int>
  • Optionals can also be specified via the type name followed by a question mark. E.g. Int?
  • In many contexts, you must unwrap the value of an optional before you can use it 
let x: Optional<Int> = 400

// equivalent (using short-hand)
let x: Int? = 400

Optional Binding

  • To conditionally bind the wrapped value of an Optional to a new variable, use one of the optinal binding structures, including: if let or switch 
if let foo = optionalFoo
{
    print ("optionalFoo has a value - '(\foox)'")
}
else
{
    print ("optionalFoo is nil")
}

Unconditional Unwrapping

  • When you're sure an Optional contains a value, you can unconditionally unwrap it using the forced unwrap operator (postfix !)
  • Unconditioanally unwrapping a nil instance will produce a runtime error 
let opt_n: Int? = 400   // an optional
let n = opt_n!          // unconditional unwrapping
