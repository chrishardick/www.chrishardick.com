Variables

    var i,j,k;
var a=0, b="abc", c=5.2;
  • Before you use a variable in JavaScript, it must be declared
  • Variables are explicitly declared with keyword var
  • If you don't explicitly declare a variable (with var), JavaScript will implicitly declare it for you
  • Remember, JavaScript is an untyped language, so there's no need to associate a type with a variable
  • If you don't specify an initial value for a variable w/i the var statement, the variables value is undefined until you initialize it
  • Variables declared w/ var are permanent -- they cannot be deleted

VARIABLE SCOPE/LIFETIME

  • Variables defined within a function and function parameters have local scope. Their scope and lifetime is from point of declaration to the end of the function
  • Local variables (defined within a function), must be declared using var
  • let specifies block scope. However, it is not supported by all browsers
  • Local variables take precedence (i.e. hide) global variables of the same name
  • Global variables have file scope. Their scope and lifetime is from point of declaration to the end of the file.

The Global Object

  • When the JavaScript interpreter starts up, before executing any code, it instantiates the Global Object
  • When you declare a global variable, what you're actually doing is defining a property of the Global Object
  • In code which is not contained within a function block, you can use the keyword this to refer to the global object (within functions, this has a different meaning)

The Call Object

  • Local variables (declared within a function) are also properties of an object -- the Call Object
  • When you call a function, you implicitly instantiate a Call Object
