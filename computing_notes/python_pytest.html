Python: pytest

  • pytest is a testing framework for Python
  • By default, when you run pytest, it will execute all tests in the current directory and any sub-directory
  • By default, it looks for files which begin with test
  • If tests are defined in functions, the functions should be prefixed with test_
  • If tests are defined within a class, the class name should begin with Test and should not have a __init() method. Test methods (similar to stand-alone functions) should begin with test_
  • You create simple tests using the Python assert statement 
# foo.py

def foo (f):

    return f+5


# test_foo.py

def test_foo ():

    assert foo(5) == 10


# to run the tests
pytest

# or alternatively
python3 -m pytest
