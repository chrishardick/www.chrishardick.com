POOL NOTES

DE Filters

Examining Grids

  • When taking apart your DE Filter, examine the grids for the following
    • cracked plastic
    • ripped cloth (check @ corners)
  • If a grid has any of these characteristics, it needs to be replaced.
  • Failure to replace these grids will allow dirty water (w/ DE) to flow into the pool
  • Also be sure to examine the o-ring where the manifold secures. A bad o-ring will have the same effect (allowing dirty water into the pool). Be sure to lubricate it so you can get it off next year.
