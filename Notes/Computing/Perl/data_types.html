PERL - DATA TYPES

  • PERL HAS 3 DATA TYPES
    1. Scalers
    2. Array of scalers
    3. Hash of scalers
  • Each variable type has it's own namespace. i.e. you can have a scaler, an array & a hash all with the same name without fear of a conflict. $Foo, @Foo, & %Foo are 3 different variables.
  • Perl also supports references -- which are like pointers in C

SCALERS

  • Scalers store a single value
  • Like most scripting languages, they are typeless; there is no seperate data types for floating point numbers, integers, characters, etc.
  • Scalers can contain strings or numbers & Perl will convert between the two as necessary.
  • All references to scalers MUST begin w/ a $ 
    my $scaler1 = "ABC";
my $scaler2 = 56.4;

ARRAY [OF SCALERS]

  • Ordered list of scalers. Each element is accessed via a numeric subscript
  • Entire arrays are denoted via @.
  • Individual scalers of an array are referenced via $
  • Arrays are indexed from 0 (just like C) 
    my @array = ("ABC", 123.4, "abcd");         # Declare and Initialize an Array
print "$array[1]\n";                        # Causes "123.4" to be printed

foreach my $i (@array)
{
    print "$i\n";
}

HASH [OF SCALERS]

  • Unordered set of key->value pairs.
  • Entire hash tables are denoted via %.
  • Individual scalers of a hash are referenced via $ -- enclose the key in curly brackets 
    my %hash = ("11731", "East Northport"        # Declare and initialize a hash
            ,"11768", "Northport"
            ,"11747", "Melville"
            );

my %hash = ("11731" => "East Northport"      # equivalent, with clearer syntax 
            ,"11768" => "Northport"
            ,"11747" => "Melville"
            );


print "$hash{11731}\n";                      # "East Northport" will be printed

foreach my $key (keys %hash)
{
    print "KEY=$key\n";
    print "VAL=$hash{$key}\n";
}

REFERENCES

  • A.k.a. a pointer
  • can point to a saler, an array, a hash, or a function
  • useful for creating complex data types in Perl
  • utilize reference couting. memory is freed when reference count goes to 0
  • any scaler can contain a reference 
    @$ptr   # dereference pointer to an array
%$ptr   # dereference point to a hash
  • The backslash operator -- similar to the & operator in C 
    my %hash_a;
$hash_a{'key1'} = 'value1';
$hash_a{'key2'} = 'value2';
$hash_a{'key3'} = 'value3';

my %hash_b;
$hash_b{'key4'} = 'value4';
$hash_b{'key5'} = 'value5';
$hash_b{'key6'} = 'value6';

my @array;

$array[0] = \%hash_a;
$array[1] = \%hash_b;

foreach my $i (@array)
{
    # i is a hash reference

    foreach my $key (keys %$i)
    {
        print "KEY=$key\n";
        print "VAL=$$i{$key}\n";
    }
}
