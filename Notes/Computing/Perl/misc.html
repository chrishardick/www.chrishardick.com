COMMAND LINE ARGUMENTS

  • command line arguments are obtained via @ARGV (a special global array)
  • $#ARGV is the number of arguments minus one
  • $ARGV[0] is the 1st argument (not the command name)
  • Use $0 for the name of the perl script being executed 
    my $num_args = $#ARGV + 1;

if ($num_args != 2)
{
     print "ERR: INVALID # OF CMD LINE ARGS\n\n"

     usage();
     exit (-1);
}
