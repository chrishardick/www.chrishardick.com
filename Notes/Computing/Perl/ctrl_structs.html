PERL - CONTROL STRUCTURES

TRUTH

  • Truth is always evaluated in a Scaler Context
  • Any string is TRUE except for "" and "0"
  • Any number is TRUE except for 0
  • Any reference is TRUE
  • Any undefined value is FALSE

LOGICAL (SHORT-CIRCUIT) OPERATORS

  • AKA Short-Circuit Operators because they skip evaluation of RHS Argument if not necessary.
  • I'm not exactly sure why there are two versions of each type
Operand Description Result
&& AND LHS if LHS is FALSE, otherwise RHS
and AND LHS if LHS is FALSE, otherwise RHS
|| OR LHS if LHS is TRUE, otherwise RHS
or OR LHS if LHS is TRUE, otherwise RHS
! NOT TRUE if FALSE, FALSE if TRUE
not NOT TRUE if FALSE, FALSE if TRUE

COMPARISON OPERATORS

Comparision Numeric String Return Value
Equal == eq TRUE/FALSE
Not Equal != ne TRUE/FALSE
Less Than < lt TRUE/FALSE
Greater Than > gt TRUE/FALSE
Less Than Or Equal To <= le TRUE/FALSE
Comparison <=> cmp 0 if Equal, 1 if LHS is Greater, -1 if RHS is Greater

FILE TEST OPERATORS

Example Description Result
-e $a Exists TRUE if file named $a exists
-r $a Readable TRUE if file named $a is readable
-w $a Writable TRUE if file named $a is writable
-d $a Directory TRUE if file named $a is a directory
-f $a Regular File TRUE if $a is a Regular File
-T $a Text File TRUE if $a is a Text File

FOREACH LOOPS

  • loop thru all items in an array 
    foreach $tmp (@array)
{
    print "$tmp\n";
}
  • loop thru all items in a hash 
    foreach $key (sort keys %hash)
{
    print "$key = $hash{$key}\n"
}
