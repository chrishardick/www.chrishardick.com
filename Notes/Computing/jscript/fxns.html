JavaScript - Functions

  • As in any language, there are two basic types of functions:
    1. User defined functions
    2. Built-in functions - i.e. provided via the language -- not covered on this page
  • As in any language, the two basic operations you want to do with functions are:
    1. Define a function (only applicable for user defined functions)
    2. Invoke a function (applicable for both user defined and built-in functions)
  • TODO: does JavaScript use pass-by-value, or pass-by-reference?

I. Defining Functions

  • JavaScript supports 3 ways to define a function
  • The most common method to define a function is with the following syntax: 
    function identifier ([parameter1, ... , parameterN])
{
     statement(s)

     ...
    
     return expression; // return value from function (not required)
}
  • The other methods to create a function are:
    1. The Function( ) Constructor
    2. Function Literals

1. Function Return Value

  • The return keyword may only be used within a function
  • It's used to terminate execution with in the function and to optionally return a value from a function
  • As in other languages, when the return statement is executed, the function is terminated and control is returned to the caller

2. In JavaScript, Functions are Objects (a Data Type)

  • In JavaScript, functions are objects (i.e. they're implemented as a data type). This is similar to function pointers in C/C++
  • Since they're implemented as a data type, they can be:
    • assigned to variables
    • assigned to array elements
    • stored as object properties (in which case they're called methods)
    • passed as arguments to other functions
    • etc. 
    function multiply (x,y)
{
     return x*y;
}
  • In JavaScript, here's what we did:
    1. Created a new function object
    2. Assigned the new function object to the variable multiply
    3. Now we can assign multiply to other variables, to array elements, pass it into other functions, etc.

3. The Call Object

  • When you call a function, you implicitly instantiate an object named call (the call object)
  • All of the functions local variables (declared using var) are implicitly members of the call object - as the call object is an object, we can be more precise and call the data members properties
  • call objects also have another property: the arguments object -- which has array-like properties

4. The Arguments Object

  • A property of the call object. It's an object which has array-like properties
    • The Arguments Object provides an alternate mechanism to access the function's parameters via number.
      • arguments[0] is an alias to the 1st argument,
      • arguments[1] is an alias to the 2nd argument,
      • etc.
    • The Arguments Object provides access to un-named parameters (i.e. if your function only named 3 parameters, but the caller passed 4 - you can access the 4th using arguments[3]). This can be used to code a function which takes a variable number of parameters
    • Like all arrays, arguments has a length property which you can use to determine how many parameters were actually passed in
    • The elements of the arguments object are true aliases to the named parameters -- i.e. changing the value arguments[1] is changing the same memory address as the 2nd named parameter
  • The Arguments Object defines a callee property which points to the function which is currently being executed -- useful for unnamed functions

5. The Function Object

  • As stated above, in JavaScript, functions are objects
  • Like all objects, they have properties and methods
  • Function properties are available inside and outside of the function -- global scope and lifetime
  • Built-in Properties
    • The length property - defines the number of parameters the function expects. I.e. the number of named parameters it has
    • The prototype property - useful when the function is used as a constructor
  • You can also define your own function object properties which (like built-in function properties) have scope and lifetime of the executing program (akin to static data members in C/C++) 
    // a user defined function property (i.e. similar to a static data member in C/C++)
// this initialization takes place prior to any code executing
getUniqueID.id = 0;

function getUniqueID ( )
{
     return getUniqueID.id++;
}

II. Invoking Functions

  • Once a function has been defined, it can be invoked using the function call operator ( ) 
    function_identifer ([expression1, ... , expressionN]);

III. Prototypes/Parameter Mismatch Support

  • JavaScript does NOT verify the number of parameters passed to a function and since it's an untyped language, obviously the types can not be verified
  • However, you can add your own run-time checks to make sure the caller passed in the correct number of parameters by comparing the length property of the arguments object with the length property of the function 
    function foo (x, y, z)
{
     if (arguments.length != length)
     {
          throw new Error ("foo: Parameter Mismatch: Expected: " + length + " Actual: " + arguments.length);
}
