I. Basic Rules

    selector(s) declaration block

selector(s) { declaration1; declaration2; }

selector(s) { property: value; property: value1 value2; }

h1,h2       { color: red; background: yellow; }
  • Selector(s) selects the piece(s) of the document which are affected by the rule.
  • Most often, selectors are XHTML elements
  • If the CSS file defines styles for an XML document, the selectors can be any element name
  • You can specify a selector list (multiple selectors) by separating each selector by a comma (,)
  • The declaration block is surrounded by curly brackets ({ ... }) and composed of one or more declarations separated by a semicolon (;)
  • Each declaration has a property and a value separated by a colon
  • Values are either a single keyword or a space separated list of keywords which are permitted for the given property
  • If you use an incorrect property or incorrect value, the entire declaration will be ignored

The Universal Selector (*)

    * {color: red; background: yellow: }
  • The universal selector matches all elements

II. Class Selectors

    /* style sheet */

*.IMPORTANT  { font-weight: bold; font-style: italic; background: silver; }

/* same thing */
.IMPORTANT   { font-weight: bold; font-style: italic; background: silver; } 

 /* only for p elements */
P.IMPORTANT  { font-style: italic; background: silver; }

P.CAUTION    { background: red; }


<!--
     xhtml markup
     
     a paragraph element which belongs to 3 classes - important, warning & caution
-->

<p class="important warning caution">paragraph text</p>
  • Allows you to assign styles independent of document elements
  • Every HTML element (todo: check this) can have a class attribute.
  • The class attribute is a space-separated list of words
  • Each word is a class in which the element belongs
  • You can then create styles which affect class members

III. Document Structure - Decendant & Child Selectors

  • All HTML documents define a hierarchy of elements (a tree)
  • A parent is directly linked (1 level up)
  • A child is directly linked (1 level down)
  • An ancestor is more general than a parent - i.e. one or more levels up
  • An descendant is more general than a child - i.e. one or more levels down
  • The root element (HTML in a HTML document) is the ancestor to all elements

1. Decendant Selectors

    ancestor descendant declaration block

/* this rule applies only to em elements which descend from h1 elements */
h1 em { color: red; }

/* similar - but with a selector list (rather than a single selector) */
h1 em, p em { color: gray; }

/* decendant selector which uses class selectors */
h1.important em.not_so_important, h2.important em.not_so_important { color: gray }
  • Descendant selectors are a space separated list of selectors (the decendants are listed later)
  • Also known as contextual selectors

2. Child Selectors

    parent > child  declaration block

h1 > strong { color: red; }
  • Specified by using a > separated list
  • E.g. select a strong element which is a child of a H1 element
