I. Inner Join

  • table1,table2
  • Same as table1 JOIN table2
  • Same as table1 CROSS JOIN table2
  • Only rows which match the condition(s) of the where clause are selected
  • For example, the following joined table would only show rows in which payment.invoice_id = invoice.id 
    SELECT invoice.id, payment.amt, payment.date, payment.notes FROM payment,invoice WHERE payment.invoice_id=invoice.id;
    invoice.idpayment.amtpayment.datepayment.notes

  • The tables are joined in the manner that the SQL Engine deems most efficient
  • The SQL Engine can accomplish this query in one of two ways
    • For each invoice, get all payment(s)
      • probably the algorithm the SQL Engine uses
      • the payment table probably has an index for this
      • only display invoices which have payment(s)
    • For each payment, get all invoice(s)
      • there will only be 1
      • probably no index for this - i wouldn't create one
      • only display payments which have invoice(s)
  • Either way, we'll only display invoices with payments (or vice-versa, payments with invoices)
  • There's no way to get invoices without payments (or payments without invoices - which would be a referential integrity violation). For this, we'll need an outer join.


II. [Left] Outer Join

  • table1 LEFT [OUTER] JOIN table2 ON clause
  • Selects all rows from table1
  • If table2 does not have a matching row, a row of NULLs is used to join with table1
