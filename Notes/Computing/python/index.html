Python

Misc

  • Like most scripting languages, variables in Python are untyped
  • Unlike most computer languages, white space matters. Rather than using brackets to denote the beginning and end of control structures, functions, classes, etc. the body of the block in question is denoted via indention 
    if today == 'Wednesday':
    print "Today is Hump Day"
else:
    print "Today is ", today
  • Unlike most computer languages, noticeably missing are the semi-colons to denote the end of statements. Instead, the end of each statement is denoted by a newline
  • One of the criticisms of Perl was that once written, it was very hard to read -- which proved a barrier for new developers. The things that are different about Python (e.g. whitespace, newlines, etc), seem to (intentionally or not) address this shortfall.

    Comments

    • start via pound sig (#) and continue until the end of line

    Variables

    • Like most scripting languages, variables in Python are untyped -- they can hold integers, floating point numbers, strings, etc.

    Strings

    • Strings can be defined using double or single quotes 
      s = "Hello, World!"
    • You may be access individual characters of a string via indexing (square brackets). Like C/C++, indexing starts from 0 (zero) 
      print s[0] # H
    • Slicing
      • print s[0:5]    # Hello
print s[:5]     # equivalent
print s[7:13]   # World
print s[7:13]   # equivalent
      • Notice with slicing, the beginning character is included and the last character is excluded

    List

      days = ['Sunday','Monday','Tuesday','Wednesday','Thursday','Friday','Saturday']
    • Similar to a vector in C++ -- I believe look-up is in constant time
    • A list is written as a list of comma separated values between square brackets
    • You can access individual elements via indexing (square brackets). Lists are indexed from 0 (zero) 
      days[3]='Humpday'
    • You can get the length of a list using the len function. 
      print len(days)    # would print out 7

    Dictionary (Hash)

    • A dictionary is written key:value pairs surrounded by curly braces 
      states = {   'NY': "New York"
            ,'NJ': "New Jersey"
         }

states['CO'] = "Colorado"

for abbr in states:
    print abbr, '-->', states[abbr]

# try this
print states

    Conditionals

    • The syntax in Python is different than other programming languages. Notably missing are parenthesis and like most definitions in Python, the statement ends with a colon (:) 
      i = 5
if i == 5:
    print "i equals 5"
elif i == 6: 
    print "i equals 6"
else:
    print "i equals ", i

    For Loops

    • For iterating a known number of times 
      words = [ 'every', 'good', 'boy', 'does', 'fine' ]
for w in words:
    print 'word=', w, " length=", len(w)

for i in range(0,10):
    print i

    Functions

      # function definition
def foo(n):
    print "foo: Hello, World"
    print "foo: n=" , n

# function call
foo (5)
    • functions are defined with the keyword def, followed by the function name, followed by a list of parameters surrounded by paranthesis, followed by a colon (:)
    • functions must be defined before they are called. I.e. it is not legal to call a function which is defined later in the same source code
