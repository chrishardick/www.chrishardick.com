XML

  • A markup language toolkit
  • Well-formedness
    • An XML document is well-formed when it obeys all of the rules of XML
    • A well-formed XML document can be parsed without errors
    • XML parsers should stop and complain upon encountering the first error
  • Validity
    • XML is a markup language toolkit - it allows you to define a language
    • Being well formed XML simply means the document you created obeys all of the general rules of XML
    • Validity is stricter than well-formedness; it means that your XML document obeys the rules of your markup language
    • Markup languages can be formally defined using DTDs and schemas
