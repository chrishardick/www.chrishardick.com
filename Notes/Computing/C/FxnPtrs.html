Function Pointers

A pointer stores an address. A Function has an address. A pointer can store the address of a function. Every pointer has a type (e.g. ptr-to-double, ptr-to-int, etc.). A function pointer (ptr-to-fxn) must have a return type & parameter type list. This infers that a function pointer can only point to functions with the same return type & paramter type list.

I. General Form

Here's an example of a function pointer declaration: 
double (*pfxn) (char*, int, int*);
void (*pfxn) (void)
or, more generally: 
return_type (*ptr_name) (list of parameter types);
The parenthesis around the pointer name are required, without them, it would be a normal function prototype: 
double* pfxn (char*, int, int*);


II. Assignment

long sum (long x, long y);
long (*pfxn) (long, long) = sum;  // declaration & assignment
-OR- 
long (*pfxn) (long, long);        // declaration
pfxn = sum;                       // assignment


III. Using a Function Pointer to Call a Function

Usage is simple, simply use the name of the pointer as if it were the function name. For example: 
long lResult = pfxn (5L,4L);


IV. Ptr-to-fxn as a Function Argument

long doit (long lArr[], int nNumItems, long (*pfxn)(long,long));


V. Array of Function Pointers

double (*pfxn[3])(double,double) = {sum, difference, product};

pfxn[1](5.0,4.0);
