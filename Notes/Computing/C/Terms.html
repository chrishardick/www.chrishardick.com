TERMS & DEFINITIONS

Blocking Function
A function which when called, puts the calling process (or thread) into a wait state until some event occurs. E.g. until a mutex is released, etc. Examples of blocking functions: sleep( ), pthread_join(), pthread_mutex_lock(), connect(), etc.

Re-enterant Function
A function which can have multiple simultaneous, interleaved, or nested invocations which will not interfere with one another. Re-enterant is an important concept for multi-threaded programming, in which multiple threads may be running simultaneously or may be interleaved. Re-enterant functions are a subset of thread-safe functions, as a function which is thread safe need not be re-enterant, but re-enterant functions must be thread-safe. Re-enterant functions are also called "efficiently thread-safe" as they can efficiently run in multiple threads and require no threading support (i.e. mutexes, thread-specific data, etc.). Re-enterant is also an important concept in signal handling programming because signal handling functions may be interleaved with main program execution.
