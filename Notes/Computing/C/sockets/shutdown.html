shutdown ( )

  • causes all (read and write) or part (read or write) of a full duplex connection on the socket descriptor to be shutdown depending on howto
  • SHUT_RD
    • close the read half of the connection
    • read( ) can no longer be called for the given socket descriptor
    • no more data can be received
    • any data in socket receive buffer is discarded
    • any data received after this call for a TCP socket is acknowledged and then silently discarded
    • TODO: not sure when this would be useful
  • SHUT_WR
    • close the write half of the connection
    • Similar to close( )
    • Unlike close( ), such that the write half of the connection is closed regardless of the reference count (FIN sent to peer)
    • half-closed - we can no longer write to socket, but peer can still write
  • SHUT_WR
    • Close both the read and write halves of the connection
    • Equivalent to shutdown(fd,SHUT_RD); shutdown(fd,SHUT_WR) 
    /*
 * SHUTDOWN ( )    
 *
 * RETURN
 * ======
 *  0 = success
 * -1 = error (check errno)
 */
#include <sys/socket.h>

int shutdown (int sockfd,     // in:  socket descriptor to shutdown
              int howto);     // in:  SHUT_RD|SHUT_WR|SHUT_RDWR
