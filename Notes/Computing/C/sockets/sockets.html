Sockets

  • The purpose of this page is to describe sockets.

Socket Definition

  • A socket consists of two numbers: an address and a port number
  • There are three types of sockets
    1. Active sockets
    2. Listening sockets
    3. Connected sockets
  • Active Sockets
    • Only clients have active sockets
    • Active sockets connect to servers
  • Listening Sockets
    • Only servers have listening (passive) sockets
    • Listening sockets wait for incoming connections
    • Normal servers have only one listening socket which exists for the lifetime of the server
    • Listening socket are formed by:
      • socket( ) = create a socket (active by default)
      • bind( ) = server binds to its well-known port
      • listen( ) = convert socket from active (default) to listening (passive) socket
    • Listening sockets are passed to accept( ) which returns a connected socket
  • Connected Sockets
    • Only servers have connected sockets
    • Connected sockets are returned by accept( )
    • A server can have multiple connected sockets
    • A connected socket is created for every successful incoming connection

Socket Pair

  • A socket pair uniquely identifies a tcp connection
  • 4 tuple {local ip address, local port, foreign ip address, foreign port}
