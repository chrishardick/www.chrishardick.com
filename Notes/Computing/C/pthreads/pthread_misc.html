PTHREADS - MISC INFO



I. PTHREADS & ERRORS

  • traditional UNIX C functions return:
    • 0 = success
    • -1 = check errno
    • else = useful value
  • pthread functions return
    • 0 = success
    • otherwise an error code from <errno.h> is returned. strerror() can be used to convert to get a string description of the error #
    • an additional output parameter is used to pass back the address of any useful return information


II. COMPILING/LINKING NOTES

  • Define _REENTRANT prior to any includes
    • causes some functions to get prototyped with a re-entrant equivalent (normally w/ same name w/ _r appended)
    • the variable errno, is changed to a function call so that it's thread-safe
    • etc. 
    #define _REENTRANT -OR- -D_REENTRANT
  • Include pthread header file: 
    #include <pthread.h>
  • Link with pthread library: 
    -lpthread


III. TERMS & DEFINITIONS

  • Opaque Datatype
    • datatype based upon the concept of encapsulation in which only the external interface is guaranteed.
    • to manipulate an opaque datatype, use only the given interface
    • I.e. pthread_t (thread identifier) is opaque and to determine if 2 threads are equivalent, you have to use pthread_equal(), rather than using '==', etc.
    • You should never copy an opaque type (unless there's a supported copy routine - as in c++, etc.) - the result is undefined
    • If you need access to an opaque type, you can copy a pointer to it (into a function, etc.)
