PTHREADS: ATTRIBUTE OBJECTS

  • There are attribute objects for:
    • threads (pthread_attr_t)
    • mutexes (pthread_mutexattr_t)
    • condition variables (pthread_condattr_t)
  • provide an extended argument list when you initialize a thread, mutex or condition variable
  • allows POSIX (or an individual system) to add options without requiring changes to existing code
  • private structures. you use get/set funtions to read/write members, use init/destroy functions to initialize and destory
  • not all attributes are supported by all systems. check system documentation


I. THREAD ATTRIBUTE OBJECTS

    #include <pthread.h>

pthread_attr_t attr;

/*
 * initialize thread attribute object w/ default values
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_attr_init (pthread_attr_t* attr);


/*
 * destroy the thread attribute object
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_attr_destroy (pthread_attr_t* attr);

    1. detachstate ATTRIBUTE

    • Supported by all POSIX systems
    • Possible values: {PTHREAD_CREATE_JOINABLE, PTHREAD_CREATE_DETACHED}
    • Default value: PTHREAD_CREATE_JOINABLE
    • Joinable threads are joinable and cancelable
    • Detached threads are not joinable, nor cancelable. They release all of their system resources upon termination. Their identifier can no longer be used
    • When you create threads that you will not need to cancel nor join with, you should create the threads detached 
      /*
 * GET DETACHED STATE
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_attr_getdetachstate(pthread_attr_t* attr,      // in:  attribute object
                                int* detachstate);         // out: PTHREAD_CREATE_JOINABLE|PTHREAD_CREATE_DETACHED

/*
 * SET DETACHED STATE
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_attr_setdetachstate(pthread_attr_t* attr,      // in/out: attribute object
                                int detachstate);          // in:     PTHREAD_CREATE_JOINABLE|PTHREADE_CREATE_DETACHED

    2. stacksize ATTRIBUTE

    • Supported by MOST POSIX systems.
    • To test for support, check if the following symbol is defined: _POSIX_THREAD_ATTR_STACKSIZE
    • Specifies the minimum stack size of a thread created w/ the object
    • Avoid using an absolute size due to portablity issues--different systems require different stack sizes
    • POSIX defines the symbol PTHREAD_STACK_MIN (minimum stack size required for a thread) which can be used to compute relative stack sizes (more portable). I.e. 2*PTHREAD_STACK_MIN, PTHREAD_STACK_MIN/2, etc. 
      #ifdef _POSIX_THREAD_ATTR_STACKSIZE

/*
 * GET STACK SIZE
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_attr_getstacksize(pthread_attr_t* attr,      // in:  attribute object
                              size_t* stacksize);        // out: stack size

/*
 * SET STACK SIZE
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_attr_setstacksize (pthread_attr_t* attr,      // in/out: attribute object
                               size_t stacksize)          // in:     stack size

#endif
