PTHREADS: THREADS


1. THREAD CREATION - PTHREAD_CREATE( )

  • pthread_create( ) creates a thread which will start by calling the specified thread start function (it will be in a READY state)
  • When a process creates a new thread, it gets its own stack (hence local variables), but shares everything else (global variables, file descriptors, signal handlers, & current directory)
  • IMPORTANT TIP: thread start functions should always return a value (even if NULL), such that if another thread is waiting for it (blocked on pthread_join( )), it does not de-reference a bad pointer & possibily crash 
    #include <pthread.h>

/*
 * thread identifier 
 * - opaque type 
 */
pthread_t thread;

/*
 * create a thread
 * 
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_create(pthread_t* thread,                // out: thread identifier
                   const pthread_attr_t* attr,       // in:  thread attributes (pass NULL if N/A)        
                   void* (*start) (void*),           // in:  thread start fxn - expects a void* & returns a void*
                   void* arg);                       // in:  argument that will be passed to thread start fxn


2. THREAD IDENTIFICATION - PTHREAD_SELF( ) & PTHREAD_EQUAL( )

  • threads are identified by a pthread_t identifier type - which is opaque (see Opaque Datatypes)
  • a thread can get its own identifier by calling pthread_self( )
  • to determine if two thread identifiers are equivalent, use pthread_equal( ) 
    /*
 * return the thread identifier for the current thread
 */
pthread_t pthread_self (void);


/*
 * are the 2 thread identifiers (pthread_t), the same thread?
 *
 * return
 * ======
 * non-zero = same thread
 * 0        = not same thread
 */
int pthread_equal(pthread_t t1,
                  pthread_t t2);


3. THREAD TERMINATION

A thread can terminate by any of the following:
  1. returning from the thread start function 
    


  2. calling pthread_exit( )

    /*
 * terminate the current thread
 * - never returns
 * - since it never returns, i'm not sure why it has a return value
 */
int pthread_exit(void* value_ptr);        // out: thread's return value (void*)

    


  3. another thread can call pthread_cancel( ).

    /*
 * cancel the given thread
 * - CAUTION: advanced use only
 * 
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_cancel(pthread_t thread);

    




If the thread is detached when it terminates, it is immediately recycled. Otherwise the thread moves to the 
terminated state in which it waits to be either detached or joined, at which time it will be recycled.



A. MAIN THREAD


    

  • in a threaded program, main( ) is called the initial (or main) thread

  • the initial thread is special in that when it terminates, the entire process terminates w/o allowing other threads to complete
	- unless main( ) exits by calling pthread_exit( ), which allows the process to continue until all threads have terminated








4. DETACH THREADS: FREE SYSTEM RESOURCES



    

  • detaching a thread tells the operating system that when the thread is finished executing, you no longer need it & that its system resources can be freed up

  • some of its system resources may have been freed when it finished executing (implementation dependent) - but at least the return value & its identifier must be retained

  • you can set the thread's attribute such that it's started detached

  • once a thread is created, you can call pthread_detach( ) to make a thread detached, passing in the thread's identifier (any thread can do this - as long as it knows the thread's identifier)

    /*
 * detach the given thread
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_detach (pthread_t thread);

    


  • pthread_join( ) automatically detaches a thread upon return

    /*
 * blocking fxn
 * - will block until the specified thread completes
 * - automatically detaches the thread
 * - if > 1 thread needs to know when a given thread terminates, use a condition variable 
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_join(       pthread_t thread,       // in:  thread to wait for
                        void** value_ptr);      // out: return value of thread

    








5. THREAD LIFECYCLE





STATENOTES




READY

    

  • Waiting for processor time

  • could have just started (yet to be swapped in)

  • could have been swapped out (a.k.a. time sliced out or preempted by another thread or process)

  • bottom line: the thread is ready-to-run and is waiting to be swapped in







RUNNING

    

  • Thread is currently running. 

  • I.e. eating up processor time







BLOCKED

    

  • Thread is not able to run because it's waiting for something. 

  • I.e. mutex lock, or some other blocking call







TERMINATED

    

  • Thread is terminated (returned from start function, called pthread_exit( ), cancelled, etc.),
but is still occupying system resources because it not yet become detached







RECYCLED

    

  • A TERMINATED thread that is detached  will be recycled

  • I.e. will release any system resources which were not released @ termination













6. MISC


    

  • the initial thread runs on the default process stack (which can grow to be pretty large), the stack size for other threads is usually
	much smaller & if a thread's stack overflows, your program will fail w/ a segmentation fault or bus error
