PTHREADS: ONE TIME INITIALIZATION


  • A facility to manage pthread initialization
  • Useful when writing library code


1. ONE TIME INITIALIZATION DATATYPE: PTHREAD_ONCE_T

    #include <pthread.h>

pthread_once_t once_ctrl;
  • an opaque type -- (see Opaque Datatypes)
  • MUST be statically initialized using the PTHREAD_ONCE_INIT macro

2. INITIALIZATION FUNCTION & PTHREAD_ONCE()

  • you create a function (void function which accepts no parameters) that performs all initialization associated w/ a pthread_once_t control variable
  • any time you need to depend on the initialization, you call pthread_once( ), specifying the pthread_once_t variable and a pointer to the associated initialization function. The first time it's called, your initialization function will be called. The 2nd - Nth time it's called, pthread_once() simply returns.
  • Either way, when pthread_once() returns, the caller is assured that the necessary initialization has been successfully completed. 
    /*
 * pthread_once()
 *
 * RETURN
 * ======
 * 0 = success
 * else - see discussion on pthreads and errors
 */
int pthread_once (pthread_once_t* p_OnceCtrl,            // in:  
                  void (*InitFxn) (void);                // in: initialization routine
