Typecasting

  • typecasting is done implicitly anytime you perform mixed mode operations (i.e. adding a double and a float; the float is first converted to a double (using a temporary memory location as to not change the physical value of the float) and the operation is then performed
  • C++ also allows you to explicitly cast between different types
  • C style casts 
    (type to convert to)(expression)
  • In addition to C style casts, C++ added 4 new cast types
    • static casts
      • the validity of the cast is checked @ compile time (statically) 
        static_cast<type to convert to>(expression)
    • dynamic casts
      • the validity of the cast is checked @ run time (dynamically) 
        dynamic_cast<type to convert to>(expression)
    • const casts
      • removing the 'const' from a expression 
        const_cast<type to convert to>(expression)
    • reinterpret casts
      • unconditional cast 
        unconditional_cast<type to convert to>(expression)
