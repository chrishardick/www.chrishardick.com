Member Functions

  • A function which has its definition or prototype within the class definition.
  • If a member function has its definition within the class, it is implicitly declared as inline
  • It's a good practice to declare all member functions which do not alter the object as constant member functions, which is accomplished by placing the keyword const after both the function prototype and header (only functions defined outside of the class definition have a function prototype). Declaring a member function as constant, ensures that it does not modify any of the object's data members.
  • See also Virtual Member Functions 
    /*
 * member fxn definition w/i the class
 */
class CBox
{
	double m_dLength, m_dWidth, m_dHeight;

	public:
		// Constructor - Implicitly inline
		CBox (double dL=0.0, double dW=0.0, double dH=0.0);

		// Volume() - Implicitly inline (a constant member function)
		double Volume () const { return m_dLength * m_dWidth * m_dHeight; }
};


/*
 * member fxn definition outside the class
 * - in order to be inline, must be explicitly defined
 */
class CBox
{
	double m_dLength, m_dWidth, m_dHeight;

	public:
		// Constructor - Implicitly inline
		CBox (double dL=0.0, double dW=0.0, double dH=0.0);

		// Volume() 
		double Volume ();
};

inline double CBox::Volume () const
{
	return m_dLength * m_dWidth * m_dHeight;
}
