Functional Notation

In addition to standard notation for initializing variables (e.g. int x = 5;), C++ supports Functional Notation for variable (or object) initialization. Instead of using an equal sign and the value, you can simply write the value in parenthesis following the variable name 
// Standard Notation
int x = 5;
float y = 10.0;

// Functional Notation
int x(5);
float y(10.0);
