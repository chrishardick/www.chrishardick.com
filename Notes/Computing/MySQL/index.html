FREQENTLY USED SQL COMMANDS

  • show databases;


  • use DBNAME


  • create database DBNAME;


  • create table TABLENAME (field1-name field1-type field1-modifiers, ... fieldN-name fieldN-type fieldN-modifiers;
    • create table Event (	id int not null primary key auto_increment,
			object_id int not null,
			start_dt date not null,
			time time not null,
			freq char(1),
			inst varchar(50) not null,
			end_dt date,
			last_update timestamp,
			unique index ByStart (start_dt, time, id),
			index ByEnd (end_dt, id));


  • describe table TABLENAME;


  • show index from TABLENAME;


  • insert into TABLENAME (col1, col2, ... colN) values (val1, val2, ... valN);


  • update TABLENAME set column=value [where clause];


  • select col, col2, ... colN from TABLENAME1, TABLENAME2, ... TABLENAMEN [where clause];
    • Functions
    • Aggregate Functions


  • delete from TABLENAME [where clause];


  • alter table: to modify the structure of a table. Add/remove column(s), add/remove indexes (or unique indexes), etc.
