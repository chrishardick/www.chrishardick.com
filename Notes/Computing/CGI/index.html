CGI - COMMON GATEWAY INTERFACE

DEFINITION

A Program (or script) executed by a Web Server (e.g. Apache) which (1) can accept input as either a Query String and/or CGI Parameters, (2) can do some form of processing (just like any other program or script), and (3) whose output (usually HTML-if any) is transmitted to the Web Client to be viewed by the user.
