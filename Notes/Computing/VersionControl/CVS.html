CVS - Concurrent Versions System

  • Open source

UPDATING A SANDBOX

cvs update
  • U
    • UPDATE SUCCESSFUL
    • a newer version from the repository has replaced the sandbox version
  • M
    • MERGE SUCCESSFUL
    • the file in the sandbox is more recent than the repository version (NOTE: no change) -OR-
    • both the repository version & the sandbox version have changes that CVS safely MERGED into your sandbox version. CVS automatically merges when the changes are on different lines
  • C
    • CONFLICT
    • both the repository version & the sandbox version have changes. @ least one of the changes could not be automatically merged & requires human intervention. I.e. the changes are on the same line(s)
    • original file is saved as .#file.revision
    • conflicts are denoted as follows: 
      <<<<<<<
      lines from sandbox
      =======
      >>>>>>>
      lines from repository
  • ?
    • CVS does not know what to do with this file

ADDING FILES

cvs add filename
  • MARKS a file for inclusion in the repository
  • a file is only MARKED for addition; it is not actually added to the repository until you run 'cvs commit'
  • directories are added to the repository immediately
