RCS - Revision Control System

  • Made By GNU
  • Multiple commands for managing source files

rcs

rcs -i <filename>
Initialize RCS Control over a file

ci - checkin

ci <filename>
Check a file in

co - checkout

co <filename>
Copy a file out (no exlusive lock)
co -l <filename>
Check a file out (lock it)

rlog - Look at Revision Log Summaries

rlog <filename>
Display Log Summaries

rcsdiff - Look at All Changes (diff) from One Revision to Another

rcsdiff -r<Revision 1> -r<Revision 2> <filename>
Display Diff

Macros

  • RCS Supports Macros inside your source file
  • Macros are strings which are automatically exanded anytime a file is checked out & updated when a revision is checked in
  • Macros start and end with a dollar sign ($)
  • Commonly macros are: $Header$, $RCSFile$, & $ID$
  • $Header$ usually expands to contain the full pathname of the RCS file, the revision number, date and time stamp, author, state, and locker (if locked)
  • $RCSFile$ usually expands to the name of the RCS file without a path
  • $ID$ usually the same as $Header$, except that the RCS filename is without a path
  • Consult man pages for full list of macros supported & what they actually expand to

Identifying Files Within Executables: ident

  • ident identifies expanded RCS macros
  • ident searches for all instances of the pattern '$keyword: text$' in the named files (or standard input)
  • ident works on
    • text files (usually source files)
    • object files
    • archive files
    • executables 
    USAGE: ident [files...]
