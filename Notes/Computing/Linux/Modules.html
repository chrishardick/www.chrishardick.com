Modules

  • Modules are object files which can be dynamically loaded into the kernel.
  • Modules are typically used for device drivers
  • Modules can be loaded @ boot time by rc scripts
  • I've also seen them loaded on demand (i.e. ide-tape module was not loaded until I attempted a backup)

Commands (typically in /sbin)

  • insmod
    • Install (Load) the module into RAM.
  • modprobe
    • Install module dependancies before loading the module.
  • rmmod
    • Unload (remove) the module from RAM.
  • lsmod
    • List the currently installed modules
