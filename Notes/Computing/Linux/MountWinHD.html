Mounting a Window's Hard Drive in Linux

  1. Determine the Drive Name

    2. As root:

    fdisk {name of drive}

    Drive Name Examples:
    • /dev/hda --> 1st IDE Hard Drive
    • /dev/hdb --> 2nd IDE Hard Drive
    • /dev/sd0 --> 1st SCSI Hard Drive
    • /dev/sd1 --> 2nd SCSI Hard Drive

  2. Determine which Partition you want to mount

    3. In fdisk, enter 'p' to print the partition table

  3. Mount the drive

    4. mount -t vfat -r/dev/hda1 /DirectoryName

    NOTES:
    • t --> Drive Type
    • r --> Drive Partition
    • hda1 is used for illustrative purposes
    • The directory MUST exist before a drive (or partition) can be mounted to it
